TR dynamic disable calibration

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable3 minutesNot Applicable

About this task

This calibration should be run on:
  • System installation
  • Driver Module replacement
  • Body Coil replacement
  • Body Hybrid replacement
  • Replacement of cabling between any of the above

Procedure

  1. Note: Restricted Service tools available to GE Field Service. Make sure your service key is installed.
    To start the TR Dynamic Disable Calibration, select Calibration Wizard from the calibration menu and select Click here to start this tool.
  2. Once the Calibration Wizard starts, select TR Dynamic Disable Calibration from the menu, review and confirm the pre & post-dependencies, and then select Click here to start this tool.
  3. If you are unable to start the Restricted Service tools, use the non-proprietary method:
    1. From the Common Service Desktop, select Calibration.
    2. From the Calibration menu, select TR Dynamic Disable Calibration.
    3. Select Click here to start this tool to start the procedure with the non-proprietary service tools.

    Once the calibration is complete, the results will display in the Test Results text area.

Finalization

Perform a TPS Reset for changes to take effect.
