Move Patient Table Outside

Procedure

  1. Perform LOTO for ISC.
  2. Remove Base Covers.
  3. Disconnect all cables connected to Patient Table, if necessary, remove magnet covers.
  4. (For Telescopic Cover)
    1. Remove six screws for telescopic cover bottom and move the cover up.
    2. Fix the telescopic cover with masking tape.
  5. (For Bellows Cover)
    1. Remove the six screws securing the bottom of the bellows cover; three on the left-hand side and three on the right-hand side.
    2. Lift up the bellows cover and secure it in the up position with six strips of Velcro.
  6. Insert the screw rod and rotate it to clockwise till it engages to carriage plate.
  7. Remove two screws fixing table and dock frame.
  8. Install casters at four locations with two screws per each caster.
    Note

    In case casters cannot be installed because leveling pad height is too low, turn the leveling pad by same rotation at the six locations and move the Table up. Record the number of rotation to restore the Table at original height.

    Leveling Pad Number of rotation
    Pad 1~ Pad 6

    (same number of rotation)
  9. Adjust the Caster height.
    1. Loosen the caster locking nut.
    2. Bring up Table by rotating the caster nut till the leveling pad becomes free.
    3. Tighten the caster locking nut.
    4. Perform the same procedure for the rest of casters.
  10. Move the Table outside of Magnet Room.
Topic ID: id_SL13503804-1241292

Restore Table to Magnet Room

Procedure

  1. Move the table to the Magnet Room as it was installed.
  2. Connect all cable.
  3. Perform Removing LOTO - Integrated System Cabinet (ISC).
  4. Restore all covers.
  5. Perform Table level Check and Top height Check. Refer to Leveling Table and Top Height Adjustment.
  6. Perform Table Gap. Refer to Table Dock Frame Location Check and Adjustment.
