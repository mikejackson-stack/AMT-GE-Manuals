About this task

Overview

This document provides instruction on configuring both network and local printers on Linux systems.

Depending on the software version loaded on the system, and the printer type, refer to the appropriate procedure listed below.

Instructions for Software Release Pre-15.0_M4B, 20.x, and 21.x

Topic ID: id_SL3521428-486274

Procedure for Network Printer

Procedure

  1. Log out by clicking on System Restart then OK. The system will then reboot.
  2. When the login screen appears, login as root password is operator. Place cursor in the background, and “right click” on the mouse.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  3. Select Configure Printer option. The following GUI will display (shown below).
  4. Click New to add printer to the system. A new window will appear (shown below). Click Forward to continue.
  5. At the Queue name screen, type a name for the printer (shown below). After entering the name, click Forward to continue.
  6. Select Queue type as Networked Unix (LPD) (shown below).
  7. Select the printer type (shown below). Then select Forward.
  8. Click Finish to complete printer installation.
Topic ID: id_SL3521433-486274

Procedure for Local Printer

Procedure

  1. Connect local printer to the parallel port in the rear of the Linux PC.
  2. Log out by clicking on System Restart then OK. The system will then reboot.
  3. When the login screen appears, login as root password is operator.
  4. Place cursor in the background, and “right click” the mouse.
  5. Select Configure Printer option. The GUI shown below will start.
  6. Click New. A GUI will display, see Figure 2.
  7. Click Forward. Then enter printer name if needed and short description (see Figure 3). Click Forward again.
  8. The “Queue Type” will now appear. If the printer is recognized by the system, it will display (shown below).
  9. Verify that “Locally-connected” option on top is selected. Click Forward.
  10. Verify that the proper printer model is selected. Click Forward.
  11. If the system does not recognize the printer that is connected, select Printer Manufacturer and Model from the top screen (shown below). Then select the exact printer and click Forward.
  12. Click Finish. The printer is now selected. If needed, print a test page.

Procedure for Network Printer

Procedure

  1. Reboot the system.
  2. When the login screen displays, login as root and password is operator.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  3. Place the cursor in the background, and right click the mouse.
  4. Select the Configure Printer option, and the following GUI will display (shown below).
  5. Click Add to add the printer to the system (shown above). If selecting a printer for the first time, a pop-up will display (shown below). Click OK to continue.
  6. On the Add New Printer Configuration screen, click Connection Wizard (shown below). The GUI in Figure 12 will display.
  7. Under the Access Network Printer or Printerserver Box via label, select Line Printer Daemon (LPD) Protocol (shown below). Fill in the printer IP Address, printer name, and select the manufacturer (shown below).
  8. Click Test Connection, which will verify that the IP address entered is valid for the site network.
  9. Click OK.
  10. The system will search for printer drivers. Select the appropriate driver (shown below) and click OK to return to the Printer Configuration GUI.
  11. Print a test page to ensure that the printer has been configured correctly.
  12. Click OK to exit the Printer Configuration GUI.
Topic ID: id_SL3521443-486274

Procedure for Local Printer

About this task

Note:

Only USB connected printers are supported.

Procedure

  1. Connect local printer to the USB port on the Linux PC.
  2. Reboot the system.
  3. When the login screen displays, login as root and password is operator.
    Note:

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  4. Place the cursor in the background, and right click the mouse.
  5. Select the Configure Printer option, and the following GUI will display (see Figure 9).
  6. Click Add to add the printer to the system (see Figure 9).
  7. The directly connected printer will be automatically recognized, as evident by two popup process bars (shown below).
  8. Click OK to accept detected printer and return to the Printer Configuration GUI.
  9. Print a test page to ensure that the printer has been configured correctly.
  10. Click OK to exit the Printer Configuration GUI.
