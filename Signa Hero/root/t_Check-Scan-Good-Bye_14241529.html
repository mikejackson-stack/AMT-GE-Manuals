Check Scan (Good-Bye)

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable15 minutesNot Applicable

About this task

This document details the “check scan” used at the conclusion of many procedures. This functional check assures the unit is in good clinical working order.

It is important to use a phantom with known geometry, such as the DQA Phantom, so the image can be analyzed for correct orientation.

Procedure

  1. Place the DQA III phantom on the Table.
    1. Place phantom positioner onto the hollow for HNU. R/L direction will be fit to the hollow.
    2. Push phantom positioner toward the magnet until the two bottom bars reach the end of hollow.
    3. Place DQA III phantom onto the phantom positioner and verify its orientation and levelness.
  2. Landmark on the center line of the DQA III phantom. The laser must be in the middle of the black circumferential line on the phantom. Press [Advance to Scan] button.
  3. Notice
    Depending on site configuration and/or rules, you may want to temporary disable Auto Archive or Auto Network.
    Create a New Worklist item.
    1. Click New Worklist .
    2. Select a Patient ID workflow (other than geservice).
    3. Enter for Weight: 111
    4. Select Show All Protocols....
    5. When the Protocol Selector menu opens:
      1. Select for the Protocol Library: GE.

      2. Select Adult.

      3. Select the Template tab.

      4. In the Template tab, select 3 - Plane 2D Localizer.

      5. In the Template tab select the right arrow to move to the box on the right.

      6. Click on Accept.

    6. Click on Save.
    7. Select Start Exam.
  4. Enter the following Image parameters.
    1. Edit the frequency field of view (FOV) (Freq. FOV): 30.0
    2. Edit the Phase FOV: 1.00
    3. Edit the Slice Thickness: 5.0
    4. Select Body Coil.
    5. Right click on Task and select Change/Select Anatomy.
    6. Select Anatomical Region (Any) and click Accept.
    7. Click Save RX.
    8. Click Scan.
  5. Review the images and verify that you have the correct orientation.

Finalization

No finalization steps.
