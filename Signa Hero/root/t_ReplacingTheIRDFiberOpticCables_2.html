Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

About this task

Before starting this procedure, GE recommends doing the following:

  1. Make sure that the issue is resolved by directly connecting the cables from the IRD to the Host PC.
  2. If any IRD cables or components are swapped for troubleshooting, return them to their original position.
Note Depending on the routing of the IRD cables, you may need to remove ceiling panels from the MR room, corridor, or operator room. Please notify and consult with the customer regarding the ceiling panel removal and other locations impacted by this procedure.

Procedure

  1. Make sure that you have read and understood the electrical safety requirements before starting this procedure. See Electrical Safety.
  2. Shut down and power off the host computer. See Shutting down the host computer.
  3. Apply ISC LOTO. See Applying LOTO - Integrated System Cabinet (ISC).
  4. Remove the covers to access the IRD cables:
    1. Remove the left and right hand lower access panels. See Removing the magnet left- and right-hand lower access panels.
    2. Remove the dockable table interface cover. See Removing the dockable table interface cover.
    3. Remove the left and right control panel covers. See Removing the magnet left and right control panel covers.
    4. Remove the right-hand top cover. See Removing the magnet right-hand top cover.
    5. Remove the rear upper left-hand cover. See Removing the magnet left-hand upper rear cover.
    6. If the space between the magnet front cover and the magnet is not sufficient to route the new IRD cable(s), remove the magnet front cover. See Removing the magnet front cover.
  5. Disconnect the defective cable(s) from the Host PC.

    If you are not removing the defective cable(s), label the existing damaged IRD cable(s) as Defective, roll up the extra cable length, and secure it with a tie-wrap.

  6. Route the replacement IRD cable(s) along the same route as the existing IRD cable, starting from the IRDs in the magnet room.
    Note To connect the cables to the IRD, see Installing the magnet left and right control panel covers.
  7. Reinstall the covers:
    1. Install the front cover. See Installing the magnet front cover (if necessary).
    2. Install the control panel covers. See Installing the magnet left and right control panel covers.
    3. Install the dockable table interface cover. See Installing the dockable table interface cover.
    4. Install the left and right-hand lower access panels. See Installing the magnet left- and right-hand lower access panels.
    5. Install the right-hand top cover. See Installing the magnet right-hand top cover.
    6. Install the left-hand upper rear cover. See Installing the magnet left-hand upper rear cover.
  8. Connect the new, functional cable(s) to the Host PC.

Finalization

  1. Remove ISC LOTO. See Removing LOTO - Integrated System Cabinet (ISC).
  2. Start up the host computer/system. See Starting up the host computer.
  3. Make sure all system interconnects are returned to normal configurations.
  4. Make sure the new cables work by running the associated diagnostic, if necessary. From the Common Service Desktop, select Diagnostics > Hardware Location > Magnet Room > In Room Display.
    Note If any issues are encountered, run Reset IRD Console and try again.
  5. Do a check scan. See Doing a check scan.
