Safety
Warning
POSSIBLE PERSONAL INJURY OR EQUIPMENT DAMAGE!
THE MODULE COULD FALL WHEN USING LIFT TOOL.
Before putting weight on the hoist chain, make sure that the links are aligned properly. This will help keep the chain from binding up, or becoming kinked, which is nearly impossible to correct when the chain is under tension.
CAUTION
Do the proper Lockout/Tagout (LOTO) procedure for the type of replacement being done. The cabinet should not have any power as you assemble and use the hoist kit.
Warning
Potential crush hazard
If the replacement part accidentally falls, it can cause serious injury.
Do not put any part of the body below the replacement part.

Topic ID: id_SL14184533-1179504

Hoist base installation for ICC

Procedure

  1. Assemble the ICC Rear Table Bracket (5554986), Hoist Rear Bracket Long (5554765), and Hoist Rear Bracket Short (5554764) with seven screws.
  2. Install the ICC rear hut bracket (5548602) with two screws per each.
  3. Install the assembly onto the rear hut bracket with four screws.
  4. Assemble the front base bracket (5548593) and ICC front hut bracket (5548602) with two screws per each.
  5. Install the assembly onto the front top frame with two screws per each.
  6. Install the Support Tube (5548592) with two screws.
    Note The Support Tube (5548592) is stored behind the ICC front cover.
Topic ID: id_SL14184541-1179504

Hoist beam setup

Procedure

  1. Open the ISC door.
  2. Loosen two screws and lift up the main lifting beam to remove it.
    Note The main lifting beam setup position depends on the replacement FRU location.
    Position Lifting component
    1Patient Blower
    2GCU, CCU
    3Body Coil Blower
    4ICC Control Unit
    5RF Amp, SSSA, SSSPS
    6Driver Module
  3. Setup the main lifting beam into the brackets.
    1. Slide the hook plate into the rear bracket.
    2. Insert the locking projection into the hole of the front bracket.
  4. Inspect the ball bearing in the locking pin to make sure it is operating correctly and is not worn.
  5. Insert the hoist assembly into the front end of hoist rail, and then insert a locking pin into the hole of front rail. This locking pin prevents the hoist assembly from sliding out of the rail.
  6. Secure the locking pin ring with a tie wrap to keep it in position.
    Important This step will make sure the locking pin cannot slide out while lifting a component.
