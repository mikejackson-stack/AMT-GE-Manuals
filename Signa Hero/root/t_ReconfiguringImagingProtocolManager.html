Imaging Protocol Manager (IPM) procedures for Load from Cold (LFC) or software upgrade

Imaging Protocol Manager (IPM) procedures for Load from Cold (LFC) or software upgrade.

About this task

Before a load from cold (LFC) software installation for the same software or software upgrade, some configuration data must be collected if this data does not transfer over during LFC.

Note Always do a SaveInfo before changing or upgrading MR scanner software, and restore the SaveInfo after the change or upgrade.
Topic ID: task_d3p_rtn_sbc

Before LFC procedure

Procedure

  1. Determine if your MR scanner is connected to IPM. See Determining if an MR scanner is connected to Imaging Protocol Manager (IPM).
  2. Collect the IPM configuration settings. See Collecting Imaging Protocol Manager (IPM) configuration settings.
  3. Do a SaveInfo. See Saving information.
Topic ID: task_y35_rtn_sbc

After LFC procedure

Procedure

  1. Restore SaveInfo. See Restoring information.
  2. If SSL certificates are required, refer to the following scenarios for next steps:
    • If the software version is 30.3, complete the steps in Configuring the SSL certificate (only for customers that use SSL configuration).
    • If the software version is 30.3 and later, skip this step. The SSL certificates are restored as part of the SaveInfo.
    • If the software version is prior to 30.3, complete the steps in Configuring the SSL certificate (only for customers that use SSL configuration).
  3. Check the IPM connection:
    1. On the Service Desktop Manager navigate to Configuration.
    2. Click Imaging Protocol Manager (IPM) if you have the new agent, or click Configure Cloud Connectivity if you have the old agent.
    3. Make sure the IPM agent is connected and the window shows a green circle.
    4. If the green circle and the same message appear, check with a GE HealthCare Digital Solution Team member or TSE/OLE/RSL that the MR state is shown Activated and the status field contains a green check mark in the IPM application.
      • If a GE HealthCare Digital Solution Team member or TSE/OLE/RSL indicate that the status does contain a green check mark, go to Step 4.
      • If a GE HealthCare Digital Solution Team member or TSE/OLE/RSL indicate that the status does not contain a green check mark, do the following:
        1. Open a Command Prompt/C Shell as a root user.
          Note The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log off and then log back on as the correct EA3 user with the authorized permissions.
        2. Navigate to the IPM configuration directory: cd /opt/gehc/mr_ipm/config/
        3. Open the AWS configuration file: vi ccl_aws_config.cfg
          Note If a message like the one shown below appears after opening the AWS configuration file, press E for (E)dit anyway to continue.
        4. Set the following parameters to true:
          • IS_DEVICE_REGISTERED
          • IS_DEVICE_CONNECTED
          • IS_DEVICE_ENROLLED
          Note Useful commands in vi editor:
          • i - Switch to Insert mode (allows you to edit the file)
          • Esc - Switch to Command mode (Press Esc on the keyboard)
          • :wq - Save and quit/exit
          • :q! - Quit and do not save changes
        5. Close the Command Prompt/C Shell.
        6. Stop and restart IPM:
          1. Open a Command prompt/C Shell as an sdc user.
            Note The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log off and then log back on as the correct EA3 user with the authorized permissions.
          2. Navigate to the IPM scripts directory: cd /opt/gehc/mr_ipm/scripts/
          3. Stop IPM:
            1. Type the following command and press Enter: hmstop mr-ipm
            2. Type the following command and press Enter: ./mr-ipm stop
          4. Type the following command to restart IPM and press Enter: hmrestart mr-ipm. Wait approximately 3 to 5 minutes.
        7. Go back to the IPM agent. If the green circle or message has changed, or if the green check mark is still not showing in the IPM application, see Reenrolling an MR scanner in Imaging Protocol Manager (IPM) and complete the reenrollment process.
    5. If the green circle and message in Checking IPM agent connectivity does not appear, see Reenrolling an MR scanner in Imaging Protocol Manager (IPM) and complete the reenrollment process.
  4. Run the diagnostics and make sure that all status fields are green. If any of the status fields are not green, see Doing the Imaging Protocol Manager (IPM) diagnostics.
  5. Tell a GE HealthCare Digital Solution Team member or TSE/OLE/RSL that an import must be done on the IPM application. Refer to the Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972).
  6. Do a SaveInfo. See Saving information.
