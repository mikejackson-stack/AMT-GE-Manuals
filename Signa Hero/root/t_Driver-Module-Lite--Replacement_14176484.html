Procedure

  1. Remove right front cover per following steps.
    1. Open right front cover and remove a screw to disconnect GND cable.
    2. Unlock the cover.
    3. Lift up and remove the cover.
    Note If the service area is narrow, do the same for left front cover.
  2. Perform the Hoist Setup procedure to set up and secure the hoist for Driver Module lifting.
  3. Perform the following steps.
    1. Disconnect all connectors from front panel of Driver Module Lite.
    2. Remove 4 screws fixing driver module lite and chassis.
    3. Slide out the Driver Module.
  4. Perform the following steps.
    1. Hook the winch and spreader bar to the lifting brackets.
    2. Using the hoist, apply tension to the lifting chain until the weight of the Driver Module is supported by the hoist.
    3. Press the release tabs in on each side and pull Driver Module forward.
    Warning
    Potential crush hazard
    If the replacement part accidentally falls, it can cause serious injury.
    Do not put any part of the body below the replacement part.
  5. Use the hoist and slowly lower the Driver Module to the floor.
  6. Remove the Driver Module from Tray by loosening 6 fixing screws.
  7. Remove Driver Module tray brackets by removing fixing screws and install to the new one.
  8. Restore Driver Module to ISC by reverse order of removal.

Finalization

  1. Restore the Power. Refer to Removing LOTO - Integrated System Cabinet (ISC).
  2. Perform TR Dynamic Disable Calibration.
  3. Perform check scan.
