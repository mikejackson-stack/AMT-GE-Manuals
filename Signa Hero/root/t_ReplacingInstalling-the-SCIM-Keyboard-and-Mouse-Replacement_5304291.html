About this task

Overview

In this section you will replace the old keyboard or install the new keyboard.

Topic ID: id_SL1564926-1180634

LOTO the PDU

Procedure

  1. Shut down the software as follows:
    1. Click the Toolbelt icon.
    2. Click System Shutdown on the Service Desktop Manager.
    3. Select OK to confirm the shutdown.
    4. Wait for the system to indicate that it is safe to power off the computer before proceeding. (It usually takes about 90 seconds for this message to appear.)
  2. Perform LOTO for ISC.
Topic ID: id_SL1564936-1180634

Keyboard Replacement

Procedure

  1. Disconnect the USB extension cable from the keyboard. The one-meter long USB extension goes directly to the host computer.
  2. Lift up on the Keyboard to detach it from the SCIM base plate. The keyboard is attached with Velcro.
  3. Pull the cable and defective Keyboard clear of the SCIM and set it aside
  4. Place new Velcro strips on the top of the strips attached to the SCIM as shown in Figure 1.
  5. Pull the replacement keyboard USB cable through the opening in the SCIM.
  6. Remove the protective covering from the Velcro, see Figure 1. Position the replacement keyboard, then firmly push down to fasten Velcro.
    Note: The glue on the Velcro must be given time to set. Do not attempt to remove the keyboard from the SCIM for 24 Hrs.
  7. Connect the keyboard USB cable to the Host Computer through the USB extension cable.
  8. This completes the Keyboard Replacement.
Topic ID: id_SL1564945-1180634

Mouse Replacement

Procedure

  1. Unplug the defective Mouse from the host computer USB connector.
  2. Install the new mouse by plugging it directly into the host computer USB connection.
  3. This completes the Mouse Replacement.
Topic ID: id_SL66938-1180634

SCIM Replacement

Procedure

  1. Disconnect the USB extension cable from the keyboard. The one-meter long USB extension goes directly to the host computer.
  2. Lift up on the Keyboard to detach it from the SCIM base plate. The keyboard is attached with Velcro.
  3. Pull the cable and Keyboard clear of the SCIM and set it aside
  4. Turn the SCIM over to expose the cable connections. See Figure 2.
  5. Remove the Data cable from the defective SCIM.
  6. Turn the replacement SCIM over to expose the cable connections, as in Figure 2.
  7. Connect the data cable to the new SCIM, see Figure 2.
  8. Turn the SCIM over (top facing up).
  9. Pull the keyboard USB cable through the opening in the SCIM. See Figure 1.
  10. Remove the protective covering from the Velcro, see Figure 1. Position the keyboard then firmly push down to fasten Velcro.
    Note: The glue on the Velcro must be given time to set. Do not attempt to remove the keyboard from the SCIM for 24 Hrs.
  11. This completes the SCIM Replacement.
Topic ID: id_SL1564959-1180634

SCIM,Keyboard and Mouse Install

Procedure

  1. Remove the SCIM, Data Cable, Keyboard and SCIM language overlay from the box.
    Note: SCIM's come with one overlay for the selected language.
    Note: For the availability of other languages check the Sales Catalog.
  2. Remove the Protective film from the language overlay and position it over the SCIM. When you are satisfied it is in the proper position, rub your finger over it lightly, in between the Scan buttons and around the Emergency Stop button to press it in place.
  3. Flip the SCIM unit up side down exposing the cable connections.
  4. Attach the data cable. see Figure 2
  5. Flip the SCIM over so it is right side up and guide the keyboard cable through the center opening.
  6. Center the keyboard, Flipping it on top of the SCIM patient speaker (Bottom of keyboard facing up) Keep the Cable as short as possible so when the key board is flipped right side up onto the Velcro, the keyboard cable does not interfere with the installation.
  7. Remove the plastic strips from the Velcro, exposing the adhesive surface. See Figure 5.
  8. Guide the cable back into the center notched opening until all the remaining cable is under the SCIM base.
  9. Place the keyboard tight against the SCIM, Center it as best as possible, and drop into place. The Velcro pads will now be sticking to the bottom of the keyboard.
    Note: The adhesive on the Velcro takes 24 hours to completely adhere to the bottom of the keyboard. Allow the adhesive to dry completely before removing keyboard from SCIM base.
  10. Position the SCIM Assembly in front of the monitor and guide any excess data cable through the opening provided in the Workspace Desktop.
  11. Connect the USB cable from the Keyboard to the USB extension cable which connected the host Computer.
  12. Plug the mouse cable directly into the USB port on the Host computer.
  13. This completes the installation of the SCIM Assembly.
Topic ID: id_15819977

Finalization

Procedure

  1. Restore Power by referring to Removing LOTO - ISC
  2. When the system is fully booted, perform a scan to ensure proper system operation. Refer to Check Scan.
