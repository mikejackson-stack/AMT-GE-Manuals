Troubleshooting the In-Room Display (IRD)

Diagnose and fix issues with the IRD screen.

Notice
If any IRD cables or components are swapped for troubleshooting, return them to their original position before doing the next action.
Notice
Read the following for swapping during troubleshooting.
  • For IRD swap, ISC PDU LOTO is required.
  • For DP optical cable and USB optical cable, hot swap is accepted. Be careful not to disconnect the other cable.

Troubleshooting steps

Note At any point during the troubleshooting, if the DP AOC cables are connected to any other open mini DP port, re-install the IRM software to make sure that the IRDs are functional. See Reinstall IRM.

Make sure the IRDs have power

If there is no power, check the M3314 connections to ISC PW/PEN > PHPS2 > J42 and ISC PW Filter > J143.

For systems with remote (off the wall) siting configuration:

  1. Check the E3314 connections to ISC PW/PEN > J42 and ISC > Cabinet IF > J42.
  2. Check the E3302 connections to ISC PW/PEN > J40 and ISC > Cabinet IF > J40.

Replace the cables, if necessary.

Note The 14V output from the PHPS supplies the IRD display back light. The 8V output from the DCPS supplies the IRD touch circuitry and IRD display.

Make sure that the fiber optic cables are connected

Make sure that the USB fiber optic cables P5006 are properly connected to the correct USB 3.1 ports on the GOC. See IRD Block diagram for more information.

Make sure that the connections are clean

  1. Disconnect the PHPS power, DP, and USB 3.0 cables from the IRD(s).
  2. Check the connectors for debris or damage, and clean or replace, if required.
  3. Reconnect the cables.

Make sure that the IRDs are connected to the host PC

Make sure that two displays and two mouse devices are detected by the host PC.

If necessary, re-install the IRM software to resolve problem.

Resolve issue if one of the IRDs does not work

Note When troubleshooting, connect the cables from the GOC to the IRD before routing the cables to make sure that the IRD is functional. After you check the IRD functionality route the cables.
  1. Re-install the IRM software and check if the issue is resolved. See Reinstall IRM.
  2. Swap the malfunctioning IRD and the working IRD.

    Follow these procedures to remove the control panel covers:

    • Removing the magnet left- and right-hand lower access panels
    • Removing the dockable table interface cover
    • Removing the magnet left and right control panel covers

    If the same IRD is malfunctioning, then replace the IRD. See Replacing the In-Room Display (IRD).

  3. If the problem moves to the other IRD, the cables or the GOC port might be causing the problem.
    1. Go to the GOC and make sure that the cables are properly seated and connected as described in the block diagram. If no issues are found, go to the next step.
    2. For touch-related issues, swap the USB cable connections on the GOC ports.
      • If the problem stays on the same IRD, replace the USB cable.
      • If the problem moves to the other side IRD, the GOC port might be causing the problem.
        1. Move the USB connections back to the default ports. Restart the host PC to see if that resolves the issue.
        2. If the problem is not resolved, connect the USB cable to an open USB port. Restart the host PC to see if that resolves the issue.
        3. If no open USB ports are available or if the problem is not resolved by restarting the host PC, replace the host PC.
    3. For display-related issues, swap the mini DP cable connections on the GOC ports including the dongle.
      Important Handle the cables carefully. The fiber optic cables are easily damaged and have a minimum bend radius of 50 mm.
      • If the problem stays on the same IRD, swap the mini DP to DP dongle for port 1 (5851077-2) with the mini DP to DP dongle for port 2 (5851077-3) to examine if the issue is with the dongle.

        If the problem stays on the same IRD, replace the cable. Otherwise replace the mini DP to DP dongle.

      • If the problem moves to the other side IRD, the GOC port might be causing the problem.
        1. Move the DP connections back to the default ports. Re-install the IRM software to see if that resolves the issue. See Reinstall IRM.
        2. If the problem is not resolved, connect the DP cable from the malfunctioning mini DP port to one of the open mini DP ports. Re-install the IRM software to see if that resolves the issue.
        3. If the problem is not resolved by connecting to an open mini DP port or by re-installing the IRM software, replace the host PC.

Resolve “No signal” message

If both IRDs show No signal, determine if the system has been idle for more than 2 hours. The IRDs can lock due to noise exposure on the video line. When this happens, do the following to power cycle the IRD monitor.

  1. Press the E-stop button on the SCIM.
  2. Press the green EMO RESET on the PDU.
Note Damaged fiber optic cables can expose the IRD monitor to prolonged levels of video noise, causing the IRD monitor to enter a locked state, present in paths of both left and right IRD monitors. The cables consist of a single fiber with DP converters at each end, one fiber each for the left and right IRD monitors. Make sure that the ESD protective shipping cover is affixed and secured over the DP converter.

Finalization

  1. If you removed covers, reinstall them:
    • Installing the magnet left and right control panel covers
    • Installing the dockable table interface cover
    • Installing the magnet left- and right-hand lower access panels
  2. Make sure that all system interconnects are returned to normal configurations.
  3. Do a check scan. See Doing a check scan.
