Restoring information

Restore the current configurations and files from the SaveInfo media.

Prerequisites

Required conditions
Have the SaveInfo media available for use.
A Class M SSA key or Class C/A2 SSA soft key license is needed to access Guided Install from SIGNA applications. The service key is not needed when Guided Install is launched as Root. Refer to Service licensing for information on how to install an SSA soft license.

Procedure

  1. Launch Guided Install.
    If needed, see Accessing Guided Install for more information.
  2. In the left navigation pane, go to Utilities > Save/Restore.
  3. Insert the SaveInfo media.
  4. In the field next to Restore Information, select All (which is the default value). Then select Restore Information.
    Note Additional restore options are available:

    (For software version 29.0 and later) Click Restore w/o Passwords to restore all the information from the media except the system OS and EA3 passwords.

    (For software version 30.0 and later) Click Restore Calibration to restore only the calibration data from the media.

    (For software version 30.1 and earlier) Go to Step 8.

    (For software version 30.2 and later) The following message shows: Select the media you want to use. Go to Step 5.

  5. (For software version 30.2 and later) Select either USB or CD/DVD.
  6. (For software version 30.2 and later) Click OK to continue.
    Note If you selected USB and there are multiple USB drives on the system, a dialog box shows this message: Please select USB drive to transfer data.Select the correct USB drive for Restore Information and click OK.

    This message shows: Select SaveInfo.

  7. (For software version 30.2 and later) Select the correct SaveInfo for Restoring Information and click OK.
  8. The process starts and takes approximately 10 minutes to complete.
    Note Any potential differences between the previously installed and currently installed Service Pack(s) may be shown in a dialog box. If that occurs, refer to the latest revision of MR Service Pack Software Matrix (DOC1667089), available from the online documentation library, to identify the latest Service Pack available.
  9. After a restore is completed, remove the media.
    Note Beginning with software version 29.0, restoring software information will automatically set the PNF Filter setting to ON regardless of the previous setting. Make sure you re-set the PNF filter to the previous setting after consulting with the customer.
  10. Do a Check Scan to make sure that the system is functioning properly.
