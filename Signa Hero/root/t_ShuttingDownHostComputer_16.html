Shutting down the host computer

Shutting down the host computer shuts down the system safely and turns off the power to the host computer.

Procedure

  1. To shut down the system, click the arrow on the Tools High Level Access tab.
  2. Click System Power Off.
  3. Click Yes to make sure the system power is off.
