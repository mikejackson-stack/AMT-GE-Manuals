Verifying Save Restore Media

About this task

Overview

Verify SaveInfo Data is used to verify content of SaveInfo media to the original data on the system disk drive. The program firsts checks that all files are present on the SaveInfo media and then if check sums match.

Procedure

  1. Insert your already created SaveInfo DVD into the appropriate drive if it's not already there.
  2. At the host computer, go to the Service Desktop and open the Service Browser if it's not already running and start the Guided Install tool in FE Mode. See the illustration below.
  3. In Guided Install, perform the following steps.
    1. Go to the Save / Restore screen.
    2. Start the verification process by selecting [Check Information] button.
  4. The tool will verify the data on the media with that on the system hard drive. If no media is present, the you see an error message. While the media is being checked, the popup shown in the following alert box displays. The process takes about two minutes.
  5. Once verification is complete, the system will ask if you want to view the log. See . Click Yes .
  6. The Log Contents alert box, similar to the illustration below, displays a list of the located content. If any errors are reported, create a new SaveInfo.

Finalization

  1. Store Save/Restore media in a safe place.
  2. Do a test scan before customer turnover to ensure proper operation.
