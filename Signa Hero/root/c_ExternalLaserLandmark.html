External laser landmark

Intructions to use the external laser as a landmark source to expedite the patient setup.

MR systems with software version 30.2 or later support the use of an external laser as a landmark source to expedite the patient setup in MRI Radiotherapy applications. The customer is responsible for the installation, servicing, and troubleshooting of the external laser landmark. GE HealthCare is not involved in calibrating the external laser or in measuring the offset value. The details captured here are for informational purpose only.

Using the external laser landmark

  • The extlaser option key is installed.
  • The calibrated offset value of the external laser is entered by the customer. The customer must be logged on as an administrator.
    Note The calibrated offset value of the external laser is the difference between the scanner alignment light (internal laser) and the external laser. The scanner alignment light value is saved as IsoVectorZ in the Hardware window in Guided Install.
  • In the Select the desired Operating Mode, or the In Room Display, the operator selects External Laser as the Landmark Source. For more information about using this feature, see the MR Product User Manual.
Note After running the DQA tool, the customer must recalibrate the external laser offset value. The DQA tool calibrates the distance between the magnet isocenter and the scanner alignment light (IsoVectorZ). If the IsoVectorZ value changes, the calibrated external laser offset value is reset to 0.
