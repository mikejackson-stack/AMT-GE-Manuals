Logging on to the system

About this task

Most service functionality, including software updates and patches, can be completed with operator-level privileges. Because logging on as a super user allows you to make changes that can do irreparable damage to the system, do not log on as root unless necessary.

Procedure

  1. Log on to the system.
  2. If the system is idle for too long, or the last user did not log off, a dialog appears indicating the system is in use and has been locked. Change the Logon Name field to either your Enterprise User ID (if the enterprise ID is set up) or your Local User ID (if the enterprise ID is not set up).
  3. Enter the password and click Logon.
    Note It is possible the customer changed the default password. If you cannot log in, contact the customer for the correct password.

    Logging on as an operator opens the applications desktop. A window appears that shows the message: Please do not interact with the system until this message disappears.

    Note During some startups, restarts, and shutdowns, the system may seem to have stalled. These processes can take an extended period of time. Wait at least 30 minutes before calling the GE HealthCare Online Center.
Topic ID: task_wwj_4mp_nlb

Logging off of the system

Procedure

  1. Click the Service Desktop Manager tab.
  2. Click Lock Screen Switch User to log off.
