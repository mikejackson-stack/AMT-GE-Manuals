Doing the EPI White Pixel Test (PM mode)

The Echo Planar Imaging (EPI) white pixel tool is used to troubleshoot image artifacts.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-10 minutes-
Required conditions
When running the following tasks in PM Mode, insert an M-Class SSA Hard Key to enable access to the PM Assist menu options on the PM tab of the Common Service Desktop (CSD). Or, install the C-Class SSA Soft Key.

About this task

The Echo Planar Imaging (EPI) white pixel tool is used to troubleshoot image artifacts. Run this during the Planned Maintenance (PM), before running System Performance Test (SPT) (PM mode). Click View Report to view results.
Note The Echo Planar Test (EPT) is no longer required for systems running software version 30 or later; consequently, the EPI White Pixel Test must be run separately on these systems since it will not be run in EPT.

Procedure

  1. Remove any phantoms from the cradle.
  2. Move the cradle 320 mm from the Home position, landmark, and then advance to scan.
  3. On the MR Service Desktop, select the PM tab, and select PM > PM Assist > EPI White Pixel PM Mode > Click here to start this tool.
    Note The tool runs Body EPI White Pixel PM Mode. If the test stops before the tool completes body modes, view the Error Log to determine the troubleshooting needed.
  4. The EPI PM Mode files generated by this tool can be found in the Report Manager tool. To access:
    1. (For MR29 and earlier) From the service desktop, on the Utilities tab, select Report Manager. Use the password mrgo1.
      Note It is possible that the customer changed the default password. If you cannot log on, contact the customer for the correct password.
    2. (For MR29 and earlier) From the File menu, select Open.
    3. (For MR29 and earlier) Select EPT and locate files with the PM extension (IBIS looks for PM files to track Planned Maintenance completion).
    4. (For software version 30 and later) The EPI WP Results windows opens and displays the last results. Click the File menu In the EPI WP viewer to select more files.
