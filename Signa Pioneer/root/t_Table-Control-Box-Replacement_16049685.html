Replacement when Table is at the highest position

Procedure

  1. Perform LOTO for ISC.
  2. Remove Dock Interface Cover.
    1. Remove front lower trim ring.
    2. Remove two screws.
    3. Unhook two points at bottom.
  3. Remove 3 screws and remove Table base cover.
  4. Remove Table Control Box per following steps.
    1. Disconnect all cables from Table Control Box.
    2. Remove 4 screws which is fixing Table Control Box.
    3. Remove Table Control Box
  5. Connect the adapter 5485745 to J10. (Refer to service note DOC2790643)
  6. With new FRU, restore the Table Control Box and all cables and screws.
    Note TCB part number is labeled on TCB. If TCB is replaced from TCB1~3(5500801, 5500801-2, or 5750127) to TCB4(5750127-2), it is necessary to install the Jumper connector (5768908-2).
  7. Turn the system power ON. Refer to Removing LOTO - Integrated System Cabinet (ISC)
  8. (For TCB with J12 Cable) If the table is at up-limit position, need check Item 1; If the table is not at up-limit position, need check item 2 and then move up table to up-limit position to check item 1. See LED and Connectors
  9. Restore table base cover.
Topic ID: id_SL14243720-1284591

Replacement when table is at the lowest position and does not move up

Procedure

  1. Perform LOTO for ISC.
  2. Remove three screws at the bore end of base cover and remove base covers.
  3. Remove Table Control Box per following steps.
    1. Disconnect all cables from Table Control Box.
    2. Remove 4 screws which is fixing Table Control Box.
    3. Remove Table Control Box .
  4. Connect the adapter 5485745 to J10. (Refer to service note DOC2790643)
  5. With new FRU, restore the Table Control Box and all cables and screws.
    Note TCB part number is labeled on TCB. If TCB is replaced from TCB1~3(5500801, 5500801-2, or 5750127) to TCB4(5750127-2), it is necessary to install the Jumper connector (5768908-2).
  6. Connect the pedal switch cables coming from bottom cover.
  7. Turn the system power ON. Refer to Removing LOTO - Integrated System Cabinet (ISC).
  8. Move the Table at up limit position.
  9. (For TCB with J12 Cable) If the table is at up-limit position, need check Item 1; If the table is not at up-limit position, need check item 2 and then move up table to up-limit position to check item 1 , See LED and Connectors
  10. Turn the system power OFF. Refer to Lockout / Tagout for ISC
  11. Remove Dock Interface Cover.
    1. Remove front lower trim ring.
    2. Remove two screws.
    3. Unhook two points at bottom.
  12. Restore table base covers with three screws.
  13. Restore Dock Interface Cover and front lower trim ring.
