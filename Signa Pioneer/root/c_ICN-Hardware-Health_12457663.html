Doing the Image Compute Node (ICN) hardware health diagnostic

The Image Compute Node (ICN) hardware health diagnostic is a shorter form of diagnostics that covers the ICN hardware, communication, and PCIe adapter card health status.

This diagnostic does a quick test of the components inside of the ICN. It does not test the VRF card.

Diagnostic Path

Diagnostics > System Function > Recon > ICN Quick Health Check > ICN Hardware Health

Diagnostics > Hardware Location > Integrated System Cabinet > Recon > ICN Quick Health Check > ICN Hardware Health

Purpose

The ICN quick health check is a shorter form of diagnostics that covers the ICN hardware, communication, and PCIe adapter card health status.

Components tested

ICN H/W: (30~50 seconds)
  • Fans
  • Processor
  • Memory
  • Solid state disk drives, SSD (FRU)
  • Power supply
  • Intrusion
  • Battery
  • SD card
  • Temperature, voltage, current, redundancy
  • NIC statistics
Communication: (~ 2.5 minutes)
  • Ethernet connectivity
  • Stress and IPMI connectivity
PCIe adapter: (~ 10 seconds)
  • VRF card or
  • PCIe adapter

Requirements

  1. ICN configuration has been completed.

  2. BMC cable and network cable are connected, required for complete ICN configuration.

  3. The ICN is turned on and has at least one network connection from the ICN motherboard Ethernet port to the Host.

Note The dual fiber optic cables and the RRx module do not need to be connected to the Ethernet switch for this diagnostic.

Block diagrams

Test sequence

  1. On the ICN Quick Health Check screen, select ICN Hardware Health.
  2. Click Run.
    Note After you click Run, do not click anywhere else in the Common Service Desktop until the test is complete. If you need to abort the test, click Stop.
  3. Make sure the ICN passes the diagnostic by reviewing the status in the Diagnostic results table.

Results

Diagnostic results show a status of Pass or Fail. If you receive a Fail status, click GE System Log to view the error message. The system log records errors with the date, time, the process tested, and a detailed error message.
