Configuring the Cisco router for hospital network access

Create the Cisco router for hospital network access.

Procedure

  1. In the Cisco ASDM Home page, click Configuration in the top toolbar.
  2. In the left navigation panel, select Device Setup > Interface Settings > Interfaces.
  3. Select Ethernet1/1 and click Edit.
  4. Under the General tab in the IP Address section, enter the IP Address and Subnet Mask as shared by the hospital network team for the Cisco router.
  5. Click the IPv6 tab and select the Enable IPv6 check box.
  6. In the Interface IPv6 Addresses section, click Add.
  7. Enter the IPv6 Address/Prefix Length as shared by the hospital network team for the Cisco router.
  8. Click OK twice.
  9. Click Apply.
  10. Click Refresh in the top toolbar and then click Save.
  11. If the hospital network team has provided a default gateway address, do the following:
    1. In the left navigation panel, select Device Setup > Routing > Static Routes.
    2. Select the IPv4 radio button and click Add.
    3. Fill the following fields:
      • Interface: outside
      • Network: any4
      • Gateway IP: enter the IPv4 default gateway IP address from the hospital
    4. Click OK.
    5. Select the IPv6 radio button and click Add.
    6. Fill the following fields:
      • Interface: outside
      • Network: any6
      • Gateway IP: enter the IPv6 default gateway IP address from the hospital
    7. Click OK.
  12. Click Apply.
  13. Click Save.
  14. Click Refresh.
