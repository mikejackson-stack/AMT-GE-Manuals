Installing BrainWave software

About this task

The BrainWave software configures automatically when you install the software.
Note This procedure applies only to software versions 27 and earlier. The BrainWave application on 28 software is automatically loaded through the USB installer.

Procedure

  1. Go to Guided Install > Verification.
  2. Insert the BrainWave disc.
  3. Click Install Software.
  4. Reboot the system.
