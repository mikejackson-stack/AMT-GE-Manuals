Installing the PS filter box

Install the PS filter box in the Integrated System Cabinet (ISC) Penetration Wall (PW).

About this task

Procedure

  1. From the equipment room side of the Penetration Panel, move the PS filter box into place on the Penetration Panel.
  2. Secure the PS filter box to the Penetration Panel with 20 screws.
  3. On the equipment room side, connect each of the PS filter box cables.
    1PS filter box
    2PS filter box cables
  4. On the scan room side, connect the PS filter box cables.
