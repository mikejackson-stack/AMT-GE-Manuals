        Diagnostic procedures related to the Physiological Acquisition Controller (PAC), which include: a PAC manual test, a PAC respiratory test, a PAC power-up test, the Signal Processing Unit (SPU) to PAC IF loopback test, the SPU to PAC loopback diagnostic, the SPU to Field Programmable Gate Array (FPGA) loopback test, the SPU respiratory test, and the SPU cardiac diagnostic.

        • Doing a Physiological Acquisition Controller (PAC) respiratory test

          The Physiological Acquisition Controller (PAC) respiratory test causes the PAC module to test its respiratory gain and offset circuits.

        • Doing the Signal Processing Unit (SPU) to Physiological Acquisition Controller (PAC) IF loopback test

          The Signal Processing Unit (SPU) to Physiological Acquisition Controller (PAC) IF loopback test verifies that the PAC TX and RX port on the ICE board (J38, J39) is functioning correctly.

        • Doing the Signal Processing Unit (SPU) to Physiological Acquisition Controller (PAC) loopback diagnostic

          The Signal Processing Unit (SPU) to Physiological Acquisition Controller (PAC) loopback diagnostic verifies that the ICE board can send data to the PAC module over the PAC's fiber optic cables.

        • Doing the Signal Protection Unit (SPU) to Field Programmable Gate Array (FPGA) loopback test

          The Signal Protection Unit (SPU) to Field Programmable Gate Array (FPGA) loopback test verifies the data path in the PAC I/F in the PSC FPGA on the Integrated Control Engine (ICE) board.

        • Doing the Signal Processing Unit (SPU) respiratory diagnostic

          This Signal Processing Unit (SPU) respiratory diagnostic verifies that the trigger signals (respiratory trigger), which are launched from the SPU in Integrated Control Engine (ICE), could be correctly captured by the sequencer module in ICE.

        • Doing the Signal Processing Unit (SPU) cardiac diagnostic

          The Signal Processing Unit (SPU) cardiac diagnostic verifies that the trigger signals (cardiac trigger), which are launched from SPU in Integrated Control Engine (ICE), could be correctly captured by the sequencer module in ICE.
