Installing host system software from Remote Software Download (RSD) for software version 30.2 and later

Install the host system software from Remote Software Download (RSD) for software version 30.2 and later.

About this task

The footer area contains the Remote Software icon. When a new software update is available to install, the Remote Software icon appears with a small orange circle.
Note See Observing system tray status icons for information about the status icons of RSD.

Procedure

  1. The EA3 account used for the software install must have the GESoftwareInstaller role. To switch users and log in with the correct privileges, do the following:
    1. In the header area of the window, click Tools.
    2. In the System Management work area, click Service Desktop Manager.
    3. Click Lock Screen Switch User.

      Result

      The Logon window shows.
    Note If the package user role is GEService, the FE needs to be present and with the M-Class SSA Hard Key inserted into the system before starting the installation. Click Details of the downloaded package in the Software Delivery Manager window to identify which role is assigned to the package. See Install downloaded software.
  2. If the software has downloaded, in the footer area of the window, click the green Remote Software icon.
  3. If the software has not been downloaded automatically, it can be downloaded manually.
    1. Open the Service Browser.
    2. On the Utilities tab, select Remote SW download and click Click here to start this tool.
    3. From the Software Delivery window Updates tab, select the check box next to the item you want to download.
    4. Click Download Now.
      Note The Downloads tab will show a progress bar of the download. The status icon will also show the progress of the download. When the download is complete, it may briefly disappear from the Downloads tab and the status icon may temporarily change back to all grey while the download package is validated.
  4. If there is only one software update available, it will start automatically. If there is more than one update available, select the check box next to the software version you want to install, and click Install Now.
  5. A dialog window opens. Select the I acknowledge that I have checked all the above requirements check box, and click Proceed.
  6. A second acknowledge dialog window will show. Select the check box and then click Continue.
  7. A window will show the progress of the software preparing to install. The system will then reboot and will continue with software installation unattended. See Installing full software releases from Remote Software Download (RSD) for software version 30.2 and later.
