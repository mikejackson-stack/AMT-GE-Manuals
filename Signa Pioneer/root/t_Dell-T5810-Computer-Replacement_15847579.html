Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

DANGER
Electrocution Hazard!
Hazardous voltage is present when GOC is energized.
Before beginning any work, perform lockout/tagout (LOTO). See Applying LOTO - Global Operator Cabinet (GOC) and Operator Workspace.

About this task

This procedure provides instruction to replace the host computer with a Dell T5810 computer.
Topic ID: id_SL12053591-1311832

Prepare Workstation for Host Computer Removal

Procedure

  1. Make sure the customer has archived all images to an external storage device such as a PACS or DVDs.
  2. Perform Save Info.
  3. (For FRU which will be returned as Good Item Only) Setup Bios for “AC Recovery” to “Power Off” (Default for FRU).
    1. Right-click on the Linux desktop to access the Root Menu and then select “System Restart”.
    2. Press [F2] on Keyboard before entering the OS. The BIOS setting GUI will show up. Perform the followings for BIOS setting.
    3. Use Mouse to select Power Management section > AC Recovery > Power Off.
    4. Click Apply button on GUI and Exit button to exit.
    5. When system is rebooted and login menu is shown, select Menu > Shutdown in welcome login screen to shutdown the system.
  4. Perform LOTO on the GOC/operator workspace. See Applying LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
Topic ID: id_SL12053592-1311832

Remove Host Computer from GOC

Procedure

  1. Remove the two screws that secure the left side panel of the GOC.
    Note The side panel has a short ground lead connecting it to the main chassis. When removing the side panel, do not strain this ground lead.
  2. Disconnect the short ground lead that connects the side panel to the GOC main chassis at the center of the lead.
  3. Remove the left side panel and put it in a safe place.
  4. Remove all the cables connected to the host computer.

    Confirm that the cables are properly labeled. Note their locations for reattachment.

    Note
    • For older GOCs which include an 8-port hub, route and connect Ethernet cable from GOC hub to this port.
    • For newer GOCs without a hub, this port is available for connecting to a service laptop, site network, or AW option. If connection to multiple Ethernet devices is required, a customer-supplied switch must be used.
  5. Remove the strap(s) from the computer.
  6. Lift the front of the computer, carefully slide the computer away from the brackets, and then lift to remove it. If necessary, loosen or remove the bracket(s).
  7. Perform a disk wipe on all applicable hard drives in the old computer. See the latest revision of the Disk Management Tool Service Manual, PN 5500610-1EN available from the online documentation library.
Topic ID: id_SL16214630-1311832

Transfer USB Expansion Panel from Old PC to New PC

Procedure

  1. Lift up the cover release latch, tilt the cover about 45-degree angle, and remove it from the old host PC.
  2. Notice
    Electrostatic discharge (ESD) can cause permanent damage to electronic components.
    Observe the following ESD precautions:
    Wear a static wrist strap to ensure that any accumulated electrostatic charge is discharged from your body to the ground.
    Create a common ground for the equipment being worked on by connecting the static-free mat, static wrist strap, and peripheral units to that piece of equipment.
    Connect ESD strap to Ground of GOC chassis and wear ESD wrist band.
  3. Press the blue plastic latch of 7th slot from inside of PC and pull the Expansion slot bracket with USB cable.
  4. Push side of PSU shroud (black cover) and slide toward the front to remove it from old PC.
  5. Remove the other end of USB cable from CN26 of Computer Board to fully remove the Extension bracket with USB cable.
    Note To remove the connector from CN26, extend the socket of the connector to the left using small flathead screwdriver and pull out the cable.
  6. Restore PSU cable shroud.
  7. For new PC, lift up the cover release latch, tilt the cover about 45-degree angle, and remove it. See PC Cover Removal.
  8. Press the blue plastic latch of 7th slot and pull the bracket away from the new PC.
  9. Insert expansion slot bracket to new PC which was removed from old PC. Then, secure it with blue plastic latch. See Expansion slot bracket with USB cable.
  10. Push side of PSU shroud and slide toward the front to remove it from new PC. See CN26 Cable.
  11. Connect the other end of USB cable to CN26 of Computer Board.
    Note Make sure the direction of connector is as shown in illustration below.
  12. Restore PSU cable shroud.
  13. Install the blank bracket to slot7 of the old PC which was removed from new PC.
  14. Restore PC Cover to both new and old PC.
Topic ID: id_SL12053594-1311832

Install New Host Computer

Procedure

  1. Install the computer into the bracket(s), and tighten the bracket screws.
  2. Install and tighten the strap(s).
  3. Connect all cables to the computer.
  4. Remove the dust filter and Velcro strips from the old computer, and install them on the new computer. If the old filter or Velcro strips are not reusable, install a new set.
  5. Assemble the GOC using the steps above in reverse order.
Topic ID: id_14946788

Finalization

Procedure

  1. Note BIOS setting for 'AC Recovery' is required during PC boot up. Otherwise, the HOST will not start up.
    Remove LOTO from the GOC to return power. See Removing LOTO - Global Operator Cabinet (GOC) and Operator Workspace. Then, press F2 on Keyboard before entering the OS. The BIOS setting GUI will show up. Perform the followings for BIOS setting.
    1. Use Mouse to select Power Management section > AC Recovery > Power On
    2. Click Apply button on GUI and Exit button to exit
      Note

      Verify that the host computer front panel power LED is on continuously.

  2. Load software and applications onto the operating system.

    See Loading Host System Software

    Note Load From Cold (LFC) must be performed to properly transfer customer options.
  3. Update the eLicense with the new host ID. See Software Option Installation with eLicense Generated Keys.
  4. Perform Check Scan to confirm the system and applications are working correctly.
  5. Confirm that all customer functions are operational (auto voice, filming, network, archive).
  6. Notice
    Heavy Object
    The computer weighs 29.8lbs(13.5kg). Proper lifting techniques shall be used for replacement.
    Repackage the defective computer for return.
