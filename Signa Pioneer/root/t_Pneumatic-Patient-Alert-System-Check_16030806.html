Pneumatic Patient Alert System Check

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable5 minutesNot Applicable

About this task

Overview

The Pneumatic Patient Alert System is a stand alone system that allows the Patient to contact the Operator even when the Console volume is turned down. Patient to Operator contact is accomplished by means of the Patient depressing a hand-held squeeze bulb that activates an audible and visual alarm near the Operator. The Operator must reset the Control Box in order to stop the alarms. Either a PULSE or STEADY audible tone can be selected at the Control Box. Use the following procedure to verify proper functioning of the Pneumatic Patient Alert System.

Procedure

  1. Check that green LED is lit.
    Table 2.
    ItemDescription
    1Steady/Pulse Switch
    2Reset Switch Button
    3Green LED
    4Audible Alarm
    5Power Supply
    6Squeeze Bulb
  2. Set the Control Box Steady/Pulse Switch to Pulse.
  3. Compress the Squeeze Bulb slowly until fully collapsed.
  4. Make sure the red LED on the Control Box is lit, and the audible alarm is emitting a pulsating tone.
  5. Set the Control Box Steady/Pulse Switch to Steady.
  6. Make sure the red LED on the Control Box remains lit, and the audible alarm is emitting a steady tone.
  7. Press the Reset button on the Control Box.
  8. Make sure the red LED on the Control Box and the audible alarm are off, but the green LED remains lit.
Topic ID: task_lyd_rzk_lhb

Squeeze Bulb / Tubing Coupler Interface

Procedure

Examine the squeeze bulb-tubing interface for wear. If the tubing becomes separated from the squeeze bulb (i.e. gets caught in the table), reinsert the tubing onto the coupler, otherwise replace with appropriate FRU.
Topic ID: task_g4y_5zk_lhb

Finalization

Procedure

  1. Compress the squeeze bulb, make sure the red LED is lit and an audible alarm is heard.
  2. Press the Reset button on the control box, the red LED should be off and the green LED lit.
