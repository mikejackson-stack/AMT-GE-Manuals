Troubleshooting the In-Room Display (IRD)

This document describes the IRD Troubleshooting for two phenomena: the touch panel does not work or there is no display on IRD.

Before starting this troubleshooting, see In Room Display Diagnostics.

Notice
Before disconnecting or reseating the cables at GOC, always turn the GOC power off. Otherwise, it may cause the system problem.
Topic ID: id_SL14175898-1292863

Touch panel does not work

If touch panel does not work, complete the following steps

  1. Check panel functionality. If both touch panels do not work. If both touch panels do not work, see 2. If one touch panel is working, see 3.
  2. Check if IRM software is installed or not. If not, open Guided Install, select IRM Installation, and then click Install IRM Software to install IRM software.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  3. Check if there is any warning message of DCPS for IRD Power (+8V) or not at OW.
    • If the error message is shown, replace DCPS for IRD and confirm that the problem is resolved.
    • If the error message is not shown, see 4.
  4. Make sure the USB fiber optic cable at GOC is correctly seated, and is connected to the USB 3.0 port (). If needed, unplug the cable, check the connector, and plug it back in.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  5. Check the optical cable at the IRD. Unplug the cable, check the connector, and plug it back in. Refer to the IRD, control panel, E-stop replacement procedure for your system. For instructions on how to access the IRD cables, see IRD, Control Panels, and E-Stop Buttons Replacement.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  6. Check optical cable connection at ICC PW (J301, J303). Unplug the cable, check connector, and plug again.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  7. If problem still remains, order optical cable and tentatively connect the cable from Host PC to IRD.
    • If problem is resolved, route the cable correctly using replaced cable.
    • If problem is not resolved, continue to the next step.
  8. If problem still remains, try to replace IRD.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  9. If problem still remains, replace host PC.
Topic ID: id_SL14175899-1292863

No display on IRD

  1. Check both IRDs. If both IRDs fail to display, continue to 2. If one IRD displays, see 3.
  2. Check if IRM software is installed. If not, open Guided Install, select IRM Installation, and then click Install IRM Software to install IRM software.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  3. Check if there is any warning message of DCPS for IRD power (+8V) or not at OW. If it’s shown, replace DCPS for IRD.
    • If the error message is shown, replace DCPS for IRD and confirm that the problem is resolved.
    • If the error message is not shown, continue to the next step.
  4. Perform Doing the Patient Handling Power Supply (PHPS) board level diagnostic.
    • If the diagnostic failed with internal power issue, replace PHPS.
    • If the diagnostic passed, go to the next step.
  5. Check the power LED of HDMI splitter.
    • If LED is lit, see 8.
    • If the LED is not lit, see 6.
  6. Check the voltage of cable connected at J1 of the HDMI Splitter.
    • If 5V exists, replace HDMI splitter.
    • If 5V does not exist, see 7.
  7. Check the voltage at J7 of GOC cable.
    • If 5V exists, replace the cable between J7 of GOC PDU and J1 of HDMI Splitter.
    • If 5V does not exist, replace the GOC PDU.
  8. Check J5 (E2026) and J6 (E2028) connection of the HDMI Splitter.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the nest step.
  9. Check the optical cable at IRD (M2026 and M2028). Unplug the cable, check connector, and plug in again. For instructions on how to access the IRD cables, see IRD, Control Panels, and E-Stop Buttons Replacement.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  10. Check optical cable connection at ICC PW (J301, J303). Unplug the cable, check connector, and plug again.
    • If problem is resolved, troubleshooting is complete.
    • If problem is not resolved, continue to the next step.
  11. If problem still remains, order optical cable and tentatively connect the cable from GOC to IRD.
    • If problem is resolved, route the cable correctly using replaced cable.
    • If problem is not resolved, continue to the next step.
  12. If problem has not been resolved, replace the IRD following the replacement procedure.
