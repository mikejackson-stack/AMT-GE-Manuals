Installing the patient blower air flow filter

Install the patient blower air flow filter.

Procedure

  1. Install the patient blower air flow filter for standard and remote siting configuration.
  2. Secure the patient blower air flow filter clamp.
  3. Remove ISC LOTO. See Removing LOTO - Integrated System Cabinet (ISC).

Finalization

  1. Start up the host computer/system. See Starting up the host computer.
  2. Do a check scan. See Doing a check scan.
