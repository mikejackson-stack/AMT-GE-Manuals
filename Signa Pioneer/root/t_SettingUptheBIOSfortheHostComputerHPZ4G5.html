Setting up the BIOS for the host computer for the HP Z4 G5

Restore the BIOS configuration on the host computer.

About this task

This procedure describes how to set up the BIOS on the HP Z4 G5 host computer.

Procedure

  1. Power on the host computer, and then start to set up the BIOS.
  2. During the host computer startup, press F10 to open the BIOS Setup menu when the HP startup logo shows on the screen.

    The screen shows Entering Startup Menu . . . in the lower left corner.

    Note Alternatively, press Esc to open the Startup Menu. Then select the BIOS Setup (F10) menu.
    Note If a screen with UEFI Firmware Settings opens instead of the Startup Menu, click UEFI Firmware Settings and press Enter.

    The Main menu opens.

  3. Under the Main Menu, select Change Date and Time.
  4. Set the correct time and date.

    Result

    After you set the time and date, the BIOS settings open.
  5. Restore the customized BIOS settings. Change only the values specified below, see HP Z4 G5 Customized BIOS settings
