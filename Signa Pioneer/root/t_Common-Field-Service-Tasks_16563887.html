Opening common service desktop

Procedure

  1. From the Tools menu, select Service Desktop Manager.
  2. On the Service Desktop Manager, click Service Browser.

    From the Common Service Desktop, you can do many maintenance and service tasks.

Opening Guided Install in FE Mode

Procedure

  1. Open the Common Service Desktop.
  2. Under the Configuration tab, select Guided Install > FE Mode > Click here to start this tool.
  3. When the C Shell opens, type your root password.
    Note It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

Laptop to host communication (FE)

About this task

By default, the Product Network Filter (PNF) firewall is enabled. This means that network communication to the host computer is limited to secure shell (SSH) and ping commands, as well as InSite connectivity. (Image browser networking is not affected by the PNF configuration.) With this security in place, it will not work to use a Windows command shell, Exceed, or other communication tool to telnet or ftp files. Turning off the PNF firewall is not an option; many sites require this additional security. To enable your laptop to communicate with the host computer, confugure the PNF to add your laptop’s IP address, as described below. For details on all the PNF options, see Product Network Filter (PNF) firewall.

Procedure

  1. Insert a service key, and from the Common Service Desktop, select the Utilities tab.
  2. Under Toolbox, select Produt Network Filter.
  3. In the Service Name field, add the service name if you want to connect using telnet or ftp commands.
  4. In the Allowed IPs field, enter your laptop IP address.

    To find your laptop’s IP address, select Start > Run. Enter cmdEnter. At the command prompt, type ipconfig /allEnter.

  5. Select Add Filter.

    A dialog box displays telling you to restart the firewall. Close the dialog box.

  6. Click Restart Firewall.

Remote tools: putty and WinSCP

About this task

Due to security updates in the DV25.1 R01 SW, telnet and ftp no longer work with DV25.1_R01 Software. PuTTY replaces telnet and WinSCP replaces ftp.

Procedure

  1. At the GE software download site, enter requests to download PuTTY and WinSCP software.
  2. Connect to the host with PuTTY.
    1. Open PuTTY.
    2. Enter the Host IP address. The connection type is SSH and port is 22. Click Open.
    3. If prompted with a security alert, click Yes. The security alert may not appear each time when logging in.
    4. Enter login ID and password at the command line when prompted. Some sites are configured to disable login as sdc. Login as insite instead (provided restricted service software is installed).
    5. The command line interface becomes available for telnet commands.
  3. Connect to the host with WinSCP.
    1. Open WinSCP.
    2. Enter the Host name (IP address). The file protocol is SFTP and port is 22.
    3. Enter user name and password. Click Login. Some sites are configured to disable login as sdc. Login as insite instead (provided restricted service software is installed).
    4. When prompted to trust the host, click Yes.
    5. When prompted with an authentication banner, click Continue.
    6. The local and remote interfaces are displayed for file transfer operations.
  4. The following configuration settings are recommended to make the keyboard/mouse act the same on different systems. If using these settings, check that the system behaves as expected.
    1. For Terminal > Window settings, change the Backspace key default to Control-H.
    2. For Window > Selection settings, change the mouse button action to xterm.
