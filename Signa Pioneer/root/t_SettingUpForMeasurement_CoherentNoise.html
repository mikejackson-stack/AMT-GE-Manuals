Setting up for measurement

Set up the transmitter (Tx) and receiver (Rx) from the coherent noise tool kit to measure the attenuation of the magnetic and electric field.

Procedure

  1. After zeroing the receiver (Rx) and transmitter (Tx), select Meas, then Auto.
  2. Keep the Rx and Tx in their current positions and make sure that they are fully zeroed by selecting Now. Measuring should only take a couple of seconds to complete.
    Note When measurement is completed, the screen will show the message Scan Terminated Press 1-4 to save or Escape.
  3. To see the measured attenuation, click Esc.
  4. Select Show and then Last.
  5. Use the 1stF and NxFr buttons to review all three frequencies and attenuations.
  6. Make sure the attenuation values are ± 3 dB. If they are not, examine cable connections, and set up and re-zero the Rx and Tx.
  7. Make sure the frequencies shown are correct. Refer to the table below. If frequencies are incorrect, change them to the correct list (L1, L2, or L3) or see Entering frequencies using SEMS software to enter frequencies using the SEMS software.
    Table 1. Frequencies
    List selection Product type Frequencies
    L11.5T Products 63.86 MHz
    51.00 MHz
    76.60 MHz
    L23.0T Products 127.72 MHz
    102.20 MHz
    153.30 MHz
    L37.0T Products 238.4 MHz
    238.9 MHz
    298.0 MHz
  8. If all three attenuation values are ± 3 dB and frequencies are correct, click Esc until you see the Ready for Measuring screen.
  9. Select Meas.
  10. Select Unc.
  11. The screen will open to Remove Connections. Remove the fiber-optic cable adapters from the Rx and Tx units.
    Note On the Tx a red LED will turn ON. This shows that the two units are transmitting.
