MCQA Setup - AA

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable30 minutesNot Applicable

The 1.5T GEM Coil MCQA will use the 1.5T phantoms, which are green in color. The 3.0T GEM Coil MCQA will use the 3.0T phantoms, which are pink in color.

Note

Coils do not ship with phantoms. Phantoms come in a Unified Phantom set with the MR System.

Procedure

  1. Place the Flat Filler Panel (shown below) on the table.
  2. Perform the following steps.
    1. Place two TL Unified Phantoms. Phantom aligns with the edge of the flat filler panel as shown.
      Note

      Phantom positioner spacer is not needed for MCQA AA setup.

    2. Place PA Phantom Positioner onto two TL Unified Phantoms as illustration below.
  3. Setup AA Coil per following steps.
    1. Place the AA Coil on top of the PA Phantom Positioner, and secure to each other with Velcro® straps as shown.
    2. Connect the coil to the P2 port.
  4. Set center position of the AA Coil connected on Port2 using the Touch and Go strips on the side of the table.
  5. Landmark on the AA Coil crosshairs as shown, and press Advance to Scan.
  6. Run the Multi-Coil Quality Assurance Tool.
    Note

    Select “3.0T_16Ch_AA_by_GE” for Current Coil field.

Finalization

No finalization steps.
