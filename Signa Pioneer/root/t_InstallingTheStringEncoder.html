Installing the string encoder

Procedure

  1. Find the label on string encoder replacement and record the manufacturer's position sensitivity number. This number will be entered into Guided Install as table encoder calibration value.
    Note If the PPI has 8 digits, round the last number to the nearest thousandth. For example, if the PPI number is 1000.7002, enter 1000700. If the PPI is 1000.7009, enter 1000701.
  2. For parts 5446108 and 5772529, install the string encoder assembly by securing four screws.
  3. SW Version PX26.0_R02 or later is required. For part 5795074, install the replacement encoder by securing two screws.
  4. Connect the encoder table connector and replace the tie-wraps.
  5. Install the string connector ring by securing a screw under the cradle.
  6. Install the cradle stopper by securing one screw.
  7. Install side covers. Refer to Installing the patient table side covers.
  8. Install bottom cover. Refer to Installing the patient table bottom cover.
  9. Install motor cover. Refer to Installing the motor cover.
  10. Do the following:
    1. Remove cradle support pad from under the cradle.
      Note There is a string for the encoder. Use caution when removing the support pad to avoid the string.
    2. Locate the cradle at about 200mm the towards bore and lift table top on handle end to get access to the cradle cover screws.
  11. Secure the cradle using the egress handle.
    To avoid locking, do not move the cradle to the Home position. Leave 500 mm (align touch-and-go switch end and cradle top cover end).
  12. Restore the power. Refer to Removing LOTO - Integrated System Cabinet (ISC).
  13. Align the cradle outside of the bore.
  14. Make sure the cradle moves in and out smoothly.
