Setting up the Bird 5000-EX wattmeter

This procedure describes how to configure the Bird 5000-EX wattmeter to measure maximum forward power.

Procedure

  1. Press the ON button on the wattmeter.
    If the coupler and sensor are not correctly attached to the amplifier, you will see a No Sensor indication.
  2. Press ▲ under Scale.
  3. Set the range by entering the value listed in Bird 5000-EX wattmeter ranges, based on calibration type, and press ENTER.
    Table 1. Bird 5000-EX wattmeter ranges
    Calibration typeRange
    Body Channel 150,000
    Body Channel 250,000
    Head Channel5,000
  4. To check the setting, press ▲ under Scale.
  5. Press ENTER to exit.
  6. Press ▲ under Fwd Units. Make sure the scale reads W (or kW on some wattmeters).
    • If the scale reads dBm, press ▲ under Fwd Units again to toggle the scale to read W or kW on the TOP forward power scale.
    Ignore the BOTTOM reflected power scale value. It is not used during maximum power calibration.
  7. Press SHIFT.
  8. Press ▲ under Setup.

    Result

    This shows the sensor type configured in the wattmeter. This procedure uses sensor type 43, which is optimized for peak power measurement.
  9. Make sure the wattmeter display shows 43 and press Enter.
    • If not, type 43 and press ENTER.
  10. Press ENTER.
  11. Press ▲ under Type and then toggle to change the unit of measurement to Peak.
  12. All kits require an offset to make sure of accurate measurement.
    Table 2. Element offsets
    TypeOffset
    Single drive RF amplifiersFind the offset for 3T G3 or DVMR Body Output.
    Dual drive RF amplifiersFind the offset for 3T Dual Drive Body Output.
    Head channelFind the offset for 3T DVMR Head Output and 4500W.
  13. Press MENU on the wattmeter. Select OFFSET and press OK.
  14. Enter the numerical value that was shown on the kit’s offset card and press OK.
    The wattmeter rounds to three significant digits.
    Note If the offset value is negative, first enter the numerical value, then the minus symbol (-).

Results

The meter is now ready for calibration.
