Finalizing the Physiological Acquisition Controller (PAC) replacement

This procedure finalizes the Physiological Acquisition Controller (PAC) replacement.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
2-30 minutes-

Procedure

  1. Remove ISC LOTO. See Removing LOTO - Integrated System Cabinet (ISC).
  2. Start up the host computer/system. See Starting up the host computer.
  3. Make sure that the reported problem has been resolved by running PAC or SRI diagnostics. In the Service Methods, instructions for these diagnostics can be found in Troubleshooting > Diagnostics > Hardware Location > Magnet Room > PAC Diagnostic Tests and SRI Functional Diagnostics.
  4. Do a check scan. See Doing a check scan.
