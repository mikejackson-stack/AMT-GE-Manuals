Setting up the coherent noise tool kit

Set up and connect the transmitter (Tx), receiver (Rx), and antennas in the coherent noise tool kit.

Procedure

  1. Put the receiver (Rx) and transmitter (Tx) on the two tripods found in the tool kit.
    Notice
    Possible equipment damage
    Never turn on the transmitter (Tx) without an antenna connected.
  2. Connect the biconical antennas to the Rx and Tx units, using the male-to-male couplers.
    Notice
    Possible equipment damage
    Failure to connect the attenuators will result in receiver (Rx) equipment damage.
    If using the dipoles or rod antennas, a 10 dB attenuator must be connected.
    Notice
    Possible equipment damage
    If using the tuned loop antennas, the loop antenna with the preamplifier must be connected to the receiver (Rx) not the transmitter (Tx).
    Note In most scenarios the biconical antennas will be used. Coherent noise tool kit items contains additional information on each antenna if another setup is needed.
  3. Adjust the height of each tripod to approximately 120 cm (47.24 inches).
  4. Align one of the tripods approximately 2m (6.56 ft) away from the other.
    Note The Rx and Tx units should face each other with their antennas in position as shown in Rx and Tx setup.
  5. Connect the small fiber-optic cables to the fiber-optic adapters [approximately 1.5 cm (0.59 inches) should be seated into the adapters]. Make sure to match black to black and white to white.
  6. Connect the fiber-optic adapters to the bottom of the Rx and Tx.
    Note Make sure that the fiber-optic cables are securely attached to the fiber-optic adapters. One should be able to lightly pull on each of the four cables without the cables falling out of the adapters.
  7. Press the power button on the Rx and Tx. The devices will turn on.
    Note Only press the power button for 1 second. Pressing the power button for more than 2 seconds will cause a system reboot. This is valid for both the Rx and Tx.
    Note The Tx power button is the black button on top. A yellow LED will start to flash when the unit is ON.
