Doing the leak sensor functional check (cabinet monitor 3 ISR) (Legacy leak sensor)

Follow this procedure to do the leak sensor functional check.

Prerequisites

Personnel Requirements
Required personsPreliminary requirementsProcedureFinalization
1-30 minutes-
Required conditions
System power is on.
Cabinet monitor identification
Cabinet monitorPart number
Cabinet Monitor 3 ISR5789922

About this task

There are two leak sensor routes. This test checks that each sensor route is operational.

  • Leak Sensor route 1 (blue line in illustration below): Connected to J6 of cabinet monitor
  • Leak Sensor route 2 (red line in illustration below): Connected to J6 of cabinet monitor

Procedure

  1. Disconnect leak sensor 1 connector.
  2. Reconnect the leak sensor 1 connector.
  3. Press the EMO Reset button.
  4. Make sure that the system functions connected to the emergency stop booted up properly.
  5. Make sure the leak sensor error message is not shown on the operator console.
  6. Do a TPS reset.
  7. Repeat for leak sensor 2.
