Doing DQA calibration with the Sphere With Spout (SWS) phantom

Details the steps needed to run the Gradient Calibration Tool (GCT) for systems running MR31.0 and higher and that possess the 17cm Sphere with Spout (SWS) phantom. GCT does the same checks and produces the same output as DQA.

Prerequisites

Doing DQA calibration with the Sphere with Spout (SWS) phantom is for systems above MR31.0 and that possess a Sphere with Spout (SWS) phantom.
Note For systems running software version below MR31.0, or sites that do not have a Sphere with Spout (SWS), see Doing DQA calibration with the DQA III phantom.

Required conditions
This procedure requires an accurate landmark. Make sure the laser light alignment is complete. Troubleshoot any problems you find while doing this calibration.
Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

About this task

The 17cm Sphere with Spout (SWS phantom), replaces the DQA-III phantom for systems running MR31.0 and above.

The Gradient Calibration Tool (GCT) offers the same functionality as the DQA tool for:
  • Checking the gradient connections
  • Checking the image orientation
  • Calibrating the gradient and table related parameters (xfull, yfull, zfull and isoVectorZ)

This tool uses the clinical head coil, a SWS phantom positioner, and the SWS phantom.

Note

Like the DQA tool, if calibration adjustments are required, GCT does the applicable iterations until complete. Therefore, the GCT time to complete may vary.

Procedure

  1. Select the phantom positioner that is correct for the head coil that will be used. Set phantom positioner onto the coil.
  2. Set the SWS phantom into the phantom positioner, The SWS phantom can only fit one way into the positioner. There is a pocket in the positioner where spout will fit.
    Note Do not install the top side of the coil at this time.
  3. Set a landmark on the center line of the SWS phantom and on the lines on the positioner. If the laser does not align with both the lines on the phantom and the lines of the positioner, align the laser with the lines of the positioner, then install the top of the coil.
    Note The current photo of positioner below does not have these lines, the future version of positioner will have these lines.
  4. Start the DQA tool, select one below:
    OptionDescription
    For non-proprietary mode:
    1. From the Common Service Desktop, select Calibration > DQA Calibration, then select Click here to start this tool.
  5. On the Gradient Calibration window, select 17cm sphere with spout.
  6. On the Gradient Calibration Tool window, click Start.
    Note Never use the touch-and-go landmarking strip when manually landmarking as part of a calibration tool procedure.
  7. The calibration tool runs automatically. Status messages will show initial calibration and last calibration values when tool completes its iterations. The MR system is automatically updated with the final calibration values.
    1. After the calibration wizard starts, select DQA from the menu. Examine the dependencies and then click Click here to start this tool.
  8. After the tool successfully completes its tasks, click Exit.

Finalization

Note If a customer has a configured external laser device and the DQA tool altered the value of Z isocenter (IsoVectorZ), then the DQA tool will automatically set the external laser offset value to the invalid value of zero (0) and display the following:

The external laser offset value must be recalibrated and entered into Guided Install for the external laser feature to be functional. The calibration of the offset value is the responsibility of the customer.
