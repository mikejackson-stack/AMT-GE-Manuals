Restarting the host computer

About this task

Restarting the host PC shuts the system down safely and then automatically starts up the system. Restarts are often required to finalize changes or updates.

Procedure

  1. To restart the system, click the arrow on the Tools High Level Access tab.
  2. Click System Restart.
  3. In the dialog window, click Service.
  4. Click Yes to confirm the restart.
