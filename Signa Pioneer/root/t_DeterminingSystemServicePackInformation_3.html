Determining service pack information

Find which service pack is installed on the system before attempting to load any service pack update.

Procedure

  1. Get the latest version of the MR Service Pack Software Matrix (DOC1667089) from the online documentation library.
  2. Open a command window, type getver, and click Enter.
    Note The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log off and then log back on as the correct EA3 user with the authorized permissions.
  3. The loaded service pack information is in bold typeface in the results list.

    Example

    In this example (for system HD16.0_V02), Service Pack 02 is loaded.
  4. Compare the service pack version that is on the system with the MR Service Pack Software Matrix (DOC1667089).
    • If the correct service pack has been loaded, get the GE Equipment Maintenance Sticker (5661793), write the date and service pack number on the sticker, and put the sticker on the GOC for future reference.
    • If the latest service pack is not loaded, invoke Guided Install as root and load the latest software updates as described in the following tasks. See Invoking Guided Install as root for more information.
  5. If needed, refer to Installing updates from Remote Software Download (RSD) to enable users to download and install updates as needed (optional).
