Reenrolling an MR scanner in Imaging Protocol Manager (IPM)

Learn how to reenroll an MR scanner in IDAM.

About this task

You must add and enroll any MR scanner at the customer facility to the Customer IPM Organization in IPM before you can exchange protocols between them. In this process, enrollment code or username/password credentials, which provides authorization for the exchange of data, are generated by IPM and stored on the MR scanner.

You might need to reenroll a device if the previous credentials/enrollment code were deleted or corrupted on the MR scanner, or if you are upgrading the MR software. You can complete this process in tandem with the GE HealthCare Digital Solution Team member or OLE/TSE/RSL. They will complete the necessary steps in the IPM Application while you complete these steps on the MR scanner. For more information on who the GE HealthCare Digital Solution Team is, see the Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972).

To reenroll the MR scanner with IPM:

Procedure

  1. To make sure the following information is correct, see Check/configure network information on the scanner:
    • The MR scanners Host IP Address, Netmask/Subnet Mask, and Default Gateway/Router IP Address.
    • NTP Server IP address.
    • DNS Server Information.
  2. Check that this scanner has a proxy server configured. See Configuring a proxy server.
  3. If a proxy server is configured, make sure that the correct customer-provided SSL certificates are installed. See Configuring the SSL certificate (only for customers that use SSL configuration).
  4. Make sure network communication between the MR scanner and the IPM application is working. See Checking the MR scanner-IPM network connectivity.
  5. Disconnect the MR scanner from IPM:
    1. In the imaging device console, open a Command Prompt/C Shell as a root user.
    2. Navigate to the IPM configuration directory:cd /opt/gehc/mr_ipm/config/
    3. Make a backup of the current configuration:cp ccl_aws_config.cfg ccl_aws_config.cfg-bkp
    4. Open the AWS configuration file:vi ccl_aws_config.cfg
      Note If a message like the one shown appears after opening the AWS configuration file, enter E for (E)dit anyway.
    5. Change the values for the following parameters from true to false:
      • IS_DEVICE_REGISTERED
      • IS_DEVICE_CONNECTED
      • IS_DEVICE_ENROLLED
      Note Useful commands in vi editor
      • i - Switch to Insert mode (allows you to edit the file)
      • Esc - Switch to Command mode (press the Esc button on keyboard)
      • :wq - Save and quit/exit
      • :q! - Quit and do not save changes
    6. Close the Command Prompt/C Shell with superuser permissions.
  6. Stop and restart IPM from the MR scanner:
    1. Open a Command Prompt/C Shell with sdc user.
    2. Navigate to the IPM scripts directory:cd /opt/gehc/mr_ipm/scripts/
    3. Stop IPM:
      1. Type hmstop mr-ipm and press Enter.
      2. Type ./mr-ipm stop and press Enter.
    4. Restart IPM and wait for approximately 3 to 5 minutes.
      1. Type hmrestart mr-ipm and press Enter.
    5. Close the Command Prompt/C shell.
  7. Reboot the imaging device.
  8. Wait for the GE HealthCare Digital Solution Team member or OLE/TSE/RSL to provide the enrollment code or the username and password credentials, and the IPM device config URL.
  9. In the Service Browser, press IPM if you have the new agent, or press Cloud Connectivity if you have the old agent.
    • If you have the new agent, enter the following information and press Connect to reenroll the MR scanner.
      • IPM Configuration URL: Enter the IPM device configuration URL. See the Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972) for more information.
      • Enrollment Code: Enter the enrollment code that is specific to this MR scanner.
    • If you have the old agent, enter the following information and press Connect to reenroll the MR scanner.
      • User name: Enter the username from the credentials for the specific MR scanner.
      • Password: Enter the password from the credentials for the specific MR scanner.
      • IPM Configuration URL: Enter the IPM device configuration URL. See the Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972) for more information.
  10. Tell the GE HealthCare Digital Solution Team member or OLE/TSE/RSL that the device has been reenrolled.
