Installing the penetration panel for remote (off the wall) siting configuration

Topic ID: id_SL12242365-1178803

Installing the penetration panel

Procedure

  1. In the equipment room, install 36 mounting blocks and 36 screws on the RF shield wall around the wall opening.
    Note The RF vendor must supply the M6 fasteners, M6 nuts, and M6 washers (36 each) to mount the penetration panel to the GE-supplied mounting blocks.
  2. From the scan room, install the nuts onto the screws. Do not tighten the nuts at this time.
  3. From the equipment room, install the penetration panel in the wall opening using the attached hanging studs.
    Note Hardware for the penetration panel installation is contained in the bags attached to the penetration panel.
    Note Remove the yellow plastic sheeting from the penetration panel before its installation.
  4. Secure the penetration panel:
    1. Rotate the mounting blocks to secure the penetration panel.
    2. From the scan room, tighten the nuts securing the mounting blocks.
      Note If you use a power driver, go slow and take care not to break the screws.

Installing the coldhead EMI filter on the penetration panel

Procedure

  1. Open or Remove protect cover:
    1. If it is Legacy cover (5507920+5507919) on ICC: loosen 10 screws (green-marked) and open the protective cover.
    2. If it is new structure cover (5953417-2+5953417-1+5507920) on ICC: remove right side cover by removing right side 14 screws(green-marked).
  2. Loosen 10 screws, and open the protective cover and remove the cable in equipment room.
  3. Remove the EMI Filters.
    1. If it is One-piece filter on the Legacy cover: Remove the filter by removing 3 screws on the small panel.
    2. If it is Three-pieces filter on the Legacy cover: Remove the filter by removing 10 screws on the small panel (green-marked).
    3. If it is Three-pieces filter on the new structure cover: Remove the filter by removing 10 screws as shown below.
  4. Route the cable E0011 and install the protect cover on the ICC side.
    Note The length of the E0011 cable along with the compressor is 16m for the normal length. If the distance is longer, the optional E0011 cable (19m) can be used for remote siting configuration.
  5. Remove 2 screws to remove the protect cover from each side of the penetration panel as shown below.
  6. Install the EMI filter onto the compatible small adapter (connect board).
    Note There are two types of filter and connect boards. One is 5877362 for one-piece filter; the other is 5877362-2 for three-pieces filter.
  7. Install the EMI filter with connect board to the penetration panel.
  8. Connect E0011 from the compressor to the filter in the equipment room.
    1. Connect and secure power cables (blue, brown and black) onto the filter.
    2. Connect and secure the ground cable (yellow/green) onto the ground point.
      Note Make sure the color codes on equipment room match with magnet room side.
  9. Connect M0011 coldhead power to the filter in the scan room.
  10. Install back the protect covers for the filter from both the equipment room and the scan room.

Installing the gradient filter assembly on the penetration panel

About this task

CAUTION
THE WEIGHT OF THE GRADIENT FILTER IS 25 kg (55 lbs).
Two persons are required for installing the gradient filter, and safety shoes should be worn.

Procedure

  1. Remove the gradient filter covers if they are not already removed.
  2. On the equipment room side, position the gradient filter in the opening using the guide pegs for support and positioning.
  3. Secure the gradient filter plate to the penetration panel and use the supplied 32 pcs screws (1000-M5C012-31) and 32 pcs washers [(2000-M5-10) and (2203-M5-16)].
  4. Remove the 6 ground double clamps from both the equipment room and the scan room.
  5. Install the new clamps (5873390) in the equipment room and the scan room, do not secure the clamps until the gradient cables are installed.
  6. Install the remote cable bracket (5866655) in the equipment room and the scan room.

Installing the DCPS filter on the penetration panel

Procedure

Install the DCPS filter (6859100) by fixing 16 pcs screws (1007-M5C010-31) in the scan room if it has not be pre-installed on the penetration panel.
Topic ID: task_tyk_5wz_rqb

Installing the BNC/DB filter on the penetration panel

Procedure

  1. Remove the thru panel assembly (5549212) from the ICC. See BNC/DB filter.
  2. Remove 6 fiber connectors from BNC/DB filter, keep the screws and reuse them in the next step.
    Note It is applicable for 48m IRD HDMI cable.
  3. Install the small blank panel using the 12 screws from the previous step at the same location of the BNC/DB filter.
  4. Remove the blank plate from the penetration panel.
  5. Install the blank plate on the ICC.
  6. Install the thru panel assembly (5549212) onto the penetration panel.
