Image Compute Node (ICN) on/off procedure for Dell R620, R630, R640 (Gen 7), and SIP (ICN Gen 8)

This procedure documents the proper methods of shutdown for the ICNs.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-30 minutes-
Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

DANGER
Electrocution hazard
Hazardous voltage is present when the cabinet is energized.
Before beginning any work, do LOTO. See the MR Service Safety Manual (5452735).
Notice
Failure to properly power down the ICN can result in premature ICN failure.
Never turn the ICN ON/OFF from the power button on the front. There is software running on ICN disk drives that can be corrupted if not shut down correctly.
Follow the procedure for removing power to the ICN chassis.

About this task

This procedure documents the proper methods of shutdown for the Dell R620, R630, R640 (Gen 7), and SIP (ICN Gen 8) ICNs. The ICNs are powered up when the host is started. There is no need to switch the ICNs on individually. If needed, you can switch on the ICNs from the VRE Power Control utility (Switch on ICNs from VRE power control).

The ICNs are powered down when the host software is shut down. To shut the ICNs down individually, use the VRE Power Control utility (Power down ICNs from VRE power control).

If the preferred shutdown method does not work, a last resort is to use the ICN power button (Power off ICNs manually).

Topic ID: id_SL1918785-1054787

Switch on ICNs from VRE power control

Procedure

  1. On the Common Service Desktop, go to Utilities > Toolbox > VRE > Power Control.
  2. Click POWER ON ICN for the selected ICN.
    The ICN is automatically powered on.

    The Dell ICN shows the boot status on the LED readout, located on the front panel of the ICN.

  3. If the application software is down, you can power on the ICNs from the xterm command line. Type: /etc/init.d/poweron_vres start and press Enter.
Topic ID: id_SL1909354-1054787

Power down ICNs from VRE power control

About this task

This is the preferred method for shutting down the ICNs.

Procedure

  1. At the host computer, on the Service Browser, select Utilities > Toolbox > VRE > Power Control.
    Note The number configuration should match the number of VREs. The illustration above shows images from a system with a Sun 4100 ICN. Systems with an R620 or R630 ICN have only one ICN selection.
  2. Make sure of the ICN numbers and their MAC addresses. The MAC addresses are printed on a sticker on the front of the ICNs.
  3. Click POWER OFF ICN(x). Wait for the ICN to power off.

    The screen shows the power status of the ICN as it is switching off.

  4. Refresh the Power Control link to see the current state of the ICN.
  5. The Dell ICN is powered down when the green power LED located on the upper left side of the front of the ICN for Dell R630/Dell R620 is not illuminated.
  6. The Server Imaging Platform (SIP) (ICN Gen 8) is powered down when the green power LED located on the upper right side of the front panel is not illuminated.
Topic ID: id_SL1918778-1054787

Power down from root level

About this task

If the application software is down, you can power down the ICNs using command line at the root level.

Procedure

  1. Log on to the application using the root login.
    Note It is possible that the customer changed the default password. If you cannot log on, contact the customer for the correct password.
  2. In the xterm window, type: /etc/init.d/poweron_vres stop and press Enter.

    The ICN(s) should turn off after 1 minute.

    The Dell ICN is powered down if the green power LED located on the upper left side of the front of the ICN is not illuminated.

Topic ID: id_SL1918782-1054787

Power off ICNs manually

About this task

Notice: If neither the browser nor the command line are accessible, the ICNs can be powered off manually. Try this method before powering off the Global Operator Cabinet (GOC). This is the preferred method because it does not corrupt the files on the hard drive.

Procedure

  1. Momentarily press the power button. (For Dell ICN, the green LED is also the power button.) This brings down the ICN in a soft method. It takes a minute or two for the operating system to boot down.

    The Dell ICN is powered down if the green power LED located on the upper left side of the front of the ICN is not illuminated.

  2. If the OS freezes or is not responding, then the soft method did not work properly. In this case, hold the power button down for 6 seconds to force the power off.
