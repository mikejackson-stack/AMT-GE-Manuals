Installing Trellix antivirus for software version 30 and later

Use the Trellix ePolicy Orchestrator (ePO) to install Trellix antivirus software.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-60 minutes-
Required conditions
Antivirus Option Key installed on system.
IP Address and logon credentials for ePO server from customer IT.

About this task

Beginning at software release 30, the MR scanner comes with antivirus software installed but must be activated with an option key, if purchased. Antivirus software is an optional feature of the MR scanner. The antivirus software uses Trellix ePolicy Orchestrator (ePO) to schedule and automatically update the virus signature definition (DAT) files. This ePO server should be set up by and maintained by an on-site IT administrator. The MR scanner should be connected by the field engineer.

The Trellix ePO is a software server application that orchestrates the virus definition updates for all the clients configured on it. The antivirus option key purchased through catalog G7009SD activates the Trellix antivirus software on your MR scanner. However, this does not automatically enable the antivirus updates as and when released by Trellix. GE HealthCare strongly recommends that the customer set up an ePO server in the facility through which the MR system can get the latest virus definitions from Trellix as and when they are available.

GE Healthcare provides the license for the Trellix ePolicy Orchestrator upon purchase of the Antivirus option key through catalog G7009SD.

Note The ePO License key is included in the customer bulletin/letter delivered with G7009SD.

The customer takes on the responsibility of checking that they meet the product requirements, downloading the ePO software, and configuring the server appropriately. The system requirements for ePO can be found in the ePO installation guide on the Trellix website:

https://docs.trellix.com/bundle/endpoint-security-10.7.x-installation-guide-windows/page/GUID-AAF59512-ACEC-482B-9F65-C0DD7CF4F02C.html

After proper installation, the customer also owns the process of updating the ePO software in accordance to Trellix's recommendations.

Note If there is already an instance of the ePO server in your facility, the following steps to install the ePO server do not need to be done. Simply configure the MR system as a client on the ePO server per instructions provided in Connecting an MR system to a Trellix ePolicy Orchestrator (ePO) server.
Topic ID: task_m1t_v25_flb

Trellix ePO initial installation

Procedure

  • Trellix ePO should be installed by downloading the free demo from the Trellix website: https://www.trellix.com/downloads/my-products/. Then inserting the license key provided by GE HealthCare during the setup process in order to upgrade to the full licensed version of the software.
  • The customer should follow the installation steps for the Trellix ePO server installation and configuration procedure provided in Installing Trellix ePolicy Orchestrator (ePO).
Topic ID: task_xpq_w25_flb

Trellix ePO licensing

Procedure

  • During the ePO installation process, specifically after the Administrator Information step, the customer will be prompted to insert the license key in order to upgrade to the full version of the software. Apply the license key during this step.
  • If missed, it can also be entered in after the installation is completed by going to Trellix's ePO Settings or Software Catalog.
