Checking the MR scanner-IPM network connectivity

Confirm the network connections between the imaging device and the IPM application.

About this task

After the FE has configured the customer’s network information, the network communication must be checked by using curl commands. The curl commands will test data exchange between the modality device and certain IPM application activities to make sure these activities are running properly through the customer network.

Procedure

  1. In the MR scanner console, open a Command Prompt/C Shell.
  2. Run the appropriate curl commands for the regional IPM instance.
    Note During initial installation, the IPM Project Manager will provide the FE with the curl commands. If curl commands need to be run after initial installation, see Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972).
    Important If the IPM Agent is configured with a proxy server, the curl commands are slightly different. Refer to the Curl Command Options section in the Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972).
