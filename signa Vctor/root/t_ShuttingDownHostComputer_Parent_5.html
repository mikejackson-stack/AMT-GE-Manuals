Shutting down the host computer

Shutting down the host computer shuts down the system safely and turns off the power to the host computer.

About this task

  • Shutting down the host computer or powering down the MR system (for LX platform)
  • Shutting down/powering off the host computer (for CX platform)
Topic ID: task_vc3_kj5_pfc

Shutting down the host computer or powering down the MR system (for LX platform)

Procedure

  1. Click the arrow on the Tools High Level Access tab and click System Shutdown or System Power Off (as applicable).
  2. When prompted, click on the reason for the system shutdown: Daily, Service, or Other. Or click Cancel to exit the shutdown of your system.
    • The application begins to shut down, which can take up to 15 minutes.
    • When the shut down is completed, the screen goes blank and the computer turns off.
  3. To power on the system, see Starting up the host computer.
Topic ID: task_fxx_kj5_pfc

Shutting down/powering off the host computer (for CX platform)

Topic ID: task_t4r_hrm_rfc

Shutting down the system from the Overflow menu

Procedure

  1. From the main menu, click the Overflow icon to open the Overflow menu.
  2. From the Overflow menu select Tools.
  3. From the Tools menu select System Power Off.
  4. In the prompt, select the reason for power off.
Topic ID: task_byb_5xl_rfc

Shutdown Host Computer from System Tool

Procedure

  1. From the keyboard, press Alt F1 to open the root menu.
  2. From the Service Tools menu, click System Shutdown.
  3. Select the reason for power off to confirm.
    • The application begins to shut down, which can take less than 15 minutes.
    • When the shut down is complete, the screen goes blank and the computer turns off.
