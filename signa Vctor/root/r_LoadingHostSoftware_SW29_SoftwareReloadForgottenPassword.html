Reloading software version 30.1 and later (USB load only) for system recovery from forgotten passwords

Reload the host system software for software version 30 and later (USB load only) if you want to reset your passwords.

Notice
Potential software corruption
Never insert the USB Software Media on any other laptops or computers as it will likely corrupt the software on the media.
Loading software
StepProcedure for USB load only

Prerequisites

IMPORTANT: This upgrade erases all EA3 user accounts and settings. Check with the customer administrator or lead technician to record any custom user accounts and settings that they may have configured. Please work with your customer administrator to plan for manual creation of the user accounts following the completion of software upgrade.

    • Record the service license ID. This upgrade will most likely change the service license ID and the SSA licenses will need to be updated. On-site Internet connectivity is required. See Service licensing.
    • Record the CRM number, serial number and proxy settings from the Remote Service Platform (RSvP) agent configuration UI in case the SaveInfo did not contain these details.
    • Request customer to back up image data as needed.
    • If research software and hardware are installed, contact GE HealthCare Research Support for backup and restore instructions.
Note Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.

Required media
  • USB Software Media.
  • GE Equipment Maintenance Sticker (5661793).
  • M-Class SSA Hard Key (5431898-3).
  • Operator Manual DVD.
  • Service Pack DVD (as required).
  • Blank DVD (quantity as needed for SaveInfo).

Perform SaveInfo (Check Information instead if using an older SaveInfo media)

Saving information.

If you are unable to login to perform SaveInfo due to lost passwords, skip this step and use a previous/older SaveInfo media.

Load USB host system software

SINCE OLD PASSWORDS SHOULD NOT BE RESTORED DO NOT INSERT SAVEINFO MEDIA FOR THIS PART OF THE PROCESS.

Loading USB host system software

Note The Host OS Load, Applications Software Load, and ICN OS copy actions should complete automatically. The Configure ICN action may fail, which would be reported as a failure in the final report.

If any failures occur prior to the Applications Software Load completion, restart the Software Load process.

For a list of errors and possible actions during the software load procedure, see Troubleshooting the software load.

Restore w/o passwords
  1. After Applications software load is completed and Guided Install is available, insert the SaveInfo media.
  2. Do a Load GI operation using the SaveInfo media:
    1. File → Load GI Information from CD/DVD.
    2. Configure the correct time zone and date/time.
    3. Click Configure on every tab highlighted in blue color.
  3. Navigate to Save/Restore tab and click Restore w/o Passwords.
  4. RestoreInfo runs to completion without restoring OS passwords and EA3 accounts/settings and passwords.

Configuring the SIP, ICN, or VRE.

Install IRM

Installing IRM software.

RSvP registration

Register device with RSvP to establish remote connectivity. See Configuring the Remote Service Platform (RSvP). See Enabling the Remote Service Platform (RSvP) iLinq to enable iLinq. If more information on connectivity is needed, refer to InSite RSvP.

Install SSA

The SSA license is restored during the RestoreInfo process. This step is not necessary for re-installation unless the service license ID has been modified. If the service license ID has been modified, or if this is a new install, record the service license ID and contact OLE to generate a new license for the site.

See Managing SSA service licenses for information on how to record the service license ID.

See Loading service license softkey to load the license.

Update System configuration

Update the system configuration, hardware configuration, and Security levels for software version 30 and later configuration in Guided Install. Complete any other site configuration as needed in Guided Install and click Configure in each tab.

Loading proprietary software

Load the proprietary software.

Install options/option keys

RestoreInfo should have brought back all the option keys.

For the purchasable option keys, see Option key catalog matrix.

Install operator manual

Installing operator documentation (online help).

Install latest service pack (if required)

Loading software updates from the repository or CD/DVD.

Note Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.

Close Guided Install from File → Quit option and then reboot the system
  1. Set the date and time correctly before rest of the configurations. A wrong date or time setting could lead to safety issues.
  2. Closing Guided Install allows for the remainder of the USB installer actions including scantools (default) option keys install and upgrade mode checks for ICW. This step is critical for successful completion of software load, thus do not reboot the system without closing Guided Install.
  3. Guided Install may display messages stating that Product Configuration is not matching the option keys. If this message appears, make sure the hardware configuration is configured correctly and all required option keys for the configuration settings are installed.
  4. Remove the software installer USB key.
  5. Reboot the system.

Set up customer accounts and passwords (OS & EA3)

Setting up customer accounts and passwords (OS & EA3).

Setup EA3 gesvc password
  1. If the system is already booted in applications, click Lock Screen Switch User in the Service Desktop manager to access the Logon screen.
  2. Log in using the gesvc account. The default password is operator and this password will be forced to change on first use.
  3. Create the gesvc password.
  4. This password can continue to be used for the lifetime of the equipment as the gesvc login password for any service activity needed at site.
  5. The gesvc EA3 account is intended to be used as a password recovery mechanism in case the customer forgets their logon password.

Do a check scan
Note The first boot after a software upgrade will take a long time due to extended TPS Reset.

Doing a check scan.
