Configuring OpenVPN Client - MR Host as Client

About this task

An MR Host computer OpenVPN client configuration requires the IP address of the OpenVPN server. In the steps below the server IP address is represented by <SERVER-IP> (this SERVER-IP should be provided by site administrator). This string should be replaced by the OpenVPN server IP.

Procedure

  1. Insert the OpenVPNFIPS DVD into the DVD-RW drive.
  2. Run the following commands on the MR host computer in the command window:
    Note The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log off and then log back on as the correct EA3 user with the authorized permissions.
    Note The <SERVER-IP> is the same for both IPv4 and IPv6.
    1. In the root terminal type su - and press Enter.
    2. Enter the root password and press Enter.
    3. In the root terminal type ifconfig eth0 | grep inet and press Enter.
      Note This step is required to see that tun0 has not been added yet. This can be seen in the results of the command. Tun0 is added in the following steps.
    4. In the root terminal type mount /media/cdrom and press Enter.
    5. In the root terminal type bash /media/cdrom/inst/OpenVPNFIPS-install -c <SERVER-IP> and press Enter.

      Result

      The results display as follows:
      
            Shutting down openvpn [ OK ]
            Shutting down openvpn [ OK ]
            Starting openvpn: FIPS mode initialized [ OK ]
    6. In the root terminal type ifconfig tun0 and press Enter.

      Result

      The results display as follows:
      
            tun0      Link encap:UNSPEC  HWaddr 00-00-00-00-00-00-00-00-00-00-00-00-00-00-00-00
              inet addr:10.8.0.6  P-t-P:10.8.0.5  Mask:255.255.255.255
              UP POINTOPOINT RUNNING NOARP MULTICAST  MTU:1500  Metric:1
              RX packets:0 errors:0 dropped:0 overruns:0 frame:0
              TX packets:0 errors:0 dropped:0 overruns:0 carrier:0
              collisions:0 txqueuelen:100
              RX bytes:0 (0.0 b)  TX bytes:0 (0.0 b)
  3. The output of ifconfig tun0 above contains a tunnel interface tun0 which is assigned an address 10.8.0.x. If the OpenVPN server is not running yet, ifconfig tun0 may return nothing. When the server is running, it may be advisable to restart OpenVPN by running service openvpn stop; service openvpn start. In the root terminal type umount /media/cdrom and press Enter.
  4. If both client and server are an MR Host computer and have been configured as above, no further steps are required. If the client or server is not an MR Host computer, the corresponding OpenVPN configuration archive should be copied to the system serving as the OpenVPN client or server and the system setup accordingly.
    • Client: /etc/openvpn/client.cfg.tgz.
    • Server: /etc/openvpn/server.cfg.tgz.
  5. In the root terminal type chkconfig openvpn on and press Enter.
