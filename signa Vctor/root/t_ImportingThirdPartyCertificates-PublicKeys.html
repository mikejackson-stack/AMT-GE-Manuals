Importing third-party certificates - public keys

Import the third-party certificate using a public key from a USB flash drive.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-20 to 30 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
USB Flash Drive1--

About this task

The keys that are used in the certificate management process are private keys and public keys. A public key is provided to clients who send a request to the host. A private key is sent back to the host from the client, which is encrypted using the public key.

Third-party certificates are provided by a Certificate Authority (CA) to the host after a request by the IT professional. When the client attempts to connect to the host, the host will provide the third-party certificate to the client upon the request for connection. This is in conjunction with/as the certificate.

Procedure

  1. Insert the USB flash drive containing the third-party certificates into the Global Operator Console (GOC).
  2. On MR Service Desktop, click Service Browser.

    Result

    The Certificate Management browser opens.
  3. Click the Utilities tab.
  4. In the left toolbar, select Security Tools > Certificate Management.
  5. Click Click here to go to the link.

    Result

    The Certificate Management window opens.
  6. Click Import Third Party Certificate.

    Result

    The window refreshes with the applicable fields to populate.
  7. Enter the file name of the certificate as it will be stored on the client's server into the Certificate Name field.
  8. Import the certificate using one of the following:
    • Select the correct storage device from the Select USB menu.
    • Select the certificate type from the Certificate Content menu.

    or

    • Enter the certificate path in the Certificate URL field. For example: /home/certificates/servercertificate.pem
  9. Click Submit.
  10. When the dialog confirmation window appears, click Accept.

    Result

    The message Certificate Saved Successfully opens below the Submit button that confirms the certificate was successfully imported.
