Installing host system software

This quick start guide provides an overview of the procedures required to load host system software. Refer to the tasks included within this procedure for detailed information.

Choose from one of the following installation workflows:
  • USB software installation
  • Remote software download
  • Software Version 30.1 and later (USB and IRIS load)
    Install or upgrade the host system software for Software Version 30.1 and later (USB and IRIS load).

    Installing system software - remote software download only.
