Upgrading Software Version 30 and later (USB load only)

Upgrade the host system software from Software Version 30 (USB load only).

Notice
Potential software corruption
Never insert the USB Software Media on any other laptops or computers as it will likely corrupt the software on the media.
Note Most process steps have been automated in the software load. Any failures will appear in the installation window and are required to be fixed in Guided Install. Automated process steps have been included in the workflow.
Note (For software version MR30.2 and later) If the system is not qualified, a warning window will show. More information can be found in System Health Alert.
Loading software
StepProcedure for USB load only

Prerequisites
  • IMPORTANT: This upgrade erases all EA3 user accounts and settings. Check with the customer administrator or lead technician to record any custom user accounts and settings that they may have configured. Please work with your customer administrator to plan for manual creation of the user accounts after the completion of software upgrade.
  • Record the service license ID. This upgrade will most likely change the service license ID and the SSA licenses will need to be updated. On-site Internet connectivity is required. See Service licensing.
  • Request customer to back up image data as needed.
  • If research software and hardware are installed, contact GE HealthCare Research Support for backup and restore instructions.

  • Check with the site IT team regarding InSite RSvP connectivity and collect the following information:

    How will the site connect to InSite RSvP?
    1. Site DNS Server, Primary DNS IP Address: ___.___.___.___ , Secondary DNS IP address: ___.___.___.___
    2. Site Proxy Server, Proxy Server IP address: ___.___.___.___, Port#:___, Proxy Login credentials as applicable.
    3. GE VPN Proxy Server, ensure that the region connectivity team has setup VPN tunnel for this site. The same team, will also provide Proxy IP address and port number details.
  • Active SSA Class M hard key is required.
  • Update the eLicense portal to map the GON number with System ID and generate the applicable option keys for the site.
Note Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library, and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.

Required media
  • SV29.1 USB Installer with Label (5871260) or Software Version 30 USB Installer.
  • M-Class SSA Hard Key (5431898-3).
  • Operator Manual DVD/USB.
  • Service Pack DVD/USB (as required).

Perform SaveInfo (Check Information instead if using an older SaveInfo media)

Saving information.

Load USB host system software

Reloading or upgrading USB host system software

Note If a RestoreInfo media with all the required files is available, then Host OS load, Applications Software Load, ICN Configuration, and SSA licenses, including restore of connectivity settings, are all automatically executed sequentially.
Note Beginning with software release 30 software restoring information will automatically set the PNF Filter setting to ON regardless of previous setting. Make sure you reset the PNF filter to previous setting after consulting with the customer.

In case any failures are observed, after the completion of applications software load, a dialog box appears showing all remaining tasks that need to be completed. To complete these tasks manually, see the procedures in this table.

If any failures occur prior to the applications software load completion, restart the software load process.

For a list of errors and possible actions during the software load process, see Troubleshooting the software load.

Configure ICN (VRE) OS

This task is automated for software reinstallations and upgrades if the RestoreInfo action is successful.

In case of any failure, this can be attempted manually. See Configuring the SIP, ICN, or VRE.

Loading proprietary software

This task is automated. In case of any failure, this can be attempted manually.

RSvP registration

This task is automated for software reinstallations and upgrades if the RestoreInfo action is successful.

Register device with RSvP to establish remote connectivity. See Configuring the Remote Service Platform (RSvP). See Enabling the Remote Service Platform (RSvP) iLinq to enable iLinq.

Install SSA

This task is automated for software reinstallations and upgrades if the RestoreInfo action is successful.

If you are upgrading to any of the following software revisions or later, software version 30, or changing the host PC or any of its components, the SSA 16-digit license code will change. Additionally, the SSA API requires an additional signature file. This requires the SSA soft key license for the site to be regenerated and both files (.dat & .ssa) must be reloaded to the host computer.

See Managing SSA service licenses for information on how to record the service license ID.

See Ordering service license softkey to order the license.

See Loading service license softkey to load the license.

Update System configuration

This task is automated for software reinstallations and upgrades if the RestoreInfo action is successful.

Update the system configuration, hardware configuration, and Security levels for software version 30 and later configuration in Guided Install. Complete any other site configuration as needed in Guided Install and click Configure in each tab.

Update software eLicense with new host IDSee Installing software options with eLicense generated keys.

For the purchasable option keys, see Option key catalog matrix.

Note Signa Secure Advanced option: If the customer purchased this license, configure the security setting in Guided Install to Signa Secure Advanced. The system must be restarted to enable the highest security configuration in Guided Install.

Install operator manual

Install latest service pack (if required)

See Loading software updates from the repository or CD/DVD or Remote software download.

(For the software version 30 and later) See Loading service pack from USB installer or Remote software download.

Note Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library, and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.

Close Guided Install from File → Quit option and then reboot the system
  1. Set the date and time correctly before setting the remaining configurations. A wrong date or time setting could lead to safety issues.
  2. Closing Guided Install allows for the remainder of the USB installer actions including scantools (default) option keys install and upgrade mode checks for ICW. This step is critical for successful completion of software load, thus do not reboot the system without closing Guided Install.
  3. Guided Install may display messages stating that Product Configuration is not matching the option keys. If this message appears, make sure the hardware configuration is configured correctly and all required option keys for the configuration settings are installed.
  4. Remove the software installer USB Key.
  5. Fill out the label on the software installer USB key with the current version of software.
  6. Reboot the system.

Set up customer accounts and passwords (OS & EA3)

Setting up customer accounts and passwords (OS & EA3).

Set up EA3 gesvc password
  1. If the system is already booted in applications, click Lock Screen Switch User in the Service Desktop manager to access the Logon screen.
  2. Log on using the gesvc account. The default password is operator and this password will be forced to change on first use.
  3. Create the gesvc password.
  4. This password can continue to be used for the lifetime of the equipment as the gesvc login password for any service activity needed at site.
  5. The gesvc EA3 account is intended to be used as a password recovery mechanism in case the customer forgets their logon password.

EA3 User Group Establishment

Add EA3 users to their correct user groups to establish the correct permissions. For information on adding user groups, see Configure user accounts for Role Based access controls.

  • GESoftwareInstallerGroup
  • ProtocolEdit
Add the administrator user to groups:
  • GESoftwareInstallerGroup
