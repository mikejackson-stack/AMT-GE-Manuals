Head Neck Array (HNA)/Posterior Array (PA) Check

Procedure

  1. Connect the HNA cable to Port B of MR System.
  2. Position the HNA and the phantoms. Make sure to use the phantom positioner and that the HNU pad is underneath the phantoms.
  3. Landmark on the HNA coil marking.
  4. Perform the QA Check using Multi-Coil Quality Assurance Tool procedure.

Anterior Array /Posterior Array Coil Check

Procedure

  1. Connect the AA cable.
  2. Position the Phantoms on the cradle between marker 3 and marker 4. Make sure that the space between the phantoms is aligned with the line between marker 3 and marker 4. Place the AA coil on top of the phantoms. Make sure that the marker line between A, B are aligned with the space between the phantoms.
  3. Wrap the strap around coil.
  4. Landmark on the AA coil marking.
  5. Perform the QA Check using Multi-Coil Quality Assurance Tool procedure.
  6. Take note of which Test# and which Sig_Img failed (if any). To determine which coil/s has issue, refer to the matrix below.

    For coil layout, refer to Element layout section of this document.

  7. Place the AA coil on top of the phantoms. Make sure that the maker line between B, C are aligned with the space between the phantoms.
  8. Wrap the strap around coil.
  9. Landmark on the AA coil marking.
  10. Perform the QA Check using Multi-Coil Quality Assurance Tool procedure.
  11. Take note of which Test# and which Sig_Img failed (if any). To determine which coil/s has issue, refer to the matrix below.

  12. Remove the AA Coil.
