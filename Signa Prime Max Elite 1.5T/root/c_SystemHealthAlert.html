System Health Alert

A set of software warnings to tell users of decreased system performance.

The System Health Alert is a software feature that examines the system calibration and performance. The display shows the user the system status, along with recommendations (if any issues are detected). This feature was introduced in software version 30.2.

Overview

If issues are found, the alert shows daily until the issues are resolved. The alert shows after the system is powered on or after the first scan of the day.

The alert shows in these scenarios:
  • Hardware replacement without correct calibration
  • Planned Maintenance (PM) not completed
  • Hardware not identified

Hardware replacement without correct calibration

This alert can be triggered because:
  • A hardware component was replaced without completing necessary calibrations or functional checks. For example, if the RF Amplifier was replaced without completing the power monitor functional checks [in the RF Amp and Power Monitor (RAP) Tool]] and System Performance Test (SPT) tool.
  • The SaveInfo media used for a software installation or upgrade contained incomplete or failed results for the necessary calibration or functional checks. Make sure that the necessary calibrations and checks are completed after replacing a hardware component or before a software upgrade.

PM not completed

This alert can be triggered because:
  • PM is overdue (for example, the current date is 180 days after the last PM Registered date).
  • PM is overdue in the SaveInfo media used for a software installation or upgrade.
  • Any of the PM check tool results are incomplete, failed, or tampered.
Make sure that the PM is completed as per schedule and that these tools have passing results:
  • Doing the System Performance Test (SPT)
  • Calibrating LVShim
  • Doing the EPI White Pixel Test (PM mode)

Hardware not identified

This alert can be triggered if a hardware component can not be identified by the system. This could be the result of unauthorized hardware being installed, a hardware defect, a Controller Area Network (CAN) communication issue, or a software issue.

Make sure that authorized FRUs are used for replacements. Make sure that the hardware components are powered ON and the cables are connected correctly. Do a TPS reset or system reboot. If the issue is not resolved, contact your local service team.
