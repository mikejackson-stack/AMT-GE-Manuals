Finalizing the CMOS battery replacement - HP Z4 G5

Finalize the replacement of the CMOS battery in the HP Z4 G5 host computer.

Procedure

  1. Remove GOC LOTO. See Removing LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
  2. Set up the BIOS. See Setting up the BIOS for the host computer for the HP Z4 G5.
  3. Make sure that the host computer front panel power LED is illuminated as a steady blue signal.
  4. Do a check scan to make sure the system and applications are working correctly. See Doing a check scan.
  5. Make sure that all customer functions are operational (auto voice, filming, network, archive).
  6. Follow the local or site regulations for battery disposal.
