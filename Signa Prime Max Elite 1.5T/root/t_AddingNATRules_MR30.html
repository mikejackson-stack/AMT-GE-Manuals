Adding NAT rules

Add NAT rules.

Prerequisites

The sequence of how NAT rules are added is important. All IPv6 translations must be configured in the following order:
  • DICOM server
  • PHI server
  • NTP server
  • WinSysLog server
  • LDAP server
  • Trellix ePO server

Procedure

  1. In the left navigation panel, select NAT Rules.
  2. Click Add.
  3. Under Match Criteria: Original Packet:
    1. in the Source Address field, select the MR Host IPv4 internal address object name
    2. in the Destination Address field, select the external server translated IPv4 internal address object name
  4. Under Action: Translated Packet:
    1. set the Source NAT Type field to Static
    2. in the Source Address field, select the MR Host IPv6 external address object name
    3. in the Destination Address field, select the external server IPv6 address object name
  5. Select the Use one-to-one address translation check box.
  6. Click OK.
  7. Repeat Step 2 through Step 4.
  8. Click Add.
  9. Under Match Criteria: Original Packet:
    1. set the Source Address field to Any
    2. in the Destination Address field, select the MR Host external IPv4 address object name
  10. Under Action: Translated Packet:
    1. set the Source NAT Type field to Static
    2. set the Source Address field to Original
    3. in the Destination Address field, select the MR Host internal IPv4 address object name
  11. Select the Use one-to-one address translation check box.
  12. Click Apply.
  13. Click Save.
