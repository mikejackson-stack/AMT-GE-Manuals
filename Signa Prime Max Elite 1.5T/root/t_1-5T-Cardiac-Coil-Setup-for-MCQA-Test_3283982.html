Required conditions
For HDx, HDxt and HDe, the following coil configuration names must be installed to run this tool: HDx CardiacServ.
For Discovery MR450 and Optima MR450w, the following coil configuration names must be installed to run this tool: GE_HDx 8Cardiac.

About this task

This procedure prepares for the automated SNR test using the 1.5T HDx Cardiac Array by GE/USAI, catalog M3335MD.
Note Coils do not ship with phantoms. Phantoms come in a unified phantom set with the MR system.
Topic ID: id_SL2924734-624407

Unified Phantom Setup

Procedure

  1. Place the posterior section of the coil on the table as shown.
  2. Place the TL Unified Phantoms over the posterior section so the phantom set is well centered in the S/I and R/L directions as shown in both illustrations below.
  3. Place the anterior section onto the phantom set so the coil is well centered in both S/I and R/L directions as shown.
  4. Fasten the Velcro® straps to firmly snug the coil to the phantom as shown below.
  5. Connect the coil to Port A of the system's LPCA.
  6. Landmark the coil at the crosshairs as shown below, and Advance to Scan.
  7. Proceed to the Multi-Coil Quality Assurance Tool to test the coil.
