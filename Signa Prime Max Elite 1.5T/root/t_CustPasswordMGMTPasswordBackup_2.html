Password backup

About this task

The customer is responsible to save and maintain the passwords such that the system is accessible for use at all times. The method to back up the passwords is a customer prerogative and GEHC does not take any ownership or responsibility for lost passwords.

In order to maintain service continuity, and provided there is a valid service contract with the customer, GEHC will back up the passwords either remotely or through manual means. The details of the passwords backed up and the methods used are provided below:

Topic ID: task_nvp_n2q_nlb

Connected sites

Procedure

  1. If connectivity is available at the time of changing the passwords the new passwords are immediately submitted to the FFA Vault.
  2. The passwords for the following accounts are backed up in FFA:
    1. OS accounts root, sdc, insite
      Note The sdc OS account is not available for software version 30.2 and later.
    2. EA3 account gesvc
  3. If connectivity is not immediately available the last entered password is queued and FFA password vault is undated when connectivity is restored.
Topic ID: task_hn1_42q_nlb

Non-connected sites

About this task

If you have access to Field Force Automation (FFA), the password vault can be updated on the FFA site (https://ffa.cloud.ge-healthcare.net. Refer to the Field Force Automation (FFA) User’s Guide (DOC2333725).

Procedure

  1. GE HealthCare FE will need to contact the regional connectivity team to update user accounts and password for the asset in the regional CRMs.
