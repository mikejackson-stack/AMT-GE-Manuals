Installing full software releases from Remote Software Download (RSD) for software version 30.2 and later

Install full software releases from Remote Software Download (RSD) for software version 30.2 and later.

Note Most process steps have been automated in the software load. Any failures will appear in the installation window and are required to be fixed in Guided Install. Automated process steps have been included in the workflow.
Note (For upgrade to MR30.2 and later) If the system is not qualified, a warning window will show. More information can be found in System Health Alert.

Load host system software from RSDInstalling host system software from Remote Software Download (RSD) for software version 30.2 and later.
Note Remote software download will do a SaveInfo to the eDelivery partition prior to starting software installation. Software versions 30.2 and later will use that most recent SaveInfo found on the system. Host OS load, Applications Software Load, ICN Configuration, IRM software and SSA licenses, including restore of connectivity settings, are all automatically executed sequentially.
Note Beginning with software release 30 software restoring information will automatically set the PNF Filter setting to ON regardless of previous setting. Make sure you reset the PNF filter to previous setting after consulting with the customer.

In case any failures are observed, after the completion of applications software load, a dialog box appears showing all remaining tasks that need to be completed. To complete these tasks manually, see the procedures in this table.

If any failures occur prior to the applications software load completion, restart the software load process.

For a list of errors and possible actions during the software load process, see Troubleshooting the software load.

The following tasks will be completed automatically during software installation:
  • ICN (VRE) OS Configuration. In case of failure, this can be attempted manually. See Configuring the SIP, ICN, or VRE.
    Note (For software version MR30.1_R04 and later) VRE configuration may take up to 4 hours if the scanner is configured to an invalid MGD subnet or other ICN communication fault. For more information, see VRE subnet automatic configuration.
  • IRM installation. In case of any failure, this can be attempted manually. See Installing IRM software.
  • RSvP registration. If manual RSvP registration is required, see Configuring the Remote Service Platform (RSvP). To enable iLinq, see Enabling the Remote Service Platform (RSvP) iLinq.
  • Install SSA. See Managing SSA service licenses for information on how to record the service license ID. See Ordering service license softkey to order the license. See Loading service license softkey to load the license.
  • Install options/option keys. Option keys will be loaded from SaveInfo. If any option keys still need to be loaded, see Distributing and installing eLicenses for software options for software options.
    Note Signa Secure Advanced option: If the customer purchased this license, configure the security setting in Guided Install to Signa Secure Advanced. The system must be restarted to enable the highest security configuration in Guided Install.

Close Guided Install from File → Quit option and then reboot the system
Note The first boot after a software upgrade will take a long time due to extended TPS Reset.
  1. Set the date and time correctly before setting the remaining configurations. A wrong date or time setting could lead to safety issues.
  2. Closing Guided Install allows for the remainder of the installer actions including scantools (default) option keys install and upgrade mode checks for ICW. This step is critical for successful completion of software load, thus do not reboot the system without closing Guided Install.
  3. Guided Install may display messages stating that Product Configuration is not matching the option keys. If this message appears, make sure the hardware configuration is configured correctly and all required option keys for the configuration settings are installed.
  4. Reboot the system and start the system software. Click Start and enter EA3 username and password.
    Note The system may restart automatically after Guided Install has closed.
