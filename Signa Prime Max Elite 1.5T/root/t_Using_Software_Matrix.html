Using the Software Matrix

How to use the Software Matrix to perform the software revision check for safety during Planned Maintenance.

Procedure

  1. Access DOC1667089 (Software Matrix) from the online documentation library.
  2. Make sure you are on tab "ePM Form Data" within the spreadsheet.
  3. In the dropdown menu for Input 1, select the product name as it is shown in "About MR Scanner".
  4. In the dropdown menu for Input 2, select the product name as it is shown on GI (Short Name).
  5. In the dropdown menu for Input 3, select the Site Subregion.
    Note Some regions may be identified as Global in the datasheet. If “N/A” shows up in Output, choose “Global” instead.
  6. In the dropdown menu for Input 4, select the Software Revision that is on the system.
  7. Optional for Input 5: Type in the number of the Service Pack installed on the system, if that information is available.
  8. After the inputs are filled correctly, information will show up automatically in the Output cells.
    1. Output 1 lists the latest Applications Software Version. Record this information on the ePM form.
    2. Output 3 lists the latest Minimum Safety Service Pack. Record this information on the ePM form.
