Updating Trellix ePolicy Orchestrator (ePO)

After the Trellix ePolicy Orchestrator (ePO) ePO server is properly installed by the customer, the customer also owns the process of updating the ePO software in accordance to Trellix’s recommendations. These steps are only to be referenced by the FE if the customer has questions.

Prerequisites

Note This task is to be done by the customer IT. The information in this topic is just informational for the FE, and not for the FE to actually complete.
Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
--30 minutes of customer IT time. The GE HealthCare FE does not need to be on site.-

About this task

Procedure

  1. Download the ePO latest update from the Trellix website. The different ePO packages can be found here: https://www.trellix.com/downloads/my-products/.
  2. Locate downloaded software and extract the compressed file into preferred location.
    Note If you try to run the updater without first extracting the files, the installation will fail.
  3. Find the ePOUpdater executable file in the installation folder, right-click, and select Run as Administrator.
  4. After the updater starts, enter the following information and click Continue:
    • Database Name
    • Database Server Name
      Note Remember to enter the server name, continued by a backslash and MSSQLSERVER, similarly to the initial software installation process.
    • Port Number
      Note Default SQL UDP port is 1434, but type in the port number selected in the installation process if you are not going with the default port assignments.
    • User Name
    • Password
  5. On the Current Update screen, make sure the update selected is the latest update available to you, and click Continue.
  6. An Apply Update window will show and ask whether you would like to have the TrellixFtp source site automatically update. Checking the box is optional, but recommended. Click OK.
  7. In the next window, wait for all the updates to be applied and then click Finish. Your Trellix EPolicy Orchestrator is now ready to be run.
