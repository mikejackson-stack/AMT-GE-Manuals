Doing power monitor function check for head

Procedure

  1. Cable setup for check.
    1. Unplug the cable from OM J8 and Rear Pedestal dummy load.
    2. Disconnect cable connection (M1336) from OM J4 and DPP Rx Dist J13.
    3. Get the extension cable (5860974) from system cabinet left side.
    4. Connect the M1336 and extension cable 5860974 together, then one end to the dummy load, the other end to the OM J8.
  2. No phantom is needed. Landmark on cradle and press the Advance to scan.
  3. Bypass the monitoring by enabling Local TR error mask on Service Panel.
  4. Enable RF on Service Panel.
    Note RF will be automatically disabled while any error mask is enable. Make sure RF is enable before going on with this test.
  5. On the Common Service Desktop, from the Calibration menu, select Calibration > RAP Tool and select Click here to start this tool.
  6. Select RF chain to Head.
  7. Click Start.
  8. Click Yes when the prompt asks if the hardware setup is correct.
  9. Prompts are displayed during test execution, including a pop up message about the UPM tripping and a power trip error message. Do not click Yes or No. Check the error log in CSD first.
  10. From the CSD, open the error log. Verify that the error log contains the message that the UPM has “detected a power fault on Head Short Term Average.” If so, select Yes on the pop up message.
  11. View the results. If all tests pass, select Exit .
  12. Restore the cable connection with OM/Dummy load/Rx dist.
  13. A TPS Reset must be performed when testing is complete before scanning resume.
  • Transmit chain LED and toggle UI substitute
    This is a substitute action before the LEDs and toggle UI is ready to use.
