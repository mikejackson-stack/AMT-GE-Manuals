Formatting the USB flash drive

Format the USB flash drive to save and restore system data.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-10 minutes-
Consumables
ItemQuantityPart numberManufacturer
Save-Restore USB with Label15969477-

About this task

The USB flash drive must have a supported file format. If it does not have a supported file format, the USB flash drive will not be able to mount, and the following error message will show. This procedure describes the acceptable file system formats and how to change the format of the USB flash drive.
Note The supported USB flash drive formats include FAT, exFAT, vFAT, and NTFS. The recommended size of the USB flash drive is 64 GB.
Notice
Possible data loss
When a USB flash drive is formatted, all existing files on the drive are deleted.

Procedure

Format the USB flash drive using either a Windows laptop computer or the MR host computer.
Type of computerSteps in procedure
Laptop (Windows)
  1. Insert the USB flash drive into any USB port on the laptop.
  2. Open Windows File Explorer and locate the USB flash drive.
  3. Right-click on the USB flash drive.
  4. Select Format on the menu.

    A Format USB Drive window opens.

  5. Under File system, select an acceptable format.
    Table 1. Acceptable file system formats
    Software operating systemAcceptable formats
    SUSE O.S.NTFS, FAT, exFAT, and vFAT
  6. Click Start to format the drive.
  7. Click OK on the Format complete window.
  8. Close the Format USB Drive window.
  9. When the drive has been formatted, disconnect the USB flash drive so that it does not become corrupted. Under the Start menu, locate This PC. Right-click on the USB flash drive and select Eject.
  10. Close all windows and remove the USB flash drive from the laptop.
MR host computer (Linux)
  1. Insert the USB flash drive into any USB port on the host computer.
  2. Go to the Service Desktop.
  3. Open a C Shell.
  4. To find the systems USB drive device designation, type: Isblk-f

    Result: This gives the location of the USB drive. Use the location in the next step.

  5. Based on Acceptable file system formats, select the appropriate format and run the following command:
    Note In the text below, USB_drive_location is the result of the Isblk-f command.
    • (For FAT format) Type: mkfs.fat -I /dev/USB_drive_location
    • (For vFAT format) Type: mkfs.vfat -I /dev/USB_drive_location
    • (For exFAT format) Type: mkfs.exfat /dev/USB_drive_location
    • (For NTFS format) Type: mkfs.ntfs /dev/USB_drive_location
  6. After the drive is formatted, eject the USB flash drive. Go to the Browser and click the Eject button. When the drive is ejected in this way, it does not become corrupted.

  7. Close all windows and remove the USB flash drive from the host computer.
