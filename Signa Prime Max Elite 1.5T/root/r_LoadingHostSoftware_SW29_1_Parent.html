Software Version 30.1 and later (USB and IRIS load)

Install or upgrade the host system software for Software Version 30.1 and later (USB and IRIS load).

Beginning with software release 30.1, the software load procedure has been split into different workflows. Be sure to select the link for the specific instance you require.

Note Before beginning, talk with your customer administrator to identify the user accounts they will want to create during the setup process. See MR customer password management process and Password rules.
  • For a new installation, see Installing Software Version 30.1 (USB load only) on a new system.
  • If you need to reload the host system software, see Reloading Software Version 30.1 and later (USB load only).
  • If you need to reload the host system software because of forgetting passwords, see Reloading software for system recovery from forgotten passwords.
  • Installing Software Version 30.1 (USB load only) on a new system
    Install the host system software for or MR30Software Version 30.1 (USB load only).
  • Upgrading from previous software versions (IRIS installation)
    Install the host system software for software releases after Software Version 30 (IRIS load only).
  • Upgrading Software Version 30 and later (USB load only)
    Upgrade the host system software from Software Version 30 (USB load only).
  • Reloading Software Version 30.1 and later (USB load only)
    Reload the host system software for MR30 and later (USB load only) if you do not want to reset your passwords.
  • Reloading software for system recovery from forgotten passwords
    Reload the host system software for and later (USB load only) if you want to reset your passwords.
