Replacing the sensor flag

Procedure

  1. Remove the left rear pedestal cover. See Removing the rear pedestal covers.
  2. Move the LPCA to IN direction as shown illustration. (Reference Value 180 mm to IN direction)
  3. Check that there is Sensor Flag at position of illustration.
  4. Shut down and power off the host computer. See Shutting down the host computer.
  5. Apply LOTO to the ISC. See Applying LOTO - Integrated System Cabinet (ISC).
  6. Loosen the belt tension with belt tension lever.
  7. Remove the Sensor Flag by removing the 2 screws.
  8. Install the new sensor flag by reversing the order of the removal.
  9. To ensure the cables under bridge have been tightened by ribbons.
  10. Move table advance to reach home position, and double check there is no contact between cables (under bridge) and home sensor flag when cradle belt is moving.

Finalization

  1. Restore the rear pedestal covers. See Installing the rear pedestal covers.
  2. Remove ISC LOTO. See Removing LOTO - Integrated System Cabinet (ISC).
  3. Start up the host computer/system. See Starting up the host computer .
  4. Calibrate the longitudinal drive. See Calibrating the longitudinal drive.
  5. Do DQA calibration. See Doing DQA calibration with the DQA III phantom.
