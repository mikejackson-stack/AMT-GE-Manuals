Product Network Filters (PNF) for software version 29.0 and later

Use these steps to set filters that restrict which system services are allowed to be controlled by other devices trying to access the Operator console.

Topic ID: concept_cgb_1sy_zmb

Overview

Product Network Filters (PNF) is a software firewall tool that lets a site Network Administrator control traffic from the site's internal network to the Diagnostic Imaging System. This tool was created in response to the customer's need for security.

Upon installation, PNF automatically enables itself to start after every reboot by default.

  1. To be able to make changes to the PNF, log on with an Enterprise Authentication Authorization Audit (EA3) user account that is a part of the Administrator group. Some features are only available when logged on with a Class M SSA key or with Research Option Key.
  2. Click the Utilities tab on the Common Service Desktop (CSD) and select Product Network Filter.
  3. Click Click here to go to the link.
    Note: When accessing PNF configuration, the firewall status shows Pause, but is still turned On.
  4. The main page of PNF configuration will show.
    Note: The ability to turn off the firewall is now limited to GE service users and research admins.
Topic ID: concept_kvf_bsy_zmb

Firewall rules (filters)

Notice
The system ships with factory default firewall rules already loaded and firewall turned On. Factory defaults effectively isolate the system's external Ethernet connection (eth2) from the hospital backbone.
Generally, firewall rule creation is not necessary.
(For RX 29.1 and later) The ability to create rules for non-standard ports is now limited to GE service users with an M-Class key and research admins.

Edit or add a rule

Notice
Editing or adding of rules should not be done unless the user understands what is required and has been trained or guided appropriately. Changes to the rules may cause improper networking functionality, which may also cause applications to fail on the system.
  1. By expanding Named Services, the user will see all rules applied as well as the Edit, Delete, and Add a rule buttons.
  2. Click Edit to open the Edit a firewall rule page.
    Note: Only whitelisted ports are able to be edited while signed in as an EA3 Administrator user.
  3. Make changes required and then click Save.
  4. Adding a rule in the category may be accomplished by clicking the Add a rule button and completing the necessary information in the Add a Rule page.
  5. Rules previously created may be deleted by selecting Delete.
Topic ID: concept_ccl_hsy_zmb

Backup current rules

Use this feature for creating a backup of the firewall rules once the system has been fully installed, the options loaded, and the application features configured. This backup can be used to restore the firewall rules if software corruption occurs or to recover from improper configuration attempts. Also note that the firewall rules are included in the system state backup. The backup cannot be used to restore the firewall rules when updating to new software.

To create a backup of the firewall rules:

  1. Click the Backup Current Rules link on the PNF Configuration page.
  2. The Backup page will open.
  3. Enter a Backup Name for the backup file, then click Save.

The backup file will be created and saved in the /usr/share/gehc_security/pnf/backups directory. The filename is a combination of the date and the name the user applied to the backup.

Topic ID: concept_rk5_3sy_zmb

Restore from backups

To restore a backup of the firewall rules:

  1. Click the Restore from Backups link on the PNF Configuration page.
  2. The Restore rules from backup page will open.
    Note: User may quit the Restore rules from backup page at any time by clicking Close.
  3. Select the desired backup file from the list.
  4. Once the backup file is selected, click Apply Rules to load rules to the system.
  5. Click OK to restore and apply firewall rules.
    Note: The new rules are applied automatically and the firewall is restarted. It is not necessary to manually restart the firewall.
Topic ID: concept_ttr_cqt_mnb

Finalization

  1. Close the Service Desktop.
  2. If changes have been made in the PNF configuration, run save System State. Run System State - Save and Restore from the Software procedure list.
