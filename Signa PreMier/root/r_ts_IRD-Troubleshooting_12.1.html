Troubleshooting the In-Room Display (IRD) - 12.1 inch IRD

Diagnose and fix issues with the 12.1 inch IRD screen.

Notice
If any IRD cables or components are swapped for troubleshooting, return to their original position before performing the next action.
Notice
Read the following for swapping during troubleshooting.
  • For IRD swap, ISC PDU LOTO is required.
  • For DP optical cable and USB optical cable, hot swap is accepted. Be careful not to disconnect the other cable.

Troubleshooting steps

Note: At any point during the troubleshooting, if the DP AOC cables are connected to any other open mini DP port, re-install IRM software to make sure that the IRDs are functional.

Make sure the IRDs have power

If there is no power, confirm M3314 connections to ISC PW/PEN > PHPS2 > J42 and ISC PW Filter > J143.

For systems with Remote (off the wall) siting configuration:

  1. Confirm E3314 connections to ISC PW/PEN > J42 and ISC > Cabinet IF > J42.
  2. Confirm E3302 connections to ISC PW/PEN > J40 and ISC > Cabinet IF > J40.

Replace cables if necessary.

Note: The 14V output from the PHPS supplies the IRD display back light. The 8V output from the DCPS supplies the IRD touch circuitry and IRD display

Make sure the fiber optic cables are connected

Make sure the USB fiber optic cables P5006 are properly connected to the correct USB 3.1 ports on the GOC. Refer to Figure 1 for more information.

Make sure the connections are clean

  1. Disconnect the PHPS power, DP, and USB 3.0 cables from the IRD(s).
  2. Check the connectors for debris or damage and clean or replace if required.
  3. Reconnect the cables.

Make sure the IRDs are connected to the host PC

Make sure that two displays and two mouse devices are detected by the Host PC.

If necessary, re-install IRM software to resolve problem. See Figure 7.

Resolve issue if one of the IRDs does not work

Note: When troubleshooting, connect cables from GOC to IRD before routing the cables to make sure that IRD is functional. Route cables once IRD functionality is confirmed.
  1. Re-install the IRM software and check if the issue is resolved. See Figure 7.
  2. Swap the malfunctioning IRD and working IRD.

    Follow these procedures to remove the control panel covers:

    • Removing the magnet left- and right-hand lower access panels
    • Removing the dockable table interface cover
    • Removing the magnet left and right control panel covers

    If the same IRD is malfunctioning, then replace the IRD. Follow the instructions in Replacing the In-Room Display (IRD) - 12.1 inch IRD.

  3. If the problem moves to the other IRD, there may be a problem with the cables or the GOC port.
    1. Go to the GOC and make sure that the cables are properly seated and connected as described in the block diagram. If no issues are found go to the next step.
    2. For touch related issues, swap the USB cable connections on the GOC ports.
      • If the problem stays on the same IRD, replace the USB cable.
      • If the problem moves to the other side IRD, there could be a problem with the GOC port.
        1. Move the USB connections back to the default ports. Restart the Host PC to see if that resolves the issue.
        2. If problem is not resolved, connect the USB cable to an open USB port. Restart the Host PC to see if that resolves the issue.
        3. If no open USB ports are available or if the problem is not resolved by restarting the Host PC, replace the Host PC.
    3. For display related issues, swap the mini DP cable connections on the GOC ports including the dongle.
      Important: Handle the cables carefully, the fiber optic cables are easily damaged and have a minimum bend radius of 50 mm.
      • If the problem stays on the same IRD, swap the Mini DP to DP Dongle for port 1 (5851077-2 ) with the Mini DP to DP Dongle for port 2 (5851077-3) to check if the issue is with the dongle.

        If the problem stays on the same IRD, replace the cable. Otherwise replace the Mini DP to DP Dongle.

      • If the problem moves to the other side IRD, there could be a problem with the GOC port.
        1. Move the DP connections back to the default ports. Re-install the IRM software to see if that resolves the issue. See Figure 7.
        2. If the problem is not resolved, connect the DP cable from the malfunctioning mini DP port to one of the open mini DP ports. Re-install the IRM software to see if that resolves the issue.
        3. If the problem is not resolved by connecting to an open mini DP port or by re-installing the IRM software, replace the Host PC.

Resolve “No signal” message

If both IRDs display No signal, determine if the system has been idle for more than 2 hours. The IRDs can lock due to noise exposure on the video line. When this happens, do the following to power cycle the IRD monitor.

  1. Press the E-stop button on the SCIM.
  2. Press the green EMO RESET on the PDU.
Note: Damaged fiber optic cables can expose the IRD monitor to prolonged levels of video noise causing IRD monitor to enter a locked state, present in paths of both left and right IRD monitors. The cables consist of a single fiber with DP converters at each end, one fiber each for left and right IRD monitors. Make sure ESD protective shipping cover is affixed and secured over the DP converter.

Finalization

  1. If you removed covers, reinstall them:
    • Installing the magnet left and right control panel covers
    • Installing the dockable table interface cover
    • Installing the magnet left- and right-hand lower access panels
  2. Make sure all system interconnects are returned to normal configurations.
  3. Run the Check scan.
