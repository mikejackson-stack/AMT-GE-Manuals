Installing system software - RX27 (DVD load only)

Loading software
StepProcedure for RX27
Prerequisites(For new installation only)
  • Identify the information you will need to have about the site and the site’s hardware. See System and hardware configuration.
  • After the HIPAA/Security setting is configured, the choice cannot be changed without reinstalling the software. Highest Security Settings requires SIGNA Secure Advanced option key.
(For reinstallation only)
  • Record the service license ID.
  • Request customer to back up image data.
  • Determine if the system is IPM connected and if connected, collect IPM configuration settings. See Determining if an MRI scanner is connected to IPM.
  • If research software and hardware are installed, contact GE HealthCare Research Support for backup and restore instructions.
  • If the host PC, its components, or language change, then SSA licenses must be updated. On-site Internet connectivity is required. See Service licensing.
  • After the HIPAA/Security setting is configured, the choice cannot be changed without reinstalling the software. See Security levels.
Note: Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.
Required media
  • MR Host PC Linux Base Load OS DVD.
  • MR Applications Software DVD.
  • MR Service Software DVD.
  • MR VRE Linux OS DVD.
  • Operator Manual DVD.
  • MR Brainwave Software DVD.
  • Service Pack DVD (as required).
  • Blank DVD (quantity as needed for SaveInfo).
(For reinstallation) Perform SaveInfo (Check Information instead if using an older SaveInfo media)Saving information.
Load Linux OSInstalling Linux host OS software.
Load applicationsInstalling MR applications software.
(For reinstallation only) Perform RestoreInfoRestoring information.
Configure ICN (VRE) OSConfiguring the ICN - VRE.
Install IRM(For new installation only) Installing IRM software.

(For reinstallation only) IRM software is restored by SaveInfo/RestoreInfo. It is not required for reinstallation.

Install SSAThe SSA license is restored during the RestoreInfo process. This step is not necessary for reinstallation unless the service license ID has been modified. If the service license ID has been modified, or if this is a new install, record the service license ID and contact OLE to generate a new license for the site.

If you are upgrading to any of the following software revisions or later, RX 28.0_R02, 29.0_R02, or 29.1_R02, or 30, or changing the host PC or any of its components, the SSA 16-digit license code will change. Additionally, the SSA API requires an additional signature file. This requires the SSA soft key license for the site to be regenerated and both files (.dat & .ssa) must be reloaded to the host computer.

Install options/option keys

For the purchasable option keys, see Option key catalog matrix.

Note: Signa Secure Advanced option: If the customer purchased this license, configure the security setting in Guided Install to Signa Secure Advanced. Guided Install may need to be restarted to enable security configuration.
Configure training PC (ONLY if installing as such)
Note: The training PC is an optional standalone PC used for training on systems other than MR.

See Configuring a Training PC.

Install third-party software and/or devices (for example - Brainwave, FUS, MRE, and so forth) as applicable

The BrainWave application is one of the third-party software items that must be installed at this time. See Installing BrainWave software.

Check and install any other third-party applications that the customer may have ordered. See the online documentation library for vendor-specific installation manuals.
Install latest service pack (if required)Loading software updates from the repository or CD/DVD.
RebootReboot and log in to applications.
Installation and calibration(For new installation only) Continue with the next steps in the Installation and Calibration Wizard. Refer to Installation and calibration wizard (ICW) Installation mode.

(For reinstallation only) Launch Installation and Calibration Wizard and complete any necessary calibration procedures. Refer to Installation and calibration wizard (ICW) Upgrade mode.

Configure or reconfigure Imaging Protocol Manager (IPM)If required:
  • (For new installations) Do Configuring Imaging Protocol Manager (IPM).
  • (For reinstallation or upgrade) Do Reenrolling the device to IPM.

Do a check of the cyber security compliance

See Doing a check of the cyber security compliance.

Configure About MR ScannerIf not completed during previous steps, run the About MR Scanner tool. See Running the About MR Scanner tool.
