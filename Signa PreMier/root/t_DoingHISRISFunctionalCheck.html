Doing an HIS/RIS MWL and PPS for DICOM functional check

Check connectivity and set information retrieval preferences.

Procedure

  1. Click the Work List icon for the scan screen.
  2. To make sure of the connectivity of the system to the RIS system, click the [New Patient] icon in the scan desktop.
  3. On the scan screen, enter the following:
    1. Patient ID: geservice
    2. Weight: 111
  4. Click Save.
  5. In the Search/Refresh box, click Search.

    Result

    The Search Data window shows (see figure below).
  6. Select how you want to pull information from the RIS system in the Search Data window. The Get Patient List options are:
    1. Enter a patient Name, Patient ID, Accession, or Procedure ID to define the search.
    2. Selecting Date Range pulls patient lists for any set day or date range.
    3. Selecting This System pulls the patient lists entered for this system.
    4. Selecting This Modality pulls the patient list for all MR systems at this facility.
    5. Selecting All Modalities pulls the patient list for all systems associated with this facility. Using this option may cause the scanner to hang if the facility has a large Work List for all the scanners at the site.
  7. After entering the correct Search Data, click Search.

    Result

    The results show in the list above the patient information.
