Checking the power up procedure and hardware system

Procedure

  1. Use the Reset button to power cycle the Cedrus Lumina box.
  2. Update the General Application Port field to /dev/ttyCedrusLumina, if the controller being used is the Cedrus Lumina.
  3. Set the General Application Baud Rate field for the Cedrus Lumina to 9600.
    Note: If the site has a NNL SyncBox connecting to the Host PC, use the following settings:
    • General Application Port: /dev/ttyNNLSync
    • Baud Rate: 57600
  4. Click Exit on the Offline Paradigm Manager window and save settings when prompted.
