Installing the ground strap and gradient coil manifold brackets

Install the gradient coil manifold brackets and ground strap.

Procedure

  1. (For systems with High Order Shim (HOS)) Connect the HOS gradient coil connector to the cable.
    Table 1. Gradient coil connector
    CoilConnect to cable
    57681025498220-2
    5863473HOS Scan Room Cable
  2. Remove the protective cap from the gradient coil connector.
    Note: Gradient coil 5863473 has a double-headed cable connector. Connect the larger head to cable HOS Scan Room Cable.
  3. On the service end of the magnet, install the RF shield ground strap (5768286) to the magnet and gradient.
    1. Install the RF shield ground strap to the gradient using an M10 x 35 Stud (2116325-7), M10 Nord-Lock Washer (5214524-6), and M10 Flange Nut (2274863-2).
    2. Attach the other end to the magnet with an M10 x 16 mm Brass Bolt (5110638-61).
  4. (For UA/3TLC upgrade only with rigid copper manifold) Install three gradient coil manifold brackets.
    1. Install a gradient coil manifold bracket (5782116) on the first and second holes to the left of the top center hole, and secure with two M10 x 16 Socket Head Screws (1000-M10C016-33).
    2. Install a gradient coil manifold bracket (5782117) on the first and second hole to the right of the center hole, and secure with two M10 x 16 Socket Head Screws (1000-M10C016-33).
    3. Install a gradient coil manifold bracket (5782116) in the location shown and secure with M10 x 16 Socket Head Screws (1000-M10C016-33) (standoffs are shown for perspective; they are not yet installed).
    4. Tighten both the nut and screw to a torque of 15 ft-lb (20.33 N m).
    1Gradient coil manifold bracket location, top left bracket (5782116)
    2Gradient coil manifold bracket location, top right bracket (5782117)
    3Gradient coil manifold bracket location, bottom left bracket (5782116)
  5. (For UA/3TLC upgrade only with rigid copper manifold) Install the manifold retaining clips (5782118) and Velcro straps (5754795).
    1. Slide the three manifold retaining clips between the blue and black manifold at each gradient coil manifold bracket.
    2. Secure a spacer to each bracket with an M6 x 50 Socket Head screw (1000-M6C050-33).
    3. Install a Velcro strap (only one is shown) on each side of each manifold support bracket assembly.
    1M6 x 50 Socket Head screw (1000-M6C050-33)
    2Manifold retaining clip (5782118)
    3Velcro straps (5754795)
  6. Attach the supply and return hoses to the heat exchanger. The supply hose has fittings on both ends and connects to the upper most fitting on the heat exchanger. Tighten the fittings securely.
  7. Connect the supply and return hose to the top ports on the manifold. - Open the supply valve at the rear of the magnet if a servivce.
  8. (For UA/3TLC upgrade only with flexible additive manifold) Install two gradient manifold brackets:
    1. Assemble the two bracket assemblies using one bracket (5782116), one support (5837423), and one M6 x 12 Screw (1000-M6C012-33) per assembly.
    2. Install one bracket assembly to the (+330°/+345°) hole positions on the magnet service end interface ring, using two M10 x 16 screws.
    3. Install one bracket assembly to the (+15°/+30°) hole positions on the magnet service end interface ring, using two M10 x 16 screws.
    4. Guide the 1-inch blue and black manifold hoses on the gradient service end into the support.
    5. Wrap two pieces of Velcro straps around the manifold hoses near each of the two installed bracket assemblies.
  9. (For W-WB/G3 upgrade only) Install the busbar lower support plate (5759493) using three M10 x 30 Socket Head Screws (1000-M10C030-33) and M10 Stainless Steel Washers (2000-M10-17) in the first three slots, and an M10 x 30 Button Head Screw (2109872-14) and M10 Stainless Steel Washer (2000-M10-17) in the fourth slot.
    1, 2, 3M10 x 30 Socket Head Screws (1000-M10C030-33) and M10 Stainless Steel Washers (2000-M10-17)
    4M10 x 30 Button Head Screw (2109872-14) and M10 Stainless Steel Washer (2000-M10-17)
    5Right side gradient coil manifold bracket location
    6Left side gradient coil manifold bracket location
  10. (For W-WB/G3 only with rigid copper manifold) Install two gradient coil cable manifold supports:
    Note: If the black flexible gradient coil hoses interfere with the manifold bracket, attempt to rotate the gradient coil manifold assembly to remove the interference (the movement comes from the flexible hoses).
    1. Attach the two gradient coil manifold brackets (5782532) to the busbar lower support plate with two M6 x 20 Stainless Steel Screws (1003-M6C020-33).
    2. Position a manifold retaining clip (5782118) below the hoses and a top bracket. Slide the manifold support bracket between the hoses and align it with the top bracket.
    3. Attach the manifold retaining clip to the manifold bracket with an M6 x 50 Socket Head screw (1000-M6C050-33) by inserting the screw into the plastic manifold bracket from below.
    4. Repeat with the second manifold support bracket.
    5. On each side of each manifold support bracket assembly, install a Velcro strap (5754795).
    1Manifold retaining clip (5782118)
    2Velcro straps (5754795)
  11. (For W-WB/G3 upgrade only with flexible additive manifold) Install two gradient manifold brackets:
    1. Assemble bracket assembly A using one bracket (5782532), one support (5837423), and one M6 x 12 Screw (1000-M6C012-33).
    2. Assemble bracket assembly B using one bracket (5837415), one support (5837423), and one M6 x 12 Screw (1000-M6C012-33).
    3. Install bracket assembly A to the 345° position on the magnet service end interface ring and bracket assembly B to the 15° position on the magnet service end interface ring.
      Note: Use the existing six (three for each bracket) buttonhead cap screws from previous brackets.
    4. Guide the 1-inch blue and black manifold hoses on gradient service end into the support.
    5. Wrap two pieces of Velcro straps around the manifold hoses near each of the two installed bracket assemblies.
  12. Attach the supply and return hoses to the heat exchanger. The supply hose has fittings on both ends and connects to the upper most fitting on the heat exchanger. Tighten the fittings securely.
  13. Connect the supply and return hose to the top ports on the manifold. Open the supply valve at the rear of the magnet.
  14. (For Gradient coil (HRMw) replacement only) Do the following after you install the HRMw gradient coil:
    1. Manually reinstall all passive shim trays into the correct slots. For UA series magnet: Refer to Direction 5431810-2. For W/WB series magnet: Use the XRMw Shim Tray Puller (5325761) that is included in the Universal Field Mapping Fixture Kit with Extension (5266042-5).
