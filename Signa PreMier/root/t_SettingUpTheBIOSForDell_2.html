Setting up the BIOS - Dell T5810/T5820

Restore the BIOS configuration on the Dell system.

Prerequisites

Required conditions
  1. Disconnect the cable connecting to port 1 slot 2 of T5820.
  2. Disconnect the cable connecting to port 1 slot 4 of - Dell T5810/T5820, and then connect it to port 1 slot 2 of - Dell T5810/T5820.
  3. Power on - Dell T5810/T5820, and then start to set up the BIOS.

Procedure

  1. When the Dell circle shows on the screen, press F2.
  2. If a message shows indicating the time of day is not set, press F2.
    1. Select General > Date/Time and set the correct time.
    2. Use the Tab key to move the cursor, and then use the left and right arrow keys to change the values.

      Result

      After you set the time and date, the BIOS settings opens.
  3. Restore the customized BIOS settings. Change only the values specified below.

    Result

    The system reboots. The BIOS configuration is complete.

Finalization

  1. Power off the Dell T5810/T5820.
  2. Recover the cable connections.
  3. Disconnect the cable connecting to port 1 slot 2 of the Dell T5810/T5820, and then connect it to port 1 slot 4 of the Dell T5810/T5820.
  4. Power on the Dell T5810/T5820 and make sure the LCD is on.
