Configuring tuning software IP address

About this task

The process to configure the IP address on your computer is similar for Windows 7 and Windows 10 operating systems, but the exact steps differ. Power on the computer and set the following IP address:

Procedure

  1. Connect the computer to the network analyzer with the Cat5 crossover patch Ethernet cable (5337743) in the Network Analyzer Service Tool Kit.
  2. Configure the IP address for Windows 7:
    1. On the laptop, go to Start > Control Panel.
    2. Set the View by option on the right side to Category.
    3. Click Network and Internet.
    4. Under Network and Sharing Center, click View network status and tasks.
    5. In the left column, click Change adapter settings.
    6. Double-click Local area connection. If a pop-up dialogue appears asking to make changes on this computer, click Yes.
    7. In the Networking tab, scroll down to Internet Protocol Version 4 (TCP/IPv4).
    8. Double-click Internet Protocol Version 4 TCP/IPv4 and set the following:
      • IP address: 192.168.200.100.
      • Subnet mask: 255.255.255.0.
  3. Configure the IP address for Windows 10:
    1. Right-click the Window's Start button and select Control Panel.
    2. On the Control Panel window, click the Network and Internet link.
    3. On the Network and Internet window, click the Network and Sharing Center link.
    4. On the Network and Sharing Center window, click the Local Area Connection link.
    5. On the Local Area Connection status window, click Properties.
    6. On the Networking tab, select Internet Protocol Version 4 (TCP/IP IPv4). Make sure the checkbox to the left is checked.
    7. Click the Properties button.
    8. On the Internet Protocol Version 4 (TCP/IPv4) Properties window, select Use the following IP address.
    9. Set the following:
      • IP address: 192.168.200.100.
      • Subnet mask: 255.255.255.0.
