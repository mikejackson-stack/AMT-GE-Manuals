Finalizing eddy current compensation

Do final steps to complete the eddy current compensation.

About this task

Note: Failure to follow finalization procedure may result in an Install in Spec (IIS) failure.

Procedure

  1. Run Install in Spec (IIS) using the C Shell (see Doing Installation and Calibration Wizard (ICW) Install In Spec (IIS)).
    Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions. In the C Shell, type install_in_spec and press Enter.
  2. If IIS does not report an eddy current compensation failure, exit the tool (this saves the eddy current data to disk) and continue to Step 4.
  3. If IIS reports an eddy current compensation failure but the tool did not, run a scan for the failing component(s) in eddy current compensation manual mode after selecting Never Accept from the menu (see Running eddy current compensation in manual mode). Then exit the tool and run install_in_spec again.
  4. Remove the phantom, positioner, and coil from the table.
  5. If calibration is being run within ICW installation mode, continue to the next calibration procedure. Otherwise, save eddy current calibration data to SaveInfo media. See Saving information.
  • Saving information
    Save the current configurations and files in order to restore them later, if needed.
