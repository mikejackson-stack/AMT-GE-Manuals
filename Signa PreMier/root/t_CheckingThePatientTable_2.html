Checking the patient table

Makes sure the following systems operate correctly: patient table up and down, cradle in and out, emergency egress, and touch-and-go strip.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-60 minutes-

About this task

Do the following checks to complete checking the patient table:
  • Checking the table up and down functions
  • Checking the cradle in and out functions
  • Checking the emergency egress function
  • Checking the touch-and-go strip function
  • Doing the cradle motion test
  • Doing a TPS Reset

Systems with a dockable table must have a table docked electrically prior to beginning the checks.

  • Checking the table up and down functions
    Makes sure the patient table up and down movement systems operate correctly.
  • Checking the cradle in and out functions
    Makes sure the patient table cradle in and out movement system operates correctly.
  • Checking the emergency egress function
    Checks the patient table emergency egress system for correct operation.
  • Checking the touch-and-go strip function
    Makes sure the touch-and-go strips display the landmark on the In-Room Display (IRD) correctly.
  • Doing the cradle motion test
    Makes sure the motion of the patient cradle into and out of the magnet bore is operating correctly.
