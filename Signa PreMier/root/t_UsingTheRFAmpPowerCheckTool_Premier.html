Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

About this task

Expected Results - RF Power Measurements

Procedure

  1. Set up the appropriate phantom.
    • If selecting the body, body channel 1, or body channel 2 RF chain, set up the 3.0T body sphere and loader phantom assembly in the center of patient cradle (landmark the center of phantom at 1080 mm from home position).
    • If selecting the head RF chain, set up the phantom inside the local TR coil by referring to the MCQA procedure, and landmark the phantom.
  2. If a problem is suspected in the transmit chain resulting in a poor RF load that is causing RF amp faults, substituting the fan-cooled dummy load from the RF power measurement in place of the normal body or head transmit loads may confirm this. Otherwise, refer to Launching RF Amp Power Check Tool.
    1. Make sure the phantom is landmarked.
    2. Obtain a digital voltmeter (DVM) reading and configure to measure resistance.
    3. Measure the resistance between the center pin and the shield of the RF connector on the fan-cooled dummy load from the RF Power Measurement Kit. Make sure it measures 50 ohms, ±5 ohms.
    4. Disable RF input to the amplifier by putting the RF ENB switch on the DTX1 exciter module, located in the Integrated System Cabinet (ISC), in the disabled (down) position.
    5. Connect the fan-cooled dummy load to the body or head ports on the RFamplifier. If you are testing body ports, connect dummy load to J4 for channel 1 or J22 for channel 2.
      Note: To prevent damage to the DTRSW, body coil, and 2-channel preamp, disconnect the RF cable attached to the RF amplifier port that is not connected to the dummy load. Install the quarter wave stub from the RF Power Measurement Kit to that port.
      Note: An alternative means would be to disconnect both RF transmit cables at the input side of the DTRSW. The FE would have to remove the side magnet enclosures to access those connection points.
    6. Disable TR driver module fault monitoring.
    7. Enable RF input to the amplifier by putting the RF ENB switch on the exciter in the enabled (up) position.
  3. Insert the service key into the computer.
  4. From the Common Service Desktop, click the Utilities tab.
  5. Select RF Amp Power Check Tool to launch the tool.
  6. Select the desired test to run (default recommended):
    • Low Duty Cycle Test: Determines if the amplifier is functioning properly under low stress conditions.
    • Stress Power Test: Simulates aggressive protocol issues for certain areas.
    • Automatic Procedures: Runs both low-duty cycle and stress power tests back-to-back.
  7. Select Body, Body Ch-1 Only, Body Ch-2 Only, or Head. Listed below are the selections available for the RF chain field.
    Table 1. RF chain selection
    RF chain selectionWhat is tested
    BodyBoth channel 1 and channel 2 are transmitting RF.
    Body Ch-1 OnlyChannel 1 is transmitting RF.
    Body Ch-2 OnlyChannel 2 is transmitting RF.
    Local TxLocal Tx is transmitting RF.
    Note: When running the RF power check tool into the system loads/coils, use the default (or lower) TG value that the tool sets up for the RF chain you selected. When running the RF power check tool into the dummy load setup, TG can be manually adjusted up to maximum of 200 to stress the RF amplifier.
  8. Close the magnet room door.
  9. Click START to begin the test.
  10. Click OK in the High E-field warning box.
  11. Click Yes if the body coil is set up with the body TLT phantom and land marked.
  12. To verify that the coil and phantom selected was properly set up and landmarked, a dialog box appears. Click OK to continue with the test.
    • To see the results of the latest test, click View Report. Scroll to the bottom of the file for the latest results.
    • To see the results of earlier tests, you can use the more command to display the test results.
      1. Open a C-shell or terminal window.
      2. Type cd /usr/g/service/cclass/rfamp_power_check/ and then press Enter.
      3. Type ls *.results -ltr and then press Enter. This lists all of the results files. The names of these files contain the dates when the tests were run.
      4. Type more filename.results, where filename is the date of the results file you want to display.
      5. Press Enter.
    • Repeated iterations of the tool will append the results to the end of the file created for the day on which the tool is run.
    • Press the space bar to make sure the most recent data is being viewed. This will always be located at the end of the file.
    • View the date and time printed in the header preceding the data to confirm the most recently collected data is displaying.

    All zeros reported for the selected Head or Body port (VSWR will never be zero) means either the port was not selected from the RF chain pull-down, or the RF amplifier never completed the test and collected the data. Check the test setup and landmarking, and check for any RF amplifier faults in the GE System log.

    The following are test execution hints:

    • The default setting is TG=170. For body scans, make sure that body TLT loader and sphere are in the bore and are properly landmarked before increasing TG to 200.
    • The ability to test at other TG levels is provided for assistance in troubleshooting issues that seem to correlate to peak output levels.
    • The results are most consistent when using a dummy load for the setup.
    • The test results from multiple tool passes will be appended in a single file for the day to allow reviewing of results under different test conditions.
    • UPM1 and 2 errors indicating head forward and reflected power levels of 2 W or less may be logged during body stress power test. These do not interrupt test execution and can be ignored.
    • This tool is not a substitute for the RF Power Measurement Kit.
    • Watch the Stop Scan button after starting the test to make sure it backlights after approximately 40 seconds. Failure to backlight means that the RF amp did not pulse.
    • The Stop Scan button should remain backlit for approximately 180 seconds for each test selected. If the backlight extinguishes too soon, check the error log, as the amp has likely faulted. Wait for the test to end, reduce TG by 5 to 30 counts and begin the test again. Repeat TG reductions as necessary until the test completes.
    • Some failures only happen at higher power levels. Try running the test with TG levels just below the point where the amp faults.
    • At a TG setting of 170, peak output power should be half of the output seen when measured at a TG setting of 200.

    • Tests run with a dummy load attached to body or head output usually result in reported VSWR closer to 1.00. The closer the load matches the transmission line and amplifier, the closer the reported VSWR will be to 1.00.
  13. Click OK.

Finalization

  1. Click EXIT to quit the tool.
  2. Remove all coils and phantoms from the patient table.
  3. Remove dummy load if connected.
    1. Disable RF input to amplifier by placing the RF ENB switch on the DTX1 exciter module in the disable (down) position.
    2. Remove load and reattach transmit line to RF amplifier.
    3. Enable TR and DD fault monitoring at driver module.
    4. Put RF ENB switch in Enable (up) position.
    5. Complete local Tx or body scan to make sure the system is functioning correctly.
