About this task

Eddy current compensation adjusts and compensates medium, long, and very long time constant eddy currents for both linear and B0 terms, and it adjusts oscillatory eddy currents for B0 terms (X- and Y-axis).

Use the following procedure to do eddy current compensation. Eddy current compensation should be run in auto mode first. If auto mode fails to bring any of the terms into specification, manual mode can be used.

Table 1. Eddy current calibration modes
Auto mode - The Eddy Current Calibration tool is initially run in auto mode. See Running eddy current compensation in auto mode.
Note: (For 3TLC/UA only) XB0 and YB0 oscillatory mode is part of auto mode. The tool also picks the optimal number of oscillatory fitting terms automatically. Long X and Y are run automatically after the oscillatory mode to make sure that the system is within specification.
Manual mode - When doing this procedure, if auto mode does not bring all the terms into specification (still red in the Result/Area table), see Running eddy current compensation in manual mode.
Note: If VLong, Long, or Medium components are failing, manual mode should be run to bring the failing component(s) into specification.

Eddy current compensation uses dedicated pulse sequences, the Head TLT phantom, and the TDI HNA coil.

Procedure

  1. Put the TDI Head Neck Array on the table and connect it to the appropriate port.
  2. Put the Head TLT Phantom into the positioner in the coil, make sure the holder touches the end of the coil at the cable side, and landmark on the cross hairs of the coil making sure the alignment lights are also on the center of the phantom.
  3. Push Advance to Scan.
  4. If auto mode does not bring all the terms into specification (still red in the Result/Area table), run eddy current compensation in manual mode.
  5. Determine if the existing terms should be zeroed out.
    • For new system calibrations, click the Zero Out tab.

      Select all the terms on the left and click Zero Out Cal Values before continuing to the next step.

    • For performance checks only, continue to the next step.
  6. Click Scan to start the calibration.

    When the scan is active, it can be stopped by clicking Abort on the window and Yes on the subsequent dialog box to confirm.

    In auto and manual modes, a position check is done to make sure of the proper state of the phantom. If the phantom is not properly positioned, a message window opens advising the user on how to fix the error.

    The eddy current compensation software runs multiple scans to bring each component into specification. It iterates up to the maximum amount specified. When each component finishes a scan/analysis iteration, the residual of the eddy current of the measurement shows in the results table. The results are color-coded.

    Text colorDefinition
    RedValues above specification
    GreenValues within specification

    Highlight the desired cell in the results table and click Show to show the result graphs.

    Auto mode acquires data in the following order:

    • Vlong
    • Long/Medium
    • Short
