Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.
  • Electrical Safety
    You must follow all recommended safety procedures when servicing and working near energy sources.
  • Shutting down the host computer
    Shutting down the host computer shuts down the system safely and turns off the power to the host computer.
  • Applying LOTO - ISC
    Apply LOTO to both the gradient and system Power Distribution Unit (PDU) breakers on the MDP when servicing either of these items in the ISC. Apply LOTO to make sure of a safe environment when working on these parts.
  • Removing the magnet left- and right-hand lower access panels
    Removes the left- or right-hand lower access panel from the magnet front cover.
  • Removing the table interface cover
    Removes the fixed or dockable table interface cover from the magnet front cover.
  • Removing the table base covers
    Removes the base covers from the patient table.
  • Replacing the limit switch
    Replaces the up or down limit switch on a fixed table with either an SKF or EHA actuator.
  • Removing LOTO - ISC
    Remove LOTO from the gradient and system PDU breakers on the MDP before restoring power to the ISC.
  • Starting up the host computer
    How to start the host computer.
  • Finalizing replacing the table up-limit or down-limit switch
  • Adjusting the patient table top height and level
    Adjusts the height and level of the patient table top. Do this procedure when the patient table height or level is not within acceptable limits. Always recheck the table longitudinal gap after making adjustments per this procedure.
  • Adjusting the patient table up-limit or down-limit switch
    Adjusts the up-limit or down-limit switch for patient table up and down movement. Do this procedure when the fully up or fully down position of the table needs to be adjusted.
  • Installing the fixed table mechanical latch
  • Installing the table base covers
    Installs the table base covers onto the patient table.
  • Installing the table interface cover
    Installs the fixed or dockable table interface cover onto the magnet front cover.
  • Installing the magnet left- and right-hand lower access panels
    Installs the left- or right-hand lower access panel onto the magnet front cover.
  • Checking the patient table
    Makes sure the following systems operate correctly: patient table up and down, cradle in and out, emergency egress, and touch-and-go strip.
  • Doing a check scan
    A check scan is done at the conclusion of many procedures. This functional check assures the unit is in good clinical working order.
