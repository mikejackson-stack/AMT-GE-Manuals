RF amplifier power check tool

This tool provides a quick check for gross deviations in RF power levels (inputs and outputs), Power Supply Unit (PSU) voltages, and Field Effect Transistor (FET) junction temperatures for the RF amplifier.

Required conditions
This test requires appropriate sphere and loader assembly landmarked at the proper location on cradle.

About this task

This tool provides a quick check for gross deviations in RF power levels (inputs and outputs), Power Supply Unit (PSU) voltages, and Field Effect Transistor (FET) junction temperatures for the RF amplifier. Testing can be done using an appropriately loaded body or head coil, or using the fan-cooled dummy load.

This tool is not a substitute for the RF Power Measurement Kit.

Topic ID: id_SL2119600-1062914

Setting up phantoms

Procedure

This test can be run in two different configurations:
  1. The recommended initial configuration is with phantoms positioned at isocenter with no other changes to the system. See Running RF amplifier power check tool to execute in this configuration.
  2. The second configuration isolates the RF amplifier from the rest of the external transmit chain and coils by executing the test with the dummy load attached to the RF amplifier head or body RF outputs. This configuration requires a dummy load, and is used when it is necessary to isolate the RF amplifier from possibly faulty head or body RF transmit loads. See Isolating RF amplifier to execute in this configuration.
Topic ID: id_SL11951002-1062914

Isolating RF amplifier

About this task

This section is only for the second configuration (which isolates the RF amplifier from the rest of the external transmit chain and coils, and requires a dummy load). For the standard configuration, skip to Running RF amplifier power check tool.

Procedure

  1. Confirm that the phantom is landmarked as described in Setting up phantoms.
  2. Obtain a DVM and configure to measure resistance.
  3. Measure the resistance between the center pin and the shield of the RF connector on the fan-cooled dummy load from the RF power measurement kit, and confirm it measures 50Ω ±5Ω. Only use loads that measure within the limits.
  4. Disable RF input to the amplifier by placing the RF ENB switch on the DTX1 exciter module, located in the Penetration (PEN) cabinet, in the Disabled (down) position.
  5. Disable TR fault monitoring by placing the SW2 switch on the front of the driver module in the down (TR DISABLE) position.
  6. Enable RF input to the amplifier by setting the RF ENB switch in the Enabled (up) position.
  7. Continue with Running RF amplifier power check tool.

Running RF amplifier power check tool

Procedure

  1. Insert the service key into the computer.
  2. From the Common Service Desktop (CSD), select Utilities > RF Amp Power Check.
  3. Select the desired test to run. The recommended default is shown below.
    Test Description of Test
    Low Duty Cycle TestDetermines if the amplifier is functioning properly under low stress conditions.
    Stress Power TestUsing high average power, simulates aggressive protocol issues for certain areas.
    Automatic ProceduresRuns both Low-Duty Cycle and Stress Power tests.
  4. Manually set TG level down to 140 to prevent RF amp faults during initial test. TG can be increased to 200 for later iterations if desired.
  5. Close the magnet room door.
  6. To verify that the coil and phantom that is selected is properly stationed and landmarked, the window shown below displays. Click Yes to continue with the test.

Viewing test results

Procedure

  1. To see the results of the latest test, click View Report. Scroll to the bottom of the file for the latest results.
  2. To see the results of earlier tests, you can use the more command to display the test results.
    1. Open a C Shell or terminal window.
      Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions.
    2. Type cd /usr/g/service/cclass/rfamp_power_check/ and then press Enter.
    3. Type ls *.results -ltr and then press Enter.

      This lists all of the results files. The names of these files contain the dates when the tests were performed.

    4. Type more filename.results, where filename is the date of the results file you want to display.
    5. Press Enter.
  3. The final test results are displayed.
    Note:
    Repeated iterations of the tool will append the results to the end of the file created for the day on which the tool is run.
    • Press the space bar to ensure the most recent data is being viewed. Data for recent iterations is located at the end of the file.
    • View the date and time printed in the header which is preceding the data to confirm the most recently collected data is displaying.
  4. All zeros reported for head or body results (Voltage Standing Wave Ratio [VSWR] will never be zero) means that either the port was not selected from the RF Chain menu or scanning prematurely ended during the test due to occurence of a system fault or other scan setup problem. Check the test setup and landmarking and check the GE System message log for system faults. See the Test Execution Hints section below for tips on successfully completing the test.
    The expected result values below were collected with amplifier outputs connected to 50 Ω dummy load. Results obtained with a properly functioning head or body coil, loaded with sphere and loader phantom assembly and landmarked at isocenter, will be similar.
    Note: The delta temperature is an estimate of the temperature difference between the FET junction and the cold plate.

    Test execution hints:

    • The ability to test at other TG levels is provided for assistance in troubleshooting issues that seem to correlate to peak output levels.
    • Most consistent results are obtained when the test is run with an ideal RF load connected (properly functioning and properly loaded head or body coil, or RF dummy load measuring 50 Ω).
    • The test results from multiple tool passes are appended in a single file for the day to allow reviewing of results under different test conditions.
    • UPM1 and 2 errors indicating head forward and reflected power levels of 2 W or less may be logged during body stress power test. These do not interrupt test execution and can be ignored.
    • Watch the Stop Scan button after starting the test to confirm that it backlights after approximately 40 seconds. If the button fails to backlight, the RF amplifier did not pulse due to internal fault, power loss, etc.
    • The Stop Scan button should remain backlit for approximately 180 seconds for each test selected. If the backlight stops too soon, check the error log, because the amplifier has likely faulted. Wait for the test to end, reduce TG by 5 to 30 counts, and begin the test again. Repeat TG reductions as necessary until the test completes.
    • Some failures only happen at higher power levels. Try running the test with TG levels below the point where the amplifier faults.
    • Tests run with a dummy load attached to body or head output usually result in reported VSWR closer to 1.00. The closer the load matches the transmission line and amplifier, the closer the reported VSWR will be to 1.00.
Topic ID: id_14993718

Finalization

Procedure

  1. Click EXIT to quit the tool.
  2. Remove all coils and phantoms from the patient table.
  3. Remove dummy load if connected.
    1. Disable RF input to the amplifier by placing the RF ENB switch in Disable (down) position.
    2. Enable TR and DD fault monitoring at the driver module. (See Figure 2.)
    3. Place RF ENB switch in Enable (up) position.
  4. Complete a head or body scan to confirm system functionality.
