Gradient FRU compatibility guidance

This document provides guidance on how to replace the existing gradient amplifier (RGA) or gradient power supply (RPS) with the RG5 generation of gradient amplifier (RGA5) or gradient power supply (RPS5).

Replacing any RGD hardware with RG5 requires a complete replacement of all six units. Generations of control boards cannot be mixed within a system. If any of the gradient power supplies or gradient amplifiers fail, and the direct replacement is not in stock, all gradient power supplies and gradient amplifiers must be replaced with RPS5 gradient power supplies and RGA5 gradient amplifiers simultaneously.

Any system transitioning from RGD to RG5 requires a minimum software level of 30.

The replacement procedures are the same as the existing procedures and can be found in the appropriate service manuals.

Physical difference

This section provides details about how to differentiate between the RG5 hardware and the RGD hardware.

Note:

RPS5, reference number, and other important information is printed on the rating plate.

RPS5 will also be printed on the face plate.

The RJ45 port on the RPS has been replaced with a USB-B port on the RPS5.

Note:

RGA5, reference number, and other important information is printed on the rating plate.

RGA5 will also be printed on the face plate.

The RJ45 port on the RGA has been replaced with a USB-B port on the RGA5.

Guided install

Though the back end software configuration is the same between RG5 and RGD, make sure that the hardware config is changed to RG5 when a system is transitioned from RGD to RG5 hardware.

Gradient control architecture"Gradient Type" selection in guided install
RGDRGD
RG5RG5
Other interfaces used by service to interact with the gradient subsystem (e.g., diagnostics) are unchanged between RGD and RG5.

Gradient selection: Package Name and Gradient Type

Guided install Package Name and Gradient Type fields are modified to present selections for RG5 where RGD is currently selectable.

Part return instructions

  • For the FRU part(s) that is not operational, return it normally as a bad part. Clearly label it and indicate it as not functional.
  • For the operational FRU parts that were replaced, return them with a red label similarly to non-functional parts. This will make sure the parts are not accidentally scrapped. Clearly indicate in the debrief notes and on the red label that the parts are operational: "Replaced due to compatibility issues. Part is fully operational".
  • Reuse the appropriate containers that were used to ship the new hardware and modules to the site to return the removed FRU parts.
