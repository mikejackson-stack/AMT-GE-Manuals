Connecting an MR system to a McAfee ePolicy Orchestrator server (ePO)

Follow this procedure to connect a GE MR system to an McAfee ePolicy Orchestrator server (ePO) server.

Prerequisites

This task is to be completed by the GE Field Engineer assigned to the respective system, along with a site IT representative with knowledge of the ePO server details and an administrator account.
Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-30 minutes-
Required conditions
Existing and functional ePO server, along with the server details and access to the machine it is set up on.
An ePO account with administrator rights.

Procedure

  1. Identify the MR system that is to be connected to the ePO server.
  2. In the MR interface, open Guided Install and select Option Key.
  3. Select the Manual option key option and enter the antivirus option key.
    Note: The antivirus option key purchased through catalog G7009SD activates the McAfee antivirus software on your MR scanner.
  4. Click Install.
  5. When the installation finishes, close Guided Install.
  6. On the MR system, go to Service Browser > Utilities > Security Tools > Antivirus.
  7. Click Antivirus ePO Setup.
  8. Enter the following information, and click Apply ePO Settings:
    1. ePO Server IP Address.
      Note: Information about the ePO server can be found in the ePO by going to Home > Server Settings > Server Information.
    2. ePO Port Number.
      Note: Port information can also be found in the ePO by going to Home > Server Settings > Ports. The port required for this step is the Console-to-application server communication port, which is usually defaulted to port 8443. Make sure the port number is consistent with your ePO configuration.
    3. ePO Username.
      Note: This username was created during the ePO installation process. User names and passwords can be managed in the ePO.
    4. ePO Password.
  9. Wait for the system to connect to the ePO. This process could take a few minutes.
  10. The upper right corner of the browser shows the status of the ePO. After the ePO settings have been applied, the status should change to Connected.
  11. After the status shows connectivity, confirm the presence and status of your target system in the ePO by going to Menu > System Tree, and preset the group to This Group and All Subgroups. The name of the target system should show up in the list, with the state of Managed.
    Note: The following step changes the default settings on the ePO server and prevents the ePO server from interfering with the MR Scanner performance.
  12. After you connect the MR system to the ePO work with the site IT administrator for configuring McAfee ePO server policies.
    1. On the ePO Server, create a new subgroup for MR Scanner under the System Tree.
      Note: Refer to the following link for customizing ePO server policies for the newly added MR Scanner subgroup and modifying Client Tasks. https://www.mcafee.com/enterprise/en-in/products/epolicy-orchestrator/support.html
    2. Clear the On-Access Scan policy by deselecting the checkbox.
    3. Clear the automatic Engine updates for the MR scanner subgroup by deselecting the checkbox. Select the automatic DAT updates for the MR scanner subgroup by selecting the checkbox.

    Result

    Your target system and ePO are now connected and ready for use.
