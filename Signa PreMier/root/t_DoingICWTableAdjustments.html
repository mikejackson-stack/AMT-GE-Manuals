Doing ICW fixed table adjustments

Completes the Installation and Calibration Wizard (ICW) table adjustments. Required measurements will be entered and tasks will be marked as complete in the ICW.

About this task

During the table adjustments the following tasks must be completed and checked off:
  • Checking and adjusting the patient table
  • Aligning the bridge cover
  • Checking the cradle home sensor
  • Installing the total digital imaging posterior array coil

Procedure

  1. Open the Table Adjustments section in ICW.
  2. Do Checking and adjusting the patient table and enter the listed ICW items.
    Note:

    ICW requires the following measured values:

    • Lateral difference between table and bridge
    • Gap between bridge and table
    • Gap difference between left and right sides of the table
    • Height difference between the table and bridge
    • Distance (in mm) between the table top and the level at 910 mm when bubble of level is centered
    Important:

    Save the following items and keep them together for future use:

    • Table casters
    • Screw rod
    • Relief valve opening tool
    • Table gap check tool
  3. Move the cradle into the bore and make sure it moves freely off of the bridge and check the appropriate box.
  4. Do Checking the cradle home sensor and check the appropriate box.
  5. Do Installing the Posterior Array (PA) coil and check the appropriate box.
  6. See Checking the patient table to ensure all table functionality is within specification.

Finalization

Once ICW table adjustments are complete, click Submit.
  • Adjusting the cradle home sensor
    Adjusts the cradle home sensor. Do this procedure if the cradle home sensor fails checking the cradle home position sensor.
  • Installing the Posterior Array (PA) coil
    Installs the PA coil as part of the Installation and Calibration Wizard (ICW).
  • Checking the patient table
    Makes sure the following systems operate correctly: patient table up and down, cradle in and out, emergency egress, and touch-and-go strip.
  • Checking and adjusting the patient table
    Makes sure the longitudinal gap, lateral center, height, and level are within tolerance. Provides adjusting procedures for out of tolerance measurements.
