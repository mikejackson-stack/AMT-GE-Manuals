Installing the table control box

Installs the table control box and bracket to the dock frame.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-15 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
Nonmagnetic Titanium Service Tool Kit, Small Set15113258-

About this task

Warning
Ferrous material hazard
Components in this procedure contain ferrous material. Ferrous materials can become dangerous projectiles within the magnetic field.
Handle the components with care, making sure they are secure at all times within the magnetic field.

Procedure

  1. Install the table control box and bracket.
  2. Install the five screws securing the table control box and bracket.
  3. Connect the table patient alert and respiratory tubes to the remote Physiological Acquisition Controller (PAC) interface.
  4. Connect TABLE-IO-TABLECNTBOX-J1, J2, J3, J4, J5, J6, J7, J8, J9, J10, J11, and J12 to the table control box.
    Note: For tables with an SKF actuator, TCB connectors J11 and J12 will not be present.
  5. Connect the adapter 5485745 to J10. (Refer to service note DOC2790643)
