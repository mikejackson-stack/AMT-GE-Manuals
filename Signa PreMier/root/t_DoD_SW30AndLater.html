Setting up a Department of Defense (DoD) system with software version 30 and later

Use this workflow to install software version 30 and later on a Department of Defense (DoD) system.

Prerequisites

Tools and test equipment
ItemPart numberManufacturer
USB Software--

M-Class SSA Hard Key5431898-3

About this task

General procedure to set up a DoD system with software version 30 and later.

Procedure

  1. If the software is installed on the system, you can manually check the integrity of the USB Installer Media content. See USB Installer Media Checksum.
    Note: The installation process contains an automated integrity checker that is run after software installation. If the USB content has been tampered or altered, the installation process is stopped.
  2. Install and calibrate the system. See USB software installation.
  3. No change is needed for the boot sequence, unless specified by the customer. See Setting the boot sequence if the customer specifies a change to the boot sequence.
  4. Enable and set up the BIOS password. See Setting or changing the BIOS password.
  5. Turn the firewall ON. See Product Network Filter (PNF) firewall.
  6. Set up and assign EA3 User Roles as appropriate for the site. See Configure user accounts for Role Based access controls.
    1. Password controls:
      • Max logon attempts before lock: 3
      • Lock duration (minutes): 10
      • Password expiry period: 60
      • Minimum password length: 15
      • Advanced password rules: checked
    2. Configure local user administrators and local users:
      • Admingroup
      • GESystemPreferenceGroup
      • GELevel2Group
      Note: There are no default users aside from the "root" user.
  7. Install McAfee Antivirus on the MR System. See Installing antivirus software.
    Note: If you are permitting McAfee ePO to connect to the McAfee Endpoint Security for Linux Threat Prevention (ENSLTP) on the MR scanner, corresponding port 1434 is required to be open on the external interface using Product Network Filter (PNF).
  8. Install and configure the IPv6 network. See Configuring IPv6.
  9. Configure the DICOM networking. See Configuring DICOM networking (standard or DICOM over TLS).
  10. Enable the Enterprise Audit Trail audit logging. See Enterprise Audit Trail (EAT)-audit logging.
  11. Activate remote system logging. See Sending Linux system logs to a remote server.
  12. Create a customized logon message. See Creating a customized logon message.
