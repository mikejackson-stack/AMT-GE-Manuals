Transferring files between the host computer and a USB flash drive

Use this procedure to transfer files between a USB flash drive and the host computer. Do not use this procedure to save or restore configuration files.

Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

About this task

Use this procedure to either transfer files from the USB drive to the host computer, or from the host computer to the USB drive. Transferring files to the USB drive is useful when you need to share site data to the OLE or engineering teams for troubleshooting.

Procedure

  1. Put the USB flash drive into any USB port on the host computer.
  2. Go to the Service Desktop.
  3. Open a C Shell.
    Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions.
  4. Run the following command: nautilus --version. Note the version of GNOME nautilus.
  5. Run the following command: nautilus &.
  6. Select the appropriate procedure from the options below based on the version of GNOME nautilus:
    • Transferring files on MR software version 27 and prior (Nautilus 2.x)
    • Transferring files on MR software version 28 and later (Nautilus 3.x)
Topic ID: oss_yg5_stb

Transferring files on MR software version 27 and prior (Nautilus 2.x)

Procedure

  1. From the menu bar, select Places > Computer.

    Result

    The Computer window will open.
  2. In the Computer window, select the USB device that you connected to the host computer in Step 1.

    Result

    The USB device opens in a separate window.
  3. In the Computer window, select Filesystem.

    Result

    The host computer file system opens in a separate window.
  4. Drag and drop files as necessary either from the USB drive to the correct folder in the host computer directory, or from the host computer to the USB drive.
    Note: By default, files are copied (not moved).
  5. In the Computer window, right-click the USB device and select Unmount.
  6. In the Computer window, right-click the USB device and select Eject.
  7. Close all windows and remove the USB flash drive from the host computer.
Topic ID: task_eg4_p23_wtb

Transferring files on MR software version 28 and later (Nautilus 3.x)

Procedure

  1. In the left pane, right-click the USB flash drive and click Open in New Window.
  2. In the left pane of the original window, click Other Locations in the window.
  3. Double-click Computer and navigate to the folder required for file transfer.
  4. Drag and drop files between the windows as necessary to copy files from the USB drive to the host computer and/or from the host computer to the USB drive.
    Note: By default, files are copied (not moved).
  5. When copying is complete, in the left pane of either window, click the Eject button next to USB DRIVE.
  6. Close all windows and remove the USB flash drive from the host computer.
