Installing the dockable table handle-end cradle cover

Installs the cover on the handle-end of the dockable table cradle.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-15 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
Nonmagnetic Titanium Service Tool Kit, Small Set15113258-
Required conditions
The cradle hardtop cover is installed.

Procedure

  1. If removed, position the handle-end cradle cover at the handle end of the cradle.
    Note: When lowering the cover, make sure there are no cables or air hoses pinched between the cover and the cradle.
  2. Connect any previously removed handle-end cradle cover components to the cover as follows:
    1. Install the two screws securing the pneumatic connection bracket to the cover.
    2. Install the four screws securing the microphone to the cover.
    3. Install the two screws securing the PG bracket to the cover.
    4. Connect the egress switch connector.
    5. Install the four screws securing each P-port to the cover.
  3. Lower the handle-end cover towards the cradle until any baluns that are out of their holders can be reinstalled.
  4. Install any baluns into their holders by opening the holder with one hand while placing the balun into the holder with the other hand.
  5. Install the handle-end cover onto the handle-end cover brackets.
  6. Make sure the ECG connector is aligned with the ECG opening on the handle-end cradle cover. If it is not aligned, adjust the ECG connector bracket to roughly center the connector with the cover opening.
  7. Make sure the turn-up coil port covers open easily and close automatically.
    Note: If the covers do not open easily or close automatically, lift the cover, move any cables that may interfere with the counterbalance, lower the cover, and retest the covers.
  8. Install the four screws securing the cover to the cradle.
  9. Install the side covers onto the handle-end cradle cover.
