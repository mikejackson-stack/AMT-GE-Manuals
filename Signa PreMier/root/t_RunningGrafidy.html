Running grafidy

Running grafidy in auto mode includes all axes.

Procedure

  1. Start the Grafidy tool.
    • (For non-proprietary service tools) From the Common Service Desktop, select Calibration > Grafidy. Select Click here to start this tool.

    Result

    The Grafidy tool window appears.
  2. Determine if the existing terms should be zeroed out.
    • For new system calibrations, click on the Zero Out tab.

      Select all the terms on the left and click Zero Out Cal Values before continuing to the next step.

    • For performance checks only, continue to the next step.
  3. Select the Auto Mode tab. All three coil axes are selected automatically.
  4. Click Scan to start the calibration.
    • When the scan is active, it can be stopped by clicking Abort on the window and pressing Stop on the keyboard.
    • Highlight the desired axis and click Show to show the result graphs. Or, on the Oscillatory cells, click Show Oscil to show the oscillatory graphs.
    In auto and manual modes, a number of signal checks are done to make sure of the proper state of the Grafidy fixture. The following signals are examined from every channel. An error is reported if a problem is found.
    • Position
    • Signal-to-Noise Ratio (SNR)
    • Signal saturation

    The Grafidy software runs multiple scans to bring each term into specification. It iterates up to the maximum amount specified (default is five iterations). When each component finishes a scan/analysis iteration, the residual of the eddy current of the measurement shows in the results table. The results are color-coded.

    Text colorDefinition
    RedValues above specification
    GreenValues within specification
    Auto mode acquires data in the following order:
    • DC
    • Vlong
    • Long
    • Short
    • Oscillatory (x & y)
    • Long (x & y) - second pass
    The oscillatory mode acquires 12 iterations per axis:
    • 7 for the transfer function
    • 4 for the data acquisition
    • 1 for a performance check

    Failing results during the first 11 iterations in oscillatory mode (red numbers) can be ignored. The 12th iteration of oscillatory mode will indicate whether the result is within specification.

  5. Review the numeric output values from the auto mode scan. Make sure that the results of the final iteration for each component are within specification (green).
  6. If a component is not within specification after the maximum number of iterations, use manual mode to calibrate that component.
