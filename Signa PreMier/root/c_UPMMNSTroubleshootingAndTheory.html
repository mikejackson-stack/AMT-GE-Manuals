UPM - MNS Troubleshooting and Theory

UPM - MNS Troubleshooting

Solution 1:
  1. Check all cabling to the UPM boards to make sure that they are properly cabled.
  2. Repeat the UPM functional test (MNS).
Solution 2: Recheck RF amplifier output.
  1. Cycle power to the UPM chassis.
  2. Reset TPS.
  3. Repeat the UPM functional test (MNS).

Solution 3: Reboot the system. Repeat the UPM functional test (MNS).

Solution 4:
  1. Remove power from the UPM.
  2. Reseat the processor module.
  3. Restore power to the UPM.
  4. Reset TPS.
  5. Repeat the UPM functional test (MNS).
Solution 5:
  1. Remove power from the UPM.
  2. Reseat the MNS detector boards.
  3. Restore power to the UPM.
  4. Reset TPS.
  5. Repeat the UPM functional test (MNS).
Solution 6: The problem could be a bad processor module.
  1. Remove power from the UPM.
  2. Replace the processor module.
  3. Restore power to the UPM.
  4. Reset TPS.
  5. Repeat the UPM functional test (MNS).
Solution 7: The problem could be a bad detector board.
  1. Remove power from the UPM.
  2. Replace both detector boards.
  3. Restore power to the UPM.
  4. Reset TPS.
  5. Repeat the UPM functional test (MNS).

For additional troubleshooting information, see Universal Power Monitor (UPM) troubleshooting.

UPM - MNS Theory

The UPM calibration parameters found in the UPM calibration file (/export/home/signa/tools/upm.config) are used in the calibration/functional check program. The program code sets the digital attenuators in the UPM based on the results of the tests run, and a comparison to these UPM calibration parameters. This calibration file is accessible from within the UPM calibration tool from the File menu, Edit Config option. These values can be edited and saved during troubleshooting to help understand where the power monitor is tripping (if at all). Before changing any parameters, make sure to select and run the Bkup UPM Cal option. This lets you return to the default values at any time. The UPM calibration file shown in Figure 1 contains the default configuration values for all of the UPM parameters. This screen is just for reference, because the content and values are different based on the system type and calibration results. Use Restore Defaults on the config file editor interface to return to known default values. The final UPM digital attenuator values are written to the UPM calibration configuration files (for example, Upm1Cal.cfg) located in the w/config directory.

  1. The format of Upm1Cal.cfg and Upm2Cal.cfg example is as follows:
    1. 85 Head FORWARD Power, attenuator setting in HEX
    2. 9f Head REFLECTED Power, attenuator setting in HEX
    3. 0 Head Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)
    4. 8d Body FORWARD Power, attenuator setting in HEX
    5. 8e Body REFLECTED Power, attenuator setting in HEX
    6. 9d Body Quad Hybrid Reflected Power, attenuator setting in HEX
    7. 93 MNS FORWARD Power, attenuator setting in HEX
    8. 83 MNS REFLECTED Power, attenuator setting in HEX
    9. 0 MNS Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)
    10. 0 CW FORWARD Power, attenuator setting in HEX (currently not used)
    11. 0 CW REFLECTED Power, attenuator setting in HEX (currently not used)
    12. 0 CW Quad Hybrid Reflected Power, attenuator setting in HEX (currently not used)
  2. Any changes to these values are temporary and can be restored by clicking Restore Defaults.
