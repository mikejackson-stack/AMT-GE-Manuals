Running the EPT Calibration tool

About this task

Note: The Echo Planar Test (EPT) procedures are no longer required for systems that have software versions 30 and later.

Procedure

  1. Start the EPT calibration tool:
    • From the Common Service Desktop, select Calibration > Calibration Tools > Echo Planar Test and click Click here to start this tool.

    The Echo Planar Test window appears.

  2. (For non-proprietary service tools) From the Common Service Desktop, select Calibration > Echo Planar Test. Select Click here to start this tool.

    The Echo Planar Test window appears with partial test selection.

  3. For calibration, set the Select All Tests? option to Yes.
    The default is No.

    For troubleshooting, select individual tests as needed.

  4. Two lines of Comments: can be entered, if needed.
    If no comments are entered, the text NO COMMENT is entered into the results file.
  5. Select a Test Purpose from the menu.
  6. For normal operation, the options buttons on the screen are set correctly by default. You can change the options to suit the tests you need to run.
    1. To perform more than one pass of the tests, select Multi Passes and enter a number in the text box.
    2. One or more of the selected tests can automatically update the configuration files with new calibration data if the new data is within specification. Select Config Update before starting EPT.
  7. Click Start EPT. Running all the tests takes about 30 minutes and thoroughly tests the system’s EPI performance.
    While EPT is running, each test is displayed in the message window showing the amount of time the test requires to run.
    Note: For 3.0T systems, B0 Dither is no longer run. Zeros are placed in the B0 Dither calibration files.
