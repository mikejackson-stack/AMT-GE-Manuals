Loading USB host system software

An overview of the steps required to reload or upgrade USB host system software.

Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

Procedure

  1. Insert the USB software device required for this procedure.
    Note: A USB-3 port is recommended. The port has a blue-colored plug or is labeled on the box.
  2. Set up the correct Firmware on the host PC:
    1. (For Dell T5810 or Dell T5820) Press the Power button on the host PC to boot the system.
      Note: Beginning at RX29.0 the Dell T5820 is the only PC available.
      1. Press F12 to enter the Boot menu, when DELL logo appeared on the screen.
      2. Make sure the Boot mode is set to UEFI. If the Boot mode is set to Legacy, you must change it to UEFI mode. See Changing Boot mode.
  3. Use the up and down arrows on the keyboard to select the USB software media listed under UEFI Boot. Brand and model may vary.
  4. Press Enter to select the USB software installer media under the UEFI Boot menu.

    Result

    The software version shows in the upper left corner.
  5. Select the option shown in the format [apps]<Apps Software revision> and press Enter.
  6. (For HELiOS) OS installation (RX29.1 and earlier):
    Note: (For RX29.1 and earlier) At times during the software load, a blank (frozen) screen may show due to a known Red Hat bug (bug ID 1432436). If this occurs, you must restart the software load from the beginning. Press Ctrl + Alt + F2 to access the Command prompt screen and restart the software load.
    • At the start of OS installation, automated OS configuration takes place and then OS install starts within a few minutes.
    • OS installation continues to completion.
  7. (For SUSE) OS installation (software version 30):
    • At the start of OS installation, automated OS configuration takes place and then OS install starts within a few minutes.
    • OS installation continues to completion.
  8. If the OS install fails, remove and reinsert the USB software device, and try the install again.
    • If the OS install is successful, the system automatically reboots.
    • The application's software load automatically starts.
    • The language menu can be used to select a different language.
  9. If the application's software install fails for any reason, remove and reinsert the USB software device, and try the install again.

    If multiple dialog boxes appear during this process, click OK on the boxes (three total) and then click Run.

    Note: For a new installation, Guided Install is not yet configured correctly and the ICN load may fail. Please configure ICN manually after completion of the automated software load and Guided Install configuration. In addition, the USB installer provides a default MGD subnet IP address , which can be used for all sites. If ICN detection fails with this subnet, see Resetting the Image Compute Node (ICN) BMC interface and retry the ICN configuration.

    Make sure the MGD subnet IP is not conflicting with the local site network. If the subnet IP is conflicting, see Changing the MGD/TPS subnet address.

    Note: The Installer Info window shows along with the Locale Selection window.
    Note: The Info Window lists all the software load actions that have either not been attempted or have failed.
  10. Guided Install language selection and System Configuration should now be completed. See System and hardware configuration. Click Configure on each tab of Guided Install where configuration is updated.
    Note: Pending software load tasks from the Info Window must be completed manually. To complete the actions, see Installing host system software. The system will not boot to a scannable state if these actions are not completed. Pending tasks include:
    • Guided Install Configuration entries
    • ICN Configuration
    • IRM installation
    • Service Pack Load as necessary per DOC1667089
    • Service Software Load (this task is not automated as part of the USB software load)
    • Set up InSite RSVP Connectivity
    • SSA License installation
    • Option Keys installation
    • Operator Manual installation
    • Reboot the system
    • Finalization steps as listed in Installing host system software procedure (ICW actions)
    For detailed information on completing these remaining tasks individually, see Installing host system software.
  11. After all pending actions are completed on the Guided Install window, click File > Quit.
  12. Close the GE HealthCare MR Installer status window.

    Result

    A software check for upgrade scenarios runs, checking for software upgrade scenarios and setting up ICW as needed.
  13. Return to Installing host system software and complete the remaining tasks individually based on the status of the software load.
