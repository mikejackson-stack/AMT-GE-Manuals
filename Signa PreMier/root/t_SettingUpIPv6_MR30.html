Configuring IPv6 with Cisco Firepower 1010

The IPv6 transformer provides communication capability between the MR console, and IPv6 devices. The FE must work with a site IT administrator to do this procedure.

Prerequisites

Required conditions
The FE must work with the local IT team to collect two static IP addresses: one for the MR System and one for the Cisco router.
Note: If sites have a dual stack network, they will have both IPv6 and IPv4 addresses. In this situation, you will need to get four addresses - two for each.
The FE must work with the local IT team to collect the NTP server IP address for the hospital network, if available.
Java version 9 must be installed on the FE laptop for router configuration. See https://www.java.com/en/.
Cisco Firepower 1010 must be available.
2 LAN cables must be available. You may need a LAN adaptor to connect the LAN to the FE laptop.

Procedure

  1. Power on the Cisco router by plugging in the power adaptor to the router. Wait approximately 30 minutes and make sure all three activity indicator lights turn solid green.
  2. The back of the router has assigned port numbers. When configuring the router, connect the laptop to LAN port 2 (LAN ports 3 through 8 and two service ports are disabled by default).
  • Connecting the laptop to the Cisco router for initial configuration
    Connect the laptop to the Cisco router as part of the initial configuration.
  • Installing Cisco ASDM software
    Install the Cisco ASDM software on your laptop.
  • Configuring the Cisco ASDM interface
    Configure the Cisco ASDM interface.
  • Configuring the Cisco router date and time
    Configure the Cisco router date and time.
  • Configuring the banner
    Configure the banner.
  • Configuring the Cisco router for hospital network access
    Create the Cisco router for hospital network access.
  • Creating an IP translation map
    Create an IP translation map.
  • Configuring MR System network information
    Configure the MR System network information.
  • Doing final health checks
    After the network is configured, health checks can be done on any of the MR System servers as usual.
  • Doing a backup of the configuration
    Do a backup of the configuration and store it on the FE's laptop.
  • Restoring the configuration
    Restore the backup configuration file.
