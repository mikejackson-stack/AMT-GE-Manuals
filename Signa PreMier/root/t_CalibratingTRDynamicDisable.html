Calibrating transmit/receive dynamic disable

Calibrates the open circuit fault detection levels of the dynamic disable drivers in the driver module. Do this procedure after system installation, driver module replacement, body coil replacement, body hybrid replacement, or replacement of cabling between any of the previously listed devices.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-3 minutes30 minutes

About this task

Calibration Wizard is a restricted service tool. Make sure your C-class or M-class service key is installed.

Procedure

  1. (For proprietary mode)
    1. On the Common Service Desktop, select Calibration > Install and Calibration Wizard.
    2. Click Click here to start this tool.
    3. After the calibration wizard starts, select TR Dynamic Disable Calibration from the menu.
    4. Review the pre- and post-dependencies, and then click Click here to start this tool.
  2. (For non-proprietary mode)
    1. On the Common Service Desktop, select Calibration > TR Dynamic Disable Calibration.

    Result

    When the calibration is complete, the results will show in the test results text area (see figure below).
  3. Do a check scan. See Doing a check scan.
  • Doing a check scan
    A check scan is done at the conclusion of many procedures. This functional check assures the unit is in good clinical working order.
