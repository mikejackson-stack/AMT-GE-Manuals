Configuring the RF coupler for body calibration

Procedure

  1. Insert the 50 kW element (blue 4300A374-3) into the forward sensor port and the 5 kW element (blue 4300A374-6) into the reflected sensor port.
    1. Make sure the arrows on the elements point in opposite directions.
    2. Lock the elements in place using the sensor locking tabs.
    The reflected port is not used during this procedure. Placing the 5 kW element into the reflected port is just a safety measure.
  2. Use a DVM to measure the resistance of input to the dummy load.
    1. Measure directly on the dummy load input connector – center pin to GND.
    2. Make sure that the resistance measures 50Ω ± 5Ω.
      Notice
      Possible calibration failure
      If the dummy load is out of specification, the calibration will fail. Do not proceed with the RF amplifier output calibration. Return the RF kit for repair.
      Make sure that the resistance measures 50Ω ± 5Ω.
