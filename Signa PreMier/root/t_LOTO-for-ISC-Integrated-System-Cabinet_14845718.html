Applying LOTO - ISC

Apply LOTO to the Power Distribution Unit (PDU) when servicing this item in the Integrated System Cabinet (ISC). Applying LOTO ensures a safe environment when working on this part.

About this task

Warning
Electrocution hazard
High voltage present.
Use proper LOTO procedures before servicing and/or maintaining.
This document covers ISC PDU Main Breaker - Lockout and ISC PDU - Restoring Power. Prior to doing work on the ISC electronics (except PDU), Integrated Cooling Cabinet (ICC) electronics (except F50 Cryocooler Compressor), and electronics in the magnet room (except magnet), the steps in this Lock Out Tag Out Procedure must be completed by a LOTO authorized GE HealthCare Field Engineer (FE). Completing all the steps in this procedure ensures a safe environment and avoids equipment damage when working on these parts.

About this task

Types of equipment and/or methods used to ensure disconnections

Procedure

  1. One personal lock and tag per FE at the site working on the de-energized equipment at the time of LOTO.
  2. Voltmeter to read voltage for verification that energy has dissipated in the PDU.
Topic ID: id_SL13909672-1178697

Power down the computer subsystems

About this task

System Power Off, under Access tab, is for customer use since it will require 1 hour at the most to power down the system to cool down gradient coil temperature, and reduce B0 drift in customer scan level. For service LOTO, use system shutdown for immediate shutdown. However, note that it will be required to wait 1 hour after restoring power for certain calibration and/or customer scan.

Topic ID: id_SL14015070-1178697

System shutdown when system is in operator level

Procedure

  1. To prepare for shutdown of equipment, notify affected personnel working in the area the LOTO is being done.
  2. From the Common Service Desktop, select Utility > System Shutdown and click Shutdown to shutdown the PC and ICN.
Topic ID: id_SL13909676-1178697

System shutdown when system is in root level

Procedure

  1. To prepare for shutdown of equipment, notify affected personnel working in the area the LOTO is being done.
  2. Power Off the ICN. Refer to ICN On/Off Procedure for Dell R-620 or Shutting down the ICN for Dell R630 (Gen 6) and R640 (Gen 7).
    Note: If the system is logged on as root, refer to Powering Down from Root Level.
  3. Right-click on the Linux desktop to access the Root Menu and then select Logout.
  4. Select Menu > Shutdown on the Welcome login screen to shut down the system.
  5. Make sure the system is shut down.
Topic ID: id_SL28617-1178697

ISC PDU main breaker - lockout

Procedure

  1. Rotate the larger main breaker labeled INPUT counterclockwise to the green Off (O) position.
  2. Apply LOTO to the PDU input breaker by pressing the left-pointing arrow on the end of the handle to expose the location where the lock and tag can be placed.
