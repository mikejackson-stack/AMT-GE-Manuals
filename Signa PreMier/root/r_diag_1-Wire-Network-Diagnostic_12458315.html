Doing the 1-wire network diagnostic

The 1-wire diagnostic makes sure that all of the 1-wire devices in the network are connected.

Purpose

The 1-wire diagnostic makes sure all of the 1-wire devices in the network are connected (shown in the block diagrams). Some 1-wire devices report status information for the hardware in which they reside.

Expected system operation status, such as cable connections and power status, shows in blue text. Unexpected test results, such as 1-wire devices not detected or cables not connected, shows in red.

Note:

The test also allows you to reset the 1-wire network by selecting the optional Force 1-Wire Reset check box before running the test. Do this if the network is not responding or if the network configuration requires refreshing after changes have been made to the network.

Topic ID: id_SL1989767-1224951

Components tested

  • 1-wire network
  • Power and cable connections
  • Temperature and humidity sensors
Topic ID: id_SL1989771-1224951

Requirements

Before the 1-Wire Network Diagnostic can be run, the following requirements must be met:

  • The USB cable from the USB-to-serial converter [which is connected to the Patient Handling Power Supply (PHPS)] must be connected to a USB port on the host computer.
  • The PHPS must be powered up.

Block diagrams

Topic ID: id_SL1989773-1224951

Test sequence

  1. (Optional) Select alternate test parameters as described below:
    • To run the diagnostic more than once, enter a different value in the Iterations box.
    • To remap the 1-wire network, select the Force 1-Wire Reset check box. This option is useful when hardware has been replaced to identify 1-wire devices in the new hardware (a TPS reset also accomplishes a 1-wire reset, but any new hardware installed during troubleshooting can be identified using this option prior to doing a TPS reset.).
    • To show all information programmed in the 1-wire board identifier devices, select the Display Extended 1-Wire Information check box. This option provides more detailed information than the HART log. It also shows information for all bits of programmable input and output, including those that may not currently be used.
  2. Click Run.
Topic ID: id_SL1990901-1224951

Expected results

The blue text in the Test Output area shows successful tests and 1-wire devices detected by the 1-wire network diagnostic. The red text in the Test Output area shows failures and 1-wire devices that are not detected by the 1-wire network diagnostic.
