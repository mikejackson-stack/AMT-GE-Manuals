Setting LVShim Expert mode parameters

The Expert mode of LVShim lets you use several features that are normally not necessary during magnet shimming.

About this task

LVShim Expert features are designed for experienced users. The Expert mode options are:
  • Cal file
  • Scale currents (for example, selecting 0.5 inserts half of the calculated current)
  • Bandwidth

Procedure

  1. Select the Shim Type (Gradient Shim, Supercon Shim-Rough, Supercon Shim-Fine, or Test) before you click More Actions > Expert Mode, because the Expert mode contents depend on the shim type.
  2. To access Expert mode, select More Actions in the upper left section of the LVShim tool and select Expert Mode.
