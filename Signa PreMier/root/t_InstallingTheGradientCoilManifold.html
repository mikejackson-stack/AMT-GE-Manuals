Installing the gradient coil manifold

Install the replacement gradient coil manifold or reinstall the existing manifold, if removed.

About this task

This is a two-person procedure until several hoses are connected or the support brackets are reinstalled.

Procedure

  1. Apply a small amount of vacuum grease or similar lubricant to each barb to assist in ease of hose attachment. Only apply enough grease to allow the hose to slide onto the barb smoothly.
    Note: If there is residual grease on the barbs, do not apply vacuum grease.
  2. Apply tape or a cap to the 1-inch male connection threads to protect the threads from damage, if a cap is not present.
  3. Move the manifold into place in front of the service end of the bore.
    Important: Do not put pressure directly on the elbows of the gradient manifold. They bend under direct pressure.
    Important: The manifold must be centered as much as possible to avoid interference with the covers when they are installed.
  4. Starting with the inner hoses, working from left to right at the top of the gradient coil, do the following:
    1. Slide a worm gear clamp onto a hose.
    2. Slide the hose all the way onto the corresponding barb.
    3. Tighten the clamp using a nonferrous screwdriver.
    4. Fully cover the clamp with heavy duty electrical tape.
    5. Repeat for each inner hose and then each outer hose.
    Note: If Oetiker clamps were removed, replace them with nonferrous worm gear clamps [9 mm x 12-20 Hose Clamp, Stainless Steel (46-252065P155)]. If worm gear clamps were already installed, replace all damaged clamps and reuse the clamps that are in good condition.
  5. (For UA/3TLC only with rigid copper manifold) Install three gradient coil manifold brackets.
    1. Install a gradient coil manifold bracket (5782116) on the first and second holes to the left of the top center hole and secure with two M10 x 16 Socket Head Screws (1000-M10C016-33).
    2. Install a gradient coil manifold bracket (5782117) on the first and second hole to the right of the center hole and secure with two M10 x 16 Socket Head Screws (1000-M10C016-33).
    3. Install a gradient coil manifold bracket (5782116) in the location shown and secure with M10 x 16 Socket Head Screws (1000-M10C016-33) (standoffs are shown for perspective, they are not yet installed).
    4. Tighten both the nut and screw to a torque of 15 ft-lbs (20.33 N m).
    1Gradient coil manifold bracket location, top left bracket (5782116)
    2Gradient coil manifold bracket location, top right bracket (5782117)
    3Gradient coil manifold bracket location, bottom left bracket (5782116)
  6. (For UA/3TLC only with rigid copper manifold) Install the manifold retaining clips (5782118) and Velcro straps (5754795).
    1. Slide the three manifold retaining clips between the blue and black manifold at each gradient coil manifold bracket.
    2. Secure a spacer to each bracket with an M6 x 50 Socket Head screw (1000-M6C050-33).
    3. Install a Velcro strap (only one is shown) on each side of each manifold support bracket assembly.
    1M6 x 50 Socket Head screw (1000-M6C050-33)
    2Manifold retaining clip (5782118)
    3Velcro straps (5754795)
  7. (For UA/3TLC upgrade only with flexible additive manifold) Install two gradient manifold brackets:
    1. Assemble the two bracket assemblies using one bracket (5782116), one support (5837423), and one M6x12 Screw (1000-M6C012-33) per assembly:
    2. Install one bracket assembly to the (+330°/+ 345°) hole positions on the magnet service end interface ring, using two M10 x 16 screws.
    3. Install one bracket assembly to the (+15°/+30°) hole positions on the magnet service end interface ring, using two M10 x 16 screws.
    4. Guide the 1-inch blue and black manifold hoses on the gradient service end into the support.
    5. Wrap two pieces of Velcro straps around the manifold hoses near each of the two installed bracket assemblies.
  8. (For W-WB/G3 upgrade only with flexible additive manifold) Install two gradient manifold brackets:
    1. Assemble bracket assembly A using one bracket (5782532), one support (5837423), and one M6 x 12 Screw (1000-M6C012-33).
    2. Assemble bracket assembly B using one bracket (5837415), one support (5837423), and one M6 x 12 Screw (1000-M6C012-33).
    3. Install bracket assembly A to the 345° position on the magnet service end interface ring and bracket assembly B to the 15° position on the magnet service end interface ring.
      Note: Use the existing six (three for each bracket) buttonhead cap screws from the previous brackets.
    4. Guide the 1-inch blue and black manifold hoses on gradient service end into the support.
    5. Wrap two pieces of Velcro straps around the manifold hoses near each of the two installed bracket assemblies.
  9. (For W-WB/G3 only with rigid copper manifold) Install two gradient coil cable manifold supports:
    Note: If the black flexible gradient coil hoses interfere with the manifold bracket, attempt to rotate the gradient coil manifold assembly to remove the interference (the movement comes from the flexible hoses).
    1. Attach the two gradient coil manifold brackets (5782532) to the busbar lower support plate with two M6 x 20 Stainless Steel Screws (1003-M6C020-33).
    2. Position a manifold retaining clip (5782118) below the hoses and a top bracket. Slide the manifold support bracket between the hoses and align it with the top bracket.
    3. Attach the manifold retaining clip to the manifold bracket with an M6 x 50 Socket Head screw (1000-M6C050-33) by inserting the screw into the plastic manifold bracket from below.
    4. Repeat with the second manifold support bracket.
    5. On each side of each manifold support bracket assembly, install a Velcro strap (5754795).
    1Manifold retaining clip (5782118)
    2Velcro straps (5754795)
  10. Connect the gradient manifold to the magnet manifold:
    • (For rigid copper manifold) Connect the male 1-inch JIC fitting on the rigid copper manifold to the female 1-inch JIC fitting coming down from the magnet manifold.
    • (For flexible additive manifold) (5822816-2) Install a 1-inch male-to-male JIC adapter onto the gradient manifold that has a female 1-inch JIC fitting, and then attach the adapter to the female 1-inch JIC fitting coming down from the magnet manifold.
  11. Connect the hoses to heat exchanger.
  12. Connect the return hose (black) and supply hose to the magnet manifold.
  13. Open the supply and return valves on the coolant supply and return lines.
