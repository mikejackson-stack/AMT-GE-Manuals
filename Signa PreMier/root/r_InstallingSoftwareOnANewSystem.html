Installing software on a new system (USB load only)

Install the host system software on a new system (USB load only).

This flowchart shows the high-level summary of the USB host system software load workflow. Boxes shown in white are automated. All other actions must be completed manually. Note the important step of updating EA3 login, root, and admin passwords to new defaults (not applicable to SW reloads) in the red box. This has been mandated from the RX28 software release.

Use this flowchart only as a high-level insight into USB software load. The detailed procedures for the software load are provided in the table below.
Notice
Potential software corruption
Never insert the USB Software Media on any other laptops or computers as it will likely corrupt the software on the media.
Note: Most process steps have been automated in the software load. Any failures will appear in the installation window and are required to be fixed in Guided Install. Automated process steps have been included in the workflow.
Loading software
StepProcedure for USB load only

Prerequisites
  1. Identify the information you will need to have about the site and the site’s hardware. See System and hardware configuration.
  2. Check with the site IT team regarding InSite RSvP connectivity and collect the following information. How will the site connect to InSite RSvP?
    1. Site DNS Server, Primary DNS IP Address: ___.___.___.___ , Secondary DNS IP address: ___.___.___.___
    2. Site Proxy Server, Proxy Server IP address: ___.___.___.___, Port#:___, Proxy Login credentials as applicable
    3. GE VPN Proxy Server, make sure that the region connectivity team has set up VPN tunnel for this site. The same team will also give Proxy IP address and port number details
  3. SSA Softkey licenses would need to be generated as soon the 16-digit code is accessible post install of software. Make sure SSA softkey administrative personnel are available to configure the 16-digit code in SSA portal and generate the softkeys.
  4. An active SSA Class M hard key is required for service software install.
  5. Update the eLicense portal to map the GON number with the system ID and generate the applicable option keys for the site.
Note: Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library, and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.

Required media
  • USB software media for new installations.
  • USB installer with label.
  • GE Equipment Maintenance Sticker (5661793).
  • Operator Manual DVD/USB.
  • Service Pack DVD (as required).

Load USB host system software

Loading USB host system software
Note: The Host OS Load, Applications Software Load, and ICN OS copy actions should complete automatically. The Configure ICN action may fail, which would be reported as a failure in the final report.

If any failures occur prior to the Applications Software Load completion, restart the Software Load process.

For a list of errors and possible actions during the software load procedure, see Troubleshooting the software load.

System configuration

Complete network configuration, System and hardware configuration, and Security levels for software 29.0 and later configuration in Guided Install. Complete any other site configuration as needed in Guided Install and click Configure in each tab.

Configure ICN (VRE) OS

This task is automated. If a failure should occur, this can be completed manually. See Configuring the ICN - VRE.

RSvP registration

Register device with RSvP to establish remote connectivity. See Configuring the Remote Service Platform (RSvP) for software 29.0 and later. See Enabling the Remote Service Platform (RSvP) iLinq to enable iLinq.

Install IRM

This step is automated through USB installation. See Installing IRM software.

Install SSA
  1. See Managing SSA service licenses for information on how to record the service license ID.
  2. See Ordering service license softkey to order the license.
  3. See Loading service license softkey softkey to load the license.

Install options/option keys

For the purchasable option keys, see Option key catalog matrix.

Note: Signa Secure Advanced option: If the customer purchased this license, configure the security setting in Guided Install to Signa Secure Advanced. The system must be restarted to enable the highest security configuration in Guided Install.
Note: The Signa Secure Advanced option key is no longer needed with software version 30 or later.

Install operator manual

Installing operator documentation (online help).

Install latest service pack (if required)

See Loading software updates from the repository or CD/DVD or Remote software download.

Note: Refer to the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library, and make sure the necessary service pack media (if any) is available. Do not start the software load until this media is available.

Close Guided Install from File → Quit option and then reboot the system
  1. Set the date and time correctly before setting the remaining configurations. A wrong date or time setting could lead to safety issues.
  2. Closing Guided Install allows for the remainder of the USB installer actions including scantools (default) option keys install and upgrade mode checks for ICW. This step is critical for successful completion of software load, thus do not reboot the system without closing Guided Install.
  3. Guided Install may display messages stating that Product Configuration is not matching the option keys. If this message appears, make sure the hardware configuration is configured correctly and all required option keys for the configuration settings are installed.
  4. Remove the software installer USB Key.
  5. Fill out the label on the software installer USB key with the current version of software.
  6. Reboot the system.

Set up OS passwords. Minimum length is 15 characters

(for time period during calibration)
  1. Set up a temporary OS password.
    Note: This screen will show after rebooting the system.

  2. After the passwords have been set up for all OS accounts, the password window disappears. Right-click on the blank screen, and click Logout.

Log on to Applications
Click Start to log on to applications.

Set up EA3 gesvc password
  1. If the system is already booted in applications, click Lock Screen Switch User in the Service Desktop manager to access the Logon screen.
  2. Log on using the gesvc account. The default password is operator and this password will be forced to change on first use.
  3. Create the gesvc password.
  4. This password can continue to be used for the lifetime of the equipment as the gesvc login password for any service activity needed at site.
  5. The gesvc EA3 account is intended to be used as a password recovery mechanism in case the customer forgets their logon password.

EA3 User Group Establishment

Add EA3 users to their correct user groups to establish the correct permissions. For information on adding user groups, see Configure user accounts for Role Based access controls.

Note:
Add the gesvc user to groups:
  • GESoftwareInstallerGroup
  • ProtocolEdit
Add the administrator user to groups:
  • GESoftwareInstallerGroup
