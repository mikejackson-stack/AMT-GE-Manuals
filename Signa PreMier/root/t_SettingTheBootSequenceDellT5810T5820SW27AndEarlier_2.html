Setting the boot sequence - Dell T5810/T5820 (MR27 or earlier)

Specifies the order of host computer boot devices.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-5 minutes-

About this task

Use these steps for MR27 and earlier only. For MR28 and later, see Setting the boot sequence - Dell T5810 (MR28 or later).

Procedure

  1. Turn on or restart the computer. Press F2 to enter the BIOS Setup menu.
    Note: Optionally, press F12, then select the BIOS Setup menu.
  2. In the Settings pane, expand the General menu.
  3. Select the Boot Sequence option.
  4. In the Boot Sequence pane, if checked, clear the following:
    • Diskette Drive
    • USB Storage Device
    • CD/DVD/CD-RW Drive
    • Onboard NIC
    Note: OS media will not be detected when USB Storage Device and CD/DVD/CD-RW Drive are disabled. Using the steps in this procedure, re-enable USB Storage Device and/or CD/DVD/CD-RW Drive as an external boot device prior to using the OS media.
  5. In the Boot Sequence pane, if not checked, select: both SAMSUNG SSD options.
  6. At the bottom of the screen, click Apply, then click Exit to save changes and exit BIOS.
  7. If you are setting up the computer for the first time, see Setting the BIOS password - Dell T5810/T5820.
