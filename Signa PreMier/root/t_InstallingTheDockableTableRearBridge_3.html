Installing the dockable table rear bridge

Installs the dockable table rear bridge onto the magnet.

Prerequisites

Personnel requirements

1-10 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
Nonmagnetic Titanium Service Tool Kit, Small Set15113258-

Procedure

  1. Install the rear bridge onto the guide pins at the rear of the front bridge.
  2. Remove the rear bridge tool from the side of the rear bridge.
  3. Install the four M10 x 60 Socket Head Screws and four M10 Small Washers securing the rear bridge to the front bridge in the order shown in the illustration.
    Important: The screws must be tightened in the order shown or the End Of Travel (EOT) sensor may not function properly.
  4. Place the rear bridge installation tool into its holder on the side of the rear bridge.
  5. Install the four M10 x 40 Hexagon Flange Bolts securing the rear bridge to the rear bridge mount and install caps in the order shown in the illustration.
    Important: Do not tighten the bolts below before the screws in the previous step are tightened. Doing so may cause the EOT switch to not function properly.
  6. Route cable M3507 cable under the rear bridge and connect it to end of travel switch.
  7. Install the Universal Transient Noise Suppression (UTNS) antenna as follows:
    1. Insert the BNC adapter through the bracket hole and install washer.
    2. Install the nut securing the BNC adapter.
    3. Connect the UTNS antenna to BNC adapter.
    4. Route cable M1315 under rear bridge and connect BNC connector to UTNS antenna assembly.
