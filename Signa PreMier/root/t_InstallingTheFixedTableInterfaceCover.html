Installing the table interface cover

Installs the fixed or dockable table interface cover onto the magnet front cover.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-5 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
Nonmagnetic Titanium Service Tool Kit, Small Set15113258-
Required conditions
Front endbell is installed.
Left- and right-hand lower access panels are removed.

Procedure

  1. If the fixed table is installed, raise the patient table to the up-limit position. Otherwise, undock the patient table.
  2. Install the table interface cover onto the magnet front cover.
  3. Install four M10 x 25 Socket Head Cap Screws securing the table interface cover to the magnet front cover.
