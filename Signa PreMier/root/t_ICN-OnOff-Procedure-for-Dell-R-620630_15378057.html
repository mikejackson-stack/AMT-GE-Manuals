ICN On/Off procedure for Dell R-620/630

Prerequisites

Warning
ELECTROCUTION HAZARD!
DANGEROUS VOLTAGES ARE PRESENT THROUGH OUT THE SYSTEM CABINET WHEN POWER IS APPLIED.
REFER TO the MR Service Safety Manual, PN 5452735.
Notice
Follow this procedure for removing power to the ICN chassis. Failure to properly power down ICNs may result in premature ICN failure.
Do not turn power off to the ICNs using the power button on the front panel. The ICNs have software running on disk drives that may become corrupted if not powered down properly.

About this task

This procedure documents the proper methods of shutdown for the Dell R-620/630 ICN. The ICN is powered up when the host is started. There is no need to switch the ICN on individually. If needed, you can switch on the ICN from the VRE Power Control utility.

The ICN is powered down when the host software is shut down. To shut the ICN down individually, use the VRE Power Control utility.

If the preferred shutdown method does not work, a last resort is to use the ICN power button.

Topic ID: id_SL12716908-1178714

Switch On ICN from VRE Power Control

Procedure

  1. On the Common Service Desktop, go to Utilities > Toolbox > VRE > Power Control.
  2. Click POWER ON ICN for the selected ICN.

    The ICN is automatically powered on.

    The Dell ICN displays the boot status on the LED readout, located on the front panel of the ICN.

  3. If the application software is down, you can power on the ICNs from the xterm command line. Type: /etc/init.d/poweron_vres start and press Enter.

Powering down ICN from VRE power control

About this task

This is the preferred method for shutting down the ICNs.

Procedure

  1. At the host computer, on the Service Browser, select Utilities > Toolbox > VRE > Power Control
    Note: The number configuration should match the number of VREs. The illustration above shows images from a system with a Sun 4100 ICN. Systems with a R-620/630 ICN have only one ICN selection.
  2. Confirm the ICN numbers and their MAC addresses. The MAC addresses are printed on a sticker on the front of the ICN.
  3. Click POWER OFF ICN(x). Wait for the ICN to power off as shown below.
    The screen displays the power status of the ICN as it is switching off.
  4. Refresh the Power Control link to see the current state of the ICN.
  5. The Dell ICN is powered down when the green power LED located on the upper left side of the front of the ICN for Dell R-620/630 is not illuminated.
Topic ID: id_SL1918778-1178714

Powering Down from Root Level

About this task

If the application's software is down, you can power down the ICNs by using command line at the root level.

Procedure

  1. Log into the application using the root login.
  2. In the xterm window, type: /etc/init.d/poweron_vres stop and press Enter.

    The ICN(s) should turn off after one minute.

    The Dell ICN is powered down if the green power LED located on the upper left side of the front of the ICN is not illuminated.

Topic ID: id_SL1918782-1178714

Power off ICNs manually

Procedure

  1. Notice
    If neither the browser nor the command line are accessible, the ICNs can be powered off manually. Try this method before powering off the GOC. This is the preferred method because it does not corrupt the files on the hard drive.
    Momentarily press the power button. (For Dell ICN, the green LED is also the power button.) This brings down the ICN in a soft method. It takes a minute or two for the operating system to boot down.

    The Dell ICN is powered down if the green power LED located on the upper left side of the front of the ICN is not illuminated.

  2. If the OS freezes or is not responding, then the soft method did not work properly. In this case, hold the power button down for six seconds to force the power off.
