High Order Shim (HOS) Calibration Theory

High Order Shim (HOS) Calibration Theory.

Introduction

The HOS feature allows the clinical user to shim over a specified volume to take advantage of the HOS coils embedded in the gradient coil to compensate for patient-induced magnetic field inhomogeneity. This feature can improve the local field homogeneity for use in sensitive applications such as frequency-selective fat suppression, spectroscopy, spiral scanning and functional imaging. The calculations completed as part of the HOS feature require knowledge of the change in static field behavior of each individual shim coil; therefore, a calibration tool is used to characterize the field generated by each HOS coil. The resulting information is stored in the Reference Field Maps, which must be calculated once per system installation. These field maps need to be updated only if the gradient coil is replaced. The Reference Field Maps are retained using the SaveInfo tool.

Process overview

The Reference Field Map creation process requires you to run a localizer scan on a phantom and adjust its position to within 5 mm. After the phantom is positioned, you then run the HOS Calibration Tool, which will automatically complete the following operations:
  • Loads the required scan protocol for collecting B0 maps.
    Note: The scan protocol is identical to the scan used by the LVShim tool in Test mode. The LVShim phantom is used by the HOS calibration tool.
  • Collects images with default linear shim settings to obtain the baseline field.
  • Perturbs the current for each of the coils, one at a time, by a prescribed amount.
  • Allows time for the field to stabilize before starting the scan.
  • Reconstructs the data and extracts the phase information that reflects the magnetic field variations.
  • Analyzes the data and makes sure the field results are within expected tolerances.

Field map creation

When all coils have been characterized and verified to be within expected tolerances, three reference field maps are created corresponding to three FOV/matrix combinations. These maps correspond to the three HOS protocols provided and are used to convert measured field to HOS current when using the HOS feature. The map combinations are:
  • 24 cm / 64 x 64
  • 28 cm / 64 x 64
  • 48 cm /128 x 128
