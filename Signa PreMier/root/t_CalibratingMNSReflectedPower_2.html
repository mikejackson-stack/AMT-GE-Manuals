Calibrating MNS reflected power and UPM - MNS functional check

Calibrate reflected power for the Multi-Nuclear Spectroscopy (MNS) amplifier.

Procedure

  1. Move the RF Enable S2 switch to the disable (down) position.
  2. (For CPC amplifier) Disconnect the RF output cable:
    • (For the GEN 1 CPC amplifier) (5411744) Open the rear door and disconnect the RF output cable from J3 of the combiner module in the CPC cabinet and leave open.
    • (For the GEN 2 CPC amplifier) (5750811) Open the rear door and disconnect the RF output cable from J2 of the power output in the CPC cabinet and leave open.
  3. Move the RF Enable S2 switch to the Enable (up) position.
  4. Return to the UPM Tool window.
  5. Select MNS 31P from RF Chain.
  6. Select Calibrate Power Monitor > Reflected Power from Task.
  7. Set Power Monitor to Reflected.
  8. Select Start.
  9. In a few minutes, the tool shows Pass/Fail. If failure occurs, do the following troubleshooting steps:
    1. Ensure proper setup of the calibration equipment.
    2. Check the cabling between the UPM and the amplifier.
    3. Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions.
      Check mgd_stage file: cd /w/config. Remove the “p” if necessary (p=UPM emulated).
    4. Do the maximum RF power calibration procedure. Repeat the UPM calibration.
    5. Check the UPM for power.
    6. Check the error log for details of the UPM failure.
  10. If Pass is shown, do the functional check procedure for the applicable RF output.
  11. Do the UPM MNS functional check:
    1. Disable the RF Enable S2 switch by moving it to the DOWN position.
    2. Reconnect the RF dummy load with the coupler to the RF output connector on the back of the MNS amplifier.
    3. Enable the RF Enable S2 switch by moving it to the UP position.
    4. Return to the UPM Tool window.
    5. Set Task to UPM Functional Check and click Start to complete the UPM functional check.
    6. The UPM tool takes full control and runs the functional test.
    7. A prompt shows when the UPM Host Trip test completes. Look in the error log to make sure that the test completed successfully, and that a trip error occurred.
    8. The UPM test status shows Pass or Fail.
      • If the test passes, select Quit from the UPM tool's main window.
