Observing system tray status icons

Use the system tray status to identify if any system updates area available.

About this task

After the scanner starts, the system tray status shows the availability of software updates and/or connectivity status.
IconStatus
A new service pack is available. If you click the icon, information about the service pack shows. You cannot install or decline the update from the system tray interface.
The service pack installed successfully. After 20 seconds, this notification will no longer show.
The service pack installation failed. After 20 seconds, this notification will no longer show.
Note: If the update fails to install, rollback occurs.
There are no updates available. The server connectivity icon shows when the system is connected to the back office. The system checks the connection to the back office every 5 days.

Procedure

Choose one of the following options to install a new update:
  • Restart the system to install from RSD.
  • Install the software update manually.

Finalization

Follow actions as recommended in the read me file information.
