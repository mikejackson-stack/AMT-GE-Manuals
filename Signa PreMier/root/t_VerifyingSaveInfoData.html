Do a check of the SaveInfo data

Use the checkINFO command to do a check of the contents of the SaveInfo data on the system disk and the SaveInfo media.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-5 minutes-
Required conditions
System software is running and active on the host computer.
Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

About this task

The CheckInfo program first does a check of the system disk for the correct files and correct file size.

If discrepancies are found, the program will report what is wrong. The program will stop, and not do a check of the SaveInfo media for correct file structure.

If the SaveInfo structure is correct, the program will automatically do a check of the contents of the SaveInfo media.

Procedure

  1. Make sure that the system software is running and active on the host computer.
  2. Put the SaveInfo media into the host computer.
  3. Navigate to the Service Desktop and open a C Shell.
    Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions.
  4. Log on as root by typing su - and press Enter.

    The password is operator.

    Note: It is possible that the customer changed the default password. If you cannot log on, contact the customer for the correct password.
  5. Change the directory to the bin directory by typing cd/usr/local/bin and press Enter.
  6. Start the check by typing checkINFO and press Enter. This command is case-sensitive. There are three methods to execute the checkINFO command:
    • checkINFO does a check on both the system disk and SaveInfo media. The program will not do a check on the SaveInfo media if issues are found on the system disk.
    • checkINFO -pre does a check on the system disk only.
    • checkINFO -post does a check on the SaveInfo media only.

    Result

    First, the program will make sure the files on the host scanner, which are normally written to a SaveInfo media, are present and not corrupted. Next, it will do a check of the saved information on the media to match what is on the system.

    If issues are found, a message shows the files that need to be moved or fixed in order for the SaveInfo to correctly archive to the media.

  7. If needed, correct any issues noted with the SaveInfo data on the system disk.

    Issues must be corrected in order to successfully transfer data to the SaveInfo media.

    Potential causes for failures are excessive file size (greater than 40 MB) or “special characters” such as *(&$#@ in the character string that may have been used when customers created protocols.

  8. If needed, discuss any issues with the customer and attempt to fix the offending files, or move them to a temporary directory before starting SaveInfo.

    Example

    As an example, if the file /usr/g/protocol/site/head/noggin scan is reported corrupted and it is not possible to fix, you will need to move it.
    1. Create a temporary directory: mkdir /usr/g/temp and press Enter.
    2. Move the file: mv /usr/g/protocol/site/head/noggin scan /usr/g/temp and press Enter.
    3. Run SaveInfo.
