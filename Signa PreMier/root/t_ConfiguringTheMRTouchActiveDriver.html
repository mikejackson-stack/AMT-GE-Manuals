Configuring the MR Touch active driver

Procedure

  1. At the MR console, open a C shell window.
    Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions.
  2. In the C shell window, type the following command: cat /etc/hosts and press Enter.
    This displays the hosts file for the MR console.
  3. Locate and write down the AGP address shown in the hosts file.
    The first three numbers of the AGP address provide the MGD subnet IP address.
  4. The default address of the MR Touch active driver module is 10.0.1.30. The first three numbers of the address need to match the address of the MR system MGD subnet address. If the MGD subnet IP address is not of the form 10.0.1.x (where x is a number between 0 and 255), you need to modify the IP address of the MR Touch active driver module to match the MGD subnet address, as follows:
    1. Disable wireless Ethernet communication on the laptop computer.
    2. Note: Write down the Ethernet communication settings for the laptop computer before changing them. This will make restoring the settings easier.
      Set the IP address of the laptop computer to a fixed address, as follows:
      1. Click Start > Settings.
      2. Click Network & Internet.
      3. Click Change adapter options.
      4. Click Ethernet and then click Change settings of this connection.
      5. From the This connection uses the following items list, select Internet Protocol Version 4 (TCP/IPv4), and click Properties. The system displays the Internet Protocol Version 4 (TCP/IPv4) Properties window.
      6. Select Use the following IP address.
      7. In the IP address field, enter 10.0.1.31.
      8. In the Subnet mask field, enter 255.255.255.0.
      9. Click OK to close the Internet ProtocolVersion 4 (TCP/IPv4) Properties window.
      10. Click OK to close the Ethernet Properties window.
    3. Using an Ethernet cable, connect the laptop computer to the same side of the ISC cabinet Ethernet hub where the MR Touch active driver module is connected.
    4. Insert the IP Setup Disc provided with the MR Touch option into the laptop computer.
      Note: If the IPSetup Disc is not available, download the IPSetup utility from: https://www.resoundant.com/setup
    5. Run IPsetup.exe.
    6. If the utility has a Find Legacy Applications checkbox, it must be checked.
    7. The IP Setup window shows. The MR Touch active driver module should appear in the Select a Unit field.
    8. Change the IP address for the active driver module to match the first three numbers in the IP address of the MR system MGD subnet. For example, if the first three numbers of the MR system MGD subnet are 10.0.6, change the IP address of the active driver module to 10.0.6.30. The last number of 30 must be unique to the active driver module. (In most MR system MGD subnets, this number is unused.)
    9. In the Network Mask field, enter 255.255.255.0.
    10. Highlight the active driver module, and click Set -- >.
    11. Click Launch Webpage.
    12. A web page displays. Write down the IP address and MAC address displayed under System Parameters.
    13. Important: It is critical to record the IP address of the MR Touch active driver module. The address needs to be available for future servicing of the system.
      Record the IP address of the MR Touch active driver module for future reference.
    14. Make sure the Version shown is under 22 or 22.04 or above. If the Version is above 22 and below 22.04, upgrade the firmware to 22.04 or above using the software and instructions at: https://www.resoundant.com/firmware.
      Notice
      Equipment damage risk
      Active driver may become non-functional if an invalid firmware update is attempted.
      Refer to the Resoundant firmware update instructions for valid firmware update paths.
    15. Examine the Amplifier Sleep Timer (sec) field. The value should be a number between 3600 and 5400 seconds. Set the sleep timer value as follows.
      1. Click Edit System Param.

      2. When prompted, enter the password.

        • For units made before serial number A1407001, the password is password (all lowercase).
        • For units made after serial number A1407001, the password is resoundant (all lowercase).
      3. Click Enter.
      4. Change the Amplifier Sleep time (sec) value to 3600, and click Change. This value enables the sleep timer which will place the driver in the sleep mode after 1 hour of non-use.
    16. If the System Parameters window includes Add OK to Query, make sure it is set to Enabled as follows:
      1. Click Edit System Param.
      2. Enter the password, when prompted.
        • For units made before serial number A1407001, the password is password (all lowercase).
        • For units made after serial number A1407001, the password is resoundant (all lowercase).
      3. Click Enter.
      4. Click the Enabled radio button next to Add OK to UDP Queries and click Change.
    17. If the active driver has not already been registered, register the driver at https://activation.resoundant.com using the username GE and password VS9DLXscG4.
    18. Close the web page and the IP Setup screen.
    19. Reset the laptop back to its normal IP addressing, and disconnect the Ethernet cable from the laptop and the Ethernet hub in the ISC cabinet.
    20. If you disabled wireless Ethernet communication on the laptop, re-enable it.
    21. At the MR console, use gedit to edit the /w/config/mre_comm.cfg file, and replace the IP address in the file with the address you set above.
  5. Make sure the touch2d option is installed.
