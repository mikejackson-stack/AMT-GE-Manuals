Coil datapath diagnostic concepts

Concepts and detailed information on coil datapath diagnostics.

Diagnostic path

Diagnostics > System Function > RF > Coil Datapath Diagnostics

Purpose

The MCRv tool emulates a coil by generating known test signals and providing known loads. The coil datapath diagnostic measures these signals and loads to verify connectivity between the points where the tool is connected and the rest of the system. The MCRv tool uses a variety of cables to attach the MCRv tool to various points along the receive path.
Note: You must connect the MCRv tool to a coil connection port along the coil cable path before starting the diagnostic.
Note: There are two versions of the MCRv tool; one for 1.5T and another for 3.0T. Each version uses an oscillator for the specific magnetic field strength.
