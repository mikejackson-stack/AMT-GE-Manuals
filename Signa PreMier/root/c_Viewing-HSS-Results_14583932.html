Viewing HSS Results

View the High Speed Stability (HSS) plot and data results using the HSS Viewer. The viewer provides many ways to view the results.

Example HSS Report Screens provides some examples of the HSS report screens.

HSS Shortcuts (User Interface) describes the menu selections and features of the user interface.

Viewing Results with HSS Viewer

(For viewing HSS Results with versions prior to DV26) The HSS Viewer starts automatically after the HSS Tool is finished. The HSS Viewer can also be started manually by choosing the Image Quality tab, then selecting Image Quality > HSS Viewer > Click here to start this tool.

  1. The results can also be compared to other HSS data sets using the Features > Compare option.

  2. Explanations of the options can be found under the Help menu at the top of the HSS Viewer window.

(For viewing HSS Results with versions DV26 and later) The HSS results display automatically after the HSS Tool is finished. The HSS Viewer can also be started manually by choosing the Image Quality tab, then selecting Image Quality > HSS Tool > Click here to start this tool.

  1. Select File > Open > HSS Files.

  2. Select the desired file from the list.

    Note:

    View the three limit lines visible on the plot. Ensure that none of the peaks from the plot extend beyond the red 24 cms DSV limit line.

    Note:

    The Compare files mode is currently not available for those data that have been acquired on systems running DV26.

HSS Shortcuts (User Interface)

HSS menu selections and results are described below.

Menu Selection Result
File > Open > HSS FilesOpen a file selection box so you can select an HSS file to open from any directory in the system.
File > Open > Header InformationOpen the header information associated with the current HSS file in a separate window.
File > Open > Service Config FileOpen the service config file associated with the current HSS file in a separate window.
File > Save > Save Data in PL FormatSave HSS file data in PL format.
File > Save > Capture Window as JPGSave the full window as a JPG to a desired location.
File > Save > Copy Time and Frequency PlotsCopy the time and frequency plots as separate JPGs to a desired location.
File > PrintSelect a printer and print the current window.
File > ExitClose HSS Viewer.
Features > Compare ModeOpen Compare Mode (new window).

The following table describes elements of the HSS user interface.

User Interface Description
Pass Selection MenuView data corresponding to any pass, average spectrum and concatenated data of all passes.
Baseline CorrectionRemoves wandering baseline. Low frequency oscillations in the HSS time data are removed.
Auto-ScalingScales the plot in the Time windows so that the maximum and minimum values of the data displayed are the limits of the Y-axis. Scales the plot in the Frequency window so that zero and the maximum value in the data displayed are the limits of the Y-axis.
Hanning WindowThe data displayed in the time window is multiplied with a Hanning window of equal size and the result is displayed as the time data. The Fourier transform of this time data is displayed as the frequency spectrum in the frequency window.
Cursor UpdateClick the cursor above the corresponding plot window to activate the cursor update mode for that particular window. The first click in the window creates a red * (asterisk) sign in the middle of the window. X-Y values denoting the location of the point in appropriate units are displayed next to the Cursor Update button. Further actions are:

  • Right click: Move the * to the right by one data point and update the location display.

  • Left click: Move the * to the left by one data point and update the location display.

  • Shift + left click: Move the * to any location in the axis. (The * jumps to the data point nearest to the location where the mouse was clicked). Location display is updated.

  • Click outside the plot window: Exit Cursor Update mode and close location display.

Zoom +Draw a rectangle in the time axis. The time window then displays only the data inside the rectangle. Data is not chopped in the Y direction. The frequency spectrum of the data displayed in the time plot window is computed and displayed in the frequency plot window.
Zoom -Cause the plot in the time window to revert back to the original plot for the pass selected.
Mark PeaksMark all the peaks displayed in the peaks table as red dots.
Compare ModeOnly those options that are not discussed in the help for the HSS Viewer are discussed.
Overlay FilesOverlay the data displayed in the window for the two files selected. If the data size is different, an error message displays.
Spectrum Operations (Spectrum-A +,-,/ Spectrum-B)Perform the selected operation on a point-by-point basis on the selected spectrums and display the result. The time data is neither affected nor displayed.
