Doing the In-Room Display (IRD) diagnostic - 8.4 inch IRD

The In-Room Display (IRD) diagnostic determines if the touch panels are detected by the host PC and obtains status information on the connectivity of the touch panel devices.

Topic ID: id_SL2869654-1224900

Diagnostic path

Diagnostics > System Function > Patient Handling > In Room Display

Topic ID: id_SL2869656-1224900

Purpose

This diagnostic determines if the touch panels are detected by the host PC and obtains status information on the connectivity of the touch panel devices. It provides a mechanism to restart only the IRD without restarting the host PC. The system may lose connectivity to the IRD display due to several causes:

  • Replacement of the IRD console
  • Reconnecting the USB fiber optic cables

All communication for these diagnostic functions is over the USB fiber optic connection between the IRD on the front magnet enclosure and GOC.

Topic ID: id_SL2869657-1224900

Components tested

  • IRD
  • USB Fiber Optic Connection
Topic ID: id_SL2869660-1224900

Requirements

  • IRD software must be installed.
Topic ID: id_SL2869661-1224900

Test sequence

  1. Click Run IRD Diagnostics to determine the touch panel connectivity status.
    Note: If you click Run IRD Diagnostics and the system does not respond, IRM software may not be installed. If the software is not installed, do the following:
    1. Open Guided Install.
    2. Select IRM Installation.
    3. Click Install IRM Software.
  2. Check the conditions.
    • If IRD diagnostics indicate that the touch panels are detected, and you are able to move the pointer on the IRD touch panels, there is no issue on IRD. No further steps are required.
    • If the IRD diagnostics indicate that the touch panels are detected, but you are unable to move the pointer on the IRD touch panels, click Reset IRD Console to restart the IRD. Wait 2 minutes until the IRD appears. Then, check that the IRD is functioning and both touch panels move the pointer on the IRD.
    • If the IRD diagnostics indicate that the touch panels are not detected, see Troubleshooting the In-Room Display (IRD) - 8.4 inch IRD.
Topic ID: id_SL2869664-1224900

Results

The IRD is reset and the touch panel function works to move the cursor on the IRD.
