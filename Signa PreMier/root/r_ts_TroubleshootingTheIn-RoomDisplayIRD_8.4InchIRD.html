Troubleshooting the In-Room Display (IRD) - 8.4 inch IRD

Diagnose and resolve errors related to the In-Room Display (IRD).

The following are main components around 8.4 inch IRD

Note: (For T5820) The HDMI splitter connects to the mini dp. All other connections are as indicated in the IRD block diagram.
  1. Make sure there is power to the IRD. If there is no power:
    1. Check M3314 connections to ISC PW/PEN > J42 and ISC PW Filter > J143.
    2. Check E3314 connections to ISC > Cabinet IF > J42 and ISC > Cabinet IF > J42.
    3. Check E3302 connections to ISC PW/PEN > J40 and ISC > Cabinet IF > J40.
    4. Replace cables, if necessary.
    Note: The 14V output from the PHPS supplies the IRD display back light. The 8V output from the DCPS supplies the IRD touch circuitry and IRD display video.
  2. Make sure the USB fiber optic cables P2027 and P2029 are properly connected and connected to the correct USB 3.0/3.1 ports on the GOC. Refer to the block diagram for more information.
    Note: The Dell T5810 host computer has USB 2.0 and 3.0 ports. The Dell T5820 host computer only has USB 3.1 ports, making this step unnecessary.
  3. Check the power LED on the HDMI splitter.
    1Power LED location
  4. Disconnect the PHPS power, HDMI, and USB 3.0 cables from the IRD(s). Check the connectors for debris or damage, and clean or replace, if needed.
  5. If one IRD is displaying No signal:
    1. Swap the cables between the malfunctioning IRD and working IRD. If the same IRD is malfunctioning, then replace the IRD. See Replacing the In-Room Display (IRD) - 8.4 inch IRD.
    2. If the problem moves to the other IRD, there may be a problem with the cables. To isolate a malfunctioning cable:
      1. Go to the GOC and make sure the cables are properly seated and connected, as listed in the table below. If no issues are found, continue to the next step.
      2. Swap the P2027 and P2029 IRD cables on the GOC USB 3.0/3.1 ports. If the problem stays on the same IRD, continue to the next step. If the malfunction moves to the other side IRD, replace the USB cable. See Replacing the In-Room Display (IRD) - 8.4 inch IRD for cover removal.
    3. Go to the GOC and swap HDMI cables J5 and J6 on the HDMI splitter. If the problem stays on the same IRD, replace the HDMI cable. If the problem moves to the other IRD, replace the HDMI splitter.
    4. Reconnect all cables in the original configuration.
    Important: Handle the cables carefully. The fiber optic cables are easily damaged and have a minimum bend radius of 50 mm.

  6. If both IRDs are displaying No signal, determine if the system has been in idle for more than two hours. The IRDs can lock due to noise exposure on the video line. If this happens, power cycle the IRD monitor:
    • Press the E-stop button on the SCIM.
    • Press the green EMO Reset button on the PDU.
    • Remotely log in through ISD or the open command window on the scanner.
    • Determine the status of the IRD monitors and enter map_onewire -v in the telnet window. Watch the scrolling output for the lines below.
      1Lines 1 and 3
      2Lines 5 and 6
    Lines 1 and 3 display the IRD monitor, 5502140-2. Lines 5 and 6 display Device ID:.
    • Hex code values of 0x81 or 0x80 indicate both monitors are displaying video.
    • Hex code values of 0xC1, 0xC0, 0x41, or 0x40 indicate the rhw IRD monitor is not displaying video and displaying the No signal text box.

    Damaged fiber optic cables can expose the IRD monitor to prolonged levels of video noise causing IRD monitor to enter a locked state, present in paths of both left and right IRD monitors. Premier systems use a single fiber with HDMI converters at each end, one fiber each for left and right IRD monitors. Make sure ESD protective shipping cover is affixed and secured over the HDMI converter and USB 3.0 plug when routing cables. When routing the glass fiber cable, at the GOC or IRD monitors, leave sufficient excess length in a service loop to allow cables to be swapped between IRD monitors for troubleshooting.

    If the computer graphic card has no output (during startup), damaged fiber optic cables may cause the HDMI splitter to lock the digital signal clock onto the damaged fiber optic line. When the clock is incorrect, v_sync will be missing, resulting in IRD LOS (loss of signal) until power is rebooted.
