Doing the Multi-Nuclear Spectroscopy (MNS) functional test

Do the MNS functional test to make sure the MNS subsystem is operational.

Procedure

  1. Click the Worklist icon, and then click the Add Pt Record icon.
  2. Type MNS (Last Name) and Setup (First Name), and press Enter for Patient Name.
  3. Type geservice and press Enter for Patient ID.
  4. Type 111 and press Enter for Patient Weight.
  5. Select the Service Protocol Library library and double-click MNS_Setup protocol.
    Note: At this step, if allMNS functional checks will be done, add the protocols in the table below. Otherwise, go to Step 6.
    ProtocolTest
    Func CheckMNS functional test
    SNR TestMNS signal to noise test
    Noise ScanMNS noise test
  6. Add the Func Check for the nucleus under test to the Multi Protocol Basket.
  7. Click Accept.
  8. Click Start Exam.
  9. Select the MNS coil.
  10. Click Save Rx.
  11. To set the following control variables (CVs), click the down arrow next to the Scan option. Select Research, then Display CVs.
    1. Select flip_rf1 from the CV Names list, and set the Current Value to 2. Then click Enter.
    2. Select pw_rf1 from the CV Names list, and set the Current Value to 40. Then click Enter.
    3. Select ia_rf1 from the CV Names list, and set the Current Value to 32767. Then click Enter.
    4. Select xmtaddSCAN from the CV Names list, and set the Current Value to 200. Then click Enter.
    5. Click Accept.
  12. Select the down arrow next to the Scan button, then click Research, and then Download.
  13. Select the down arrow next to the Scan button and click Spectro Prescan.
  14. Slide R1 and R2 to the maximum positions.
  15. Set TG (Transmit Gain) to 0 (zero).
  16. Set the top display mode to Magnitude (callout 3 in Figure 2).
  17. Click Start. After a few seconds you should see a peak in the top display and a free induction decay (FID) in the bottom display as shown below.

    13C spectrum is four closely spaced peaks and has been centered.

  18. Adjust the center frequency to center the peak in the Magnitude window.
    1. Move the Delta Frequency (DX) slider. A number will show above the slider.
    2. Click Apply. The Center Frequency (AX) value will change by the amount above the Delta Frequency (DX) slider.
    3. Repeat substeps a and b as many times as needed to center the peak.
    Note: If you see nothing but noise in the Magnitude window, you may be off frequency for MNS. See the following ratios for calculating the correct center frequency.

    Table 1. 3T center frequencies
    IsotopeCenter frequency (Hz) reference frequency
    1H127,732,407
    2H19,607,704
    3He97,345,529
    7Li49,645,367
    11B40,988,944
    13C32,125,190
    15N12,951,797
    17O17,322,806
    19F120,232,710
    23Na33,808,565
    29Si25,396,354
    31P51,754,323
    55Mn31,728,754
    129Xe35,328,351
  19. Use the ZOOM mode functions to measure the Magnitude peak height.
  20. Record the Magnitude peak height. The peak height at TG = 0 should exceed the minimum acceptable value in the table below.
    Table 2. Minimum performance limits for the MNS subsystem
    Nucleus Field Strength Min Mag at TG = 0 Min. SNR Max NoiseStdev
    13C3.0T2.0 X 10^812060000
    31P3.0T2.0 X 10^828060000
  21. Click Done when complete.
