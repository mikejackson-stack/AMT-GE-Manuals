Loading service pack from USB installer

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-10-20 minutes -
Tools and test equipment
ItemQuantityPart numberManufacturer
Service pack USB1--
Required conditions
Load updates after MR apps and service software have been loaded.
EA3 user account must be added to GESoftwareInstaller Group to install service pack.

About this task

This procedure is for MR30.0 or later software.

Note: To load service pack on MR29.1 or earlier software, please refer to Loading software updates from the repository or CD/DVD

Procedure

  1. Insert service pack USB installer to Host PC.
  2. From the Tools menu, select Service Desktop Manager.
  3. On the Service Desktop Manager, click Service Browser.
  4. Launch RSD (Remote Software Download) tool under Utilities tab.
  5. Click Import Packages and Select Folder to Upload window pops up.
  6. Choose the USB installer in the Navigation menu on the left side of the window. A prompt pops up to confirm file upload. Select Upload to continue uploading files.
    Note: DO NOT click on any individual files. Just press the “Upload” button on the right bottom to upload files.
  7. After you click Upload, a confirmation screen shows.
  8. Select the package check box and press Import Packages.
  9. After importing package, the imported service pack will be displayed under the Imported tab and ready to be installed.
  10. Close the “Import Packages” window. You will see the imported service pack under the Download tab of the RSD window with “DOWNLOADED” status and green tick.
  11. Reboot the system and log into the system.
    Note: Before you reboot the system and login, please make sure your EA3 account is added to GESoftwareInstallerGroup (See Configure user accounts for Role Based access controls).
  12. Once log into the system, the RSD window pops up. Select service pack just imported and press Install Now.
  13. “Install Now” window pops up with Step 1 of 2: Confirmation. Select the Acknowledge check box and press Proceed.
      • NOTE: If you see Figure 11, please make sure that:
      • The account you login are added to GESoftwareInstaller Group. See Configure user accounts for Role Based access controls (URL)
      • You reboot the system and login with the privileged account
  14. Continue to Step 2 of 2: Installation. Until the Pre-Install Check Status shows “Pass”, select the Acknowledge check box and press Continue.
    Note: If Install Fail shows, please make sure that:
    • The account you login are added to GESoftwareInstallerGroup (See Configure user accounts for Role Based access controls).
    • You reboot the system and login with the privileged account.
  15. When the installation is completed (the message area shows INSTALLED), click Close to exit screen. Also can find the installation history in History tab.
  16. Close RSD window and let system boot up.
  17. Do a check scan to make sure that the system is functioning properly. See Doing a check scan
