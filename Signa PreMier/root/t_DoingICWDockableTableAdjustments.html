      • Adjusting the cradle home sensor

        Adjusts the cradle home sensor. Do this procedure if the cradle home sensor fails checking the cradle home position sensor.

      • Adjusting the dockable table alignment

        Adjusts the table dock and the dockable table to align the table with the magnet bore.

      • Checking and adjusting the dockable table interlocks

        Checks the measurements and operation of the dockable table cradle home position, home switch position, secondary latch, flipper assembly, cradle home table down interlock, primary latch position, and primary latch bar height. Provides adjustment procedures for out-of-specification interlocks.

      • Checking and adjusting the patient table

        Makes sure the longitudinal gap, lateral center, height, and level are within tolerance. Provides adjusting procedures for out of tolerance measurements.

      • Checking and filling hydraulic fluid

        Checks and adjusts the hydraulic fluid level for the dockable patient table.

      • Doing ICW dockable table adjustments

        Adjusts the table dock and the dockable table to align the table with the magnet bore.

        • Raising the dockable table bellows

          Detaches the dockable table bellows cover from the table base covers and raises the bellows.

        • Removing the right-hand base side cover

          Removes the right-hand cover from the dockable table base.

        • Removing the left-hand base side cover

          Removes the left-hand cover from the dockable table base.

        • Lowering the dockable table bellows

          Detaches the dockable table bellows cover from the table side covers and lowers the bellows.

        • Removing the right-hand table side cover

          Removes the right-hand cover from the dockable table.

        • Removing the left-hand table side cover

          Removes the left-hand cover from the dockable table.

        • Removing the tabletop front bumper

          Removes the front bumper from the dockable tabletop.

        • Adjusting the dock hook tension

          Adjusts the dock hook tension for proper mechanical docking of the dockable patient table.

        • Measuring the dockable table bosses

          Measures the relative heights of the dock and dockable table bosses.

        • Setting up the laser level for measurements

          Set up the laser level and tripod for use in taking measurements where the horizontal or vertical laser lines bisect or align with parts of the patient table.

        • Adjusting the dockable table angle

          Adjusts the length of the dock mounting studs to align the table with the bore of the magnet.

        • Centering the dockable table

          Adjusts the dock left-to-right position relative to the magnet bore to center the dockable table cradle in the bore.

        • Selecting the tabletop front bumper

          Measures the gap between the table and the magnet to select the appropriate front bumper.

        • Adjusting the table level and height

          Adjusts the table caster heights to make the tabletop level and adjusts the hydraulic cylinder to set the tabletop height.

        • Adjusting the dockable table up-limit switch

          Adjusts the up-limit switch position and makes sure the switch actuates and de-actuates within tolerance.

        • Adjusting multiple dockable tables

          Provides instructions for adjusting multiple tables such that all tables function with the scanner.

        • Installing the tabletop front bumper

          Installs the front bumper onto the dockable tabletop.

        • Installing the left-hand table side cover

          Installs the left-hand cover onto the dockable table.

        • Installing the right-hand table side cover

          Installs the right-hand cover onto the dockable table.

        • Raising the lowered dockable table bellows

          Raises a previously lowered dockable table bellows cover and attaches the bellows to the table side covers.

        • Installing the left-hand base side cover

          Installs the left-hand cover onto the dockable table base.

        • Installing the right-hand base side cover

          Installs the right-hand cover onto the dockable table base.

        • Lowering the raised dockable table bellows

          Lowers a previously raised dockable table bellows cover and attaches the bellows to the table base covers.

      • Verifying the dockable table movement

        Make sure the patient table controls operate correctly.

Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

About this task

The following installations and adjustments must be completed and checked off when doing the dockable table adjustments in Installation mode.
Note: Download and open the Alignment Data Sheet Macro (DOC2647017) from the online documentation library to use during table adjustments.
Warning
Ferrous material hazard
The tool kit contains small ferrous objects. Ferrous object test results for these tools can be found in the following documents: DOC2306785, DOC2306775, DOC2306787, and DOC2306786.
The tripod and laser levels are classified as small ferrous objects and should not be brought within the 200 gauss line of the scanner.
