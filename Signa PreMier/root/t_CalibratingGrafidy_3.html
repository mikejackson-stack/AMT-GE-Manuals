Required conditions
DQA (Grad Cal/IsoVector2) tool is within specification. Refer to DQA calibration.
Shim within specification for rough shim.

(For 3TLC/UA magnets only) SIGNA Premier systems show a helium level dependent B0 Oscillatory Eddy Current (OEC) when the magnet helium level is under 80%. The change in the B0 OEC is less significant when the helium level is above 80%.

If there is a change in the helium level over 5% since the last grafidy calibration, then you need to recalibrate the Grafidy B0 OEC compensation.

Here is the recommendation for helium filling or grafidy calibration.
He LevelAction to the Field
60 - 80%
  1. Re-run grafidy calibration if there is a change in the helium level more than 5%.
  2. Do SaveInfo.
< 60%
  1. Top off the helium.
  2. Re-run grafidy calibration.
  3. Do SaveInfo.

About this task

Disclaimer: Depending on your service agreement, not all service tools, diagnostics, and utilities referenced in this document may be accessible. Contact your sales person for information on available service license packages.

Grafidy adjusts and compensates short, long, and very long time constant eddy currents for both linear and B0 terms. Use the grafidy procedure to complete eddy current compensation. Grafidy should be run in auto mode first. The oscillatory mode is also included in auto mode. If auto mode fails to bring any of the terms into specification, manual mode can be used.

Grafidy uses a dedicated pulse sequence, six-channel fixture, and Grafidy software. The Grafidy P-port connector plugs into the P2 port for transmit/receive. No additional fixtures or cables are needed.

This tool simplifies setting up the calibration and collects data from all six coils simultaneously.

Table 1. Grafidy calibration modes
Auto mode - The Grafidy tool is initially run in auto mode.
Note: (For 3TLC/UA only) XB0 and YB0 oscillatory mode is part of auto mode.
Manual mode - When doing this procedure, if auto mode does not bring all the terms into specification (still red in the Result/Area table), continue to Running Grafidy in manual mode.
Note: If VLong, Long, or Short terms are failing, manual mode should be run to bring the VLong mode into specification.
