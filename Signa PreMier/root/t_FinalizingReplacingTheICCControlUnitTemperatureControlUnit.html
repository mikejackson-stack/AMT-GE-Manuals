Finalizing replacing the Integrated Cooling Cabinet (ICC) control unit Temperature Control Unit (TCU)

Completes the replacement of the Integrated Cooling Cabinet (ICC) control unit Temperature Control Unit (TCU).

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-5 minutes-

Procedure

  1. Make sure the set point temperature of the replaced TCU is correct.
    TCU set point temperature
    CCU30°C
    GCU17°C
  2. Make sure that there are no errors related to the ICC TCU.

Finalization

  1. Do a check scan. See Doing a check scan.
