Image Compute Node (ICN) Dell R630 (Gen6), R640 (Gen7/Gen7-DL) firmware upgrade

Do a check manually to determine whether the need for a firmware upgrade exists.

Dell Lifecycle Controller (LCC) is an advanced embedded systems management technology that enables remote server management using integrated Dell Remote Access Controller (iDRAC). This firmware for the iDRAC and LCC have an intermittent flaw, which causes Volume Recon Engine (VRE) configuration to fail frequently. LCC database becomes corrupted during such configuration failures. This is mostly reproducible when losing power to the ICN.

The solution to this problem is to introduce an Image Compute Node (ICN) firmware check and upgrade step for every ICN configuration on Dell R630, Gen6 and R640, Gen7/Gen7-DL ICNs.

Procedure to manually check for Firmware upgrade need on Gen 6 ICN in software revision 27 and earlier

Note: Firmware versions are software controlled.
Note: Any version of Firmware and LCC that is not at 2.60.100.60 will require ICN Firmware upgrade.

Failures of ICN maintenance on Dell R630 (Gen6) and R640 (Gen7/Gen7-DL)

FailureSolution
MakeSystemReady
  • This happens when ICN is unable to respond to commands or calls to set up the ICN for firmware updates. The automatic maintenance routine attempts this task two times and then fails if this task is not accomplished.
  • Approximate time to failure from start of VRE Configuration: 20 minutes.
  • Refer to Ethernet Troubleshooting to make sure networking is correct. If ICN configuration still fails, try the following actions:
    • Recycle Power to ICN by removing the power cables for approximately 60 seconds.
    • If all of the above methods fail, replace the ICN.
iDRAC Update

If iDRAC update failed, the error is printed in the log file and ICN Maintenance is completed. VRE configuration will continue. This is treated as a potential case of not doing iDRAC firmware update, and must be resolved to make sure the update is successful:

  • Recycle Power to ICN by removing the power cables for approximately 60 seconds.
  • If all of the above methods fail, replace the ICN.
BIOS Update

If there is an ICN maintenance failure when the IDRAC is upgraded, but the BIOS is not, this will cause the VRE configuration to fail and bring the site down until this issue is resolved.

  • Recycle Power to ICN by removing the power cables for approximately 60 seconds.
  • If all of the above methods fail, replace the ICN.
iDRAC license file missing

If the ICN maintenance fails during iDRAC upgrade with below signature, then you will need to acquire the license file from Dell and updated manually.
