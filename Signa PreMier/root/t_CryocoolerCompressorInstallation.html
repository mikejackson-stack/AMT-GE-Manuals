Installing the F-50 cryocooler compressor

Follow this procedure to install the new or replacement F-50 cryocooler compressor into the Integrated Cooling Cabinet (ICC).

About this task

Table 1. Helium flexline routing
HoseConnectionRoute through
621 (helium supply flexline)ICC > Gas Supply > F-50 Cryocooler Supply Line Adapter

ICC SPW > Waveguide > J110

622 (helium return flexline)ICC > Gas Return > F-50 Cryocooler Return Line Adapter

ICC SPW > Waveguide > J111

Procedure

  1. Open the Integrated Cooling Cabinet (ICC) doors and disconnect the ground wire.
  2. Lift the door to disengage the hinge, remove the door, and set it aside.
  3. Remove the bottom reinforcement bar. Set aside for re-installation.
  4. (For Platform ICC) Remove the front gusset and set it aside for reinstallation.
  5. Position the F-50 cryocooler in the opening.
  6. Connect the helium return line adapter (5271637) to the helium return on the F-50 cryocooler.
  7. Connect the helium supply line adapter to the helium supply on the F-50 cryocooler.
  8. Connect helium flexline, Run 621, to the helium supply adapter.
  9. Connect helium flexline, Run 622, to the helium return adapter. Allow some slack on the helium flexlines.
  10. Route the helium flexline, Run 621, through the routing channel at the top left corner of the ICC to the F-50 cryocooler, onto the equipment room cable tray, and through ICC SPW > Waveguide > J110.
  11. Route the helium return flexline hose, Run 622, through the ICC cabinet, onto the equipment room cable tray, and through ICC SPW > Waveguide > J111.
    Note: If the helium lines were routed earlier and not routed on the cable tray, route them on the cable tray now.
  12. Make sure the length of the helium flexlines routed through the ICC SPW is adequate to reach the coldhead. Coil and store the excess flexline on the left side of the cryocooler to allow movement for service procedures.
  13. (For Legacy ICC) Install the cryocooler handle and secure it with three screws.
  14. Slide the cryocooler all the way into the lower opening of the ICC.
