References to various Oxygen Monitor Subsystem Manuals.

Oxygen monitor subsystem manuals

Note: GE HealthCare guidance for the minimum safe level for concentration of oxygen is 19.5%.
  • See the latest revision of the Oxygen Monitor Subsystem Manual (46-015336), available from the online documentation library. This manual applies to both the ISA-40M and ISA-60M oxygen monitors.
  • For the oxygen monitor vendor manual, see the latest revision of the ISA-60M with MRI-5175 Operator and Maintenance Manual (DOC1738693), available from the online documentation library.
  • For other oxygen monitors, such as the EC 96 model, refer to the paper version of the vendor manual that shipped with the unit.
