Enabling the Remote Service Platform (RSvP) iLinq

Configures and enables iLinq through the Remote Service Platform (RSvP).

Prerequisites

Required conditions
FFA access is required to enable iLinq on the system. If you do not have access to FFA and RSvP, contact your regional connectivity team or the MR support team to enable iLinq.
RSvP registration must be completed on the system with Registered and CRM Verified set to Yes.
Note: It may take up to 10 minutes after RSvP registration is completed for the system ID to show in FFA.
Note: The iLinq page will be blank until iLinq is enabled from FFA.

Procedure

  1. Create a service record for the site with its system ID and launch FFA.
  2. Navigate to the CONNECT tab.
  3. Make sure Connect Status for the system shows ONLINE and Connectivity Type is set to Insite2-RSvP.
  4. From the menu, select Configure iLinq.
  5. Set iLinq Status to Enabled. Select the correct language for the site from the drop-down list, and click Configure iLinq.
  6. Click Done to close the window.
  7. After the iLinq checkout has been completed, restart the host PC. The iLinq button will show. See below.
  8. Go to the iLinq tab on the service desktop. The iLinq page should show. If the iLinq page does not show, click the iLinq icon. This may take up to 15 seconds on the first attempt.
    Note: Since iLinq is always enabled remotely, a SaveInfo is often not done to immediately save this setting. This results in the iLinq feature being unavailable after a software reload. Therefore, make sure a SaveInfo is done immediately after enabling iLinq from FFA.
