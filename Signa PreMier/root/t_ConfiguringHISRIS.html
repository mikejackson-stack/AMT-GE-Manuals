Configuring HIS/RIS

This procedure documents the setup and calibration of the system to a clinical hospital information system (HIS) or a radiology information system (RIS).

Procedure

  1. From the Common Service Desktop, click Configure > Guided Install, and in FE Mode log on as root.
  2. Under Connectivity, select HIS/RIS.
  3. Enter applicable information in all fields (as provided by site) and click Configure.
  4. Under MWL Configuration, select MWL Config Details.
  5. If any fields, other than the defaults, are desired to show in the MWL Config Details, select or clear appropriately and click Configure.
  6. Under MWL Configuration, select Return Tag Configure.
  7. If any fields, other than the defaults, are desired by the site to be refreshed in the Modality Worklist, select or clear appropriately and click Configure.
  8. Under MWL Configuration, select SCP Configure.
    Note: SCP means Service Class Provider. It is used for HIS/RIS server (which provides MWL service) configuration.
  9. Click New to set up a new item.
  10. Enter applicable information in all fields (as provided by site) and click Configure.
    Note: For a first-time configure, select DefaultSelected to enable the Configure button.
  11. If required by the site, select the lock check box that enables DICOM over TLS. Make sure that third-party certificates from the MWL service class provider are installed and set up on the MR System. See MR Scanner set up as secure client.
  12. Under MWL Configuration, select Table Column Selection Configure.
  13. Select or clear any fields desired to show in the patient record table (located at the top of the scan window) and click Configure.
  14. Under MWL Configuration, select PPS Configure.
  15. Click New to start a new setup.
  16. Enter applicable information in all fields (as provided by site) and click Configure.
  17. If required by the site, select the lock check box that enables DICOM over TLS. Make sure that third-party certificates from the PPS service class provider are installed and set up on the MR System. See MR Scanner set up as secure client.
  18. To do a check of network connectivity, click Ping.
