Running High Order Shim (HOS) calibration

Procedure

  1. Start the HOS procedure/calibration:
    • (For restricted service tools) Make sure the service key is installed.
      1. On the Calibration tab, select Calibration > Install And Calibration Wizard.
      2. Select HOShim Procedure. If HOShim Procedure is not available, refer to Installation and Calibration Wizard for instructions.
    • (For non-proprietary service tools) Open the Common Service Desktop.
      1. On the Calibration tab, select Calibration Tools > HOS Calibration.
      2. Click Click here to start this tool.
      3. Click Scan.

        The system prescans first, then scans. There are multiple scans in this sequence with no user interaction required. The scan will take approximately 50 minutes to complete.

        When the scan is complete, a dialog box appears. If the calibration is successful, the values show in green and a dialog box appears indicating High Order Shim Calibration Passed.

      4. Click OK.
        Note: If the value is red, this indicates the calibration failed. A dialog window appears with the following message: High Order Shim Calibration Failed. Check High Order Shim Power Supply.
  2. Click Exit.
