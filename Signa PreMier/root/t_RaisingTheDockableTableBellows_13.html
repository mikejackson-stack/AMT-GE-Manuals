Raising the dockable table bellows

Detaches the dockable table bellows cover from the table base covers and raises the bellows.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-5 minutes-
Tools and test equipment
ItemQuantityPart numberManufacturer
Nonmagnetic Titanium Service Tool Kit, Small Set15113258-

Procedure

  1. Remove the screws securing the bellows cover to the table base covers.
  2. Lift the bellows cover and secure it in the raised position with the Velcro strips.
