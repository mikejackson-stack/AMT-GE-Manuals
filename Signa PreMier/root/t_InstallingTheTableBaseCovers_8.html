Installing the table base covers

Installs the table base covers onto the patient table.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
2-15 minutes-

Procedure

  1. Place the table base covers on their respective sides of the patient table.
  2. Connect the up/down foot pedal cables to the table control box.
  3. Install the table base joint cover onto the dock frame. Position the base joint cover close to the magnet.
  4. Join the left and right table base covers together.
  5. Slide joint cover towards the patient table over the base covers until the screw holes in the joint cover align with the screw holes in the base covers.
  6. Install the three screws and three screw covers securing the base covers.
