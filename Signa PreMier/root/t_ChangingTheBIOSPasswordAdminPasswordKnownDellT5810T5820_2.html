Changing the BIOS password - admin password known - Dell T5810/T5820

Change an existing admin password when the previous password is known.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-5 minutes -

Procedure

  1. Turn on or restart the computer. Press F2 to enter the BIOS Setup menu.
    Note: Optionally, press F12, then select the BIOS Setup menu.
  2. In the Settings pane, expand the Security menu.
  3. Select Admin Password.
  4. In the Admin Password pane:
    1. Enter the old admin password in the Enter the old password field.
    2. Enter the new admin password in the Enter the new password field.
    3. Enter the new admin password in the Confirm the new password field.
  5. At the bottom of the screen, click Apply, then click Exit.
