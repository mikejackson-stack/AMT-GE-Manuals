Doing the Multi-Nuclear Spectroscopy (MNS) signal to noise test

Do the MNS signal to noise test to make sure the MNS subsystem is operational.

About this task

If you successfully completed the MNS Functional Test procedure (see Doing the Multi-Nuclear Spectroscopy (MNS) functional test) and you now want to begin the Signal to Noise Test, in the MNS-Setup area, select SNR Test > Setup.

Procedure

  1. Click the Worklist icon, then click the Add Pt Record icon.
  2. Type MNS (Last Name) and Setup (First Name), and press Enter for Patient Name.
  3. Type geservice and then click on Enter for Patient ID.
  4. Type 111 and click on Enter for Patient Weight.
  5. Select the Service Protocol Library library and double-click MNS_Setup protocol.
  6. Add the SNR Test for the nucleus under test to the Multi Protocol Basket. Click Accept.
  7. Landmark on the center of the QA probe, if not already completed during Hardware Setup.
  8. Click Start Exam.
  9. Click Save Rx.
    Note: If the MNS Signal to noise test was completed, select Research > Download
  10. To set the following control variables (CVs), click the down arrow next to the Scan option. Select Research, then Display CVs.
    • Select flip_rf1 from the CV Names list, and set the Current Value to 2. Then click Enter.
    • Select pw_rf1 from the CV Names list, and set the Current Value to 40. Then click Enter.
    • Select ia_rf1 from the CV Names list, and set the Current Value to 32767. Then click Enter.
    • Select xmtaddSCAN from the CV Names list, and set the Current Value to 200. Then click Enter.
    • Click Accept.
  11. Select the down arrow next to the Scan button, click Research, and then click Download.
  12. Click Scan > Spectro Prescan.
  13. Slide R1 and R2 to the maximum position.
  14. Set TG (Transmit Gain) to 0 (zero).
  15. Set the top display mode to Magnitude.
  16. Click Start. After a few seconds you should see a peak in the top display and a free induction decay (FID) in the bottom display.
  17. Adjust the center frequency to center the peak in the Magnitude window.
  18. Change the display mode in the top window to Pure Absorp. The shape of the peak changes with some of the signal dipping below zero. The distortion varies depending on the QA coil and scanner.
  19. Use the Zero Order Phase control to adjust the shape of the peak until it is fully positive and symmetric. The Zero Order Phase control was used to correct the spectrum until all signals were positive and the peak shape was symmetric.
  20. Increase TG by units of 10 until the peak decreases and becomes slightly negative, about 180.
  21. Decrease TG slowly until the peak is split half-positive and half-negative.
  22. Record this null value for TG.
  23. Subtract 60 units from the null TG value and set TG to this value. Now the peak is positive again and at maximum amplitude.
  24. Click Stop and then click Done.
  25. Click Scan to collect the SNR data.
  26. Switch to the Tools Workspace and open a Command Window.
    Note: The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log out and then log back on as the correct EA3 user with the authorized permissions.
  27. Type sage and click Enter to initiate the SAGE spectroscopy analysis tool.
  28. Click File > Load > Rawdata to open the load raw data dialog window.
  29. When the scan is finished, click Update List to refresh the list of P files to choose from.
  30. The topmost P file is the latest. Select this file and click Load.
  31. In the main SAGE panel, select Macros > Func Tests > SNR Test....
  32. Move the windows around if necessary.
  33. Set up the SNR Test window as listed in the table below for the nucleus under test.
    Table 1. SNR Test window settings for SNR tests
    Field 13 C setting 31 P setting
    Spectral ApodizeYESNO

  34. Click Run on the SNR Test window. The SNR is calculated for the active data set and reported in the command window where SAGE was started.
  35. Scanning and analysis:
    1. See Table 1 for the nucleus under test.
    2. Record the n=32 value for peak SNR (AmpSNR). Compare to the minimum acceptable value in the table below.
