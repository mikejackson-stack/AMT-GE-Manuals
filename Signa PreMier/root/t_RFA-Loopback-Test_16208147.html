Safety

Ferrous Tools!
The magnetic field will permanently damage fans inside the dummy load. The dummy load contains ferrous components.
Keep the dummy load outside the magnet room.
CAUTION
Ferrous Tools!
The magnet can damage the oscilloscope.
Keep the oscilloscope outside the magnet room.

About this task

Systems using will use either the RRx receive chain or the DPP receive chain. To determine receive chain type, check the Receiver Type field in the Hardware Configure tab of Guided Install. RRx indicates the RRx receive chain, and DPP indicates the DPP receive chain.

The RFA (radio frequency analysis) tool is designed to quantitatively measure the performance of the transmit chain by allowing loopback tests from several different points along the chain. At most points, the inter-pulse RF stability and inter-pulse RF fidelity (magnitude and phase linearity) can be measured.

For information about the theory behind the tests, see RF Loopback Test Theory.

Set up test

Procedure

  1. Ensure that the system is idle, and remove all portable coils from the bore.
  2. On the driver module in the PEN cabinet, set switch 2 (SW2) to TR DISABLE.
  3. On the exciter/ref clock module located in the PEN cabinet, set the RF Enb switch down (Disable).
  4. The following table provides links to the setup diagrams for the loopback test for the various components. Locate the setup diagram that matches the system and the loopback test that you want to perform. At a minimum, run the Headdummy or Bodydummy loopback and Exciter loopback tests. Set up the components to match the setup diagram.

Running RFA in exciter, bodydummy, or headdummy mode

Procedure

  1. Set the 1 dB/step and 10 dB/step rotary attenuators to the settings shown in the appropriate setup diagram.
  2. Enable RF output from the exciter module:
  3. Landmark as indicated in the setup diagram for the test you are running, and advance to scan.
  4. In the service browser, select Image Quality > RFA Tool. The RF Analysis Tool appears.
  5. Select the Loopback Mode for the test you want to run.
  6. Select RF Pulse Type (initially use the default Standard, and select Exp (Ascending) and Exp (Descending) in the second and third iterations of the test).
  7. Select Gradient State (use the default XYZ On).
  8. Click Start.
  9. Note: SVAT errors usually indicate a setup problem such as landmark, 32-channel patient table connector not connected, TR or DD fault, etc. Check the error log.
    A popup window asks you to check the loopback setup. Check the setup, and then click Continue.
  10. After about 60 seconds, a Set loopback signal level message box appears. When this message appears, click the Patient icon.
  11. Slowly increase TG to 200 while adjusting the rotary attenuators (to prevent receiver over-range indicated by R1%>100 or R2%>100) until you achieve an R1% and R2% display on the manual prescan page of 84-94% with TG=200.
  12. When done, select the Toolbelt icon to return to the service window. Start a scan by clicking Proceed & auto-scan on the Set loopback signal level message box.
  13. After the scan and analysis ends, view the results. Compare the results to the typical normal plots shown in RFA plot results. Real failures will exceed the example plot values by 2 or more times. Minor differences are not failures. Select the popup choice to erase the displays. The plots are saved as JPG files under /usr/g/service/cclass/RFA/.

Running RFA in headsense or bodysense modes

Procedure

  1. Set the 1 dB/step and 10 dB/step rotary attenuators to the settings shown in the appropriate setup diagram.
  2. Set up the oscilloscope as described in the setup diagram.
  3. Enable RF output from the exciter module.
  4. On the driver module in the PEN cabinet, set switch 2 (SW2) to TR ENABLE.
  5. Landmark as indicated in the setup diagram for the test you are running, and advance to scan.
  6. In the service browser, select Image Quality > RFA Tool. The RF Analysis Tool appears.
  7. Select the Loopback Mode (Head or Body) for the test you want to run.
  8. Select RF Pulse Type (initially use the default Standard).
  9. Select Gradient State (use the default XYZ On).
  10. Click Start.
    Note: Do not click OK on the sense loop popup until you are ready to end the test.
  11. Note: SVAT errors usually indicate a setup problem such as landmark, 32-channel patient table connector not connected, TR or DD fault, etc. Check the error log.
    Set up the oscilloscope according to the following parameters:
    For this setting: Select:
    Channel 1Ground1 MegaOhm
    Vertical scale100 mV/division
    Vertical position0 V
    InvertOff
    BandwidthFull
    Channel 2Ground1 MegaOhm
    Vertical scale100 mV/division
    Vertical position0 V
    InvertOff
    BandwidthFull
    TriggerTypeEdge
    Trigger sourceExternal
    CouplingDC
    SlopeA trigger slope
    LevelA trigger level
    Trigger level300 mV
    Horizontal position0%
    Horizontal scale800 µs/div
    ScalingScale the amplitude of the envelope pulse so it is coincident with the envelope of the RF pulse.
  12. A popup window asks you to check the loopback setup. Check the setup, and then click Continue.
  13. After about 60 seconds, a Set loopback signal level message box appears. When this message appears, click the Patient icon.
  14. Increase TG to 200.
  15. This is a visual test only. When properly scaled, the two waveforms should be similar and it should be possible to overlay one over the other. Investigate any differences in wave shape between the two waveforms.

Topic ID: id_14998647

Finalization

Procedure

  1. On the exciter/ref clock module, set the RF Enb switch to Disable (down).
  2. When finished with the loopback test, restore the cabling to the default clinical state.
  3. On the exciter/ref clock module, set the RF Enb switch to Enable (up).
  4. On the driver module in the RF system cabinet, switch the TR drive switch (SW2) to TR ENABLE.
  5. Perform a check scan to verify the system is operating properly.
