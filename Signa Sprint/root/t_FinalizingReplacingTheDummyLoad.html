        • Replacing the dockable table dummy load

          Removes the dummy load from the dockable table and installs a replacement dummy load.

          • Lowering the dockable table bellows

            Detaches the dockable table bellows cover from the table side covers and lowers the bellows.

          • Removing the right-hand table side cover

            Removes the right-hand cover from the dockable table.

          • Removing the dockable table dummy load

            Removes the dummy load from the dockable table.

          • Installing the dockable table dummy load

            Installs the dummy load into the dockable table.

          • Installing the right-hand table side cover

            Installs the right-hand cover onto the dockable table.

          • Raising the lowered dockable table bellows

            Raises a previously lowered dockable table bellows cover and attaches the bellows to the table side covers.

          • Checking the touch-and-go strip function

            Makes sure the touch-and-go strips display the landmark on the In-Room Display (IRD) correctly.

            A check scan is done at the beginning of some procedures and at the end of many procedures. This functional check assures the unit is in good clinical working order.
