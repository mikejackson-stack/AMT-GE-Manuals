Installing the Server Imaging Platform (SIP) (ICN Gen 8)

Install the Server Imaging Platform (SIP) (ICN Gen 8) into the cabinet.

Important This chart shows the possible replacement Image Compute Nodes/Server Imaging Platforms (ICNs/SIPs) for each model. Find the installed model on the left and see what models can be used to replace it. Make sure you have the correct software level to support all possible options and a PCIe cable if changing Dolphin board types.

A SIP (ICN Gen 8) is significantly larger than an ICN Gen 5, 6, or 7. To replace an older ICN with a SIP (ICN Gen 8) requires an upgrade that can take approximately 5 hours. If possible, use ICN generations other than SIP (ICN Gen 8).

Procedure

  1. Install the inner rails onto the SIP (ICN Gen 8).
  2. Secure each inner rail to the SIP (ICN Gen 8) using one screw per rail.
  3. Assemble the universal hoist. See Installing the hoist.
    Notice
    Inspect the straps for defects.
  4. Put the yellow lifting strap on the ground and put the SIP (ICN Gen 8) on the yellow lifting strap. Attach the yellow lifting strap to the universal hoist.
    Warning
    Potential crush hazard
    If the replacement part accidentally falls, it can cause serious injury.
    Do not put any part of the body below the replacement part.
  5. Lift the SIP (ICN Gen 8) to align the inner and outer rails.
  6. If not already done, pull the outer rails out of the system cabinet and make sure they are locked into position.
  7. With the slide rails out, install the new SIP (ICN Gen 8). Line the inner rails on the SIP with the outer rails attached to the system cabinet and slide the SIP toward the cabinet.
  8. Slide the two blue release tabs toward the front of the chassis and secure the SIP (ICN Gen 8) into the system cabinet.
  9. Release the tension on the chain first and make sure that the rails are properly supporting the weight.
  10. Remove the yellow lifting strap.
  11. Connect the cables to the rear of the SIP (ICN Gen 8):
    1. Connect the 1G MR system network cable.
    2. Connect the iDRAC remote management cable.
    3. Connect the PCIe cable for Dolphin.
    4. Connect the two power cables.
    Note Replace the existing power cable with the SIP (ICN Gen 8) AC Power Cable, 5868145.
    Note If changing between ICN/SIP styles (units with Dolphin 1, Dolphin 2, or Dolphin 3 Interface), make sure that the associated PCIe cable is available. Save the alternate cable with the cabinet for future use.
    Note If changing between SIP (ICN Gen 8) configurations, make sure the correct software version is installed.
  12. On the front of the SIP (ICN Gen 8), install the two screws to secure the chassis to the system cabinet.
  13. Restore all cabinet covers.
  14. Remove ISC LOTO. See Removing LOTO - Integrated System Cabinet (ISC).

Finalization

  1. Start up the host computer/system. See Starting up the host computer .
  2. Configure the ICN-VRE. See Configuring the SIP, ICN, or VRE.
