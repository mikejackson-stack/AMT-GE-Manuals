Configuring the SIP, ICN, or VRE

This configuration procedure reinstalls the software onto the Server Imaging Platform (SIP) or Image Compute Node (ICN).

Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

Warning
Electrocution hazard
Dangerous voltages are present throughout the system cabinet when power is applied.
Refer to the MR Service Safety Manual (5452735) for information on locking and tagging out the equipment.

About this task

Use this procedure if Load From Cold (LFC) with the required software has already been completed.

The following procedure describes manual configuration of the VRE/ICN/SIP. ICN compatibility depends on the software revision. For compatibility information, see Identifying the Image Compute Node (ICN) or Server Imaging Platform (SIP) type. The terms Server Imaging Platform (SIP), Image Compute Node (ICN), and Volume Reconstruction Engine (VRE) are used interchangeably. "VRE configuration" installs the software onto the ICN. This procedure is needed after ICN replacement and may also be needed when troubleshooting issues with the ICN system.

Procedure

  1. If replacing the ICN, power on the system and the host PC, and log on as root. If the system is already on, shut down any open applications before restarting the system. To restart, right-click and select System Restart.
  2. Invoke Guided Install as root:
    1. When you power up the host computer and see the logon screen, click root login.
    2. Type the user name: root and enter the root password.
    3. Click Login.
      Note It is possible that the customer changed the default password. If you cannot log on, contact the customer for the correct password.

      Result

      Logging on as the root user automatically shows the Linux desktop and launches the Guided Install Starter window.
    4. Click Yes to invoke the guided install.
      Note If No has already been selected, right-click on the Linux desktop and select Start Guided Install.
  3. Insert the SSA Class M hard key or install the SSA soft license.
    Note The SSA class M hard key is needed only to show the ICN terminal screen.
  4. If the DVD installer is used or the installation files on the host were corrupted, insert the correct media. Otherwise, go to the next step.
    • Insert the MR Software USB Media, if required.
  5. View the current configuration of the ICNs.
    1. Select ICN Configuration and click Check ICN BMC IP and MAC.
      1. Record the ICN IP address.
        Note This makes sure of the correct baseboard management controller (BMC) connection to the host computer. The information collected may be useful for troubleshooting later.
      2. If no ICNs are listed in the dialog window, power cycle the ICN and network power card:
        1. Flip the Sequencing breaker on the System PDU to the off position.
        2. Wait at least 1 minute or until the lights on the ICN and network switch are out, and then turn the Sequencing breaker back on.
        3. Run the Check ICN BMC IP and MAC procedure again to make sure that the system sees the ICN. If the system does not see the ICN, you may need to unplug the cabling on the network switch and ICN and then plug the cabling back in.
  6. Configure the ICN.
    1. Click Configure ICN as shown on ICN Configuration for a guided install.
      1. After Configure ICN is selected, a progress window opens.
        Note If prompted, insert the USB SW installer that came with the system software into the host PC and click OK to continue the ICN configuration (this step is only necessary if repository files are corrupted on the host computer).

        ICN configuration progress and details show in a separate window. At the end of ICN configuration, another dialog box opens with an ICN configuration success or failure message.

      2. When the ICN Remote Console window opens, click OK, then Continue. This installs the Java security options.
        Note For SIP (ICN Gen 8), the iDRAC login page opens instead of Java.
        Note This remote display does not launch if a valid service license is unavailable. A message opens in the ICN configuration log that informs the user of a missing service license. This message can be ignored if there is no need to look at the ICN Remote display.
      3. When the Java Security Warning window opens, do the steps below:
        1. Select the I accept the risk and want to run this application. check box.
        2. Click on Show Options and select the Do not show this again for apps from the publisher and location above check box.
        3. Click Run.

        The Remote Console window opens showing the progress of the installation.

  7. If it was installed previously, remove the OS DVD or USB SW installation media.
  8. When the VRE configuration completes, a dialog box shows a success or failure message.
    • If the VRE configuration fails, go to Step 9.
    • If the VRE configuration is successful, go to Step 10.
  9. If ICN configuration fails, review the dialog box and details in the separate window to identify next steps.
    Note To view the output status of the ICN, open the ICN Configuration screen and click View VRE configuration file.
  10. Click OK when the VRE configuration shows successful. Click OK again when the ICN configuration shows successful.
    Note A restart is required after a complete ICN configuration.

Finalization

  1. If this procedure was done as part of a software reload, return to the software installation procedure and continue with the next steps.
  2. If this procedure was not done as part of a software reload:
    1. Do a system restart. See t_RestartingTheHostComputer.html. This is required after configuration for the changes to take effect.
    2. Do a check scan. See Doing a check scan.
    3. Save the current configuration (SaveInfo). See Saving information.
