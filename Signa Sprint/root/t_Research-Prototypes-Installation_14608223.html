Downloading Patches from SupportCentral and Burning to a CD

About this task

If a disk is shipped that contains the patches, skip this section and proceed to Preparing for Research Options. If a disk is not available that contains the patches, download the patches onto your PC and then burn them onto a disk that can be used on the MR system. The MR system requires that the disk be ISO-compliant. This format type cannot be burned with Windows XP's built-in disk burning capability. To burn an ISO-compliant disk, a program such as Sonic RecordNow must be used, which burns ISO-compliant disks by default.

Procedure

  1. From your PC, go to http://supportcentral.ge.com/products/sup_products.asp?prod_id=49981 .
  2. In the right navigation pane, click Projects and select the appropriate research protopack link based on software version. See below.
    Note

    If you do not have site access, request access from SupportCentral.

  3. Go to the Readme section to understand dependencies and possible conflicts with other patches on scanner.
  4. Select the proper version of the patches required, and download the required *.rpm files listed for that version onto your PC. In some cases, you may need to contact MR Research Support Team to confirm which *.rpm files to download. Required files depend on the agreement between the site and MR.

    The download time will vary, depending on the number and size of files to be downloaded.

    Note

    To obtain a licensed copy of Sonic, go to Software Store and download the Sonic Record Now 7.exe file or call the GE Healthcare HelpDesk.

  5. To burn these *.rpm files, insert a blank CD into the CD-ROM drive.
  6. Start Sonic RecordNow.
  7. From Sonic's homepage, select the Data Projects tab, and click Data disk. See below.
    Note

    Since the system's Guided Install automatically looks for the *.rpm files in the dist folder, this folder must be created on the CD.

  8. To create the dist folder on the CD, click the New Folder icon, and type dist in the Name field. See below.
  9. Double-click the dist folder so it appears in the Save In field, click Add Files and Folders, and browse on your PC to add the .rpm files to the Data disk list (shown below).
  10. To burn the disk, click the red Burn button.

Research .rpm Files Installation

About this task

The installation process is the same whether installing research .rpm files from a disk that was sent from GE Healthcare or one that you burned.

Procedure

  1. Log in as root at the login prompt.
    Note

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  2. Perform a SaveInfo to back up your system.
  3. Insert the disk with the patches into the Host PC disk drive.
  4. In the Guided Install window, select Patches in the left navigation pane, and select the Patches tab.
  5. Select CDROM as the patch medium. The patches contained on the disk will be listed. See below.
    Note

    Go to the Readme file to understand the order in which the patches are installed.

  6. Select each patch and click Install.
    Note

    If multiple patches are selected and Install clicked, only the top patch will be installed. Each patch is installed after the Install button is clicked.

  7. After installing all the patches, restart the system by typing reboot in a C-Shell.
  8. To verify that all the patches are installed, open a C-Shell and type getver. Verify that the research options .rpm files just installed are listed.

Option Key Installation

Procedure

  1. Note

    Every Research pack/prototype must have option key or license installed. Application cannot run without the option enabled.

    All option keys are flex trial with expiration date set to expiration date of the research agreement with the customer.

    Contact MR Research team to get the option key.
  2. Go to Guided Install and then click the Options tab to enter the license key selecting the appropriate media.
