System Health Check

Disclaimer

Depending on your service agreement, not all service tools, diagnostics, and utilities referenced in this document may be accessible. Contact your sales person for information on available service license packages.

Running System Health Check from Command Line

  1. From the Service Desktop Manager, click C Shell. Type the following command: cd /usr/g/service/cclass and press Enter.

  2. Type: sys_health -nf -ns -notns -asc and press Enter. It may take several minutes before any results display.

    • When the check is complete, or if a fatal error occurs, the tool generates and displays status output and sends it to an output file named system_health.log in the /usr/g/service/log directory.

    • Fatal errors may be caused by a missing command. For instance, an error will occur if the option key -nf is not used.

    • If a system_health.log file already exists, it will be copied to *.log.bkup when sys_health is initiated. Consequently, two versions of the log may be kept; the current one (ending in *.log) and a backup one (ending in *.bkup).

    • See Advanced System Health Commands for advanced commands.

Results File

To display the output (system_health.log) file in a command window, type:

  • cd /usr/g/service/log and press Enter.

  • more system_health.log and press Enter.

To view additional information, press the spacebar until you reach the end of the file. See Sample System_Health.log Output Format.

Miscellaneous System Data

  • Software Revision: The sys_health software determines the software revision on the current system by invoking the getver command.

  • Disk Space Report: The sys_health tool reports the number of free disk blocks on the current system.

  • Install Options: The sys_health tool checks for installed options.

  • Host HW Inventory: The sys_health tool lists the hardware components on the host computer and reports all SCSI devices on the host that are powered up.

  • File Checksum: The sys_health tool checks file checksums. This feature determines whether or not any software or patches have been loaded on the system.

  • TNS Status: The sys_health tools reads the TNS (transient noise suppression) status, which reports the spike noise count data.

Advanced System Health Commands

From a command window (C Shell) execute the following command to see available advanced options: /usr/g/service/cclass/sys_health -h, then press Enter.

Table 1. Optional Keys
Key Definition
-p Displays plots of selected data sets. You will be prompted for confirmation before plotting the selected data set.
-nf Do not terminate a program when a FATAL error is encountered.
-h Displays the command options.
more Press the spacebar to display another screen of data.
Note

Only one option at a time can be selected (that is, enter -p, -nf, or -h). In most cases, the -nf option is used.
