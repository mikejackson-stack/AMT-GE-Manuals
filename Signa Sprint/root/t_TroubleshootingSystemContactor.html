Troubleshooting the system contactor

This document describes troubleshooting steps if the system contactor is de-energized or not functioning properly.

Procedure

  1. Observe the Cabinet Monitor 3 assembly System CNT LED.
    • If the System CNT LED is illuminated, the CabMon3 is ready to supply 120 VAC. Continue on to Step 3.
    • If the System CNT LED is not illuminated, continue on to Step 2.
  2. Make sure the CabMon3 is receiving 120 VAC power on connector J1.
    • If CabMon3 has 120 VAC at connector J1, replace the CabMon3.
    • If CabMon3 does not have 120 VAC at connector J1, make sure it is wired to the SPDU correctly and repeat Step 1.
  3. Make sure 120VAC is present at the System PDU connector J1 using a DMM set to AC voltage.
    1. Put the positive probe in connector J1 pin 6 (System Contactor Coil).
    2. Put the the negative probe in connector J1 pin 3 (System Contactor Neutral).
    • If 120 VAC is measured, the problem is within the System PDU or Gradient PDU. For more information, see the System PDU Owners Manual (DOC2078322 ) or Gradient PDU Owners Manual (DOC2078325) available on MyWorkshop (MWS).
    • If 120 VAC is not measured, continue on to Step 4.
  4. Reconfigure PDU connections.
    1. Disconnect the System PDU connector J1.
    2. Connect the 120 VAC Contactor Cable (5774880) to the System PDU connector J1 that was just removed.
    3. Insert the power plug into one of the service outlets.
    • If the system contactor energizes and the subsystems connected power on, proceed to Step 5.
    • If the system contactor does not energize and the subsystems connected remain powered off, the problem is within the System PDU or Gradient PDU. For more information, see System PDU Owners Manual (DOC2078322 ) or Gradient PDU Owners Manual (DOC2078325) available on MyWorkshop (MWS).
  5. Power down the CabMon3 and remove connector J2. Use a DMM to check resistance in the contactor power cable (5749299) to verify continuity.
    • If the contactor power cable is verified to be good, replace the Cabinet Monitor 3 (5938602).
    • If the contactor power cable is bad, replace the cable and repeat Step 1 through Step 5.

Finalization

After the issue is resolved and all assemblies are properly connected, test the E-Stop circuit by pressing one of the E-Stop buttons, and then recover by pressing the EMO Reset button. This verifies the E-Stop circuit is functioning properly.
