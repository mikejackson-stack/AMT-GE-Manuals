Doing a check scan with the Sphere with Spout (SWS) phantom

How do a check scan with the SWS phantom.

About this task

Doing a check scan with the sphere with spout (SWS) phantom is for sites that have the SWS phantom, and software version 31.0 and above. If the site does not have both, see Doing a check scan.

Procedure

  1. Attach the head coil to the cradle and plug it into the port.
  2. Put the positioner into the head coil.
  3. Put the SWS phantom into the positioner. Make sure the spout is put in the raised cut-out of the positioner.
  4. Set a landmark on the center line of the phantom and on the lines of the positioner.
    Note If the laser does not align with both the lines on the phantom and the lines on the positioner, align the laser with the line on the positioner.
  5. Finish assembling the head coil if necessary.
  6. Press Advance to Scan.
  7. Click the New Worklist icon.
  8. Select a Patient ID workflow (other than geservice).
  9. Enter for weight: 111.
  10. Click Show All Protocols....
  11. When the Protocol Selector menu opens, click Protocol Details.
  12. Select the Protocol Library: GE or GEHC.
  13. Select Adult.
  14. Click the Template tab.
  15. Select 3 - Plane 2D Localizer and click the arrow to move the selection to the box on the right.
  16. Click Accept.
  17. Click Save.
  18. Click Start Exam.
  19. Type in the image parameters that follow:
    OptionDescription
    Freq FOV30.0
    Phase FOV1.0
    Slice Thickness5.0
    Center0.0 for all three columns
    Spacing0.0 for all three columns
    # Slices25 for all three columns
  20. Select Head Coil.
  21. Click Task and select Change/Select Anatomy.
  22. In the Anatomical Region field, select Head/Brain and then click Accept.
  23. Click Save RX.
  24. Click Scan. Wait for the scan to complete.
  25. Review the images to make sure the orientation is correct.
    1. Make sure that the phantom is centered near the isocenter.
      • Cycle through the sagittal images and make sure that the largest phantom size occurs in one of the images labeled R10, R5, R0, L5 or L10.
      • Cycle through the coronal images and make sure that the largest phantom size occurs in one of the images labeled between A25 and P25.
      • Cycle through the axial images and make sure that the largest phantom size occurs in one of the images labeled S10, S5, S0, I5 or I10.

      Confirmation can be done by visual inspection. That is, which slice, per orientation, has the largest circle. The phantom should be largest size within the above parameters. For example, with the sagittal images, the phantom should be seen as the largest, left to right, within 10 mm.

      If any of these conditions are not met, do DQA calibration and then rerun this Check Scan procedure. See Doing DQA calibration with the Sphere With Spout (SWS) phantom.

    2. In the sagittal images, find the phantom's spout. The spout should be visible at approximately R15 - R20 (less than 20 mm from isocenter on right side).

      If one or more of these conditions is not met, do DQA calibration and then rerun this check scan procedure. See Doing DQA calibration with the Sphere With Spout (SWS) phantom.

Finalization

If you aborted the scan, look at the error log to find the cause of the problem.
