Note The 1.5T Coil MCQA will utilize the 1.5T phantoms, which are green in color. The 3.0T Coil MCQA will utilize the 3.0T phantoms, which are pink in color.

Procedure

  1. Remove the Flat Filler Panel from the Table if present.
  2. Place the HNA posterior unit on the Table as shown. Connect the coil to the P2 Port on the table.
  3. Place the HNA Phantom Positioner into the HNA posterior unit, then place the Large Cylindrical Unified Phantom and TL Unified Phantom into the HNA Phantom Positioner.
    Note

    Use the correct Phantom Positioner. Do not use Phantom Positioner for DV system. Otherwise, it will affect MCQA result.

  4. Connect the HNA face unit with the HNA posterior unit.
  5. Landmark the coil at the crosshair mark (indicated below), and press Advance to Scan.
  6. Run the Multi-Coil Quality Assurance Tool.
    Note

    Select “1.5T_32Ch_TDI_HNU_by_GE” for Current Coil field.

Finalization

No finalization steps.
