Service licensing

Secure Service Access (SSA) is a secure service key platform for GE HealthCare medical devices developed to improve the service license renewal and replacement processes.

The SSA license is a softkey (software file) for GE HealthCare tools and information. This license is assigned to one specific system and can be downloaded by GE HealthCare customers or service providers.

Multiple service license levels are available to manage access to different features, tools, and service methods. Contact your local GE HealthCare salesperson or service representative for more information. It is very important to install the service licenses for the system to gain access to the appropriate service tools.

Note Contact your GE HealthCare salesperson or service representative for information on available service license packages if no license is found when attempting to run a service feature or tool or if the license has expired.

The MR Restricted Service Software which is included in the USB installer, is license controlled. The same licensing scheme applies to the installation of the USB SW installer onto the system (either hardkey or softkey must be present).

Sites must generate and install a service license for the following reasons:

  • New system installation
  • Software upgrade
  • GOC component hardware replacement
  • System date or time change
  • System language change
Note The system language must be decided before getting the service license ID. If the language is changed on the system, it will also change the 16-digit service license ID assigned to the system and cause the existing license to fail.
