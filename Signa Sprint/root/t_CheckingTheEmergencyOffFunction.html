Checking the Emergency Off function

Procedure to verify the Emergency Off function.

Prerequisites

Required conditions
The host software is shut down before turning off the GOC host breaker.

About this task

An Emergency Off button is located on the optional GE Main Disconnect Panel. The other Emergency Off buttons are located by the customer.

Note The AC power for the magnet monitor is not controlled by the Emergency Off button.

Procedure

  1. Make sure that the ICN and Host PC (GOC Host) is shut down. See Shutting down the ICN and host computer.
  2. Turn off the GOC Host and the DC Power Supplies breakers on the SPDU.
    1AC Input breaker
    2DC Power Supplies breaker
    3MNS breaker
    4ICC breaker
    5RF Amp breaker
    6Magnet Power Supply breaker
    7Grad Ctrl 48VDC breaker
    8GOC/HOST breaker
    9CAB Monitor breaker
    10Fan breaker
    11Sequencing breaker
    12Power OFF pushbutton switch
    13EMO Reset pushbutton switch
    Note If you do not turn off the breakers, the host computer restarts when the power is applied. You must wait for the host computer to boot before you can test the additional Emergency Off buttons.
  3. Press one of the Emergency Off buttons (the location of buttons is determined by the customer).
    Verify that power was removed from the SPDU by checking the input voltage test points or viewing the SPDU power indicator lights.
  4. Reset the Emergency Off button.
  5. If using the optional GE Main Disconnect Panel:
    1. Reset the SPDU breaker, switch the breaker to the Off position.
    2. Reset the GPDU breaker, switch the breaker to the Off position.
  6. On the optional GE Main Disconnect Panel, switch the System PDU Breaker and Gradient PDU Breaker to the On position.
    1System PDU breaker
    2Gradient PDU breaker
    3Emergency Off button
    4System Power switch
    5Cryocooler breaker
    6Power On LED
  7. On the SPDU, press the EMO Reset button.
    Note When you press the EMO Reset button, you should hear the contractor engage.
  8. Repeat the above steps for the other Emergency Off buttons.
    Normal locations for the Emergency Off buttons are in the magnet room and in the operator room.
  9. Turn on the GOC Host and DC Power Supplies breakers on the SPDU.
    1AC Input breaker
    2DC Power Supplies breaker
    3MNS breaker
    4ICC breaker
    5RF Amp breaker
    6Magnet Power Supply breaker
    7Grad Ctrl 48VDC breaker
    8GOC/HOST breaker
    9CAB Monitor breaker
    10Fan breaker
    11Sequencing breaker
    12Power OFF pushbutton switch
    13EMO Reset pushbutton switch
