Capturing screen shots using GIMP

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-5 minutes-

About this task

It may be necessary for you to capture screen shots from a host computer to share with the Online Center or other GE service representative. The following procedure describes how to use the GNU Image Manipulation Program (GIMP) to capture screen shots.

Procedure

  1. To start GIMP, open a C Shell, type gimp at the prompt and press Enter. If GIMP is not configured on the host PC, follow the screen prompts to configure.
    Note The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log off and then log back on as the correct EA3 user with the authorized permissions.
    Note GIMP often launches in two windows shown below. The Layers, Channels, Paths, Undo window can be safely closed as it will not be used.
  2. To capture a screen shot, move the GIMP windows if they are blocking any portion of the proposed shot.
  3. From the GIMP File menu, select Acquire and then Screen Shot (for GIMP versions prior to 2.6.x), or Create and then Screenshot (for GIMP versions 2.6.x and later).
  4. When the Screen Shot or Screenshot dialog box displays, select the desired preference and click OK (for GIMP versions prior to 2.6.x) or Snap (for GIMP versions 2.6.x and later).
  5. Click on the screen or window to capture. The screen shot displays in a new GIMP window.
  6. To save the file, select Save As (for GIMP versions prior to 2.10.x) or Export As (for GIMP versions 2.10.x and later) from the File menu.
  7. In the Save Image (for GIMP versions prior to 2.10.x) or Export Image (for GIMP versions 2.10.x and later) window, name the file, select a file extension, then the directory where the file should be saved.
  8. (For GIMP versions 2.10.x and later) Select PNG output options in the Export Image as PNG window and click Export.

Finalization

To locate the saved images, log onto the Host PC from your laptop, and browse to the appropriate directory. The files can then be moved to a local directory.
