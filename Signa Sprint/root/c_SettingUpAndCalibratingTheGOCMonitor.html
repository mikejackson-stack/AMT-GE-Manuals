Setting up the Eizo EV2430 24-inch monitor

  1. Make sure that you have read and understood the electrical safety requirements before starting this procedure. See Electrical Safety.
  2. Shut down and power off the host computer. See Shutting down the host computer.
  3. Apply GOC LOTO. See Applying LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
  4. Remove the monitor from the box and set the monitor on the operator workspace table.
  5. Connect the Mini DP cable from the GOC to the Mini DP port on the monitor.
  6. Connect the power cables to the monitor.
  7. Route cables neatly to the back of the monitor base and the operator workspace.
    1Factory preset is set to on.
    Note Make sure that only GE HealthCare product video hardware is connected to the GOC so that the software properly installs.
  8. Turn on the monitor if not already on. Make sure that the main LCD monitor power is on. If not, press the Power On/Off button on the front panel.
  9. Put the monitor no closer than 41 cm (16 in) and no farther than 71 cm (28 in) from the eyes. The optimal distance is 61 cm (24 in) for either of the monitors.
    Note Allow the monitor to warm up for 20 minutes before doing any adjustments.
  10. Start up the GOC and log on as root.
    Note It is possible that the customer changed the default password. If you cannot log on, contact the customer for the correct password.
  11. Open Guided Install and select Basic Configuration > System Configure.
  12. Refer to the figure below and do the following:
    1. Make sure the correct video card is selected.
      • If not, choose the correct video card model from the Video Card menu.
      • If the correct video card is not listed, make sure the most recent MrApps software and Service Packs are loaded.
    2. Select LCD Monitor - Other as the Display Type.
      • If this option is not available, use NEC LCD2490WUXi2.
  13. Click Configure. Default gamma tables will be installed on the system.
  14. When complete, exit Guided Install and restart the system.
  15. Log on as root.
    Note It is possible that the customer changed the default password. If you cannot log on, contact the customer for the correct password.
  16. Adjust the monitor to customer preference. For details and recommended settings see LCD Monitor Screen Adjustments.

Calibrating the Eizo EV2430 24-inch monitor

Follow the directions below to calibrate the Eizo EV2430 24-inch monitor.

  1. Remove GOC LOTO. See Removing LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
  2. Start up the host computer/system. See Starting up the host computer .
  3. Refer to the figure and table below for locations and descriptions of the Eizo monitor controls.
    1EcoView sense sensorDetects movement of a person in front of the monitor
    2Ambient light sensorDetects ambient brightness
    3 buttonShows the power saving setting menu
    4SIGNAL buttonSwitches input signals for display
    5MODE buttonSwitches the color mode
    6ENTER buttonShows the Settings menu, selects an item on the menu, and saves.
    7▲ / [Volume icon] , ▼/ [Brightness icon]
    • Controls navigation and adjusts settings
    • ▲ / [Volume icon]: Shows the volume adjustment menu
    • ▼ / [Brightness icon]: Shows the brightness adjustment menu
    8 buttonTurns power on or off
    9Power indicatorIndicates monitor's operation status
    • White: Operating
    • Orange: Power saving mode
    • Off
    10Main power switchTurns the main power on ( | ) or off ( O )
    11Power connectorConnects the power cord
    12Input signal connector

    Left: DisplayPort

    Center: DVI-D

    Right: D-Sub mini 15-pin

    13Security lock slotComplies with Kensington’s MicroSaver security system
    14SpeakerOutputs audio
    15HandleHandle used for transportation
    16USB downstream portConnects a peripheral USB device
    17USB upstream portConnects the USB cable for using the USB Hub function
    18Headphone jackConnects the headphones
    19Analog audio input connectorOutputs external audio from the monitor
    20StandAdjusts the height and angle (tilt and swivel) of the monitor
    21Cable holderManages cables
  4. Show the settings menu.
    1. Press Enter to show the settings menu.
    Note Default display settings for Eizo EV2430:
    ColorsRGB
    Color Temperature6500K
    Display Transfer functionGamma2.2
    BrightnessPreset at 80%
  5. Adjust settings.
    1. Select a setting to adjust with ▲▼ and then press Enter. The setting submenu opens.
    2. On the submenu, select a setting to adjust with ▲▼ and then press Enter. The adjustment menu opens.
    3. Use ▲▼ to adjust settings as needed and then press Enter to set.
  6. Exit menu.
    1. Select Return from the submenu and then press Enter.
    2. Select Exit and then press Enter.

Finalization

  1. Do a check scan to make sure the system is working properly. See Doing a check scan.
  2. If the system has a camera and the customer wants to match the camera image to the new monitor image, the customer must notify the camera vendor that a new monitor type has been installed and camera adjustments are required.
