Installing operator documentation (online help)

Load the operator manuals onto the host computer so customers can have access to the manuals any time they are using the system.

Prerequisites

About this task

All operator manuals are distributed electronically. These instructions describe how to load the operator manuals onto the system’s host computer so customers can have access to the manuals any time they are using the system.
Choose one from the following workflows:
  • Installing operator documentation through remote software download
  • Installing operator documentation through DVD media
  • Installing operator documentation through USB media
Topic ID: task_lw3_nx4_m5b

Installing operator documentation through remote software download

Prerequisites

Note If the Operator Manual was downloaded through IRIS, there is no need for a DVD/USB.

Procedure

  1. The person doing the software install must have the role as a GE software installer. To switch users and log in with the correct privileges, do the following:
    1. In the header area of the screen, click Tools.
    2. In the System Management work area, click Service Desktop Manager.
    3. Click Lock Screen Switch User.

      Result

      The Logon screen displays.
  2. From Dashboard, click the Update Available icon.
  3. After the package is imported, it will show under the Downloads tab.
  4. In the Downloads tab, select the check box next to the Operator Manual package you want to install and click Install Now.
  5. In the confirmation window, select the acknowledgement check box, then click Proceed.
  6. In the progress window, select the acknowledgement check box, then click Continue.

    Result

    • If the installation is successful, the system displays a success message.
    • If the installation fails, the system displays an error message. Contact GE HealthCare.
  7. To determine the status of the installation, click the History tab.
  8. To make sure the online help opens, from the main menu, click overflow icon.
  9. From the overflow menu, click the Online help icon. The online help opens to the home page in the HTML5 format.

Installing operator documentation through DVD media

Prerequisites

Note This feature is only available on systems using software CX40.2 and earlier.

Procedure

  1. Select the DVD that contains the language for the documentation that is to be installed on the system.
    The Operator Manual has multiple language options. Please make sure the media contains the documentation in the site’s language of choice.
  2. Launch Guided Install. See Accessing guided install for more information.
  3. Select Service SW/Insite from the Guided Install content window.
  4. Click Install Online Help.
  5. When prompted to insert the media containing online documentation, insert the DVD containing the selected language into the host computer's DVD drive and then click OK.
    Note If the Operator Manual is already downloaded through the IRIS Remote Software Download functionality, there is no need for DVD media.
    Note The DVD is available in multiple languages. Make sure that the selected DVD contains the language to be installed at the site.

    Result

    An Online Help Installation dialog box appears.
  6. Select the language that is to be used for the online help and click Install.
    If the language you want is not on the menu, try another operator manual DVD.

    Result

    After the installation is complete, a message appears indicating that the installation was successful.
  7. Remove the DVD from the drive/port, if applicable.
  8. Reboot the system and log on to applications.
  9. To make sure the online help opens, from the main menu, click overflow icon.
  10. From the overflow menu, click the Online help icon. The online help opens to the home page in the HTML5 format.

Installing operator documentation through USB media

Prerequisites

Note This feature is only available on systems using software CX41.0 and later.

Procedure

  1. Log on to the system as a member of the GESoftwareInstaller group.
  2. Insert the Operator Manual USB media into the host PC.
  3. Launch Service Browser and click the Utilities tab.
  4. In the left navigation panel, click Remote SW Download and then click Click here to start this tool to launch the Software Delivery Manager.
  5. When the Software Delivery Manager tool opens, click Import Packages in the upper right corner.
  6. Select the USB drive in the left toolbar. The contents of the USB Operator Manual file shows in the main window.
  7. Click Upload.
  8. Select the Operator Manual package and click Import Packages. A confirmation message shows.
  9. After the package is imported, it will show under the Downloads tab.
  10. In the Downloads tab, select the Operator Manual package check box and click Install Now.
  11. The Install Now dialog box opens asking you to confirm the installation. Select the acknowledgment check box and click Proceed.
  12. Continue through the checks/warnings windows by acknowledging or clicking OK or Continue. The installation process should not take more than a few minutes.
  13. To determine the status of the installation, click the History tab.
  14. To make sure the online help opens, from the main menu, click overflow icon.
  15. From the overflow menu, click the Online help icon. The online help opens to the home page in the HTML5 format.
