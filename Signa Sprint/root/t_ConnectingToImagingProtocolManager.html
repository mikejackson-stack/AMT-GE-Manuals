Connecting to Imaging Protocol Manager (IPM)

Connect the scanner to Imaging Protocol Manager (IPM) on the cloud.

Prerequisites

  • Make sure that the network information provided to you by the IPM Project Manager has been entered in the MR scanner.
    • See Check/configure network information on the scanner
    • See Configuring a proxy server and Configuring the SSL certificate (only for customers that use SSL configuration), if required
  • Make sure the curl commands were ran and are successful. See Checking the MR scanner-IPM network connectivity.
  • Make sure you have the protocol count. See Obtaining a protocol count.

About this task

Use the Service Browser on the scanner to register IPM. Procedures differ whether the MR scanner has Cloud Connectivity (old agent) or IPM (new agent).
Topic ID: task_hgk_vwm_sbc

Cloud Connectivity (old agent)

Procedure

  1. In the Service Browser, navigate to Configuration > Configure Cloud Connectivity.

    Result

    The Get Connected registration page shows.
  2. Enter details in the following fields:
    1. User name: Enter the user name from the credentials for the specific MR scanner. During initial installation, the IPM Project Manager will provide this information.
    2. Password: Enter the password from the credentials for the specific MR scanner. During initial installation, the IPM Project Manager will provide this information.
    3. IPM Configuration URL: Enter the IPM device configuration URL. During initial installation, the IPM Project Manager will provide this information. For more information, see the Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972).
  3. Click Connect to start the device authorization process.

    Result

    If all of the credentials are correct, the device is authorized and enrolled. Device credentials/security keys are generated and stored on the MR system. MR system configuration data is then uploaded to the cloud.
  4. After the following message shows the connection is successful, tell the IPM Project Manager that this MR scanner is connected. The IPM Project Manager should make sure that this MR scanner state is shown as Activated, and the status field contains a green check mark in the IPM application.
  5. To retain connectivity information, see Saving information. The system is ready to exchange protocols between this MR scanner and the IPM application.
  6. Reboot the MR scanner to implement the changes to the IPM Agent.
  7. Provide the IPM Project Manager with the following details:
    • IPM has been successfully enrolled on the MR scanner.
    • The number of protocols on this MR scanner. For more information, see Obtaining a protocol count.
Topic ID: task_hf5_5wm_sbc

IPM (new agent)

Procedure

  1. In the Service Browser, navigate to Configuration > Imaging Protocol Manager (IPM).

    Result

    The Get Connected registration page opens.
  2. Enter details in the following field:
    1. IPM Configuration URL: Enter the IPM device configuration URL. During initial installation, the IPM Project Manager will provide this information. For more information, see the Imaging Protocol Manager (IPM) Restricted Service Manual (DOC2090972).
  3. Click Connect. The MR scanner will do an authorization check on the device configuration URL. When that is successful, the Enrollment Code page shows.
  4. Enter details in the following field:
    • Enrollment Code: Enter the enrollment code that is specific to this MR scanner. During initial installation, the IPM Project Manager will provide this information.
  5. Click Connect to start the device authorization process.

    Result

    If all of the credentials are correct, the device is authorized and enrolled. Device credentials/security keys are generated and stored on the MR system. MR system configuration data is then uploaded to the cloud.
  6. After the following message shows the connection is successful, tell the IPM Project Manager that this MR scanner is connected. The IPM Project Manager should make sure that this MR scanner state is shown as Activated, and the status field contains a green check mark in the IPM application.
  7. To retain connectivity information, see Saving information. The system is ready to exchange protocols between this MR scanner and the IPM application.
  8. Reboot the MR scanner to implement the changes to the IPM Agent.
  9. Provide the IPM Project Manager with the following details:
    • IPM has been successfully enrolled on the MR scanner.
    • The number of protocols on this MR scanner. For more information, see Obtaining a protocol count.
