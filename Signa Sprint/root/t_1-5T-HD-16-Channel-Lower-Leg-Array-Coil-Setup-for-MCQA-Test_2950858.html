Required conditions
The following coil configuration names must be installed to run this tool: HD LowerLeg_serv, HD_LowerLegLserv, and HD_LowerLegRserv.

About this task

Follow this process to prepare for the automated SNR test using the 1.5T HD Lower Leg Coil by GE/USAI (M3335LY).
Note Coils do not ship with phantoms. Phantoms come in a unified phantom set with the MR system.
Topic ID: id_SL2924734-585344

Unified Phantom Setup

Topic ID: id_SL2950927-585344

Mode: Lower Leg LEFT

Procedure

  1. Place the base of the coil on the patient table and position the left leg segments on the base.
  2. Place the large and small cylindrical unified phantoms in the left leg portion of the coil.
  3. Place the large and small cylindrical unified phantoms in the left leg portion of the coil.
  4. Place the cubicle unified phantom in the foot part of the left leg portion of the coil.
  5. Cover the phantoms with the anterior portion of the coil, using the straps provided.
  6. While covering the foot part, make sure that the arrow marks are aligned with each other.
  7. Connect both the cables of the preamp box to the coil, and then connect the cables of preamp box to B port of system LPCA.
  8. Connect the coil to the respective port of system LPCA.
  9. Landmark the coil on the marks provided, and press advance to scan.
  10. Perform the Multi-Coil Quality Assurance (MCQA) Test. For Lower Leg Array left mode, the following phantom sets are listed from the drop-down menu.
  11. Select Unified Phantom Set – Single connector – Left Mode from the drop-down menu.
  12. Proceed with the test.
Topic ID: id_SL2950950-585344

Mode: Lower Leg RIGHT

Procedure

  1. Place the base of the coil on the patient table and position the left leg segments on the base.
  2. Place the small cylindrical unified phantom in the right leg portion of the coil.
  3. Place the cubicle unified phantom in the foot part of the left leg portion of the coil.
  4. Cover the phantoms with the anterior portion of the coil, using the straps provided.
  5. While covering the foot part, make sure that the arrow marks are aligned with each other.
  6. Connect both the cables of the preamp box to the coil, and then connect the cables of preamp box to B port of system LPCA.
  7. Connect the coil to the respective port of system LPCA.
  8. Landmark the coil on the marks provided, and press advance to scan.
  9. Perform the Multi-Coil Quality Assurance (MCQA) Test with the Unified Phantom Set.
  10. For Lower Leg Array Right mode, the following phantom sets are listed from the drop-down menu.
  11. Select Unified Phantom Set – Single connector – Right Mode from the drop-down menu.
  12. Proceed with the test.
