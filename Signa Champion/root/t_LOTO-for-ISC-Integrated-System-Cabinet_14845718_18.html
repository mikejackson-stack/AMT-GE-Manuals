Applying LOTO - Integrated System Cabinet (ISC)

Apply LOTO to the Power Distribution Unit (PDU) when servicing this item in the Integrated System Cabinet (ISC). Applying LOTO ensures a safe environment when working on this part.

About this task

Warning
Electrocution hazard
High voltage present.
Use proper LOTO procedures before servicing and/or maintaining.
This document covers ISC Main Breaker - Lockout and ISC - Restoring Power. Prior to doing work on the ISC electronics, Integrated Cooling Cabinet (ICC) electronics (except F50 Cryocooler Compressor), and electronics in the magnet room (except magnet), the steps in this Lock Out Tag Out Procedure must be completed by a LOTO authorized GE HealthCare Field Engineer (FE). Completing all the steps in this procedure ensures a safe environment and avoids equipment damage when working on these parts.

About this task

Time method for dissipation of stored energy: 5 minutes.

Topic ID: id_SL1770158-1178697

Types of equipment and/or methods used to ensure disconnections

Procedure

  1. One personal lock and tag per FE at the site working on the de-energized equipment at the time of LOTO.
  2. Voltmeter to read voltage for verification that energy has dissipated in the PDU.
Topic ID: id_SL13909672-1178697

Power down the computer subsystems

About this task

System Power Off, under Access tab, is for customer use since it will require 1 hour at the most to power down the system to cool down gradient coil temperature, and reduce B0 drift in customer scan level. For service LOTO, use system shutdown for immediate shutdown. However, note that it will be required to wait 1 hour after restoring power for certain calibration and/or customer scan.

Topic ID: id_SL14015070-1178697

System shutdown when system is in operator level

Procedure

  1. To prepare for shutdown of equipment, notify affected personnel working in the area the LOTO is being done.
  2. From the Common Service Desktop, select Utility > System Shutdown and click Shutdown to shutdown the PC and ICN.
Topic ID: id_SL13909676-1178697

System shutdown when system is in root level

Procedure

  1. To prepare for shutdown of equipment, notify affected personnel working in the area the LOTO is being done.
  2. Right-click on the Linux desktop to access the Root Menu and then select Logout.
  3. Select Menu > Shutdown on the Welcome login screen to shut down the system.
  4. Make sure the system is shut down.
Topic ID: task_bnv_5bj_g1c

Applying LOTO – ISC

About this task

System cabinet PDU main breaker off & Lockout/tagout for ISC main breaker in MDP or facility PDU.
Note You must wear Arc Flash Suit based on Zero Energy assessment requirement if you need to open the PDU front panel to finish the test.

Procedure

  1. Notify affected personnel that LOTO will be applied.
  2. Make sure the host computer is shut down.
  3. Open ISC Cover.
  4. Use DVM check the voltage between each two of the three contact points (for both E-STOP & GRADIENT CONTACTOR) on PDU, make sure the voltage of GRADIENT contactor is around 420V, and E-STOP contactor is around 208V.
    Note This step is to gurantee secondary input is functioning.
    Note Make sure the Main Breaker is in the Red ON (I) position.
  5. Go to MDP, Lock Out/Tag Out the INTEGRATERD SYSTEM CABINET breaker on the MDP or facility PDU.
  6. Wait five minutes for dissipation of stored energy.
  7. Go to the PDU in ISC, use DVM check the voltage between each two of the three contact points (for both E- STOP & GRADIENT CONTACTOR) on PDU, make sure that the voltage is under 1VAC.
    Note This step is to guarantee the input energy from MDP is measured.
    Note Make sure the Main Breaker is in the Red ON (I) position.
