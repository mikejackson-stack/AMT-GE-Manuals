      • Doing a check scan

        A check scan is done at the beginning of some procedures and at the end of many procedures. This functional check assures the unit is in good clinical working order.

      • Doing a compressor pressure check

        Do a check of the cryocooler compressor supply pressure.

      • Doing the local TR coil Stability test

        This tool measures and shows the magnitude drift, phase offset, and echo shift using Fast Spin Echo and Gradient Resolved Echo sequences for either the body coil or local coils. Local TR coil scans are disabled until this task is completed.

      • Doing an MRU quarterly service check

        Do a check of the functionality and operation of the Magnet Rundown Unit (MRU).

      • Doing an MRU yearly service check (MRU, ERU, or EDU PM testing matrix)

        The model number is listed on the side of the Magnet Rundown Unit (MRU), Emergency Rundown Unit (ERU), or Emergency Discharge Unit (EDU). Refer to the appropriate vendor manual available from the online documentation library for applicable testing procedures.

      • Doing the leak sensor functional check
      • Checking the Emergency Stop and Off functions

        Follow these procedures to check the Emergency Stop function of the PDU for the Gradient subsystem and RF subsystem, and to check the Emergency Off function of the power for the entire system.

      • ICC hose and valve inspection, coolant fill, and coolant leak check
      • MDP power and ground label check

        MDP power and ground connections must be tight in order to avoid system failures.
