Resetting the BIOS password for the host computer - administrator password unknown

Resets the passwords for the BIOS settings when the administrator password is not known.

Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

DANGER
Electrocution hazard
Hazardous voltage is present when the cabinet is energized.
Before beginning any work, do LOTO. See the MR Service Safety Manual (5452735).

About this task

This procedure describes how to reset the BIOS password when the admin password is unknown for the following host computers: Dell T5820 and HP Z4 G5. Follow the appropriate steps for the type of host computer installed.
Important Disconnect the power cord from the computer and let the internal components cool before doing these steps.
Notice
Potential component damage
Electrostatic discharge (ESD) can cause permanent damage to electronic components.
Observe the following ESD precautions:
  • Work on a static-free mat.
  • Wear a static strap to make sure that any accumulated electrostatic charge is discharged from your body to the ground.
  • Create a common ground for the equipment being worked on by connecting the static-free mat, static strap, and peripheral units to that piece of equipment.
  • For more information on ESD protection, see MR Service Safety Manual (5452735).

Procedure

  1. Shut down the operating system.
  2. Power off the workstation and external devices.
  3. Remove the host computer:
    • (For Dell T5820) See Removing the host computer - Dell T5820.
    • (For HP Z4 G5) See Removing the host computer - HP Z4 G5.
  4. Remove the side cover.
  5. (For HP Z4 G5) Remove the RAM fan assembly cover.
    1. Pinch the two blue release latches.
    2. Lift the RAM fan assembly cover and remove it.
  6. Find the password header and jumper. The password jumper is labeled PSWD.
  7. Make sure the power cord is disconnected from the host computer.
  8. Remove the password jumper.
    Note The password jumper is colored so that it can be easily identified.
  9. Reconnect all components and the power to the workstation.
    Note Do not install the jumper now. It will be reinstalled later.
  10. Install the side cover.
    1. Hold and align the bottom of the side cover to the chassis.
    2. Make sure that the hook on the bottom of the side cover snaps into the notch on the system.
    3. Press the system cover until it clicks into place.
      Notice
      The system will not power on without the side cover. Also, the system will shut down if the side cover is removed while the system is on.
  11. Power on the workstation until video shows on the monitor.
  12. Apply LOTO and shut down the workstation.
  13. Remove the power cord from the host computer and remove the side cover.
  14. Install the password jumper. This will clear the passwords.
    Note If the password jumper is reinstalled on different pins than it was removed from, the password cannot be set. Make sure that the password jumper is installed correctly.
    (For HP Z4 G5) The password jumper must be installed on pin 2 (middle) and pin 3 (bottom).
  15. Install the side cover.
  16. Install the host computer:
    • (For Dell T5820) See Installing the host computer - Dell T5820.
    • (For HP Z4 G5) See Installing the host computer - HP Z4 G5.
  17. Power on the computer. The computer will not require any passwords after this reset; both System and Admin passwords will be erased.
  18. To create passwords,
    • (For Dell T5810 or T5820) See Setting the BIOS password - Dell T5820.
    • (For HP Z4 G5) See Setting the BIOS password - HP Z4 G5.
