Doing a Physiological Acquisition Controller (PAC) respiratory test

The Physiological Acquisition Controller (PAC) respiratory test causes the PAC module to test its respiratory gain and offset circuits.

Diagnostic link

Diagnostics > Hardware Location > Magnet room > PAC Diagnostics Test

Note

Starting from software version(s) 30 or later:

  • "PAC" in the software now refers to either PAC (for wired gating) or WPAC/PAWS (for wireless gating).
  • "SPU" was changed to "ICE." They are equivalent.
  • There is now no difference between Short and Long Test Length.
  • SPU to FPGA DP, SPU Cardiac Diags, SPU Respiratory Diags are all now included in single diagnostic called PAC Related ICE BLD

Purpose

This diagnostic makes sure that the trigger signals (respiratory trigger), which are launched from the SPU in ICE, could be correctly captured by the sequencer module in ICE.

Components tested

  • PAC Module
  • The SPU (at the ICE board) and PAC communication link

Requirements

None

Block diagram

None

Test sequence

  1. Select PAC Resp. from the PAC diagnostics screen.
  2. Click Calculate Time to get an estimate of the time it will take to run the selected diagnostics.
  3. Click Run to initiate test.
Note The Test Options settings should not be changed from their default settings unless instructed to do so by a GE Healthcare engineer. There are very few circumstances when these settings ever need to be changed.

Expected results

Output values are judged pass or fail. In the event of failure, the details of the failure can be found in the GE System Log.

Although, in the case of errors you can click the 1st Error number to see the nature of the error. We recommend that you view the GE System Log to view all the errors that were recorded.

If this test fails, do the PAC LED manual test to make sure that the SPU and PAC communication link is working, which then isolates the cause of the failure to the PAC module.
