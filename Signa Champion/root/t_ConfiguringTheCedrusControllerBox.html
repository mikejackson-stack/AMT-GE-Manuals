Configuring the controller or sync box

Procedure

  1. Go to the Service Browser.
  2. Go to Utilities > BrainWave Paradigm Manager.
  3. Click BrainWave Paradigm Manager to start the tool. The Offline Paradigm Manager window launches.
  4. Click the Settings tab, then click PXE tab.
  5. Make sure PXE Application Controller Type is set to the correct controller type.
  6. Leave the Offline Paradigm Manager window open and continue to the next section.

Configuring NNL SyncBox

Procedure

  1. Select Synchronization, which sets the SyncBox into Synchronization mode.
  2. On NNL Sync Box, go to Options > USB Mode and set it to Serial.
  3. From Main Menu, select Go to Choose Mode > Synchronization > Start Session.
    Note You should not have to select Start Session again between patients, but make sure the sync box displays Session Running before starting the fMRI scan. If not, select Start Session again.

Configuring NNL Table PC

About this task

The NordicActiva software is pre-installed on the NNL Tablet PC. Configure the setting using the steps below.

Procedure

  1. Open software on Microsoft surface.
  2. Enter the patient details and select Next.
  3. Load the Paradigm page. Select Paradigm > General > Start/Stop (Motor Paradigm).
    • Number of Volumes = 90 (must be the same for statistical samples from host monitor)
    • TR = 3000ms (must be the same for effected TR from host monitor)
  4. Make sure to check that the sync box is in serial mode
  5. Select Edit > Setting > Sync Box > Auto detect, which will detect the sync box.
  6. Select Edit > Setting > Sync Box > Displays, and select the appropriate display so that paradigm displays on that screen.
  7. Select Edit > Run mode > Synchronize.
  8. Select Edit > Setting > MR Scanners > Triggers on Every Block.
