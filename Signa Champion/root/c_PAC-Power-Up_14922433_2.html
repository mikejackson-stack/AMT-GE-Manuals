Doing Physiological Acquisition Controller (PAC) diagnostics

The Physiological Acquisition Controller (PAC) power-up test causes the Signal Protection Unit (SPU) to initiate a Physiological Acquisition Controller (PAC) module power-up. The diagnostic logs the first error found.

Disclaimer

Depending on your service agreement, not all service tools, diagnostics, and utilities referenced in this document may be accessible. Contact your sales person for information on available service license packages.

Diagnostic path

Diagnostics > Hardware Location > Magnet Room > PAC Diagnostics

Note

Starting from software version(s) 30 or later:

  • "PAC" in the software now refers to either PAC (for wired gating) or WPAC/PAWS (for wireless gating).
  • "SPU" was changed to "ICE." They are equivalent.
  • There is now no difference between Short and Long Test Length.
  • SPU to FPGA DP, SPU Cardiac Diags, SPU Respiratory Diags are all now included in single diagnostic called PAC Related ICE BLD

Purpose

Requirements

After the diagnostic is complete, do a TPS reset is required prior to scanning.

Block diagram

None

Test sequence

  1. Select PAC Board Level Diagnostics (software version 30 and later) from the PAC Diagnostics Test screen.
  2. Click Calculate Time to get an estimate of the time it will take to run the selected diagnostics.
  3. Click Run to initiate test.
    Note Do not change the Test Options settings from the default settings unless instructed to do so by a GE HealthCare engineer. There are very few circumstances when these settings need to be changed.

Expected results

Diagnostic results show a status of Pass or Fail. If you receive a Fail status, click GE System Log to view the error message. The system log records errors with the date, time, the process tested, and a detailed error message.

  • Doing the Signal Protection Unit (SPU) to Field Programmable Gate Array (FPGA) loopback test
    The Signal Protection Unit (SPU) to Field Programmable Gate Array (FPGA) loopback test verifies the data path in the PAC I/F in the PSC FPGA on the Integrated Control Engine (ICE) board.
  • Doing a TPS reset
    This document provides instructions for doing a TPS reset and examples of the results output.
