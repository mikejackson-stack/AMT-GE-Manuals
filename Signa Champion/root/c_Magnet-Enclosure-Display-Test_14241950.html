Doing a magnet enclosure display test

This test provides a quick method of testing the control panel display LEDs and indicator lamps.

Diagnostic link

Diagnostics > System Function > Patient Handling > SRI Functional Diagnostics

Diagnostics > Hardware Location > Magnet Room > SRI Functional Diagnostics

Purpose

This test provides a quick method of testing the control panel display LEDs and indicator lamps.

Note It does not test the In-Room Display (IRD) LCD monitor on systems.

Components tested

  • Operator panel lights

Requirements

None

Test sequence

  1. Select Magnet Enclosure Display Test.
  2. Click Run.

Results

  1. The operator panel lights should blink on for one second, then off for one second until the test is stopped.
  2. Click Stop to end the test.

Troubleshooting

There are two failure modes for the display test:

  • If one control panel fails, check the control panel.
  • If both control panels fail, check the cabling from the SRI or with the SRI itself.
