Removing the In-Room Display (IRD)

Remove the In-Room Display (IRD).

Prerequisites

Procedure

  1. Make sure that you have read and understood the electrical safety requirements before starting this procedure. See Electrical Safety.
  2. Shut down and power off the host computer. See Shutting down/powering off the host computer.
  3. Apply LOTO to the ISC. See Applying LOTO - Integrated System Cabinet (ISC).
  4. Remove the right hand lower access panel. See Removing the right hand lower access panel.
  5. Remove the table interface cover. See Removing the table interface cover.
  6. Remove the magnet left and right control panel covers. See Removing the magnet left and right control panel covers.
  7. Put the control panel cover with the IRD on a padded surface to prevent scratching the touch screen.
  8. Remove the screws and washers that attach the IRD to the control panel cover.
  9. Lift the control panel cover off the IRD.
  10. Repeat the procedure for the adjacent IRD, if necessary.
