2244570

ERROR: EM_GP_SGA_FAILED_READY
The %c Axis gradient amplifier failed to go to Ready when commanded. Please perform a TPS reset and try again. If the problem persists, please call service engineer.
Extended Error:
If the G_ENABLE test point on J2(front of SGA/HFA)is high(5V), the problem is likely in the gradient amplifier or power supply. Swap Gradient Amplifier Control Board with that of another axis to isolate Gradient Amplifier vs. Gradient Amplifier Control Board. If the G_ENABLE test point is low, check the cable between GP and the Gradient Amplifier, or replace the GP.

The GP reported multiple SGA Power Supply Overtemperature Faults.
Extended Error:

Proper cooling requires a vaccum to pull air through the Gradient Amplifiers, Power Supply, and GP. If fault persists on specific PSDs, write a PQR.
