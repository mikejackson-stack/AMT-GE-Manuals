DMA API - Close operation failed because the DMA interface handle's semaphore is no longer valid.
Extended Error:
When a DMA interface is opened a semaphore, which uniquely identifies the board and channel used for the DMA transfer, is created. The semaphore ID is stored in the DMA interface handle. When the DMA interface is closed using plxDmaClose(), the semaphore is 'given' using semGive(), and deleted using semDelete(). This error occurred because the semGive(<sempahore ID from DMA interface handle>) function failed. Either (1) the sempahore environment of the O/S is corrupted, or (2) the DMA interface handle is corrupted.
Possible cause(s) (most to least probable):
  1. Firmware

DMA API - Close operation failed because the blocking semaphore is no longer valid.
Extended Error:
When a DMA interface is opened, the software defaults the transfer to a blocking transfer - meaning the task initiating the DMA transfer will suspend itself until the DMA transfer is complete. Therefore, a blocking semaphore is created. (Note: If the transfer is non-blocking, the sempahore is deleted and this error cannot occur.) The semaphore ID is stored in the DMA interface handle. For blocking transfers, when the DMA interface is closed using plxDmaClose(), the semaphore is 'given' using semGive(), and deleted using semDelete(). This error occurred because the semGive(<blocking sempahore ID from DMA interface handle>) function failed. Either (1) the sempahore environment of the O/S is corrupted, or (2) the DMA interface handle is corrupted.
Possible cause(s) (most to least probable):
  1. Firmware
