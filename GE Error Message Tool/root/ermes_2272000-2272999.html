Hardware Failure. The RF Hub RFCB detected a board in the RF Hub is present via the backplane serial link, but did not detect the board present line. Board: %b
Extended Error:
The RFCB did not detect a board present line for either a RFSB or MCDB, but the board is communicating to the RFCB across the backplane serial link. Take out the RFCB and the board indicated and check for bent pins on the backplane. Try reseating both boards. If reseating the boards does not work, replace the boards or the backplane.
Possible cause(s) (most to least probable):
  1. RF Hub Control Board
  2. RF Hub Switch Board
  3. RF Hub Multi-Coil Driver Board
  4. RF Hub Backplane
