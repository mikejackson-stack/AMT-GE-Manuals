ERROR: EM_MOT_DIAG_INVALID_PWRON_STATE_ERR
Board %s is in invalid power up state %d. Verify ENV parameters and retry power up.
Extended Error:
The board may be in one of the following states: 0 - No response, 1 - OS Loaded, 2 - PPC Bug, 3 - PPC Diag, 4 - OS not loaded If the error message states that the board is in state 4, then the OS load was stopped. This may happen if characters are detected on the serial cable. In order to eliminate this problem, disconnect the serial cable from AGP/COM1 Connector or SCP/Console Connector and reboot the board. If the error message states that the board is in state 2 or 3, then run the Motorola Board Level Diagnostics to verify the board is OK. If the BLD passes but this message appears during TPS reset then it is highly probable that the boards are not being reset by STIF(or PSE) connection. You can verify if the boards are not being reset by STIF(or PSE) connection during TPS reset either by looking at the LEDs on front of the boards or by opening MGD Terminal window.
