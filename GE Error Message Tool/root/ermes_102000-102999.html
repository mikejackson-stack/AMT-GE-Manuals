102001

ERROR: EM_SYSTOOLS_DDQUAD_LOW_SNR
DD Quadrature tool: Low SNR %s in combined image. Spec is %s
Extended Error:
This error is generated when the DD Quadrature Tool performs the combined image scan i.e with both transmit channels turned on. Low SNR in the combined image could be caused by cable swaps in the transmit chain. Please troubleshoot transmit chain using the steps in the Dual Drive Quadrature tool section of service document.

Extended Error:
This error message is generated when the latest pfile by time stamp does not match the pfile generated from the last scan. This could occur when an external pfile is placed under /usr/g/mrraw or the system date and time is changed. Please try clearing the P*.7 files in the /usr/g/mrraw directory.

102806

ERROR: EM_XG2_PSX_BOOT_FAILURE_PRI
Protected image startup of the XG2 (XPS-PC2 X axis) failed. Check EMO reset and perform a TPS reset. If this error occurs again, contact your service representative.
Extended Error:
The XPS-PC2 inside X axis XPS failed to boot into protected mode. * Verify that the X axis XPS and entire XG2 gradient subsystem is powered on. * Verify that emergency stop is not active. * Verify that the X axis dual-fiber cable is connected and properly seated into the IXG SFP transceiver module and X axis XPS. * Verify X axis dual fiber optic cable linkup status and that there are no communication faults pertaining to the SFP transceiver modules in X axis XPS or in corresponding communications port on IXG board. SFP modules can be swapped between units for troubleshooting. * Verify that both ends of the X axis XPS SFP Fiber cable are not damaged. * Check the X axis XPS Heartbeat LED from the front panel is blinking. * If Heartbeat LED not blinking then check condition of PDU 48V PS2 power supply. * Power down the XG2 subsystem and reseat cables to X axis XPS. If these steps do not resolve the problem, replace the X axis XPS and perform a TPS reset.
