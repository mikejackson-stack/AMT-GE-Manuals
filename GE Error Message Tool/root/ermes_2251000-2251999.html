2251038

ERROR: EM_GIP_CLOCK_STOP
Hardware Error - No Gradient Clock.\b\ A gradient clock stop occurred. The GIP stopped receiving the gradient clock from the STIF. Check the connection between STIF Board and GIP Board. Check the STIF, SRF, & GIP Boards. Run fiber optic diagnostics.

2251053

ERROR: EM_GIP_AMP_DATA_FRAMING
Hardware Error - Gradient data framing error.\b\ The GIP reported a data framing error. Check the fiber optic clock cable between the Systems Cabinet and GIP. Check the STIF, SRF, and GIP Boards. Run fiber optic diagnostics.
Extended Error:
Run fiberoptic diagnostics and gradient data link test.

2251060

ERROR: EM_GIP_X_MGRAM_OVRANGE_FAULT
X Axis Gradient Data Overrange Occurred.\b\ The GIP detected an error in the incoming High Speed Data from the STIF/SRF. Swap fiber optics at the Systems Cabinet. Run fiber optic diagnostics.
Extended Error:
If simultaneously reported framing error, then you should troubleshoot the framing error not this overrange error. If no framing error, this error could be caused by faulty data generation hardware on the STIF/SRF, or faulty data receive hardware on the GIP. If swapping data lines at the Systems Cabinet causes the fault to change axes then suspect the STIF/SRF. Run gradient data link diagnostic to confirm overrange error.

2251760

ERROR: EM_SGDT_DYN_VCNTRL_FLATLINE
GRADIENT DRIVER TESTS - Dynamic Test failed on %c Axis. VCNTRL data does not follow the input waveform. Possible causes: Fiber Optic cable between GIP and STIF, or the GIP Board.
Extended Error:
Check GRAM Tuning first, if it fails then suspect gradient hardware and troubleshoot after putting defaults in for short time constant eddy currents. Swap miniGRAM and GPM data cables at GIP reports problem on same axis, replace the GIP. If not then swap load cables at the back of miniGRAM's. If problem followed axes next isolate between miniGRAM and GPM (in main bd, PPBM and output shelf order). Then turn off power to gradient cabinet and disconnect GRAM output cables. Then check load resistance across terminals of the BRM (0.2 ohms); from terminal of load to ground (>1K ohms); and terminal of each axis to other axes (>1K ohms). Lastly GPM Power Supply. Note: use the disconnection and drive one axis at a time information in previous message
