ERROR: EM_SPU_PAC_REV_DETECT
The system detected a PAC II connected. Please check the PAC version connected to the system. Vector Gating will ONLY operate reliably with PAC III version.
Extended Error:
PAC revision is likely mismatch or PAC to SPU communication corrupted intermittently, causing wrong interpretation of PAC revision. Run PAC diagnostics.
Possible cause(s) (most to least probable):
  1. PAC
  2. TRF Board
  3. PSE Board
  4. Dual Fiber Cable
