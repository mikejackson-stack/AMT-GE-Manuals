2250108

ERROR: EM_GP_AMP_DATA_FRAMING
The GP is reporting a data framing error.
Extended Error:
Check fiber optic clock cable between Systems Cabinet and GP. Look for swapped fiber optic cables between clock and X/Y/Z data fibers. Run fiber optic diagnostics. Check SRF/TRF and STIF boards.

2250109

ERROR: EM_GP_CLOCK_STOP
The GP is reporting a Gradient Clock Stop. The GP stopped receiving a gradient clock signal from the systems cabinet.
Extended Error:
Check fiber optic clock cable between Systems Cabinet and GP. Run fiber optic diagnostics. Check SRF/TRF and STIF baords.

2250079

ERROR: EM_GP_X_SGA_OVRANGE_FAULT
X Axis Gradient Data Overrange Occurred.
Extended Error:
This condition is noncritical and should not affect image quality, unless accompanied by additional error messages. An occurrence of this type, unless accompanied by additional error messages, is not due to hardware fault. If this error occurs frequently, please submit a PQR describing the conditions under which the error occurs.
