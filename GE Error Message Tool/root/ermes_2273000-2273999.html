2273014

ERROR: EM_MCRV_MUX_SELECT_FAILURE
Coil Datapath Diagnostic Coil MUX select error: more than one MUX select signal asserted during walking ones test. Returned: 0x%lx
Extended Error:
In Coil Datapath Diagnostic MUX test, five MUX select lines will be tested (four Mux select lines for Port A), and only one MUX select line will be active at a given time. A case has occurred where more than one MUX select lines are active at one time. This error may indicate a bad MCRv tool, an issue with a control cable in the cable chain, or a problem with the RFCB. Try a different MCRv tool, check continuity on control cables in the cable chain, and replace the RFCB to troubleshoot.
Possible cause(s) (most to least probable):
  1. RF Hub Control Board
