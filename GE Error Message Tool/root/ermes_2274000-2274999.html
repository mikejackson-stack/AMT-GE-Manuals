2274000

ERROR: EM_RFHUB_BIAS_CHECK_BIAS_ON
Multicoil bias failure. Coil bias is still enabled from a previous check. Check that the inhibit cable is connected and try again.
Extended Error:
This can occur if the inhibit cable connection between the Driver Module and RF Hub is lost during a scan and quickly recovers. Check for other inhibit cable errors in the log.
Possible cause(s) (most to least probable):
  1. RF Hub Control Board
  2. Driver Module
