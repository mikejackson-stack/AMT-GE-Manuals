Required conditions
An A-Class SSA Soft Key license is needed to access Guided Install from SIGNA applications. The service key is not needed when Guided Install is launched as Root. Refer to Service licensing for information on how to install an SSA soft license.
The USB flash drive must be the correct size and have a supported file system format prior to initial usage. If the USB drive is not already formatted, see Formatting the USB flash drive.
Note GE HealthCare recommends that a USB flash drive should contain only Save Info data from one System ID.
Notice
Possible data loss
When a USB flash drive is formatted, all existing files on the drive are deleted.
Please choose from the following:
  • Formatting the USB flash drive
    Format the USB flash drive to save and restore system data.
  • Saving information
    Save the current configurations and files in order to restore them later, if needed.
  • Checking information
    Check the current configurations and files that have been saved.

    Restore the current configurations and files from the SaveInfo media.
