PGR Cabinet Component Locations

This document provides component locations for the PGR cabinet. The PGR cabinet includes the contents of the System, RF, and Gradient cabinets from previous systems.

Power Gradient RF (PGR) Cabinet

The following illustrations show the PGR cabinet with the doors closed and opened.

You can identify the version of the cabinet by the hardware installed in it.

Closed PGR Cabinet

PGR Cabinet Contents

This section provides a high level presentation of the contents of the PGR cabinet.

Coolant Leak Sensors

This section shows the location of the coolant leak sensors.

eXtreme Gradient Drivers (XGD/XG2) and Power Supplies

This section shows the location of the amplifiers and power supplies.

Note

The XGD driver hardware is used in cabinets with a Cronus chassis. XG2 driver hardware is used in cabinets without a Cronus chassis. The Cronus chassis is used only with XGD systems.

Power Distribution Unit (PDU)

This section shows the location of PDU components.

Note

There are two versions of the PDU. The location of the PDU is identical in all PGR cabinets.

1PDU used with XGA hardware 548 V power supply location
2PDU used with XG2 hardware (with CAM SYNC RESET button) 6Fan assembly location
3PDU used with XG2 hardware (without CAM SYNC RESET button) 7CAM SYNC RESET button
4Control board location (behind front voltage test points)
