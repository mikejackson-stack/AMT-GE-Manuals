Adjusting the patient table

About this task

This procedure aligns the table with the LPCA. Adjustments are made for left-right alignment and skew alignment of the table as shown in Table adjustments.

Procedure

  1. Gently engage the dock by stepping on docking pedal (shown below). Be careful not to force the dock engagement since adjustments have not been completed. Pushing the pedal too hard can shift positioning.
  2. Run the LPCA into the bore by manually lifting the LPCA latch and using the Operator Control Panel (OCP) buttons to advance the LPCA.
  3. Examine the left and right alignment of the table cradle to the LPCA rails (blue lines) on both the left and right hand side. This alignment should be even on both sides.
  4. Check the gap between the table end and front bridge by using the centering tool as shown. The specification is 31 +/- 6 mm. The maximum width is the full width of tool. The minimum width is the 25 mm line. If both sides are not even, the skew will need to be corrected.
  5. Push the button on the left side in back of the table cradle. Gently slide the cradle into the bore (being careful to not slam it) and note where it catches. This should determine necessary left-right alignment correction. The goal is for both sides to be even.
  6. From the end of the table, align your eye so that the line of the bore is straight (red box) and see if the table is parallel and in line (blue line). Determine how the alignment needs to be adjusted.
  7. Determine the necessary table alignment.
    1. If the left to right positioning is centered (so the table does not catch) and the skew is parallel, you do not need to continue with this procedure.
    2. Otherwise, remove the cradle and undock the table.
  8. Check that the feet on both sides of the floor mount are down all the way to the floor as shown. This is critical because the insert mounts can be affected when dock screws are loosened later in this procedure.
  9. Loosen the 14 mm bolt on the dock as shown.
  10. Adjust only the bolts for needed adjustments as explained below (for example, only left-right but not in-out). These bolts are 17 mm.
    1. For left-right adjustment, loosen the bolt at position 1 on both the left and right side of the mount.
    2. For tables currently skewed to the right (needing to adjust more to the left):
      1. Loosen only the bolts labeled 2 on the right-hand side of the mount. Then push in the dock, which will close the gap measured with the centering tool in Step 5 on the right hand side.

      2. Or, loosen only the bolts labeled 2 on the left-hand side of the mount. Then pull out the dock, which will widen the gap measured with the centering tool in Step 5 on the left hand side.

    3. For tables currently skewed to the left (needing to adjust more to the right)
      1. Loosen only the bolts labeled 2 on the left-hand side of the mount. Then push in the dock, which will close the gap measured with the centering tool in Step 5 on the left hand side.

      2. Loosen only the bolts labeled 2 on the right-hand side of the mount. Then pull out the dock, which will widen the gap measured with the centering tool in Step 5 on the right hand side.

  11. Gently move the dock as needed.
    1. Push the dock left or right as appropriate.
    2. For skew, push in or pull out the dock as described in Step 10.
  12. When adjustments are complete, fully tighten all bolts.
    Note Fully tighten all bolts. If they are not firmly tightened, everything will shift when the table is docked. Then adjustments will need to be repeated.
  13. Check the alignment according to the instructions in Step 3 through Step 7.
    1. Visually check the alignment. If the table is aligned correctly, both sides will look as if they need to rotate slightly but in opposite directions.
    2. Check the alignment by pushing the rear button and sliding the cradle into the bore. It should go smoothly without catching on either the left or right side. When correctly aligned, pushing the cradle to one side (left or right) should cause it to catch only on that side. When sliding the cradle up the center, it should not catch.
    3. If alignment needs further adjustment, repeat steps Step 3 through Step 13 until it meets specification.
  14. Adjust the table height. See Table Height Adjustment.
  15. Adjust the cradle to LPCA latch. See Cradle to LPCA Latch Adjustment.
  16. Do dual drive quadrature tool calibration. See Dual drive quadrature tool calibration.
