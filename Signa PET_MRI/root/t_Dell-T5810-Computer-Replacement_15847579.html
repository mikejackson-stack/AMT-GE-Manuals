Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

DANGER
Electrocution Hazard!
Hazardous voltage is present when GOC is energized.
Before beginning any work, perform lockout/tagout (LOTO). See Applying LOTO - Global Operator Cabinet (GOC) and Operator Workspace.

About this task

This procedure provides instruction to replace the host computer with a Dell T5810 computer.

Prepare Workstation for Host Computer Removal

Procedure

  1. Make sure the customer has archived all images to an external storage device such as a PACS or DVDs.
  2. Perform Save Info.
  3. Shut down the host computer.

    The GOC supports an optional UPS. Disconnect the UPS, if installed.

  4. Perform LOTO on the GOC/operator workspace. See Applying LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
Topic ID: id_SL12053592-1311832

Remove Host Computer from GOC

Procedure

  1. Remove the two screws that secure the left side panel of the GOC.
    Note The side panel has a short ground lead connecting it to the main chassis. When removing the side panel, do not strain this ground lead.
  2. Disconnect the short ground lead that connects the side panel to the GOC main chassis at the center of the lead.
  3. Remove the left side panel and put it in a safe place.
  4. Remove all the cables connected to the host computer.

    Confirm that the cables are properly labeled. Note their locations for reattachment.

    Note
    • For older GOCs which include an 8-port hub, route and connect Ethernet cable from GOC hub to this port.
    • For newer GOCs without a hub, this port is available for connecting to a service laptop, site network, or AW option. If connection to multiple Ethernet devices is required, a customer-supplied switch must be used.
  5. Remove the strap(s) from the computer.
  6. Lift the front of the computer, carefully slide the computer away from the brackets, and then lift to remove it. If necessary, loosen or remove the bracket(s).
  7. Do a disk wipe on all applicable hard drives.
    Use the following link to do a software secure wipe process: https://isi.cloud.ge-healthcare.net/index.php/support/tools/software-secure-wipe/

    Alternatively, use an applicable disk management tool.

Upgrading to Dell Host PC

About this task

The mounting brackets must be replaced for upgrading a different host PC to the Dell T5810.

  • Cables routed to the existing PC can be reused for connecting to the new PC.

  • Remove cable ties as necessary to make it easier to remove the cables that are routed into the PC.

Procedure

  1. To remove the right side cover, unfasten the two screws, carefully move the cover forward and then lift up and to the right. Disconnect the ground cable and remove the cover. Save cover for reinstallation at completion of the PC upgrade.
  2. For the left side cover: Remove the two screws and lift the cover up. Disconnect the ground cable and remove the cover.
  3. Remove and save the ground cable attached to the cover and save it for fastening to the new cover.
  4. Remove and save the ground cable that is connected between the cover and the front vent grill. Save the ground cable for connecting between the new cover and vent grill.
  5. Make sure all cables are identified and marked as you disconnect them from rear of the PC. Disconnect all cables.
  6. Remove the existing PC mounting brackets.
    1. Remove and discard the lower rear bracket.
    2. Remove and discard the rear side bracket. Save the the two M4 fasteners for attaching the new bracket.
    3. Remove and discard the side bracket. Save the two M4 fasteners for attaching the new bracket.
    4. Unfasten and save the strap for securing the new PC.
    5. Remove and discard the bottom PC mounting chassis. Save and reuse the four M5 fasteners for installing the new chassis.
  7. Remove the PC and return for recycling.
  8. Install the new PC mounting brackets.
    1. Install the new chassis with the four M5 fasteners previously removed.
    2. Install, but do not tighten, the rear side bracket with the two M4 fasteners previously removed.
    3. Install, but do not tighten, the side bracket with the two M4 fasteners previously removed.
    4. Install the strap in the chassis slots.
  9. Install the Dell T5810 PC as follows:
    1. Slide the Dell PC into place. Fasten it securely with the rear and side brackets and the strap.
    2. Install the HOST ID label as shown in the illustration below.
  10. Route and reconnect the existing cables to host PC. Refer to Dell T5810 Cable Configuration.
  11. Install the dust filter.
    1. Remove the Velcro strips from the back of dust filter and apply them to front of Dell PC as indicated.
    2. Press the dust filter into place. Make sure that the filter is tight to the curved corner.
  12. Prepare the new GOC cover.
    1. Install the cover to the grill ground cable removed from the old cover.
    2. Install the ground cable removed from the rear of the old cover.
    3. Make sure that the teeth side of the washers are in contact with the cover sheet metal.
    4. Apply the three Earth labels next to the ground connections as shown.
  13. Install the GOC covers.
  14. Find the battery replacement sticker on the GOC and replace it with a new battery replacement sticker.

    If the GOC does not have the sticker, complete a new sticker and put it on the GOC where it can be easily seen.

  15. Proceed to the Finalization section.
Topic ID: id_SL12053594-1311832

Install New Host Computer

Procedure

  1. Install the computer into the bracket(s), and tighten the bracket screws.
  2. Install and tighten the strap(s).
  3. Connect all cables to the computer.
  4. Remove the dust filter and Velcro strips from the old computer, and install them on the new computer. If the old filter or Velcro strips are not reusable, install a new set.
  5. Assemble the GOC using the steps above in reverse order.
Topic ID: id_14946788

Finalization

Procedure

  1. Remove LOTO from the GOC to return power. See Removing LOTO - Global Operator Cabinet (GOC) and Operator Workspace.
  2. Power up the operator console.

    Connect the optional UPS, if installed, and make sure power is restored.

    Note Verify that the host computer front panel power LED is on continuously.
  3. Load software and applications onto the operating system.

    See Loading Host System Software (Quick Start).

  4. Update the eLicense with the new host ID. See Software Option Installation with eLicense Generated Keys.
  5. Perform Check Scan to confirm the system and applications are working correctly.
  6. Confirm that all customer functions are operational (auto voice, filming, network, archive).
  7. Repackage the defective computer for return.
