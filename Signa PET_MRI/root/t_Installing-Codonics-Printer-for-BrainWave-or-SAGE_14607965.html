Installing Codonics Printer for BrainWave or SAGE

Prerequisites

Table 1. Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1Not Applicable15 minutesNot Applicable
Table 2. Required conditions
ConditionReferenceEffectivity

Applications Software is installed and configured.

--

Procedure

  1. If applications are up and running, restart the computer by clicking System Restart and OK.
  2. From login screen, login as root . Do not bring up Guided Install.
    Note

    It is possible that the customer changed the default password. If you cannot log in, contact the customer for the correct password.

  3. Right Mouse click and bring up Configure Printer.
  4. Click on the New option Configure Printers.
  5. Click on Forward. The screen shown below appears.
  6. Enter name of the Codonics Printer as GENNavprntr (case sensitive). For BrainWave, you must use the name of GENNavprntr. For SAGE option, the name is not important. To proceed, click Forward.
  7. Select Queue type as Networked UNIX (LPD) as shown below. To proceed, click Forward.
  8. Enter hostname or IP address for the Server, (example IP is 10.1.11.11).
  9. Enter queue name as 2.a-cvp, then select Forward.
  10. For Printer Model, select Postscript printer, as shown below. To proceed, click Forward.
  11. At the screen shown below, click Finish.
  12. At the screen shown below, click Yes to apply changes and print a test page. The printer test page should print successfully at this time.

Finalization

  1. To verify SAGE printing, open the SAGE option. Select File then Print. A GUI will appear. In the Printer text field, remove the default printer and enter the name of the printer that was used in Step 6.
