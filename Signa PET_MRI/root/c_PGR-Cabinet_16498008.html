Gradient FRUs

Note
  • Return non-functional FRU(s) normally as a bad part. Clearly label part(s) and indicate it is non-functional.
  • If functional FRUs are replaced, return them with a red label similarly to non-functional parts. This will make sure the parts are not accidentally scrapped. Clearly indicate in the debrief notes and on the red label that the parts are operational: "Replaced due to compatibility issues. Part is fully operational".

All gradient components (power supplies and amplifiers) must be of the same generation (XGD, XG2, or XG5). Refer to Gradient FRU compatibility guidance for more information.

XGA Amplifier FRU (XGD) (5184566-2) or XGA2 Amplifier FRU (XG2) (5330684-2 / 5330684-102) cannot co-exist with XGA5 Amplifier FRU (XG5) (6420005-2) or XPS5 Power Supply FRU (XG5) (6410005-2). The XGD3 SK PDU is compatible with the legacy gradient amplifier FRUs.
