Setting up the BIOS for the host computer for the Dell T5810/T5820

Restore the BIOS configuration on the host computer.

About this task

This procedure describes how to set up the BIOS on the host computer for the Dell T5810/ T5820.

Procedure

  1. Disconnect the cable that connects to port 1, slot 2.
  2. Disconnect the cable that connects to port 1, slot 4. Connect the cable to port 1, slot 2.
  3. Power on the host computer, and then start to set up the BIOS.
  4. During the host computer start-up, press F2 when the Dell circle shows on the screen.
  5. If a message indicates that the time of day is not set, press F2.
    1. Select General > Date/Time and set the correct time.
    2. Use the Tab key to move the cursor, and then use the left and right arrow keys to change the values.

    Result

    After you set the time and date, the BIOS settings remain open.
  6. Restore the customized BIOS settings. Change only the values specified below. (For Dell T5810) See Dell T5810 Customized BIOS settings. (For Dell T5820) See Dell T5820 Customized BIOS settings.

  8. Click Exit.

    Result

    The system restarts. The BIOS configuration is complete.

Finalization

  1. Power off the host computer.
  2. Disconnect the cable that was previously connected to port 1, slot 2.
  3. Reconnect the cables.
    • Reconnect the IRD cable to port 1, slot 2.
    • Reconnect the host LCD monitor cable to port 1, slot 4.
  4. Power on the host computer (see Starting up the host computer), and make sure that the LCD is on.
