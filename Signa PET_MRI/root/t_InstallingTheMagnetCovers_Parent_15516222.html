Installing the magnet covers

Prerequisites

Required conditions
Install the PET/MR insert, the front endbell, the rear endbell, and all of the bridges before installing any covers.
Detach the patient table from the scanner. Store the patient table where it will not interfere with this procedure.

About this task

The PET/MR covers must be installed in order. The covers attach to the PET/MR using hooks, tabs, slots, and screws. These devices ensure proper installation.

Installing the top covers

Procedure

  1. Lift the right top cover into position. Secure it with screws.
  2. Lift the left top cover into position. Secure it with screws.
  3. Lift the front top cover into position. Secure it with screws.
Topic ID: id_SL11928945-1192099

Installing the front and rear covers

About this task

Each of the rear covers attaches to the system using four screws in four tabs along the outside. Align the tabs with the screw holes, as described. Start with the top screws and go down the system. Each cover secures to the rear endbell with two screws.

Procedure

  1. Put the left rear cover so that the tabs align with the brackets on the system.
    1. Start with the top screws and go down. Put three of the cover tabs on the inside of the brackets.
    2. Put the third tab from the top on the outside of the bracket. A nut is attached to the rear of the hole on the bracket.
    3. Secure the cover to the endbell.
  2. Repeat Step 1 to install the right rear cover.
  3. Install the front left cover.
    Note The two Operator Control Panels (OCPs) each hide two front cover installation screws. Remove the OCPs, install the screws, and replace the OCPs. Reconnect the OCP cables. See Replacing the Operator Control Panel (OCP).
  4. Secure the left front cover to the system.
  5. Secure the right front cover to the system.
    Push the cables inside of the cover.
  6. Both covers have vertical light strips attached. Refer to cable map and connect Runs M3382 and M3383 to each light as marked. Connect these two cables to Run M3379, which has been routed from the magnet I/O panel.

Installing the laser light cover

Procedure

  1. Slide the laser light cover into position. Secure with a screw.
  2. Check the laser light alignment.
    1. If the laser light cover is blocking the light, tighten the screw that holds the front endbell in position.
    2. Recheck the laser light alignment.
Topic ID: id_SL15516389-1192099

Installing the bridge cover

Procedure

  1. Slide the bridge cover between the mount and the system. Keep the coax cable behind the right front cover.
  2. Secure the cover with screws.
Topic ID: id_SL15516394-1192099

Installing the side covers

Procedure

  1. Install the two right-side covers.
    1. Use a single screw to secure the covers where they join in the middle.
    2. Use the lower of the two holes.
  2. Install the right center side cover.

    Insert a screw into the hole above the screw that holds the right-side covers in position.

  3. Install the two left-side covers.
    1. Use a single screw to secure the covers where they join in the middle.
    2. Use the lower of the two holes.
  4. Install the left center side cover.
    1. Pull the patient alert squeeze bulb and peripheral gating cable through the opening before installing the cover.
    2. Insert a screw into the hole above the screw that holds the left-side covers in position.
Topic ID: id_SL11928973-1192099

Installing the In-Room Display (IRD) covers

Procedure

  1. Remove the four M6 x 16 Socket Head Screws (1000-M6C016-33) on the IRD bracket.
  2. Install the left- and right-hand IRD rear pivot covers (5395809 and 5395808) using the four M6 x 16 Socket Head Screws (1000-M6C016-33).
  3. (For 12.1 inch IRD) Install the left- and right-hand IRD front pivot covers (5396352 and 5396351) using the four M6 x 16 Socket Head Screws (1000-M6C016-33).
  4. (For 15.6 inch IRD) Install the left- and right-hand IRD top pivot covers (5396351-3 and 5396352-3) using the four M6 x 12 Socket Head Screws (1000-M6C012-31).
Topic ID: id_SL15516407-1192099

Installing the rear cable cover

Procedure

  1. Set the rear cable cover into position.
  2. Fasten it with two screws.
Topic ID: id_SL11928994-1192099

Installing the rear pedestal covers

Procedure

  1. Align the left and right side pedestal covers with the three hooks and secure them to the rear pedestal.
  2. Attach the side pedestal covers to the pedestal.
  3. Align the left and right rear pedestal covers with the three hooks and secure them to the rear pedestal.
  4. Fasten the rear pedestal covers with five screws washers, two at the top of each cover and one holding both covers at the lower back.
Topic ID: id_15231201

Finalization

Procedure

Install all remaining trim rings.
