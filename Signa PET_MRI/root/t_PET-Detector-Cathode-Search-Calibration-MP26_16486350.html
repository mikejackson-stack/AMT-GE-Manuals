Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

DANGER
Radiation exposure
The phantoms used for calibrating the SIGNA PET/MR system contain a radioactive substance.
Special training and compliance with facility guidelines are required to handle these phantoms.

Cathode search calibration tool startup

About this task

This section applies only to first-time installations. Continue to Annulus phantom setup if you are replacing a detector module (DMOD) on an existing system.

Procedure

  1. Launch the Common Service Desktop and click the PET radio button.
  2. Note

    If the default files already exist, launching Detector Calibration will not generate the default calibration files.

    Click the Calibration icon and select Detector Calibration to start this tool, which will create the default calibration files (if none currently exist).
Topic ID: id_SL16017222-1359149

Annulus phantom setup

Procedure

  1. Lower the patient table to detach the cradle from the LPCA.
  2. Insert the posts on the annulus phantom holder into the holes on the LPCA, and push the holder until it clicks into place.
  3. Position the annulus phantom into the phantom holder.
Topic ID: id_SL16017237-1359149

Cathode search calibration

Procedure

  1. In the Module Selection section, select the View Detail check box.
  2. Select the 0–27 detector in the Module Selection section.
  3. (For Software Version 30.1 and earlier) Click the Select Action drop-down, then click Reset CTC.
  4. (For Software Version 30.1 and earlier) When the pop-up "Do you want to reset CTC to default?" appears, select Yes.
  5. Click the Select Action drop-down, then click Cathode Search.
  6. When Cathode Search is selected, a dialog window will open with the following message: Do you want to run Cathode Search? Note: this may take up to 3 minutes.
  7. Select Yes, then select Start PET Calibration in the next dialog window that opens.
  8. When the Cathode Search is complete, a Reset of CTC will begin. Observe the status box to confirm that the Reset CTC has started and completed.
    Note A full calibration including additional iterations of CTC to convergence are required following the Cathode Search.
  9. After the Cathode Search is completed, the user can choose to click Start or Exit. It is recommended to select Start and proceed with the PET Detector Calibrations to apply new cathode values.

    If the user chooses to Exit, two notices will appear stating cathode values will not apply without running calibrations.
