Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

DANGER
Radiation exposure
Exposure to radiation will occur when the handling the annulus phantom.
Follow facility guidelines to handle the phantom.

About this task

Overview

Normalization correction normalizes PET data to account for differences in coincidence pair sensitivity among the scanner's line of response. 3D normalization is divided into two components:

  • Geometry component

  • Crystal sensitivity component

The curvature of the detector, gaps between detector units, and gamma ray penetration into crystals create spatial non-uniformity in the actual data sampling of any given view angle. This sampling non-uniformity must be modified to an evenly spaced grid for Fourier filtering. The system correction for individual detector element efficiencies (sensitivities) is obtained using a single, standard acquisition of a centered annulus phantom that spans the entire axial field of view (FOV).

The annulus phantom contains germanium-68 (Ge-68) and can be used for the acquisition with a specified GE HealthCare protocol, normalization scanning. PETNORM3D must be used for the Patient Name and Patient ID for a normalization calibration scan to work. The normalization scan service protocol has the default acquisition mode set to Stop on Counts. The 3D normalization calibration result is calculated directly from the acquired raw data file (RDF). No image reconstruction is required for a 3D normalization correction scan.

Calibration Setup

Procedure

  1. Notice
    The number in parentheses within an instruction corresponds to the numbered item in the referenced illustration.
    Click Tools, then Service Browser in the service desktop manager section to display the MR service desktop.
  2. Click the PET radio button, then the Calibration tab, and select 3D Normalization.
  3. Select Load 3D Geometry Cal.
  4. Type 1 to load the 3D Geo Cal from system default backup.
  5. Close the 3D GEO Cal screen.
  6. Select Normalization Correction Cal.
  7. Select Worklist Manager and set up the scan as directed.

Normalization Data Acquisition

Procedure

  1. Notice
    If there are any image problems, follow facility guidelines to contact Service Engineering. Do NOT continue until the Field Engineer resolves the Blank Scan problem.
    Start a new exam:
    1. Enter PETNORM3D for Patient ID.
    2. Enter PETNORM3D for Patient Name.
    3. Enter 111 for Weight.
    4. Enter 5’0” for Height.
    Note If this is a new installation without IIS passed, start a new exam and do the scan with the patient ID set to geservice. Use the Edit patient information procedure after the exam is complete to change the patient ID to PETNORM3D.
  2. On the Service Protocol Selector screen, select PET Normalization Calibration, then click Accept.
  3. Click Start Exam.
  4. Select First Level dB/dT and First Level SAR when prompted.
  5. Set a landmark at approximately 0.5 meters from the end of the cradle, and push Advance to Scan on the magnet. (This will move the LPCA to the service end of the magnet.)

    Use the Touch-n-Go strip to move the LPCA to the service end of the magnet.

  6. Detach the cradle from the LPCA. Move the cradle toward, but not to, the home position.
  7. From the rear (bridge side) of the magnet, unplug and remove the CMA coil in order to access the rails.
  8. Remove the PET gap filler from inside the bore.
  9. Slide the right-hand lip of the phantom holder assembly inside the rails.
  10. Unscrew the left-hand side of the phantom holder assembly locking screws to adjust the left-hand side lip. Slide the lip into the phantom holder assembly so that the assembly lays flat in the bed.
  11. Slide lip out inside the left-hand side rails and tighten the locking screws.
  12. Adjust the slider to select the annulus phantom.
  13. Mount the annulus phantom to the phantom holder assembly.
  14. Slide the phantom holder assembly into the bore over the center of the gap created by the removal of the CMA coil and gap filler until it stops. The assembly will be stopped and will catch on the anti-tip rails at the appropriate location to properly center the phantom in the bore. Make sure the plate is positioned so the marking on the plate aligns with the bore mark. Phantom setup is now complete.
  15. On the console, navigate to the normalization scan screen and perform the instructions listed under Protocol Notes.
  16. Click Scan Time, and change, if necessary. Click Save Rx, then Scan.
  17. After the scan successfully completes, open the service browser and click the PET radio button.
  18. Under Calibration Manager, select Cal Manager.
  19. Determine if the 3D normalization completed in the Cal Manager list (3D normalization = true).

    If the 3D normalization value is false, confirm that the phantom is positioned correctly in the bore. If the phantom is correctly positioned, then repeat the normalization correction calibration.

  20. Close the exam session. Select End Exam from the drop-down list in the upper right corner of the screen.

System Restoration

About this task

Perform the system restoration if you are not performing the PET 3D well-counter correction calibration.

Procedure

  1. Retract the platform with the phantom.
    1. Remove the annulus phantom from the phantom holder assembly and lock it in the safe.
    2. Remove the mounting platform from the rails.
  2. Insert the gap filler and the CMA coil between the front and middle bridges.
  3. Return the LPCA to the home position.
  4. Confirm that the system has been restored to normal operating mode.

Finalization

Finalization

Continue to PET 3D well-counter correction calibration. See Calibration Sequence for PET/MR for the complete PET calibrations workflow.
