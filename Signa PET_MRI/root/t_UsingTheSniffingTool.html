Using the sniffing tool

Use the sniffing tool to measure the RF shield's effectiveness on a single frequency for leak sniffing purposes.

Prerequisites

Safety
Notice
Possible equipment damage
Never turn on the transmitter (Tx) without an antenna connected.
Notice
Possible equipment damage
Failure to connect the attenuators will result in receiver (Rx) equipment damage.
If using the dipoles or rod antennas, a 10 dB attenuator must be connected.

About this task

This tool lets you measure the RF shield's effectiveness on a single frequency for leak sniffing purposes.

Note Training is required before using the coherent noise tool kit for advanced troubleshooting. The training can be On-the-Job (OJT) training with another engineer that is familiar with the tool, or taking the MR Advanced Service class at HCI.

Procedure

  1. Put the Rx and Tx on the two tripods found in the tool kit.
  2. Connect either the dipole or biconical antenna onto the Tx.
  3. Connect the small loop antenna on the Rx.
  4. Adjust the height of each tripod to approximately 120 cm (47.24 inches).
  5. Align the tripods approximately 2m (6.56 ft) apart.
  6. Connect the small fiber-optic cables to the fiber-optic adapters. Approximately 1.5 cm (0.59 inches) should be seated into the adapters. Make sure to match black to black and white to white.
  7. Attach the fiber-optic adapters to the Rx and Tx units.
    Note Make sure that the fiber-optic cables are securely attached to the fiber-optic adapters. The cables should not come out of the adapters if lightly pulled.
  8. Press the power button on the Rx and Tx. The devices will turn on.
    Note Only press the power button for 1 second. Pressing the power button for more than 2 seconds will cause a system reboot. This is valid for both the Rx and Tx.
  9. See Zeroing the coherent noise tool kit.
  10. From the Receivers Power On menu, select Std, then select Cal.
  11. Based on system type, select the applicable preloaded frequencies from the list below. Refer to Frequencies for frequency selection.
    • L1
    • L2
    • L3

  12. Select Cal, then Snif.
  13. Using the Next and Prev options, select one of the three frequencies.
    Note The one with the least attenuation should be used for sniffing.
  14. Select Meas to start measurement.
  15. When there is a dB reading on the screen, the fiber-optic cables can be disconnected and the tool can be used for sniffing.
    Note There is approximately 10 minutes of run time before the tool times out and Step 8 through Step 14 will need to be done again.
    Note The Tx will still need to be aligned and approximately 2m (6.56 ft) apart from the Rx.

Finalization

  1. Restore the system back to normal. If equipment (injectors, monitors, anesthesia carts, and so on) was removed from the scan room put it back in its original locations.

  2. Power ON the system and do a check scan.
