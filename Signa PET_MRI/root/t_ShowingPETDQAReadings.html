Showing PET DQA readings

Show PET DQA readings.

About this task

The system stores a copy of each PET DQA you run, until you remove them from the system. Follow the procedure in this section to show the older DQA Readings.

Procedure

  1. From the header area of the screen, click the Tools arrow and select PET Daily QA.
  2. From the PET DQA screen, click Select Prior to show the prior DQA readings currently on the system.
  3. Select a prior DQA reading.
  4. Click Select to show the Summary information of the selected DQA reading.
  5. Click the View Summary arrow > View Data to show the related graphs and tables.
  6. Click Exit.
    Table 1. DQA menu items
    Menu itemDescription
    View Current Reading Shows the most recently acquired DQA.
    View Baseline Reading Shows the baseline of the currently displayed DQA. This function does not provide a summary.
    View Prior Reading Shows the selected prior DQA reading.
    Ratio Current / Baseline Shows a smoothed comparison of the current DQA reading to the baseline DQA reading. This function does not provide a summary.
    Ratio Prior / Baseline Shows a smoothed comparison of a prior DQA reading to the baseline DQA reading. This function does not provide a summary.
    Ratio Current / Prior Shows a smoothed comparison of the current DQA reading to the selected prior DQA reading. This function does not provide a summary.
    Note

    Source Annulus Phantom replacement.

    The SIGNA PET/MR System uses a germanium-68 (Ge-68) source annulus phantom during calibration. The Ge-68 has a decay half-life of about nine months. Because the recommended source phantom activity range corresponds to three half-lives, you should arrange to replace the source phantom every 27 months. The DQA View Data screen tracks the source phantom activity and shows the number of days remaining until recommended replacement.

    Contact your GE representative to order a new source phantom. The warranty contract does not include the cost of this (consumable) replacement phantom.
