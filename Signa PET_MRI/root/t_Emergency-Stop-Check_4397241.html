Checking the Emergency Stop function

Make sure the Emergency Stop function is operational.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization

About this task

Overview

This document provides the procedure for doing a check of the EMERGENCY STOP function of the Power Distribution Unit (PDU) for the Gradient subsystem, and RF subsystem.
Note To do a check of the EMERGENCY OFF function of the power for the entire system, see Checking the Emergency Off function.
The PDU EMERGENCY STOP buttons are located on the Operator Workspace Keyboard and on the Magnet Enclosure front cover (two buttons, left and right). A SYSTEM OFF button is located on the System Main Disconnect Panel.
Note The other EMERGENCY OFF buttons are located by the customer.
Topic ID: id_SL1780961-1046704

Emergency stop

Procedure

  1. Push one of the EMERGENCY STOP buttons shown in the following illustration.
  2. Make sure the power to the Gradient subsystem and RF subsystem is shut off.
    1. Gradient verification: Look at the XPS (Gradient Power Supply) Signal Board and make sure that all four of the LEDs are off (see XPS LEDs).
    2. RF Amplifier verification: Look at the bank on the front of the RF Amp and make sure that the AC Power LED is off. (See AC power LED).
      Note Activation of the Emergency Stop button for the PGR cabinet will remove the high voltage from the gradient power supply and the RF Amplifier. However, be aware that the PDU voltage will stay enabled in the PGR cabinet after the Emergency Stop button is pressed.
  3. On the PDU, press the EMO Reset button to return power to all affected cabinets. See EMO reset and input test points for PGR PDU.
    Note When you press the EMO Reset button, you should hear the contactor engage. This is another indication that the E-Stop was pressed and is active.
  4. Repeat the steps in this section for each of the other EMERGENCY STOP buttons.
Topic ID: id_15204528

Finalization

Finalization

Run the Doing a check scan procedure to make sure the system is functioning normally.
