Powering Off Host and GOCAA

Topic ID: id_SL4689905-1151904

Shut Down Software

Procedure

  1. Shut down any system applications that are still running.
  2. Click Tools.
  3. On the Service Desktop, click System Shutdown.
  4. Confirm shutdown by clicking OK.

    Wait for the system to indicate on the monitor that it is safe to power off the computer before proceeding. It usually takes about 90 seconds for this message to display. Monitor the screen and wait until the light turns yellow.

Topic ID: id_SL4689910-1151904

Remove Power to Operator Workstation

Procedure

  1. Verify that the power indicator on the Operator Workstation is off.
  2. The host circuit breaker is located on the front of the PDU. Set the host circuit breaker to the DOWN position to disconnect power.
  3. Apply LOTO (see LOTO for the PGR PDU/Gradient Subsystem).
Topic ID: id_SL4689915-1151904

Removing GOC Covers and AC Power Cord

Procedure

  1. Note

    Take extra precaution if the site has installed the optional GOC UPS accessory.

    Remove the screws that secure the left and right side panels of the GOC.
  2. Disconnect the ground leads from both side panels.
  3. Remove both GOC side panels and set aside.
  4. Remove the strain relief plate from the input AC power cable.
  5. Unplug the AC input cable from the GOC power distribution supply inlet connector.
Topic ID: id_SL4689921-1151904

Replacing Fiber Optic Converter Box

About this task

Refer to Fiber Optic Converter Box Connections and Power for the box connector assignments and Mounting Location of Fiber Optic Converter Box in GOC for box/cable harness location in GOC.

Topic ID: id_SL4689922-1151904

Remove Converter Box

Procedure

  1. Disconnect run E3019 from J4 and the sensor cable from J5.
  2. Disconnect the USB cable from J1.
  3. Disconnect the fiber optic cable run P2026 from J3.
  4. Disconnect the DVI-D cable from J2.
  5. Disconnect the AC power cord from the fiber optic converter box.
  6. Remove the fiber optic converter box by loosening the four M5 screws using the Phillips driver, and then remove the box.
Topic ID: id_SL4689929-1151904

Replace Converter Box

Procedure

  1. With the four M5 screws loose in their mounting holes, install the fiber optic converter box, and then secure the four M5 mounting screws using the Phillips driver.
  2. Connect the AC power cord to the fiber optic converter box and set the power switch to ON. The device will not power up until the operator console power is turned back on at the end of this procedure.
  3. Connect the DVI-D cable to J2.
  4. Connect the fiber optic cable run P2026 to J3.
  5. Connect the USB cable to J1.
  6. Connect run E3019 to J4 and the sensor cable to J5.
Topic ID: id_SL4689936-1151904

Installing AC Power Cord and GOC Covers

Topic ID: id_SL4689937-1151904

Install AC Power Cord

Procedure

  1. Mate the AC input cable to the inlet connector on GOC power distribution supply.
  2. Install the strain relief plate (see Strain Relief Plate) and secure it to hold the input AC power cable in place
Topic ID: id_SL4689940-1151904

Install GOC Side Cover

Procedure

  1. Connect the ground wire to the right side cover (see Right Side Panel Ground Lead).
  2. Connect the ground wire to the left side cover (see Left Side Panel Ground Lead).
  3. Secure the right side cover to the GOC (see GOC Right Panel).
  4. Secure the left side cover to the GOC (see GOC Left Panel).
Topic ID: id_15221980

Finalization

Procedure

  1. Remove LOTO from the PGR/PDU host breaker and set the host breaker on the PDU to ON.
  2. Reboot the host computer.
  3. On the Common Service Desktop, select Diagnostics > Hardware > Magnet Room > In Room Display.
  4. Run the In Room Display diagnostic.
