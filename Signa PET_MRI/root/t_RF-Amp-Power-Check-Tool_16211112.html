RF Amplifier power check

This tool provides a quick check for gross deviations in RF power levels (inputs and outputs), Power Supply Unit (PSU) voltages, and Field Effect Transistor (FET) junction temperatures for the RF amplifier.

Required conditions
This test requires appropriate sphere and loader assembly landmarked at the proper location on cradle.
When using the body coil as the load, both the body TLT phantom and loader and the head TLT phantom and loader must be in position at the proper location on the cradle, and the landmark applied at the proper location on the phantom, to prevent possible equipment damage to the GEM Posterior Array (PA) coil.
Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

About this task

This tool provides a quick check for gross deviations in RF power levels (inputs and outputs), Power Supply Unit (PSU) voltages, and Field Effect Transistor (FET) junction temperatures for the RF amplifier. Testing can be done using an appropriately loaded body or head coil, or using the fan-cooled dummy load.

This tool is not a substitute for the RF power measurement kit.

This procedure applies to both single and dual drive RF amplifiers.

Topic ID: id_SL2119600-1062914

Setting up phantoms

Procedure

  1. (For dual drive amplifiers) Station the appropriate phantom.
    Note With a dual drive amplifier, you can test Body mode in three modes: Channel 1 only, Channel 2 only, or both Channel 1 and Channel 2.
    Note If testing Body mode, make sure the phantoms are in position as noted to prevent damage to the PA coil.
    1. If testing Body, Body Ch-1, or Body Ch-2 RF Chain, set the 3.0T body sphere, head loader and sphere, and body loader assembly in the center of the patient cradle.

      This will center the phantoms over the GEM PA coil, if it is present.

      Landmark at the center of both phantoms together by finding the midpoint between the top end of the head loader and the bottom end of the body loader.

    2. If testing the head RF chain on a system with the TR head coil, set the 3.0T head sphere and loader phantom assembly on the head load positioner inside the head coil, and landmark on the crosshairs on the phantom.
      Note Starting with the release of software version 31.0, the TR head coil, head TLT loader, and head TLT phantom are no longer included with the system. The Local Tx chain can be tested using another available TR coil (18ch T/R knee, 16ch T/R hand wrist coil).
    3. If testing the local RF chain on a system without the TR head coil, set the phantom inside the local TR coil (18ch T/R knee, 16ch T/R hand wrist coil) by referring to the MCQA procedure, and landmark the phantom.
    Note 3.0T phantoms have a pink solution and 1.5T phantoms have a green solution.
  2. This test can be run using two different configurations:
    1. The recommended initial configuration is with the phantoms positioned at isocenter with no other changes to the system. See Running RF Amplifier power check tool to execute in this configuration.
    2. The second configuration isolates the RF amplifier from the rest of the external transmit chain and coils by executing the test with the dummy load attached to the RF amplifier head or body RF outputs. This configuration requires a dummy load, and is used when it is necessary to isolate the RF amplifier from possibly faulty head or body RF transmit loads. See Isolating RF Amplifier to execute in this configuration.
Topic ID: id_SL11951002-1062914

Isolating RF Amplifier

About this task

This section is only for the second configuration (which isolates the RF Amplifier from the rest of the external transmit chain and coils, and requires a dummy load). For the standard configuration, skip to Running RF Amplifier power check tool.

Procedure

  1. Make sure that the phantom is landmarked as described in Setting up phantoms.
  2. Get a DVM and configure to measure resistance.
  3. Measure the resistance between the center pin and the shield of the RF connector on the fan-cooled dummy load from the RF power measurement kit, and make sure it measures 50Ω ± 5Ω. Only use loads that measure within the limits.
  4. Disable RF input to the RF Amplifier by setting the RF ENB switch on the DTX1 exciter module, located in the Penetration (PEN) cabinet, to the DISABLE (down) position.
  5. (For dual drive amplifiers) If testing body port 1, connect the dummy lead as shown, and remove the input cable J21 from the RF amplifier.
  6. (For dual drive amplifiers) If testing body port 2, connect the dummy lead as shown, and remove the input cable J14 from the RF amplifier.
    Note To prevent damage to the combiner, remove the receive cable to the Pre-Amp Combiner (input J9 and J10).
    Note To prevent damage to DTRSW, remove the cable from the body coil to DTRSW at DTRSW from the channel connected to the dummy load.
  7. (For dual drive amplifiers) If testing the head port, connect the dummy lead as shown.
    Note Connect the N to 7/16 inch adapter between J3 and the dummy load cable as shown above.
  8. Disable TR fault monitoring by setting the SW2 switch on the front of the Driver Module to the TR DISABLE (down) position.
  9. Enable RF input to the RF Amplifier by setting the RF ENB switch to the Enable (up) position.
  10. Continue with Running RF Amplifier power check tool.

Running RF Amplifier power check tool

Procedure

  1. Insert the service key into the computer.
  2. From the Common Service Desktop (CSD), select Utilities > RF Amp Power Check.
  3. Select the desired test to run. The recommended default is shown below.
    TestDescription of test
    Low Duty Cycle TestDetermines if the Amplifier is functioning properly under low stress conditions.
    Stress Power TestUsing high average power, simulates aggressive protocol issues for certain areas.
    Automatic ProceduresRuns both low-duty cycle and stress power tests.
  4. (For dual drive amplifiers) In the normal configuration, where the phantom and coil are the connected RF load, select Head, Body Ch-1 Only, or Body Ch-2 Only. Selections available for the RF Chain field are described below. If necessary, select Body last.
    Table 1. RF chain testing parameters
    RF chain selection What is tested Recommendation
    Body Ch-1 OnlyChannel 1 is outputting RF.Run first for dual drive.
    Body Ch-2 OnlyChannel 2 is outputting RF.Run second for dual drive.
    BodyBoth channel 1 and channel 2 are outputting RF.Run only if needed or if dual drive not supported.
    HeadHead is outputting RF. Run for Head.
  5. Manually set the TG level down to 140 to prevent RF Amplifier faults during the initial test. TG can be increased to 200 for later iterations if desired.
  6. Close the magnet room door.
  7. Click START to begin the test.

    The following message shows. Click OK.

  8. To make sure the coil and phantom that were selected are properly stationed and landmarked, the dialog box shown below opens. Click Yes to continue with the test.
    Note The test is completed silently without noise from gradients. The Stop Scan button on the Scan Control Interface Module (SCIM) illuminates for about 180 seconds during the portion of the test when the RF pulses.

Viewing test results

Procedure

  1. To see the results of the latest test, click View Report. Scroll to the bottom of the file to view the latest results.
  2. To see the results of earlier tests, you can use the more command to show the test results.
    1. Open a C Shell or a terminal window.
      Note The Shell window can only be launched when the EA3 user is included in the authorized EA3 group. Users not in this EA3 group will not have access to launch the Shell window. If you are not logged on as the proper logon user, log off and then log back on as the correct EA3 user with the authorized permissions.
    2. Type cd /usr/g/service/cclass/rfamp_power_check/ and then press Enter.
    3. Type ls *.results -ltr and then press Enter.

      This lists all of the results files. The names of these files contain the dates when the tests were done.

    4. Type more filename.results, where filename is the date of the results file you want to open.
    5. Press Enter.
  3. The final test results are open.
    Note Repeated iterations of the tool will append the results to the end of the file created for the day on which the tool is run.
    • Press the space bar to make sure the most recent data is being viewed. Data for recent iterations is located at the end of the file.
    • View the date and time printed in the header that precedes the data to make sure the most recently collected data is showing.
  4. All zeros reported for head or body results [Voltage Standing Wave Ratio (VSWR) will never be zero] means that either the port was not selected from the RF Chain menu or scanning prematurely ended during the test due to occurrence of a system fault or other scan setup problem. Check the test setup and landmarking and check the GE HealthCare message log for system faults. See Test Execution Hints for tips on successfully completing the test.

    Test execution hints:
    • The power readings are most accurate at a TG setting of 200. Because the power readings are used to estimate the S11 and VSWR of the attached load, these values also are most accurate at a TG setting of 200.
    • The default setting for MR750w is TG=180. For body scans, make sure that the body TLT loader and sphere are positioned at the center of the cradle, and the landmark is applied at the correct location, before increasing TG to 200.
    • The ability to test at other TG levels is provided for assistance in troubleshooting issues that seem to correlate to peak output levels.
    • Most consistent results are obtained when the test is run with an ideal RF load connected (properly functioning and properly loaded head or body coil, or RF dummy load measuring 50Ω).
    • The test results from multiple tool passes are appended in a single file for the day to allow reviewing of results under different test conditions.
    • UPM1 and 2 errors indicating head forward and reflected power levels of 2W or less may be logged during body stress power test. UPM1 and 2 errors do not interrupt test execution and can be ignored.
    • Watch the Stop Scan button after starting the test to make sure that it backlights after approximately 40 seconds. If the button fails to backlight, the RF Amplifier did not pulse due to internal fault or power loss.
    • The Stop Scan button should remain backlit for approximately 180 seconds for each test selected. If the backlight stops too soon, check the error log, because the Amplifier has likely faulted. Wait for the test to end, reduce TG by 5 to 30 counts, and begin the test again. Repeat TG reductions as necessary until the test completes.
    • Some failures only happen at higher power levels. Try running the test with TG levels below the point where the Amplifier faults.
    • At a TG setting of 170, peak output power should be half of the output seen when measured at a TG setting of 200.

Finalization

Procedure

  1. Click EXIT to quit the tool.
  2. Remove all coils and phantoms from the patient table.
  3. Remove the dummy load if connected.
    1. Disable the RF input to the Amplifier by setting the RF ENB switch to the DISABLE (down) position.
    2. Remove the dummy load and reattach the transmit line to the RF Amplifier. Make sure that the input cables J14 and J21 are connected to the RF Amplifier.
    3. Enable TR and DD fault monitoring on the Driver Module. (See Driver Module switches.)
    4. Set the RF ENB switch to the ENABLE (up) position.
  4. Do either a Head or Body scan to confirm system functionality.
