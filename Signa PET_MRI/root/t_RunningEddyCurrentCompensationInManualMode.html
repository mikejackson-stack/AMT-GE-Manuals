Running eddy current compensation in Manual mode

Manual mode lets you iterate through the process and decide when to stop.

Procedure

  1. Select the Manual Mode tab.
  2. Select all Medium and Long components and click Scan.
  3. If the Prompt to Accept mode is active, a graph of the results shows after the scan is completed.
    • If a good fit is shown (fit line aligned with data line), click Accept. The calibration values are saved to disk and used in the next scan. Repeat this process by setting desired terms for the next scan and select Scan.
    • If a bad fit is shown, click Cancel.
    Note This leaves the last accepted values in the calibration files. Do not expect any improvement on future scans when the fit does not match the data, even if the calibration parameters are accepted.
  4. The last iteration for any component must be checked only. Do not accept the fit parameters. You will not be allowed to exit immediately after updating the calibration parameters.
  5. Clear Medium and Long components and then select all Short components. Select Never Accept mode and click Scan.
  6. If all Short components meet specification, continue to Finalizing eddy current compensation. Otherwise, continue to the next step.
  7. Select the Zero Out tab.
    1. Select all subcomponents of the Short component(s) that failed in the previous step.

      For example, if Short:ZZ:B0 failed, then select Short:ZZ:Linear and Short:ZZ:B0.

    2. Click Zero Out Cal Values.
  8. Select the Manual Mode tab.
    1. Select the corresponding Short component(s), and then select Always Accept mode.
    2. Click Scan.
  9. After scanning is complete, change to Never Accept mode and click Scan again.
  10. After scanning is complete, select the corresponding Medium component(s) and with Never Accept selected, click Scan.

    For example, if Short was scanned for the Z-axis in the previous step, select Medium for the Z-axis.

    Note At this point, it is expected that all components (with the possible exception of oscillatory components) have a passing result. Continue to Finalizing eddy current compensation.
