System Error - User Alert

Overview

Software version 30.2 introduced a feature to increase visibility of error messages that require customer action. A dialog window will display that contains the error message along with an action that needs to be completed to resolve the error. These actions will resolve the error messages and avoid downtime or the creation of a service record.

An SSA Class A2 SW license is required to enable this self-healing user alert feature. If the requisite license is not installed and the user attempts to display the error dialog window, a dialog window will instead show No license was found for this service feature, or the license has expired. Contact your sales or service person for information on available service license packages.

Error dialog window

The System Error - User Alert dialog window consists of the following details:

  • The error message that can be corrected with user action.
  • The action to be taken by the user.
  • A pictorial representation of the issue.
  • An Acknowledge button that acts to postpone user action.
  • An Action Complete button that indicates the action has been taken and clears the message.

The dialog window will list all error messages that can be corrected by user action. When either button is clicked for an error, that error will be removed from the list. Clicking the X to close the dialog window will also acknowledge all error messages in the list.

The criticality of the error message will affect the behavior of the dialog window. For error messages that are critical to proceeding with the exam, the window will display immediately. Error messages that do not require immediate action will show once per day after the first end exam. The dialog window can also be manually opened by the user by clicking on System Error – User Alert in the Tools menu.

User action

Each error listed in the System Error – User Alert dialog window will show a text description and a picture of the action recommended or required to resolve the error. The user can click Acknowledge to postpone action until a later time or do the action and click Action Complete.
