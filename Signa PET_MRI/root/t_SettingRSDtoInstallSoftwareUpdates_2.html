Setting Remote Software Download (RSD) to install software updates

Configure Remote Software Download (RSD) preferences to set system update install options.

About this task

Note This procedure does not apply to software version 30.

Procedure

  1. Log on as root to set RSD options and grant user access as needed.
    Note To log on as root, see Logging on as root.
  2. Click Preferences on the RSD user interface to set system update install options and user access for update installation.

    Choose one of the following options:

    • Install updates automatically on restart: Installation starts automatically (for all users) after 30 seconds, unless the user skips or declines the update.
    • Allow all users to install updates: Lets all users acknowledge and install a new service pack. The user can choose to install, skip, or decline the update.
    • Only allow authorized users to install updates: This is the default preference. It lets only root users and EA3 authorized users (role-based authorization) install a new service pack. The Go to User Administration Tool link launches the EA3 user interface where you can change authorization for individual EA3 users. For more information, see Configuring user access for RSD.
  3. Click Save & Close to close Preferences.
