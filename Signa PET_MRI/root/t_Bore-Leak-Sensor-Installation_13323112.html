Required conditions

Make sure PET/MR Insert is installed in the magnet bore. Refer to ‘PET/MR Insert Installation’ found under Replacements > PET-MR > System.

About this task

The bore leak sensor detects the presence of moisture inside the bore, and is located on the rear pedestal.
Topic ID: id_SL12405013-1192094

Preliminary tasks

Procedure

  1. Attach the bore leak sensor to the leak sensor detector box on the rear pedestal.
  2. Test the bore leak sensor:
    1. Make sure the sensor block changes to green when it receives power.
    2. Wet the edge of a paper towel and touch the sensor on the opposite side of the block.
    3. Make sure the sensor light changes to red. (It changes to green when the paper towel is removed.)
  3. Press EMO RESET on the PDU to restore power to the PET insert.
Topic ID: id_SL12405016-1192094

Installing the leak sensor

Procedure

  1. Remove the fiber optic cable from the Number 3 break-out box.
    Notice: Adjoining fiber-optic cables may need to be removed for ease of disassembly/reassembly. Label each cable as it is removed.
  2. Using a flashlight to see, slide the bore leak sensor assembly along and past one of the outer break-out boxes; center the sensor below the Number 3 break-out box.
  3. Feed the fiber optic cable through the opening in the leak detection sensor assembly, and reattach the cable to the Number 3 break-out box; reattach any other cables removed earlier.
  4. Use an 8 mm wrench to attach the leak sensor assembly to the PET/MR Insert with an 8 mm bolt.
  5. Install the second bore leak sensor to the cut-out on the carbon mount, using the hardware included with the leak sensor rear mount assembly.
