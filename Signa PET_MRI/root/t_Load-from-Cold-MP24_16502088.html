About this task

Overview

IMPORTANT: Make sure that the latest Service Pack is loaded. See the latest revision of MR Service Pack Software Matrix, DOC1667089, available from the online documentation library.

If more information is needed for how to load Service Packs, refer to Installing Software Updates.

This procedure details a Load from Cold (LFC) software installation on:

  • Newly installed SIGNA PET/MR Systems,

  • Systems upgraded from a Discovery MR750w to a SIGNA PET/MR System,

  • Whenever LFC needs to be performed on a PET/MR System after repairs or maintenance.

Topic ID: id_SL12011807-1192090

For existing PET/MR systems

Procedure

  1. Run install_in_spec to verify calibration status.
  2. Perform MR and PET Hello-Goodbye Scan.
  3. Open a C-shell command window on the host computer and type: # ls –alR /usr/PET/backup/.

    • Verify all files have owner:group set to sdc:informix.

    • If not sdc:informix, run this command as root: #chown –R sdc:informix /usr/PET/backup/

  4. Perform a SaveInfo to save the host settings using: Guided Install > Utilities > Save/Restore > Save Information & Save GI.
    Note

    The PARC must be up and SRM Green to save PET Calibration Files. PET Calibration files will not be saved if PARC is down.

Topic ID: id_SL15992831-1192090

Loading Operating System (OS) software

Procedure

  1. Insert the General Electric (GE) MR OS DVD into the drive on the Host PC and reboot the PC.
  2. Type GEHCMR when prompted; installation takes approximately 20 minutes. (Do not remove the OS DVD after installation until prompted in this procedure.)
  3. After OS installation completes, type root at the login prompt and operator for the Password.
  4. Notice
    The next step is necessary until a new version of the operating software is released. The System Readiness Monitor (SRM) uses the perl-Date-Manip RPM. Install perl-Date-Manip-5.54-2.46.x86_64.rpm before installing MR Applications Software.
    With the GE MR OS DVD still in the drive, right-click on the Linux desktop, open a C-shell xterm and type the following commands with the spaces indicated:

    • mount /mnt/cdrom

    • rpm –ivh /mnt/cdrom/suse/x86_64/perl-Date-Manip-5.54-2.46.x86_64.rpm

    • eject

  5. Remove the GEHCMR OS DVD from the drive.
Topic ID: id_SL11949194-1192090

Loading MR Applications software

Procedure

  1. Insert the MrpApps DVD and click OK on the Alert message.
  2. When the HDD preparation complete window displays, click OK and installation continues.
    Note The xmessage below displays and remains in the upper left portion of the screen.
  3. Notice
    The language setting described below is only for the Guided Install tool, not the Application software interface or the keyboard language.
    When the Select your Locale screen displays, select the appropriate language for the locale, choose Set as default, and click OK.
  4. When Guided Install automatically launches, click OK on the message pop-up, and the MrpApps disk will eject.
  5. When the message Select the media you want to load GI config from? displays, proceed to either Step a or b, depending on the applicable situation.
    1. (For an existing PET/MR system) Proceed as follows:

      1. Insert the SaveInfo disk created earlier, and click OK. (SaveInfo configuration will take less than one minute.)

      2. When the message Loading configuration from media Done displays at the bottom of the Guided Install screen, press the disk eject button on the computer to remove the SaveInfo disk, and close the xmessage shown in Guided install configuration in progress message.

    2. (For a new PET/MR installation or an upgrade from an MR750w system) Proceed to System and hardware configuration.
    3. Select Verification (last entry in the left navigation pane) on the Guided Install screen, then click the Install Software button.

      1. Make sure that the Status of all changed values indicates Pass.

      2. Correct any values indicated as Fail.

        Note

        Do not use network 192.x.x.x for the Host IP address. Doing so will prevent the PET from working.

  6. Click Confirm in the message window that begins with: 1. If you have an NTP server ….
  7. When Please insert MrpApps CD in the CDROM drive displays, insert the MrpApps DVD, and click OK. (Installation takes approximately 20 minutes.)
  8. When the Software Installation Done window displays, click OK and remove the DVD.
Topic ID: id_SL11949207-1192090

Loading PET Applications software

Procedure

  1. In Guided Install, select PET Configuration, and click Install PET.
  2. Note

    There is no indication the software is installing (system may appear to be locked), but installation takes about three minutes.

    When Please insert a PET Apps DVD displays, insert the pet_everest.xx DVD, and click OK.
  3. When PET Software installed successfully displays, click OK.
    1. Notice
      If data was restored using the SaveInfo DVD, remove the PET applications DVD and proceed to Running RestoreInfo Utility.
      For Product Type, select SIGNA PET/MR from the drop-down menu.
    2. For Enable PET RAW Archive, select No from the drop-down menu.
  4. Click the Configure button (1).
  5. When a pop-up indicates PET configuration completed and asks for a reboot, click OK, but do not reboot at this time.
  6. Remove the PET DVD.
  7. DANGER
    radiation EXPOSURE
    the phantoms used for calibrating the signa PET/MR system contain a radioactive substance.
    special training and compliance with facility guidelines are required to handle these phantoms.
    Notice
    Only employees formally trained in radioactive materials handling and this equipment are authorized by the General Electric Radiation Safety Officer to use radioactive materials to service the SIGNA PET/MR System.
    In Guided Install, select PET Phantom Configuration (1) and enter the Annulus Phantom details on this screen.
    1. For Activity (MBq), type the activity value (2) from the label on the Annulus Phantom.
    2. For Phantom Serial Number, type the serial no. (3) from the label on the Annulus Phantom.
    3. For Phantom Measured Date, type the calibration date (4) from the label on the Annulus Phantom.
    4. Click the Configure button (5) to save the entries.
    5. When the next message window displays, click OK.
Topic ID: id_SL11949223-1192090

Running RestoreInfo Utility

About this task

SaveInfo takes about three minutes, and restores all files if they were saved off the system.

  • If PET/MR SaveInfo disk does not exist, proceed to Loading Volume Reconstruction Engine (VRE) OS Software. Do not use the MR750w SaveInfo disk on a PET/MR system.

  • Proceed as follows if a PET/MR SaveInfo disk exists:

Procedure

  1. In Guided Install, select Utilities > Save/Restore, and click the Restore Information button.
  2. When Select the media you want to Restore Information? displays, insert the SaveInfo disk and click OK.
  3. When Do you really want to do Restore Info? displays, select Restore all files automatically, and click Continue.
  4. When After upgrading to new software you MUST run update utility displays, click OK.
  5. When the Restore Manager displays, select All, and click Update.
  6. When each message below displays, proceed as directed:
    1. Update is complete., click Quit.
    2. Do you want to quit the tool?, click Yes.
    3. Log file (restore.log) has been created …, click OK.
  7. Press the disk eject button on the computer to remove the SaveInfo disk.
Topic ID: id_SL11949235-1192090

Loading Volume Reconstruction Engine (VRE) OS Software

Procedure

  1. Close the Guided Install screen.
  2. Right-click on the Linux desktop and select Reboot....
  3. After the reboot, log in as root with operator for the Password.
  4. Notice
    Do not install VRE OS if the VRE is powered down or not available.
    When asked, Do you want to start Guided Install?, click Yes.
  5. In Guided Install, select VRE Configuration (1) from the left navigation pane, then click Configure VRE Blades (2).
  6. When Please make sure VRE-GigabitSwitch-Host … displays, click Continue.
  7. When the VRE window displays with the message, Please select the number of VRE Blades connected, select 1 from the drop-down menu, and click OK.
  8. When Please insert the VRE OS disk and click OK displays, insert the VRE OS DVD, and click OK. (Installation takes approximately 35 minutes.)
  9. When the two VRE configuration successfully completed! messages display, click OK on each.
  10. Remove the VRE OS DVD from the drive.
Topic ID: id_SL11949243-1192090

Loading PARC Software

Procedure

  1. In Guided Install, select PET Configuration, and click the Configure PARC button.
    Note

    When PARC configuration is performed as part of a post-installation service, PET raw data stored on the PARC is preserved, and the message below will not display.

  2. When the message PARC configuration will erase data on PARC. Do you want to continue? displays, click Yes.
  3. It takes two to three minutes for the system to request the Q.Core/PARC setup disk. When prompted, insert this disk into the drive and click Continue.
  4. When prompted, Please remove the optical media from the drive, remove the DVD and click Continue.
  5. When PARC configuration successfully completed! displays, click OK.

Loading Operator Manual

Procedure

  1. Insert the Operator Manual disk into the DVD drive.
  2. In Guided Install, select Service SW/Insite from the left navigation pane, and click the Install Online Help button.
  3. Calibrate the LCD Monitor, referring to LCD Monitor Screen Adjustments.
  4. Select the appropriate language and click Install.
  5. When installation is complete, click Cancel and remove the DVD from the drive.
Topic ID: id_15379463

Finalization

Finalization

  1. IMPORTANT: Make sure that the latest Service Pack is loaded. See the latest revision of MR Service Pack Software Matrix, DOC1667089, available from the online documentation library.

  2. If more information is needed for how to load Service Packs, refer to Installing Software Updates.

  3. Reboot the computer and login as sdc, with password adw2.0.

  4. Perform a connectivity check by pinging the Internet Protocol (IP) address of a connected device or the Network Interface Card (NIC) in a C-shell window. (The NIC IP address is 127.0.0.1.)

  5. If this is a first-time software installation and no previous calibration data exists, then run these calibrations:

    • MR calibrations found in the SIGNA PET/MR System Service Methods DVD, Direction 5490579-x under Adjustments/Calibrations.

    • PET calibrations found in the SIGNA PET/MR System Service Methods DVD, Direction 5490579-x under Adjustments/Calibrations > PET-MR.

  6. If this is a software reload of a working system, perform the following:

    • PET Daily Quality Assurance (DQA) check

    • MR and PET Hello-Goodbye Scan
