Load from Cold (LFC) (MP26)

This procedure details a Load from Cold (LFC) software installation on newly installed SIGNA PET/MR systems, and repaired or upgraded SIGNA PET/MR systems.

Prerequisites

Required conditions
Archive images using site procedures; use Scan Data Manager to save PET raw data. See operator manual for instructions.
PET/MR software installation uses the English language. An international keyboard cannot be used until after keyboard and language settings are configured, and the system is rebooted for the first time.

About this task

If more information is needed for how to load Service Packs, see Installing service packs.

This procedure details a Load from Cold (LFC) software installation on:

  • Newly installed SIGNA PET/MR systems
  • Systems upgraded from a Discovery MR750w to a SIGNA PET/MR system
  • Whenever LFC needs to be done on a PET/MR system after repairs or maintenance
  • Upgrading software on a PET/MR system
Important Make sure that the latest service pack is loaded. Refer to the latest revision of the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library.
Topic ID: id_SL12011807-1358931

For existing PET/MR systems

Procedure

  1. Do the PET-MR Hello-Goodbye Scan.
  2. Open a C-shell command window on the host computer and type: # ls –alR /usr/PET/backup/.
    • Make sure all files have owner:group set to sdc:informix.
    • If not sdc:informix, run this command as root: #chown –R sdc:informix /usr/PET/backup/.
  3. Do a SaveInfo to save the host settings using: Guided Install > Utilities > Save/Restore > Save Information & Save GI.
    Note

    The SPiCE (PARC) must be up and SRM green to save PET calibration files. PET calibration files will not be saved if SPiCE (PARC) is down.

  4. Remove all USBs.
Topic ID: id_SL15992831-1358931

Loading Operating System (OS) software

Procedure

  1. Insert the General Electric (GE) MR OS DVD into the drive on the Host PC and reboot the PC.
  2. Select GEHCMR when prompted; installation takes approximately 20 minutes.
    After OS load is completed, the following message will show.
  3. Remove the GEHCMR OS DVD from the drive.
  4. After the Host OS has been loaded, reboot the system and log on as root: operator.
Topic ID: id_SL16010391-1358931

Loading MR applications software

Procedure

  1. Insert the MrpApps DVD and click OK on the Alert message.
  2. Notice
    The language setting described below is only for the Guided Install tool, not the Application software interface or the keyboard language.
    When the Locale Selection screen shows, select the appropriate language for the locale, choose Set as default, and click OK.
  3. When the message Do you want to load GI config from DVD shows, continue to either Step 3.1 or Step 3.2, depending on the applicable situation.
    1. (For an existing PET/MR system) Continue as follows:
      1. Insert the SaveInfo disk created earlier, and click Yes. (SaveInfo configuration will take less than 1 minute.)
      2. When the message Loading configuration from media Done shows at the bottom of the Guided Install screen, press the disk eject button on the computer to remove the SaveInfo disk.
    2. (For a new PET/MR installation or an upgrade from an MR750w system) Continue to System and hardware configuration.
    3. Select Verification (last entry in the left navigation pane) on the Guided Install screen, and then click the Install Software button.
      1. If any values indicate Fail, select Failed Tab and make corrections as shown below.
      2. Update the time, day of week, and month accordingly.
      3. Make sure the Status of all changed values shows Pass before continuing.
  4. Insert the MrApps DVD in the CDROM drive.
  5. Click Install Software. The following message is shown.
  6. Click Confirm. MrApps takes approximately 20 minutes.
Topic ID: id_SL16010398-1358931

Loading PET applications software

Procedure

  1. In Guided Install, select PET Configuration, and click Install PET.
  2. When the Please insert a PET Apps DVD message shows, insert the petmr_k1.xx DVD, and wait until the DVD drive LED is steady off. Drive is being mounted during LED flashing. Click OK when complete.
  3. Note

    There is no indication the software is installing (system may appear to be locked), but installation takes about 3 minutes.

    When the PET Software installed successfully message shows, click OK.
  4. Do the following:
    1. For Product Type, select SIGNA PET/MR from the drop-down menu.
    2. For Enable PET RAW Archive, select No from the drop-down menu.
  5. DANGER
    Radiation exposure
    The phantoms used for calibrating the SIGNA PET/MR system contain a radioactive substance.
    Special training and compliance with facility guidelines are required to handle these phantoms.
    Notice
    Only employees formally trained in radioactive materials handling and this equipment are authorized by the General Electric Radiation Safety Officer to use radioactive materials to service the SIGNA PET/MR system.
    In Guided Install, select PET Phantom Configuration (1) and enter the annulus phantom label details on this screen.
    1. For Activity (MBq) (2), type the activity value (2) from the label on the Annulus phantom.
    2. For Phantom Serial Number (3), type the serial no. (3) from the label on the Annulus phantom.
    3. For Phantom Measured Date (4), type the calibration date (4) from the label on the Annulus phantom.
    4. Click the Configure button (5) to save the entries.
  6. Do a System restart.
Topic ID: id_SL11949235-1358931

Loading Volume Reconstruction Engine (VRE) OS software

Procedure

  1. In Guided Install, select ICN Configuration (2) from the left navigation pane, then click Configure ICN (1).
  2. When the Please insert the VRE OS disk and click OK message shows, insert the VRE OS DVD, and click OK. (Installation takes approximately 35 minutes.)
  3. When the VRE configuration successfully completed! messages show, click OK on each.
  4. Remove the VRE OS DVD from the drive.
Topic ID: id_SL11949243-1358931

Configuring SPiCE (PARC) software

Procedure

  1. In Guided Install, select PET Configuration, and click the Configure PARC button.
    Note

    When Configure PARC is done as part of a post-installation service, PET raw data stored on the SPiCE (PARC) is preserved, and the message below will not show.

  2. When the message PARC configuration will erase data on PARC. Do you want to continue? shows, click Yes.
  3. It takes 2 to 3 minutes for the system to request the Q.Core/SPiCE (PARC) setup disk. When prompted, insert this disk into the drive and click Continue. It takes approximately 15 minutes to load the SPiCE (PARC).
  4. When prompted, Please remove the optical media from the drive, remove the DVD and click Continue.
  5. When the PARC configuration successfully completed! message shows, click OK.

Do RestoreInfo (only if reloading MP26 and later)

About this task

RestoreInfo takes about 20 minutes, and restores all files if they were saved off the system. Continue as follows if a PET/MR SaveInfo disk exists with existing PET calibrations.

Procedure

  1. Note

    MR calibrations have already been restored.

    In Guided Install, select Utilities > Save/Restore and click the Restore Information button.
  2. Upon completion, press the disk eject button on the computer to remove the SaveInfo disk.
  3. After RestoreInfo is completed, click Verification on the Guided Install window and click Configure tab(s) to sync up all config file updates. Otherwise, the TPS reset may fail.

Topic ID: id_15804531

Finalization

Finalization

  1. Important Make sure that the latest service pack is loaded. Refer to the latest revision of the MR Service Pack Software Matrix (DOC1667089), available from the online documentation library.
    If more information is needed for how to load service packs, see Installing service packs.
  2. Reboot the computer and log on as sdc, with password adw2.0.
  3. Do a check of the cyber security compliance. See Doing a check of the cyber security compliance.
  4. After installing MP26 and later SP1 and SP2, do the following workaround to enable T1map and synDWI license strings:
    1. Open a C-Shell as an SDC user.
    2. At the prompt execute the following command: sok_test | grep -i cardt1map.

      If cardt1map is not installed, go to Step 4.5.

    3. If cardt1map is installed, execute the following command: /export/home/sdc/install/install.t1map.
    4. Confirm the entry of T1MAP in lock file by running: cat /export/home/sdc/vxtl/lock.
    5. At the prompt execute the following command: sok_test | grep -i synDWI.

      If synDWI is not installed, go to Step 4.7.

    6. If synDWI is installed, execute the following command: /export/home/sdc/install/install.syndwi.
    7. Confirm the entry of SYNDW in lock file by running: cat /export/home/sdc/vxtl/lock.
  5. If this is a first-time software installation and no previous calibration data exists, then run these calibrations:
    • MR calibrations found in the SIGNA PET/MR 3.0T System Service Manual DVD (5490579-x) under Adjustments/Calibrations.
    • PET calibrations found in the SIGNA PET/MR 3.0T System Service Manual DVD (5490579-x) under Adjustments/Calibrations > PET-MR.

  6. If this is a software reload of a working system, do the following:

    • PET Daily Quality Assurance (DQA) check
    • MR and PET Hello-Goodbye Scan
