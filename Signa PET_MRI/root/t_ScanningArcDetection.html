Scanning arc detection

About this task

Proceed according to the instructions that follow for the arc detection scan.

Procedure

  1. Place the antenna on the table as shown. (The antenna should be placed just behind the IV pole inserts.)
  2. Set up a scan as follows:
    1. Select New Patient and type geservice for the Patient ID.
    2. Type 300 for Weight (Lb), and press Enter.
    3. Select Show All Protocols and Service. Select APBCAL, the center arrow, and click Accept.
    4. Select Start Scan.
    5. Select Research Options from the Scan button drop-down menu, and change the following:
    6. From the Research pull-down menu, select Download.
    7. Before prescan, make sure that the “star” is present on the spectrum analyzer as shown in Figure 3.
  3. On the Scan drop-down list, select Manual Prescan, then Scan TR.
  4. Increase TG to 200.
  5. Allow manual prescan to run for 15 minutes. At the end of the 15 minute prescan at TG of 200, check the spectrum analyzer for any spike events.

    • Observe the amplitude of the spike and the star shown in Figure 3. If the star is present and there are no spikes, the coil is fine.

    • If any spike greater than -35 dbm occurs, or the star is missing (as shown below), the test failed. The spike must be fixed before returning the system to the customer.

  6. Press Done to exit manual prescan.
  7. Move the antenna out of the scan room.
  8. Repeat Verification Using Pizeo Gun. This verifies that the arc detection tool is working properly.
