Troubleshooting the Gradient Calibration Tool

Refer to the guidelines in this topic for troubleshooting the Gradient Calibration Tool.

For troubleshooting problems using the Daily Quality Assurance (DQA) II tool, see Troubleshooting the Daily Quality Assurance (DQA) II tool.

Table 1. Possible Gradient Calibration Tool errors

ERROR: SNR check failed. Image intensity too low. Check transmit and receive chain. Check system log. Review the images.

ERROR: Signal-To-Noise Ratio (SNR) check failed. Test failed. No SNR value obtained. Check that phantom is setup correctly and is centered in the images

or

ERROR: Signal-To-Noise Ratio (SNR) test failed: value N < M.

Make sure that the RF output calibration process completed successfully.

Make sure that all transmit cables are connected. Do a localizer scan, switch to manual prescan mode, and then make sure the center frequency is correct.
