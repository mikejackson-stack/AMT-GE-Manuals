XGD Gradient Master Control (GMC) Board

Topic ID: id_SL2002732-1061853

Removing XGD GMC

Procedure

  1. Apply LOTO to the PGR cabinet. See Applying LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
  2. Remove cables J7, J8, J9, and J10/J11.
  3. Loosen the top and bottom screws securing the XGD GMC.
  4. Using your thumbs, push in and then gently pull the extractor tab located on the top and bottom of the XGD GMC. The lever action of the ejectors disengages the XGD GMC from the XGD Cronus chassis.
  5. Slide the XGD GMC all the way out of the XGD Cronus chassis.
Topic ID: id_SL2002735-1061853

Installing XGD GMC

Procedure

  1. Use the ejectors to insert the new XGD GMC into the XGD Cronus chassis.
  2. Tighten the top and bottom screws to secure the XGD GMC.
  3. Attach cables J7, J8, J9, and J10/J11.

XGD Cronus Fan Assembly

Topic ID: id_SL2005289-1061853

Removing XGD Cronus Fan Assembly

Procedure

  1. Apply LOTO to the PGR cabinet. See Applying LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
  2. Rotate both thumb screws to the UNLOCK position.
  3. Pull out the XGD Cronus fan assembly from the XGD Cronus chassis using the handle provided (top of fan).
Topic ID: id_SL2005292-1061853

Installing XGD Cronus Fan Assembly

Procedure

  1. Insert the new XGD Cronus fan assembly fully into the XGD Cronus chassis.
  2. Rotate both thumb screws to the LOCK position.

XGD Cronus Chassis

Topic ID: id_SL2002760-1061853

Removing XGD Cronus Chassis

Procedure

  1. Apply LOTO to the PGR cabinet. See Applying LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
  2. Remove the following components:

    • XGD GMC. See Removing XGD GMC.

    • XGA controller board. See Removing XGA Controller Board.

    • XPS controller board. See Removing XPS Controller Board.

    • XGD Cronus power supply. See Removing XGD Cronus Power Supply.

    • XGD Cronus fan assembly. See Removing XGD Cronus Fan Assembly.

  3. Loosen the two thumb screws located to the left the chassis.
  4. Slide out the chassis from the PGR cabinet.
  5. Remove cables J1-J6 and P1 from the rear of the chassis.
  6. Remove the six screws securing the XGD Cronus chassis to the rail bracket to remove it.
Topic ID: id_SL2002763-1061853

Installing XGD Cronus Chassis

Procedure

  1. Tighten the six screws to secure the XGD Cronus chassis to the rail bracket.
  2. Attach cables J1-J6 and P1 to the rear of the chassis.
  3. Slide the chassis into the PGR cabinet.
  4. Press the slide rail, release tabs to fully insert the chassis into the PGR cabinet.
    Note

    Pull out the ICN directly below the chassis, if necessary, to access the release tabs.

  5. Tighten the two thumb screws located to the left the chassis. See XGD Cronus Chassis Thumb Screws.
  6. Reinstall the following components:

    • XGD GMC. See Installing XGD GMC.

    • XGA controller board. See Installing XGA Controller Board.

    • XPS controller board. See Installing XPS Controller Board.

    • XGD Cronus power supply. See Installing XGD Cronus Power Supply.

    • XGD Cronus fan assembly. See Installing XGD Cronus Fan Assembly.
