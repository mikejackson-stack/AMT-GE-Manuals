Installing the blower box filter

Procedure

  1. Install the EMC filter to the blower box housing.
  2. Install the charcoal air inlet filter(s).
  3. Install and hand-tighten each nut.
  4. Tighten each nut securely using a non-ferrous 7 mm wrench.
