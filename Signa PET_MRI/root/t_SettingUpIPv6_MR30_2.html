Configuring IPv6 with Cisco Firepower 1010

The IPv6 transformer provides communication capability between the MR console, and IPv6 devices. The FE must work with a site IT administrator to do this procedure.

Prerequisites

Required conditions
The FE must work with the local IT team to collect two static IP addresses: one for the MR System and one for the Cisco router.
Note If sites have a dual stack network, they will have both IPv6 and IPv4 addresses. In this situation, you will need to get four addresses - two for each.
The FE must work with the local IT team to collect the NTP server IP address for the hospital network, if available.
Make sure that the latest Java version is installed on the FE laptop for router configuration. See https://www.java.com/en/.
Cisco Firepower 1010 must be available.
2 LAN cables must be available. You may need a LAN adaptor to connect the LAN to the FE laptop.

Procedure

  1. Power on the Cisco router by plugging in the power adaptor to the router. Wait approximately 30 minutes and make sure all three activity indicator lights turn solid green.
  2. The back of the router has assigned port numbers. When configuring the router, connect the laptop to LAN port 2 (LAN ports 3 through 8 and two service ports are disabled by default).
