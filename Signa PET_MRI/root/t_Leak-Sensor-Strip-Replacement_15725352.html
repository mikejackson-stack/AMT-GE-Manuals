Leak Sensor Strip Replacement

About this task

Overview

This document covers replacing leak sensor strips on the following components:

  • Right PDU leak sensor tray (Right PDU Leak Sensor Tray)

  • Left PDU leak sensor tray (Left PDU Leak Sensor Tray)

  • XGD leak sensor tray (PDU and XGD Leak Sensor Tray)

  • RF leak sensor tray (RF Leak Sensor Tray)

Topic ID: id_SL2063282-1063536

Right PDU Leak Sensor Tray

Topic ID: id_SL2063283-1063536

Removing Leak Sensor Strip

Procedure

  1. Apply LOTO to the PDU. See Applying LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
  2. Remove cables J12 and J13 from the PDU. This allows access to the right PDU leak sensor tray.
  3. Unplug the two leak sensor strip connectors on both sides of the tray, using the white quick disconnect.
  4. Loosen the two thumb screws on the top of the tray.
  5. Pull the tray out from the cabinet.
  6. Remove all 12 retainers holding the leak sensor strip to the tray.
    Note

    The sensor is folded at the corners. This configuration will be repeated during installation of the new sensor strip.

  7. Remove the sensor strip.
Topic ID: id_SL2063286-1063536

Installing Leak Sensor Strip

Procedure

  1. Start routing the new leak sensor strip approximately 1 inch from the right edge of the tray. Seat the strip so that the first and second open wire holes fall on either side of the retainer.
    Note

    When routing this leak sensor strip, it does not matter which end is used. The ends are interchangeable.

    Before tightening, be sure all retainers lay properly on top of the sensor strip with the retainer channels and sensor interlocking.

  2. Tighten the nuts for each retainer.
  3. Continue routing the sensor strip and retainers, making sure that bends do not cause the open wire holes to cross each other.
  4. Slide the tray into the right side of the cabinet.
  5. Tighten the two thumb screws to secure the tray to the cabinet.
  6. Reconnect the leak sensor strip connectors on both sides of the tray.
  7. Reconnect cables J12 and J13 to the PDU.
Topic ID: id_SL2063289-1063536

Left PDU Leak Sensor Tray

About this task

This procedure takes 45 minutes from beginning to finalization.

Topic ID: id_SL2063290-1063536

Removing Leak Sensor Strip

Procedure

  1. Follow Step 1 through Step 5 to remove the right PDU leak sensor tray. This allows access to the left PDU leak sensor tray.
  2. Unplug the remaining leak sensor strip connector on the left PDU leak sensor tray.
  3. Remove the two thumb screws on the top of the tray.
  4. Slide the left PDU leak sensor tray to the right in the cabinet and pull it out.
  5. Remove all 12 retainers holding the leak sensor strip to the tray.
    Note

    The sensor is folded at the corners. This configuration will be repeated during installation of the new sensor strip.

  6. Remove the sensor strip.
Topic ID: id_SL2063293-1063536

Installing Leak Sensor Strip

Procedure

  1. Start routing the new leak sensor strip approximately 1 inch from the right edge of the tray. Seat the strip so that the first and second open wire holes fall on either side of the retainer. See Properly Seated Leak Sensor Strip.
    Note

    When routing this leak sensor strip, it does not matter which end is used. The ends are interchangeable.

    Before tightening, be sure all retainers lay properly on top of the sensor strip with the retainer channels and sensor interlocking Properly Seated Retainer.

  2. Tighten the nuts for each retainer.
  3. Continue routing the leak sensor strip and retainers, making sure that bends do not cause the open wire holes to cross each other. See Bending Leak Sensor Strip.
  4. Push the left leak sensor tray into the right side of the cabinet and slide it to the left side. See Slide Over Left PDU Leak Sensor Tray.
  5. Tighten the two thumb screws to secure the tray to the cabinet.
  6. Slide the right leak sensor tray into the right side of the cabinet.
  7. Tighten the two thumb screws to secure the tray to the cabinet.
  8. Reconnect the leak sensor strip connectors for both trays (4 connections total).
  9. Reconnect cables J12 and J13 to the PDU.
Topic ID: id_SL2063296-1063536

PDU and XGD Leak Sensor Tray

About this task

This procedure takes about 25 minutes from beginning to finalization.

Topic ID: id_SL2063297-1063536

Removing Leak Sensor Strip

Procedure

  1. Apply LOTO to the PDU. See Applying LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
  2. Unplug the leak sensor strip connectors on the left side of the tray.
  3. Remove the two screws holding the XGD leak sensor tray to the base of the cabinet.
  4. Remove the tray from the cabinet.
  5. Remove the four retainers holding the leak sensor strip to the tray.
Topic ID: id_SL2063300-1063536

Installing Leak Sensor Strip

Procedure

  1. Start routing the new leak sensor strip approximately 3 inches from the right edge of the tray, with the grey connector to the right side. Seat the strip so that the first and second open wire holes fall on either side of the retainer.

    Be sure the retainer lays properly on top of the sensor strip before tightening. See Properly Seated Retainer.

  2. Tighten the nuts for each retainer.
  3. Position the XGD leak sensor tray at the base of the cabinet.
  4. Tighten the two screws to secure the tray to the cabinet.
Topic ID: id_SL2063303-1063536

RF Leak Sensor Tray

Topic ID: id_SL2063304-1063536

Removing Leak Sensor Strip

Procedure

  1. Apply LOTO to the PDU. See Applying LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
  2. Remove the RF door and set aside.
  3. Remove the two screws holding the RF leak sensor tray to the base of the cabinet.
  4. Remove the lower door frame shown in Remove RF Leak Sensor Tray.
  5. Unplug both leak sensor strip connectors on the far left side of the tray. See Unplug Leak Sensor Strip Connectors
  6. Remove the two 17 mm bolts shown in Remove RF Leak Sensor Tray.
  7. Remove the tray from the cabinet.
  8. Remove all 14 retainers holding the leak sensor strip to the cabinet.
    Note

    The sensor is folded at the corners. This configuration will be repeated during installation of the new sensor strip.

  9. Remove the sensor strip.
Topic ID: id_SL2063307-1063536

Installing Leak Sensor Strip

Procedure

  1. Start routing the new leak sensor strip clockwise approximately 1 inch from the left edge of the tray. Seat the strip so that the second and third open wire holes fall on either side of the retainer.
    Note

    When routing this leak sensor strip, it does not matter which end is used. The ends are interchangeable.

    Be sure the retainer lays properly on top of the sensor strip before tightening. See Properly Seated Retainer.

  2. Tighten the nuts for each retainer.
  3. Continue routing the leak sensor strip and retainers, making sure that bends do not cause the open wire holes to cross each other. See Bending Leak Sensor Strip.
  4. Position the RF leak sensor tray at the base of the cabinet.
  5. Tighten the two screws to secure the tray to the cabinet.
  6. Reinstall the 17 mm bolts Remove RF Leak Sensor Tray.
  7. Reinstall the lower door frame Remove RF Leak Sensor Tray.
  8. Reconnect the leak sensor strip connectors.
Topic ID: id_15225342

Finalization

Finalization

Remove LOTO from the PDU. See Removing LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
