Dual drive quadrature tool overview

A dual drive system has two transmit channels. The dual drive (DD) quadrature tool is used to compensate for the amplitude and phase differences in the transmit channels. Amplitude and phase differences between the two channels can begin at the exciter and be carried through to the PET/MR insert transmit (the end of the imaging chain). Those differences can also be introduced at any of the intermediate passive components.

The dual drive quadrature tool does axial scans in three modes.

  • Combined mode
  • CH1 transmit, CH2 disabled
  • CH2 transmit, CH1 disabled

The dual drive quadrature tool calculates amplitude difference between the CH1 and CH2 channels. It also calculates phase difference between the CH1 and CH2 channels. It then updates the system calibration file with the cumulative compensation required.

Test mode without calibration is provided.

Notice: If a new CMA Coil or Proxy that does not have a quadrature calibration file is connected to a system, scanning will not be allowed. Make sure that the dual drive quadrature calibration is completed on all available CMA Coils and Proxies.

The procedure can be run in non-proprietary mode and proprietary mode. Non-proprietary mode is accessed from the MR Service Desktop. Proprietary mode is accessed through the calibration wizard.

Before starting the dual drive quadrature tool procedure

Notice: Before starting a dual drive quadrature calibration scan, make sure that there is no exam in progress. If there is an exam in progress, select End Exam.

DD Quadrature calibration must be done on both the CMA Coil and CMA Proxy (if available).

  1. Complete a successful calibration on the first CMA Coil or Proxy.
  2. Click Quit to exit the DD Quadrature Tool GUI.
    Note If attempting to calibrate multiple coils or proxies without exiting the tool, an error message will show.
  3. Connect the next CMA Coil or Proxy to be calibrated.
  4. Restart the DD Quadrature Tool and repeat the above steps.
    • If doing only the Center Location scan, continue to Setting up for center location scan.
    • If doing a Head Only or Head and Center Location scan, continue to Setting up for head only or both head and center scan.

Setting up for head only or both head and center scan

Procedure

  1. At the scanner, remove any surface or head coil from the bore. Confirm that the cradle is at the home position.
  2. If setting up for the head only scan, position the head sphere phantom as shown in the following illustration.
    • Place the pad toward the head of the table.
    • Position the head sphere phantom or SWS phantom (spout position does not matter) on the pad.
    Note Head TLT shown. To align, use the crosshair on top of the SWS phantom or the phantom positioner.
  3. From the home position, move the cradle in so that the in-room monitor shows 315 mm. Turn on the alignment lights by pressing the Alignment button on the magnet enclosure.
  4. Adjust the head sphere phantom or the SWS phantom (spout position does not matter) location where the laser light cross hairs line up on the center of the phantom or SWS phantom positioner. Press the Landmark button.
    • If scanning only the head location, press Advance to scan. Proceed to Accessing dual drive quadrature tool.
    • If scanning both head and center locations, move the cradle in an additional 765 mm.
      Align the body loader and sphere on the center of the laser light cross hairs. Press Advance to scan, and proceed to Accessing dual drive quadrature tool.
    Notice
    There should always be a distance of 765 mm between the head location and the center location of the dual drive quadrature tool.

Setting up for center location scan

Procedure

  1. At the scanner, remove any surface or head coil from the bore. Confirm that the cradle is at the home position.
  2. Position a body loader with the sphere phantom on the table.

    For flat table:

    • Place MR/PET coil foam support so that the body loader will be located at the center of the cradle.
    • Place the body loader with sphere phantom on the foam support.
  3. Turn on the alignment lights by pressing the Alignment button on the magnet enclosure.
    Item Description
    1Alignment lights button
    2Landmark button
    3Advance to scan button
  4. Move the cradle in until the display reads 315 mm. Press Landmark, but do not press Advance to scan at this point.
  5. Move the cradle in an additional 765 mm. Center the body loader and sphere over the laser light cross hairs. Then press Advance to scan.

Accessing dual drive quadrature tool

Procedure

  • (For non-proprietary mode) Select Calibration > Calibration Tools > Dual Drive Quadrature, then Click here to start the tool.
  • (For proprietary mode) Run the Calibration Wizard, and select Dual Drive Quadrature.
Topic ID: id_2012349

Running dual drive quadrature tool

Procedure

  1. Select the calibration locations to include in the scan. Click Head or Center or both.
  2. Click Start for the first iteration.

    Scan and analysis begin. It takes about 6 minutes.

  3. The tool runs up to three iterations, attempting to come to specification.

    If you have selected both head and center scans, the tool automatically moves to the next location. It reruns iterations for the first location.

    When the first iteration is complete, calibration results are passed or failed.

  4. (For passed) Click Quit to complete the calibration. Proceed to Finalization.
  5. (For failed) If the head location fails, the calibration scan stops. If you selected head and center locations to be done together, you must manually start the center location calibration scan.
    Table 1. Specifications for dual drive quadrature calibration
    Phase or Magnitude Value
    Head location phase30 degrees
    Head location magnitude20 counts (2.0 dB)
    Center location phase

    25 degrees

    Center location magnitude

    10 counts (1.0 dB)
  6. If the calibration passes within iteration 3, click Quit to exit the tool. If the calibration fails, see Quadrature calibration troubleshooting for troubleshooting information.

    Calibration must be done on all flat (GEM) tables. If you are calibrating multiple tables, exit the dual drive quadrature tool by selecting Quit, and connect the next table to be calibrated. Repeat the applicable steps above.

    If the site has one or more curved tables, you must do dual drive quadrature calibration on one curved table.

Topic ID: id_2012351

Finalization

Procedure

  1. Complete SaveInfo.
  2. Remove the phantoms, pads, body loader, service filler panels (curved table), and curved adapter (flat table) from the cradle, and return them to the assigned storage locations.
