Installing the Exciter

Install a replacement exciter.

Prerequisites

Personnel requirements
Required personsPreliminary requirementsProcedureFinalization
1-10 minutes-
Notice
Potential degraded system performance
Intermittent system issues.
Never have a clock splitter in a system with an exciter that has an electronic clock output for ICE. If you accidentally combine these items in a system, the clock power to ICE will be too low and may have intermittent issues.

Procedure

  1. Install the new Exciter in the cabinet.
  2. Connect all the cables to the front and back of the Exciter as they were prior to removing.
  3. Tighten the thumbscrews to secure the Exciter to the PEN cabinet.
    Note After LOTO is removed and power is reapplied to PEN cabinet, allow 30 minutes for the Exciter to reach operating temperature and stabilize before calibrating or scanning.
  4. Close the ISC.

Finalization

  1. Start up the host computer/system. See Starting up the host computer.
  2. Calibrate RF amp and UPM. See Calibrating RF Amplifier and UPM.
  3. (For systems with dual drive) Do the System Gain Calibration:
    1. (For systems with software version MP26 or earlier) System Gain Calibration (for systems MP26 or earlier).
    2. (For systems with software version 30 or later) Doing system gain calibration (software version 30 or later).
  4. Do the Universal Power Monitor (UPM) functional check. See Doing the Universal Power Monitor (UPM) functional check (Head and Body).
  5. (For systems with dual drive) Do Calibrating for quadrature. See Dual drive quadrature tool.
  6. Do the System Performance Test (SPT). See Doing the System Performance Test (SPT).
  7. (For systems with software version MP26) Do the Radial Acquisition Delay Calibration. See RAD Cal Tool.
  8. Do a check scan. See MR and PET Hello-Goodbye Scan.
