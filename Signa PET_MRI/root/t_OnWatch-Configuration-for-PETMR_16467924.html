Procedure

  1. Launch Guided Install in FE mode.
  2. Select Service SW/Insite, then Configure Insite/IIP.
  3. Click Accept when prompted.
  4. Select ProDiags, then Custom.
  5. Click Start Insite_Broswer when prompted.
