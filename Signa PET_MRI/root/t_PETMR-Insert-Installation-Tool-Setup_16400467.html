About this task

Overview

This procedure describes how to set up the PET/MR insert installation tool, which is used to position the PET/MR insert within the magnet, and remove the insert for service.

Topic ID: id_SL5566719-1189417

Servicing the PET/MR insert

About this task

This section is only performed when servicing the PET/MR insert. If setting up the installation tool to position the PET/MR insert within the magnet bore, proceed to Installing the interface plates.

Procedure

  1. Notice
    The transportation cart for the insert installation tool is only intended to be used by authorized personnel as described in this procedure and PET/MR Insert Installation Tool Removal. The cart should be used only to transport the PET/MR insert inside the magnet room. For more information on the cart, see the latest version of SIGNA PET/MR Transport Cart User Guide, PN 5567849, in the online documentation library.
    LOTO the PDUs in the PGR and PET cabinets. See Applying LOTO - PGR Power Distribution Unit (PDU)/Gradient Subsystem.
  2. Turn off the PET chiller.
Topic ID: id_SL5545088-1189417

Installing the interface plates

About this task

Even though the interface plates are reversible, install them as shown below. The bolts are easier to access when located on the outside of the PET/MR insert.

Procedure

  1. Remove the parts for the PET/MR insert installation tool from the shipping crate.
  2. Notice
    If the PET/MR insert is inside the magnet bore, attach the interface plates to the insert before attaching the magnet interface plate. Be aware that the interface plates can induce strong eddy currents.
    Attach an interface plate (P/N 5449133) to each end of the PET/MR insert with four M10 bolts until just finger tight.
  3. Tighten the four bolts on each interface plate using a 17 mm wrench.
  4. Attach the magnet interface plate (P/N 5459189) at the service end of the magnet bore, and use an 8 mm Allen wrench to tighten the four bolts.

    There are two holes on each of the four magnet interface plate appendages. The threaded holes are used to store the bolts when the plate is not attached to the magnet bore.

    Note

    Route the chiller hoses around the magnet interface plate.

Topic ID: id_SL11838170-1189417

Assembling the guide tube

About this task

The guide tube consists of three sections that need to be assembled prior to use.

Procedure

  1. Notice
    The number in parentheses within an instruction corresponds to the numbered item in the illustration below the step.
    Slide the two end sections of the guide tube (1, 2) onto the middle section, lining up the half-circle notch on the end sections with the round pin on the middle section.
  2. Use a 4 mm Allen wrench to secure the sections with a minimum of six 4 mm flat-head bolts.
    Note

    A total of 24 holes are provided to connect the three guide tube sections with the flat-head bolts, but it is not necessary to use all of them. Additional holes can be used if a thread becomes unusable due to cross-threading after repeated use.

  3. Place the guide tube inside the PET/MR insert.

    • If the insert is outside the magnet bore, install the patient-end section into the insert.

    • If the insert is inside the magnet bore, install the service-end section into the insert.

  4. Align and insert the pivot pin into the magnet interface plate.
  5. Use an Allen wrench to attach the tripod to the patient end of the guide tube with the four 8 mm bolts.
  6. Check that the following components on the installation tool are in place and tightened:

    • Pivot pin (1) at service end, when installation tool is in magnet bore

    • Four bolts (2) on the magnet interface plate

    • Minimum of 12 bolts (3) connecting each guide tube end section to the middle section

    • Four bolts (4) on each interface plate

    • Four bolts (5) that hold the guide tube to the tripod

Topic ID: id_SL5570829-1189417

Operating the installation tool

Procedure

  1. Use the jack screw handle (1) to rotate the screw jack (2) on the magnet interface at the service end, clockwise to raise the tool and counterclockwise to lower it.
  2. Use the jack screw handle (1) to rotate the screw jack (2) on the tripod at the patient end of the magnet, clockwise to raise the tool and counterclockwise to lower it. Use the M10 socket-head cap screw (3) for left/right adjustment.
  3. Tighten each holding bolt (1) to secure the Insert on the guide tube once the Insert is positioned in the desired location.
    Note

    Do not tighten the holding bolts until the Insert is completely removed from the bore. The holding bolts enable rotation of the Insert on the guide tube, but do not allow horizontal movement along the guide tube.

  4. Notice
    Make sure the holding bolts on the interface plates are tightened before attempting to rotate the insert.
    To reposition the PET/MR insert, turn the handle (1) to rotate the guide tube.
Topic ID: id_15243911

Finalization

Procedure

  1. Disconnect the water lines from the PET chiller at the quick disconnects on the service end of the magnet. Use the 5-gallon bucket to catch any fluid from the hoses. Position the disconnected ends of the water lines inside the insert.
  2. Disconnect the two I and Q RF transmit cables at the service end of the insert.
  3. Disconnect the air hoses and the temperature sensor at the patient end of the magnet.
  4. Remove the five fiber-optic patch cables (1) at the service end of the magnet (only two are shown).
  5. Remove the leak sensor (2) from the service end of the insert:
    1. Remove the screw.
    2. Pull the leak sensor out slightly, then slide and rotate it to the left to clear the fiber-optic breakout boxes.
    3. Pull the leak sensor out completely.
  6. Loosen the six screws (1) that secure the DMOD covers (2) and slide them off.
  7. Remove the DMOD cables from the slots in the DMOD cable trays.
  8. Remove the PET/MR insert.
