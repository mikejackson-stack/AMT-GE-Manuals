Modifying system information

About this task

You may need to change system information within eLicense due to a hardware failure, replacement of the network card, system upgrade, or human error. System information can be modified on eLicense's System Information.

Procedure

  1. Access the System Information page or click the Details button on the Order Information screen.

    Result

    The eLicense: System Edit pop-up dialogue will open.
  2. Modify the system information as needed.
    Note All changes to system information and host ID are tracked based on your single sign-on ID. Any suspicious usage of this feature will be rigorously checked to make sure that the modification was due to a valid problem.
    Model typeSystem description
    EXCITE11 or MRAll 1.5T and 3.0T 11.x systems without G3 software
    3TG3Only for early 11.x systems with G3 software. All other 11.x systems choose EXCITE11
    EXCITE12 or MRAll 1.5T and 3.0T 12.x (HD) systems
    SIGNA-HDeAll 1.5T HDe systems
    SIGNA-HDx or MRAll 1.5T and 3.0T HDx systems
    Signa_HDxT or MRAll 1.5T and 3.0T HDxt systems
    Signa_HDi or MRAll 1.5T HDi systems
    Discovery_MR750 or MRMR750
    MRMR450, MR450w, MR750w, Architect, Artist, SIGNA 7T, SIGNA Premier, Pioneer, SIGNA Prime, Voyager, 1.5T Signa HDxt(HD28, HD29), Creator, Explorer, MR355, MR360
    Note For Upgrades: Change the model type and, if necessary, update the host ID.
  3. If the host ID has been changed, before and after clicking Continue make sure that the application name key number on the System Information page actually changed.

    Result

    Depending on how many keys are regenerated, it may take up to a minute before the page refreshes and you see new numbers.
  4. If the numbers do not update, the Host ID was not entered correctly. Re-enter the information.
