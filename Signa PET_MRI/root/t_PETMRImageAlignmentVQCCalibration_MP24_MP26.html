MR–PET image alignment volumetric quality control (VQC) calibration (MP24/MP26)

When the PET/MR insert is removed or there is any mechanical alignment, do an MR-PET image alignment VQC calibration. This calibration checks for the correct relationship between magnetic resonance (MR) imaging and positron emission tomography (PET) imaging.

Required conditions

Complete the steps in the PET calibration workflow before starting the MR-PET image alignment VQC calibration. See Calibration Sequence for PET/MR.

If the phantom is 2.5 to 4.0 years old, have the customer order a new phantom.
Safety

Before working in any GE HealthCare MR suite or doing any GE HealthCare service procedure, you must:

  • Have read and understood all hazard conditions and safety requirements in the latest revision of the GE HealthCare MR Service Safety Manual (5452735).
  • Have successfully completed all relevant GE HealthCare Environmental Health and Safety (EHS) courses (or for non-GE HealthCare employees, equivalent workplace training courses).
  • Comply with all site-specific training and workplace safety requirements.

If you have any safety concerns at any time, do not begin work or immediately stop work and move to a safe location. Immediately contact your supervisor or site safety officer for instructions on how to proceed.

DANGER
Radiation exposure
Exposure to radiation will occur when handling the VQC phantom.
Follow facility guidelines to handle the phantom.
Note

The five small spheres embedded in the phantom are a source of low-dose radiation (0.7 MBq Ge-68 per sphere for a total of 3.5 MBq).

About this task

Do the MR-PET image alignment (VQC) calibration each time the PET/MR insert is removed or any mechanical alignment is done.

This procedure checks for the correct relationship between magnetic resonance (MR) and positron emission tomography (PET) imaging. It also generates offsets used by the applications software to optimize the fused images. The mechanical alignment verification procedure and software assumes the magnet, bridge, and table are correctly installed.

Calibration Preparation

Procedure

  1. Place the phantom on the table.
  2. Landmark the phantom.
Topic ID: id_SL5527809-1189120

Image acquisition

Procedure

  1. Start a new exam and select the alignment protocol for the exam:
    1. Select New Patient.
    2. Type geservice for the Patient ID.
    3. Type an identifiable Patient Name, such as VQC Cal.
    4. Enter 111 for Weight and 5’0” for Height.
    5. Click Show All Protocols.
    6. Click the Service radio button on the Protocol Selector window.
    7. Select the MR-PET Alignment VQC Calibration protocol from the Other list.
    8. Click Accept.
    9. Click Start Exam.
  2. Go to the Acquisition screen and make sure the default VQC MR Loc is selected.
  3. Click the Scan menu, then select Research and Display CVs.
  4. In the Display CVs window, type cfzfull in the CV Name field, type 0 for Current Value , then click Accept.
  5. Click the Scanmenu, then select Research and Download.
  6. Click Scan to start the VQC localization scan.
  7. Select VQC PET Task from the Task list.
  8. Click Setup, then Save Rx.
  9. Click the Scan menu and select Start PET Scan.
  10. After the PET acquisition begins, select VQC MR Acq from the Task list on the left.
  11. Click Setup, then Save Rx.
  12. Look at the PET Scan Status window and wait for the PET scan to start.
  13. Once the PET scan starts, click the Scan menu and select Manual Prescan.
  14. On the Manual Prescan screen, set Analog Gain (R1) to 11, Digital Gain (R2) to 14, and click Done.
  15. Click Scan to start the MR scan. The PET and MR scans start at the same time.
  16. Click END EXAM after acquisition completes.
Topic ID: id_SL5527864-1189120

Alignment program selection

Procedure

  1. Select Image Management from the screen header.
  2. Select both the PET (Series 2) and the MR series (Series 3).
    Note

    It will take a few minutes for the images to reconstruct.

    Note Series 2 and Series 3 are to be used as a reference. These series are based on VQC MR acquisition tasks.
  3. Click Service Tools, then Service Browser to open the Common Service Desktop (CSD).
  4. Open the Service Desktop, select the PET radio button, then Calibration.
  5. Select MR-PET Alignment from the calibration list.
  6. Click Load.
  7. If red displays in the Software Correction table (1), select Update Recon Center (2).
    Note

    If the PM Tool is failing for Image Alignment Analysis but volumetric quality control (VQC) was run, click Update Recon Center and re-run the PM Tool.

    Do this even if the Software Correction tab is NOT displaying red.

Topic ID: id_SL12016049-1189120

VQC verification

Procedure

  1. Select New Patient.
  2. Type geservice for the Patient ID.
  3. Type an identifiable Patient Name, such as VQC Verification.
  4. Click on Show All Protocols.
  5. Click the Service radio button on the Protocol Selector window.
  6. Select the MR-PET Alignment VQC Verification protocol from the Other list.
  7. Repeat Step 2 through Step 16 in Image acquisition.
  8. Click Service Tools, then C Shell... to open the Command window.
  9. Follow these steps to start the Centroid Analysis:
    1. At the prompt, change the directory by typing: cd /usr/g/service/matlab/programs64/ and press Enter.
    2. At the next prompt, type run_centroidanalysis and press Enter.
    3. When prompted for the First Image Series, select the PET images for Series 2 and press Enter.
    4. When prompted for the Second Image Series, select the MR images for Series 3 and press Enter.
    5. Make sure all alignment values in the Diff column are less than 2 mm of zero on the Centroid Analysis screen.
