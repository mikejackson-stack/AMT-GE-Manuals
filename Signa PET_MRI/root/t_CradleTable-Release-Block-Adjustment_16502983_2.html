About this task

This procedure explains how to adjust the cradle release block position and how to adjust the cradle release block retraction. The cradle release block retraction procedure shows how to adjust the cable to meet the system specification.

Topic ID: id_SL1901257-1057602

Adjusting the cradle release block position

Procedure

  1. Undock the patient table and remove it from the magnet room.
  2. Raise the table to its maximum height.
  3. Warning
    Risk of personal injury
    Severe injury can occur if the table is accidentally lowered during maintenance.
    When doing maintenance with the table in the Up position, make sure the lock bar is safely engaged.
    Lower the table lock safety bar.
  4. Lower the table and make sure that all of the table top's weight is resting on the safety bar.
  5. Remove the patient table bottom front cover.
  6. Loosen the four hex socket head screws securing the release block assembly.
  7. Adjust the housing's position to minimize the distance between the latch and the latch housing. Cycle (press) the latch several times, to make sure the latch never sticks in the down position.
Topic ID: id_SL1901261-1057602

Adjusting the cradle release block retraction

Procedure

  1. Dock the patient table.
  2. Release the cradle from the carriage and drive the LPCA into the bore.
  3. Place a straight edge (for example, a level) across the front edge of the patient table.
  4. Place a measuring device (for example, the bridge height gauge) onto the cradle release latch so that the current height can be measured.
  5. Press the cradle release block. Measure the change in height. The maximum height change is 1.0 mm.
    • If the height change is ≤ 1 mm, continue to Finalization.
    • If the height change is ≥ 1 mm, do the next steps for cradle release block adjustment.
  6. Remove the upper and lower base covers. See Fastening the patient table upper bellows and removing the lower base side covers.
  7. Loosen the lock nut, and then tighten or loosen the cable adjustment screw in the pivot block so that the cradle release block is flush or just below the level of the table top.
    Note If the adjustment screw does not provide enough range for adjustment, loosen the coarse adjustment set screw to change the cable length. Fine adjustment is required after doing a coarse adjustment.
  8. Retighten the lock nut.
  9. Recheck the height change. Repeat the adjustment until height change is ≤ 1.0 mm.
  10. Raise the table lock safety bar.
  11. Replace the upper and lower base covers as well as the patient table bottom front cover.
Topic ID: id_15361438

Finalization

Finalization

  1. Dock the table to the magnet and make sure that the table/cradle functions correctly.
  2. Make sure that the table undocks, and that the LPCA is released when the undock pedal is depressed.
